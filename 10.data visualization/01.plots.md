### 💻 اولین نمودار شما: نمودار خطی (Line Plot)

بیا ساده‌ترین نمودار ممکن رو با Matplotlib بکشیم:

```python
import matplotlib.pyplot as plt
import numpy as np

# داده‌های نمونه: فروش ماهانه
months = ['فروردین', 'اردیبهشت', 'خرداد', 'تیر', 'مرداد', 'شهریور']
sales = [120, 150, 180, 220, 200, 160]

# ساخت نمودار خطی
plt.plot(months, sales, marker='o', linestyle='-', color='blue', linewidth=2)

# تنظیمات نمودار
plt.title('فروش ماهانه فروشگاه', fontsize=14)
plt.xlabel('ماه', fontsize=12)
plt.ylabel('فروش (میلیون تومان)', fontsize=12)
plt.grid(True, alpha=0.3)

# نمایش نمودار
plt.show()
```

**خروجی:** یک نمودار خطی زیبا با نقاط مشخص روی هر ماه.

### 🎨 انواع نمودارهای پرکاربرد

#### ۱. نمودار میله‌ای (Bar Chart)

برای مقایسه‌ی داده‌های دسته‌بندی شده عالیه:

```python
import matplotlib.pyplot as plt

# داده‌ها
products = ['لپ‌تاپ', 'موبایل', 'هدفون', 'تبلت', 'ساعت']
sales = [45, 80, 120, 30, 55]

# نمودار میله‌ای
plt.bar(products, sales, color=['#FF6B6B', '#4ECDC4', '#45B7D1', '#FFA07A', '#98D8C8'])

plt.title('تعداد فروش محصولات', fontsize=14)
plt.xlabel('محصول', fontsize=12)
plt.ylabel('تعداد فروش', fontsize=12)
plt.grid(axis='y', alpha=0.3)

plt.show()
```

#### ۲. نمودار دایره‌ای (Pie Chart)

برای نشان دادن نسبت‌ها و درصدها عالیه:

```python
import matplotlib.pyplot as plt

# داده‌ها
categories = ['الکترونیک', 'پوشاک', 'کتاب', 'لوازم خانگی', 'سایر']
percentages = [35, 25, 20, 12, 8]
colors = ['#FF6B6B', '#4ECDC4', '#45B7D1', '#FFA07A', '#98D8C8']

# نمودار دایره‌ای
plt.pie(percentages, labels=categories, colors=colors, autopct='%1.1f%%', startangle=90, explode=(0.05, 0, 0, 0, 0))

plt.title('سهم فروش بر اساس دسته‌بندی', fontsize=14)
plt.axis('equal')  # دایره کامل

plt.show()
```

#### ۳. هیستوگرام (Histogram)

برای نمایش توزیع داده‌ها عالیه:

```python
import matplotlib.pyplot as plt
import numpy as np

# داده‌های نمرات
np.random.seed(42)
scores = np.random.normal(75, 15, 200)  # ۲۰۰ نمره با میانگین ۷۵ و انحراف ۱۵
scores = np.clip(scores, 0, 100)  # محدود کردن بین ۰ تا ۱۰۰

# هیستوگرام
plt.hist(scores, bins=10, color='#4ECDC4', edgecolor='black', alpha=0.7)

plt.title('توزیع نمرات دانشجویان', fontsize=14)
plt.xlabel('نمره', fontsize=12)
plt.ylabel('تعداد دانشجو', fontsize=12)
plt.grid(axis='y', alpha=0.3)

plt.show()
```

#### ۴. نمودار پراکندگی (Scatter Plot)

برای نشان دادن رابطه بین دو متغیر عالیه:

```python
import matplotlib.pyplot as plt
import numpy as np

# داده‌های تصادفی
np.random.seed(42)
study_hours = np.random.uniform(0, 10, 50)
exam_scores = 60 + study_hours * 3 + np.random.normal(0, 5, 50)

# نمودار پراکندگی
plt.scatter(study_hours, exam_scores, color='#FF6B6B', alpha=0.6, s=100)

plt.title('رابطه ساعت مطالعه و نمره امتحان', fontsize=14)
plt.xlabel('ساعت مطالعه', fontsize=12)
plt.ylabel('نمره امتحان', fontsize=12)
plt.grid(True, alpha=0.3)

# اضافه کردن خط رگرسیون (اختیاری)
z = np.polyfit(study_hours, exam_scores, 1)
p = np.poly1d(z)
plt.plot(np.sort(study_hours), p(np.sort(study_hours)), '--', color='gray', linewidth=2)

plt.show()
```

### 🎯 چندین نمودار در یک شکل (Subplots)

برای مقایسه‌ی چند نمودار کنار هم:

```python
import matplotlib.pyplot as plt
import numpy as np

# داده‌ها
x = np.linspace(0, 10, 100)
y1 = np.sin(x)
y2 = np.cos(x)
y3 = np.sin(x) * np.cos(x)
y4 = np.exp(-x/10) * np.sin(x)

# ایجاد یک شکل با ۴ نمودار (۲×۲)
fig, axes = plt.subplots(2, 2, figsize=(10, 8))

# نمودار اول
axes[0, 0].plot(x, y1, 'r-', linewidth=2)
axes[0, 0].set_title('Sin(x)')
axes[0, 0].grid(True, alpha=0.3)

# نمودار دوم
axes[0, 1].plot(x, y2, 'b-', linewidth=2)
axes[0, 1].set_title('Cos(x)')
axes[0, 1].grid(True, alpha=0.3)

# نمودار سوم
axes[1, 0].plot(x, y3, 'g-', linewidth=2)
axes[1, 0].set_title('Sin(x)*Cos(x)')
axes[1, 0].grid(True, alpha=0.3)

# نمودار چهارم
axes[1, 1].plot(x, y4, 'm-', linewidth=2)
axes[1, 1].set_title('e^(-x/10)*Sin(x)')
axes[1, 1].grid(True, alpha=0.3)

plt.tight_layout()
plt.show()
```

### 🔍 تنظیمات پیشرفته نمودارها

```python
import matplotlib.pyplot as plt
import numpy as np

# داده‌ها
x = np.linspace(0, 10, 100)
y1 = np.sin(x)
y2 = np.cos(x)

# ساخت نمودار با تنظیمات پیشرفته
plt.figure(figsize=(10, 6))

# خط اول
plt.plot(x, y1, 'r-', linewidth=2, label='Sin(x)', marker='o', markersize=4, markevery=10)

# خط دوم
plt.plot(x, y2, 'b--', linewidth=2, label='Cos(x)', marker='s', markersize=4, markevery=10)

# تنظیمات محورها
plt.xlim(0, 10)
plt.ylim(-1.5, 1.5)
plt.xticks(np.arange(0, 11, 1))
plt.yticks(np.arange(-1.5, 1.6, 0.5))

# برچسب‌ها و عنوان
plt.xlabel('محور X', fontsize=12)
plt.ylabel('محور Y', fontsize=12)
plt.title('نمودار توابع مثلثاتی', fontsize=14, fontweight='bold')

# شبکه و افسانه
plt.grid(True, alpha=0.3, linestyle='--')
plt.legend(loc='upper right', fontsize=12)

# ذخیره نمودار
plt.savefig('trig_functions.png', dpi=300, bbox_inches='tight')

plt.show()
```

### 📊 مصورسازی با Pandas و Matplotlib

پانداس به طور مستقیم با Matplotlib کار می‌کنه:

```python
import pandas as pd
import matplotlib.pyplot as plt

# داده‌های فروش
data = {
    'محصول': ['لپ‌تاپ', 'موبایل', 'هدفون', 'تبلت', 'ساعت'],
    'فروش': [45, 80, 120, 30, 55],
    'قیمت': [25000000, 15000000, 3000000, 12000000, 8000000],
    'درآمد': [45*25000000, 80*15000000, 120*3000000, 30*12000000, 55*8000000]
}

df = pd.DataFrame(data)

# نمودار میله‌ای با پانداس
df.plot(x='محصول', y=['فروش', 'درآمد'], kind='bar', figsize=(10, 6))
plt.title('فروش و درآمد محصولات', fontsize=14)
plt.xlabel('محصول', fontsize=12)
plt.ylabel('مقدار', fontsize=12)
plt.xticks(rotation=45)
plt.grid(axis='y', alpha=0.3)
plt.tight_layout()
plt.show()

# نمودار دایره‌ای
df.plot(x='محصول', y='فروش', kind='pie', figsize=(8, 8), autopct='%1.1f%%')
plt.title('سهم فروش محصولات', fontsize=14)
plt.ylabel('')
plt.tight_layout()
plt.show()
```

### 📌 اشتباهات رایج در این درس

> **🔴 فراموش کردن `plt.show()`:**
```python
plt.plot(x, y)  # ❌ هیچ چیزی نمایش داده نمیشه!
plt.plot(x, y)
plt.show()  # ✅ درسته
```

> **🟡 فراموش کردن `import matplotlib.pyplot as plt`:**
```python
plt.plot(x, y)  # ❌ خطا! plt تعریف نشده

import matplotlib.pyplot as plt  # ✅ باید اول وارد کنی
```

> **🟢 استفاده از `plot` به جای `bar` برای داده‌های دسته‌بندی:**
```python
plt.plot(categories, values)  # ❌ برای داده‌های دسته‌بندی مناسب نیست
plt.bar(categories, values)  # ✅ درسته
```

> **🟣 فراموش کردن `plt.figure()` برای تنظیم اندازه:**
```python
plt.plot(x, y)  # ❌ اندازه پیش‌فرض کوچیکه

plt.figure(figsize=(12, 6))  # ✅ تنظیم اندازه بزرگتر
plt.plot(x, y)
```

**صورت مسئله:**

   ```python
   sales_data = {
   ```

### 💪 چالش دوم (اختیاری - برای تحلیلگران بصری!)

حالا که با مصورسازی آشنا شدی، یه **داشبورد تحلیل فروش** کامل با چندین نمودار بساز:

1. از داده‌های بالا استفاده کن و این نمودارها رو توی یک شکل (`subplots`) با چیدمان ۲×۲ قرار بده:
   - **بالا چپ:** نمودار خطی فروش ماهانه
   - **بالا راست:** نمودار میله‌ای تعداد مشتریان
   - **پایین چپ:** نمودار پراکندگی فروش vs تعداد مشتری
   - **پایین راست:** نمودار دایره‌ای سهم فروش ۴ فصل سال

2. اضافه کن:
   - یک عنوان کلی برای کل شکل (`fig.suptitle()`)
   - تنظیمات `tight_layout()`
   - ذخیره‌سازی با کیفیت بالا

3. با Pandas داده‌های فصلی رو محاسبه کن:
   - بهار: فروردین، اردیبهشت، خرداد
   - تابستان: تیر، مرداد، شهریور
   - پاییز: مهر، آبان، آذر
   - زمستان: دی، بهمن، اسفند
