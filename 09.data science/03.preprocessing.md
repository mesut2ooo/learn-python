### ۱. شناسایی و مدیریت مقادیر گم‌شده (Missing Values)

#### شناسایی مقادیر گم‌شده

```python
import pandas as pd
import numpy as np

# ساخت داده با مقادیر گم‌شده
data = {
    "Name": ["احمد", "سارا", "علی", None, "زهرا"],
    "Age": [25, None, 30, 22, 28],
    "Salary": [5000000, 4500000, None, 6000000, 5500000],
    "City": ["تهران", "اصفهان", "شیراز", "تهران", None]
}

df = pd.DataFrame(data)
print("داده‌های اولیه:")
print(df)
print("\n" + "="*50 + "\n")

# شناسایی مقادیر گم‌شده
print("مقادیر گم‌شده در هر ستون:")
print(df.isnull().sum())
print("\n" + "="*50 + "\n")

# نمایش سطرهایی که مقدار گم‌شده دارن
print("سطرهای دارای مقدار گم‌شده:")
print(df[df.isnull().any(axis=1)])
```

**خروجی:**
```text
داده‌های اولیه:
    Name   Age   Salary     City
0   احمد  25.0  5000000   تهران
1   سارا   NaN  4500000  اصفهان
2   علی   30.0      NaN   شیراز
3   None  22.0  6000000   تهران
4   زهرا  28.0  5500000     None

مقادیر گم‌شده در هر ستون:
Name      1
Age       1
Salary    1
City      1
```

#### روش‌های مدیریت مقادیر گم‌شده

```python
# روش ۱: حذف سطرهای دارای مقدار گم‌شده
```

### ۲. شناسایی و حذف داده‌های تکراری (Duplicates)

```python
# ساخت داده با سطرهای تکراری
data_with_duplicates = {
    "ID": [1, 2, 3, 2, 4, 3, 5],
    "Name": ["احمد", "سارا", "علی", "سارا", "زهرا", "علی", "رضا"],
    "Score": [85, 92, 78, 92, 95, 78, 88]
}

df_dup = pd.DataFrame(data_with_duplicates)
print("داده‌های با سطرهای تکراری:")
print(df_dup)
print("\n" + "="*50 + "\n")

# شناسایی سطرهای تکراری
print("سطرهای تکراری:")
print(df_dup[df_dup.duplicated()])
print("\n" + "="*50 + "\n")

# شناسایی سطرهای تکراری بر اساس ستون خاص
print("تکرار بر اساس ستون Name:")
print(df_dup[df_dup.duplicated(subset=["Name"])])
print("\n" + "="*50 + "\n")

# حذف سطرهای تکراری (نگه‌داری اولین)
df_no_dup = df_dup.drop_duplicates()
print("حذف تکراری‌ها (نگه‌داری اولین):")
print(df_no_dup)
print("\n" + "="*50 + "\n")

# حذف تکراری‌ها و نگه‌داری آخرین
df_no_dup_last = df_dup.drop_duplicates(keep="last")
print("حذف تکراری‌ها (نگه‌داری آخرین):")
print(df_no_dup_last)
```

### ۳. تغییر نوع داده‌ها (Data Type Conversion)

```python
# ساخت داده با نوع‌های اشتباه
data_types = {
    "Name": ["احمد", "سارا", "علی"],
    "Age": ["25", "30", "22"],  # به جای عدد، رشته!
    "Join_Date": ["2023-01-15", "2023-02-20", "2023-03-10"],
    "Salary": ["5000000", "5500000", "4800000"]
}

df_types = pd.DataFrame(data_types)
print("داده‌های با نوع اشتباه:")
print(df_types)
print("\nنوع داده‌ها:")

df_types["Salary"] = df_types["Salary"].astype(int)
df_types["Join_Date"] = pd.to_datetime(df_types["Join_Date"])

print("پس از تغییر نوع:")
print(df_types)
print("\nنوع داده‌های جدید:")
print(df_types.dtypes)
print("\n" + "="*50 + "\n")

# استخراج اطلاعات از تاریخ
df_types["Year"] = df_types["Join_Date"].dt.year
df_types["Month"] = df_types["Join_Date"].dt.month
df_types["Day"] = df_types["Join_Date"].dt.day
df_types["Weekday"] = df_types["Join_Date"].dt.day_name()

print("استخراج اطلاعات از تاریخ:")
print(df_types[["Name", "Join_Date", "Year", "Month", "Weekday"]])
```

### ۴. نرمال‌سازی و استانداردسازی داده‌ها (Scaling)

```python
# ساخت داده با مقیاس‌های مختلف
data_scale = {
    "Age": [25, 30, 22, 28, 35],
    "Salary": [5000000, 5500000, 4800000, 6000000, 7000000],
    "Experience": [2, 5, 1, 4, 8]
}

df_scale = pd.DataFrame(data_scale)
print("داده‌های با مقیاس‌های مختلف:")
print(df_scale)
print("\nآمار توصیفی:")
print(df_scale.describe())
print("\n" + "="*50 + "\n")

# نرمال‌سازی Min-Max (مقیاس‌گذاری بین ۰ و ۱)
def min_max_scaling(column):
    return (column - column.min()) / (column.max() - column.min())

df_normalized = df_scale.copy()
for col in df_normalized.columns:
    df_normalized[col] = min_max_scaling(df_normalized[col])

print("داده‌های نرمال‌سازی شده (بین ۰ و ۱):")
print(df_normalized)
print("\n" + "="*50 + "\n")

# استانداردسازی Z-Score (میانگین ۰، واریانس ۱)
def z_score_scaling(column):
    return (column - column.mean()) / column.std()

df_standardized = df_scale.copy()
for col in df_standardized.columns:
    df_standardized[col] = z_score_scaling(df_standardized[col])

print("داده‌های استاندارد شده (میانگین ۰، واریانس ۱):")
print(df_standardized)
print("\nآمار استاندارد شده:")
print(df_standardized.describe())
```

### ۵. شناسایی داده‌های پرت (Outliers)

```python
# داده‌های با مقادیر پرت
data_outliers = {
    "Product": ["A", "B", "C", "D", "E", "F", "G", "H"],
    "Price": [100, 120, 110, 150, 130, 5000, 140, 160],  # 5000 یه داده‌ی پرته!
    "Quantity": [50, 55, 48, 60, 52, 45, 500, 53]  # 500 یه داده‌ی پرته!
}

df_outliers = pd.DataFrame(data_outliers)
print("داده‌های با مقادیر پرت:")
print(df_outliers)
print("\n" + "="*50 + "\n")

# شناسایی داده‌های پرت با روش IQR
def detect_outliers_iqr(column):
    Q1 = column.quantile(0.25)
    Q3 = column.quantile(0.75)
    IQR = Q3 - Q1
    lower_bound = Q1 - 1.5 * IQR
    upper_bound = Q3 + 1.5 * IQR
    return (column < lower_bound) | (column > upper_bound)

for col in ["Price", "Quantity"]:
    outliers = detect_outliers_iqr(df_outliers[col])
    print(f"داده‌های پرت در ستون {col}:")
    print(df_outliers[outliers][["Product", col]])
    print(f"تعداد: {outliers.sum()}")
    print("-" * 30)
```

### 📌 اشتباهات رایج در این درس

> **🔴 اشتباه گرفتن `dropna()` با `fillna()`:**
```python
# dropna: حذف می‌کنه
df_clean = df.dropna()  # سطرهای دارای NaN حذف میشن

# fillna: پر می‌کنه
df_filled = df.fillna(0)  # NaN با ۰ پر میشن
```

> **🟡 فراموش کردن `axis` در `dropna()`:**
```python
# axis=0: حذف سطرها (پیش‌فرض)
df.dropna(axis=0)  # حذف سطرهای دارای NaN

# axis=1: حذف ستون‌ها
df.dropna(axis=1)  # حذف ستون‌های دارای NaN
```

> **🟢 استفاده از `fillna()` بدون تعیین مقدار:**
```python
df.fillna()  # ❌ خطا! باید مقدار مشخص کنی
df.fillna(0)  # ✅ پر کردن با ۰
df.fillna({"A": 0, "B": "مشخص"})  # ✅ پر کردن با مقادیر متفاوت
```

> **🟣 فراموش کردن `inplace=True` برای تغییر دائمی:**
```python
df.drop_duplicates()  # ❌ تغییر موقتی
df.drop_duplicates(inplace=True)  # ✅ تغییر دائمی
```
