### 📦 متغیر یعنی چه؟

توی برنامه‌نویسی، ما مدام با اطلاعات مختلف سر و کار داریم؛ مثل قیمت یک کالا، تعداد موجودی انبار، یا نام کاربری یک شخص. برای اینکه این اطلاعات رو گم نکنیم و بتونیم بعداً ازشون استفاده کنیم، باید اون‌ها رو یک‌جا ذخیره کنیم.

به این مکان‌های ذخیره‌سازی می‌گیم **متغیر (Variable)**.

بهترین راه برای درک متغیر اینه که اون رو مثل یک **جعبه برچسب‌خورده** تصور کنی. شما یک وسیله (داده) رو می‌ذاری داخل جعبه و روی جعبه یک اسم (برچسب) می‌نویسی. هر وقت به اون وسیله نیاز داشتی، جعبه رو با اسمش صدا می‌زنی.

> **📌 نکته مهم:** متغیرها توی پایتون **داینامیک** هستن. یعنی می‌تونی هر لحظه مقدار جدیدی (حتی از نوع متفاوت) توی همون جعبه بذاری. اما این کار رو به حداقل برسون تا کدت گیج‌کننده نشه.

---

### 💻 چطور در پایتون متغیر بسازیم؟

ساختن متغیر در پایتون به شدت ساده‌ست. کافیه اسم متغیر رو بنویسی، یک علامت مساوی (`=`) بذاری و بعد مقداری که می‌خوای ذخیره بشه رو بنویسی:

```python
# ساختن یک متغیر برای ذخیره قیمت یک کالا
price = 45000

# ساختن یک متغیر برای ذخیره نام یک کاربر
user_name = "Amir"
```

> **⚡ عملگر انتساب:** علامت `=` در برنامه‌نویسی به معنی «مساوی ریاضی» نیست. به این علامت می‌گیم **عملگر انتساب (Assignment Operator)**. یعنی «مقدار سمت راست رو بردار و بریز داخل جعبه سمت چپ».

---

### 🔍 چطور از متغیرها استفاده کنیم؟

حالا چطور ازشون استفاده کنیم؟ کافیه اسم متغیر رو بدون هیچ علامت اضافه‌ای بدیم به دستور `print`:

```python
price = 45000
print(price)  # خروجی: 45000
```

می‌تونی چند متغیر رو با هم توی یک `print` چاپ کنی. برای این کار کافیه اسمشون رو با کاما (`,`) از هم جدا کنی:

```python
product = "کتاب"
price = 75000
print(product, price)  # خروجی: کتاب 75000
```

> **💡 نکته:** وقتی چند متغیر رو با کاما جدا می‌کنی، پایتون خودش بینشون یه فاصله می‌ذاره.

### 📋 قوانین نام‌گذاری متغیرها

پایتون روی اسم جعبه‌ها حساسه. موقع نام‌گذاری باید این چند قانون ساده رو رعایت کنی:

#### قوانین اجباری (اگر رعایت نکنی، کدت خطا میده):

1. **شروع اسم:** اسم متغیر حتماً باید با یک حرف انگلیسی (a-z) یا خط تیره زیرین (`_`) شروع بشه. نمی‌تونه با عدد شروع بشه (مثلاً `1price` غلطه، اما `price1` درسته).
2. **فاصله ممنوع:** در اسم متغیر نمی‌تونی از فاصله (Space) استفاده کنی. برای جدا کردن کلمات از خط تیره زیرین استفاده کن (مثلاً `item_count`).
3. **کاراکترهای خاص ممنوع:** استفاده از علامت‌هایی مثل `%` ، `$` ، `!` و... در اسم متغیر غیرمجاز هست.

#### قوانین پیشنهادی (اختیاری، ولی کدت رو حرفه‌ای‌تر می‌کنه):

4. **اسم‌های معنی‌دار:** از اسم‌های بی‌معنی مثل `x`، `a`، `temp` استفاده نکن. به جاش از `product_price`، `user_age` استفاده کن.
5. **نوشتن با حروف کوچک:** تو پایتون رسم بر اینه که اسم متغیرها رو با حروف کوچک بنویسن و کلمات رو با `_` جدا کنن (به این سبک می‌گن `snake_case`).

### ✅ چند نمونه درست و غلط

| ✅ درست | ❌ غلط | دلیل |
|---------|--------|------|
| `user_name` | `user name` | فاصله ممنوع |
| `price1` | `1price` | شروع با عدد ممنوع |
| `_private` | `@private` | کاراکتر خاص ممنوع |
| `total_price` | `total-price` | خط تیره (`-`) ممنوع |
| `itemCount` | `item Count` | فاصله ممنوع (و البته `itemCount` درسته ولی سبکش معمول نیست) |

### 🔄 تغییر مقدار متغیرها

متغیرها می‌تونن در طول برنامه مقدارشون عوض بشه:

```python
stock = 10
print(stock)  # خروجی: 10

stock = 25   # مقدار جدید
print(stock)  # خروجی: 25

stock = stock + 5  # مقدار قبلی رو بردار، ۵ تا بهش اضافه کن و دوباره توی خودش بریز
print(stock)  # خروجی: 30
```

خط آخر ممکنه اولش کمی عجیب به نظر برسه! پایتون اول سمت راست رو حساب می‌کنه (`stock + 5`) و بعد نتیجه رو می‌ریزه توی متغیر سمت چپ.

### 📌 اشتباهات رایج در این درس

> **🔴 کوتیشن فراموش شده:** اگه برای متن از کوتیشن استفاده نکنی، پایتون فکر می‌کنه متغیره و ارور میده:
```python
product_name = Laptop  # ❌ خطا! Laptop رو به عنوان متغیر می‌شناسه
product_name = "Laptop"  # ✅ درسته
```

> **🟡 علامت مساوی (`=`) با (`==`) قاطی نشه:** `=` برای مقداردهی استفاده میشه، `==` برای مقایسه (که بعداً یاد می‌گیریم).

> **🟢 اسم متغیر رو اشتباه تایپ نکن:** پایتون به حروف بزرگ و کوچک حساسه:
```python
Price = 100
print(price)  # ❌ خطا! price با Price فرق داره
```

### 🛠️ نوبت توئه: چالش مدیریت انبار!

فرض کن مسئول انبار یک فروشگاه زنجیره‌ای بزرگ هستی و می‌خوای موجودی یکی از کالاها رو ثبت و مدیریت کنی.

**صورت مسئله:**

1. یک متغیر بساز به نام `product_name` و نام کالا (مثلاً `"Laptop"`) رو داخلش ذخیره کن.
2. یک متغیر بساز به نام `stock_quantity` (تعداد موجودی) و عدد `15` رو داخلش بریز.
3. یک متغیر بساز به نام `unit_price` (قیمت هر واحد) و عدد `1200` رو داخلش بریز.
4. حالا با استفاده از دستور `print`، مقدار این سه متغیر رو در خروجی چاپ کن.

---

### 💪 چالش دوم (اختیاری - برای مدیران باهوش!)

حالا که با متغیرها آشنا شدی، فرض کن یه سفارش جدید اومده و ۳ تا از این کالاها فروخته شده. 

1. تعداد موجودی رو به‌روزرسانی کن (یعنی از `stock_quantity` کم کن).
2. یک متغیر جدید به اسم `total_value` بساز که ارزش کل موجودی رو حساب کنه (تعداد موجودی ضربدر قیمت واحد).
3. پیام زیر رو با استفاده از `print` چاپ کن (مقدارهای واقعی رو جایگزین کن):

```text
محصول: Laptop
موجودی جدید: 12 عدد
ارزش کل موجودی: 14400 دلار
```
