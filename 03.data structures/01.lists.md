# 📘 فصل سوم: دسته‌بندی اطلاعات (ساختارهای داده)

## 🎯 درس ۳.۱: لیست‌ها (Lists)

---

### 📦 چرا به لیست‌ها نیاز داریم؟

تا الان برای ذخیره هر مقدار، از یک متغیر جداگانه استفاده می‌کردیم. حالا فرض کن می‌خوایم نام ۱۰۰ قلم کالای موجود در یک فروشگاه، یا دمای هوای ۳۰ روز یک ماه رو ذخیره کنیم. تعریف کردن ۱۰۰ یا ۳۰ متغیر جداگانه دیوانه‌کننده‌ست!

اینجاست که **لیست‌ها (Lists)** به دادمون می‌رسن. لیست مثل یک قطار می‌مونه که واگن‌های مختلفی داره و توی هر واگن می‌تونی یک داده ذخیره کنی.

> **📌 تعریف رسمی:** لیست یک **ساختار داده‌ی ترتیبی (Sequential)** هست که می‌تونه چندین مقدار رو به ترتیب خاصی کنار هم نگه داره. لیست‌ها **تغییرپذیر (Mutable)** هستن، یعنی بعد از ساخته شدن، می‌تونیم اعضاش رو تغییر بدیم، اضافه یا حذف کنیم.

---

### 💻 چطور در پایتون لیست بسازیم؟

برای ساختن لیست، از براکت یا همان قلاب (`[ ]`) استفاده می‌کنیم و اعضای لیست رو با کاما (`,`) از هم جدا می‌کنیم:

```python
# یک لیست از متن‌ها (رشته‌ها)
fruits = ["apple", "banana", "cherry"]

# یک لیست از اعداد
temperatures = [22, 25, 19, 24, 21]

# یک لیست ترکیبی (می‌تونه انواع مختلف داده رو کنار هم داشته باشه)
mixed = ["احمد", 25, True, 3.14]

# یک لیست خالی که بعداً پرش می‌کنیم
cart = []
```

> **💡 نکته:** لیست‌ها توی پایتون می‌تونن اعضایی از هر نوع داده‌ای داشته باشن، حتی خود لیست‌ها! (لیست تو در تو)

---

### 🔢 دسترسی به اعضای لیست با اندیس (Index)

پایتون برای اینکه واگن‌های این قطار رو گم نکنه، به هر کدوم یک شماره میده. **نکته بسیار مهم اینه که شماره‌گذاری واگن‌ها در برنامه‌نویسی از صفر شروع میشه!** به این شماره‌ها می‌گیم **اندیس (Index)**.

```python
colors = ["red", "green", "blue", "yellow"]

# دسترسی به عضو اول (اندیس 0)
print(colors[0])  # خروجی: red

# دسترسی به عضو دوم (اندیس 1)
print(colors[1])  # خروجی: green

# دسترسی به عضو سوم (اندیس 2)
print(colors[2])  # خروجی: blue

# دسترسی به عضو چهارم (اندیس 3)
print(colors[3])  # خروجی: yellow
```

**نمایش تصویری:**

| اندیس | ۰ | ۱ | ۲ | ۳ |
|--------|---|---|---|---|
| مقدار | "red" | "green" | "blue" | "yellow" |

> **🔑 قانون طلایی:** اولین عضو لیست همیشه اندیس `0` داره. آخرین عضو اندیس `len(list) - 1` داره.

---

### 🔄 اندیس‌های منفی (ترفند پایتونی!)

اگر بخوای از آخر لیست به اعضا دسترسی داشته باشی، می‌تونی از اعداد منفی استفاده کنی:

```python
colors = ["red", "green", "blue", "yellow"]

print(colors[-1])  # خروجی: yellow (آخرین عضو)
print(colors[-2])  # خروجی: blue (یکی مونده به آخر)
print(colors[-3])  # خروجی: green
print(colors[-4])  # خروجی: red (اولین عضو)
```

**نمایش تصویری با اندیس‌های منفی:**

| اندیس مثبت | ۰ | ۱ | ۲ | ۳ |
|------------|---|---|---|---|
| اندیس منفی | -۴ | -۳ | -۲ | -۱ |
| مقدار | "red" | "green" | "blue" | "yellow" |

> **💡 نکته:** `-1` همیشه آخرین عضو رو بهت میده، بدون اینکه بدونی لیست چند تا عضو داره. این خیلی کاربردی‌ست!

---

### 🛠️ ابزارهای پرکاربرد کار با لیست

پایتون کلی ابزار آماده برای دستکاری لیست‌ها به ما میده:

#### ۱. اضافه کردن عضو جدید (`append`)

عضو جدید رو به انتهای لیست می‌چسبونه:

```python
shopping_list = ["bread", "milk"]
shopping_list.append("cheese")
print(shopping_list)  # خروجی: ['bread', 'milk', 'cheese']

shopping_list.append("egg")
print(shopping_list)  # خروجی: ['bread', 'milk', 'cheese', 'egg']
```

#### ۲. طول لیست (`len`)

تعداد اعضای لیست رو بهت میگه:

```python
shopping_list = ["bread", "milk", "cheese"]
print(len(shopping_list))  # خروجی: 3

empty_list = []
print(len(empty_list))  # خروجی: 0
```

#### ۳. حذف یک عضو با نام آن (`remove`)

اولین موردی که با نام مشخص شده مطابقت داشته باشه رو حذف می‌کنه:

```python
shopping_list = ["bread", "milk", "cheese", "milk"]
shopping_list.remove("milk")  # فقط اولین "milk" رو حذف می‌کنه
print(shopping_list)  # خروجی: ['bread', 'cheese', 'milk']
```

#### ۴. حذف عضو با اندیس (`pop`)

عضو رو با اندیسش حذف می‌کنه (اگه اندیس ندی، آخرین عضو رو حذف می‌کنه):

```python
colors = ["red", "green", "blue", "yellow"]
removed = colors.pop(1)  # عضو اندیس ۱ (green) رو حذف کن
print(colors)    # خروجی: ['red', 'blue', 'yellow']
print(removed)   # خروجی: green

last = colors.pop()  # آخرین عضو رو حذف کن
print(colors)    # خروجی: ['red', 'blue']
print(last)      # خروجی: yellow
```

#### ۵. عضویت در لیست (`in`)

بررسی می‌کنه که آیا یک مقدار در لیست وجود داره یا نه:

```python
fruits = ["apple", "banana", "cherry"]
print("banana" in fruits)  # خروجی: True
print("grape" in fruits)   # خروجی: False
```

### 🚶‍♂️ پیمایش لیست با حلقه `for`

یکی از قدرتمندترین کارهایی که با لیست‌ها می‌تونی انجام بدی، پیمایش اون‌ها با حلقه `for` هست:

```python
fruits = ["apple", "banana", "cherry"]

# روش ساده: پیمایش مستقیم اعضا
for fruit in fruits:
    print(fruit)
# خروجی:
# apple
# banana
# cherry

# روش پیشرفته‌تر: پیمایش با اندیس
for i in range(len(fruits)):
    print(f"{i}: {fruits[i]}")
# خروجی:
# 0: apple
# 1: banana
# 2: cherry
```

---

### 📊 جدول جمع‌بندی متدهای لیست

| متد | کاربرد | مثال |
|-----|--------|------|
| `append(x)` | اضافه کردن x به انتهای لیست | `list.append(5)` |
| `remove(x)` | حذف اولین x از لیست | `list.remove(5)` |
| `pop(i)` | حذف عضو اندیس i و برگردوندنش | `x = list.pop(2)` |
| `len(list)` | تعداد اعضای لیست | `len(list)` |
| `x in list` | بررسی وجود x در لیست | `5 in list` |
| `list[i]` | دسترسی به عضو اندیس i | `list[0]` |

### 📌 اشتباهات رایج در این درس

> **🔴 فراموش کردن اینکه اندیس‌ها از ۰ شروع میشن:**
```python
colors = ["red", "green", "blue"]
print(colors[1])  # خروجی: green (نه red!)
print(colors[0])  # خروجی: red
```

> **🟡 دسترسی به اندیس خارج از محدوده:**
```python
colors = ["red", "green", "blue"]
print(colors[3])  # ❌ خطا! IndexError: list index out of range
```

> **🟢 فراموش کردن کاما بین اعضای لیست:**
```python
colors = ["red" "green" "blue"]  # ❌ این سه تا رو به هم می‌چسبونه
colors = ["red", "green", "blue"]  # ✅ درسته
```

> **🟣 قاطی کردن `append` با `extend`:**
```python
list = [1, 2]
list.append([3, 4])  # خروجی: [1, 2, [3, 4]] (یک لیست تودرتو)
list.extend([3, 4])   # خروجی: [1, 2, 3, 4] (اعضا رو اضافه می‌کنه)
```

### 🛠️ نوبت توئه: چالش سیستم مدیریت وظایف (To-Do List)!

بیا یک نرم‌افزار کوچک مدیریت کارهای روزانه (Task Manager) بنویسیم.

**صورت مسئله:**

1. یک لیست خالی به نام `todo_list` بساز.
2. با استفاده از دستور `append` و گرفتن ورودی از کاربر با `input()`، سه کار مهمی که امروز باید انجام بدی رو یکی‌یکی به لیست اضافه کن.
3. در نهایت، با استفاده از یک حلقه `for`، تمام کارهای داخل لیست رو به همراه شماره‌شون (از ۱ تا ۳) در خروجی چاپ کن تا کاربر لیست کارهای امروز خودش رو ببینه.

**راهنمایی برای چاپ با شماره:**
توی حلقه `for` می‌تونی این‌طوری روی لیست حرکت کنی:

```python
for item in todo_list:
    print(item)
```

فقط کافیه یک متغیر ساده مثل `number` بیرون حلقه تعریف کنی که مقدارش از ۱ شروع بشه و توی هر دور حلقه، یکی بهش اضافه بشه تا شماره کارها رو هم کنارشون چاپ کنی.

### 💪 چالش دوم (اختیاری - برای مدیران حرفه‌ای!)

حالا که با لیست‌ها آشنا شدی، یه سیستم **مدیریت دمای هوای هفتگی** بساز:

1. یک لیست خالی به اسم `weekly_temps` بساز.
2. از کاربر ۷ بار (برای ۷ روز هفته) دمای هوا رو به درجه سانتی‌گراد بگیر و به لیست اضافه کن.
3. بعد از گرفتن همه‌ی دماها، این محاسبات رو انجام بده:
   - میانگین دما (مجموع دماها تقسیم بر تعداد روزها)
   - بالاترین دما (با استفاده از تابع `max()`)
   - پایین‌ترین دما (با استفاده از تابع `min()`)
   - تعداد روزهایی که دما بالای ۲۰ درجه بوده (با حلقه `for` و شرط)

4. خروجی رو به این شکل چاپ کن:

```text
دمای هفتگی: [22, 25, 19, 24, 21, 28, 23]
میانگین دما: 23.14 درجه
بالاترین دما: 28 درجه
پایین‌ترین دما: 19 درجه
تعداد روزهای گرم (بالای ۲۰ درجه): 5 روز
```

> **💡 نکته:** برای محاسبه‌ی مجموع دماها، می‌تونی از حلقه `for` و یک متغیر جمع‌کننده استفاده کنی یا از تابع `sum()`.
