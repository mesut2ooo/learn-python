---

### 💾 چرا به فایل‌ها نیاز داریم؟

تا الان هر متغیری که می‌ساختیم، به محض اینکه برنامه رو می‌بستیم، پاک می‌شد. توی این فصل یاد می‌گیریم چطور اطلاعات رو برای همیشه روی هارد دیسک ذخیره کنیم تا حتی با خاموش شدن کامپیوتر هم گم نشن.

> **📌 مثال دنیای واقعی:** برنامه‌های مدیریت مخاطبین، نوت‌برداری، ثبت فاکتورها و... همه از فایل‌ها برای ذخیره‌سازی اطلاعات استفاده می‌کنن. اگه اطلاعات توی فایل ذخیره نشن، با هر بار بستن برنامه، همه‌چیز از دست می‌ره!

---

### 🗂️ کار با فایل‌ها در پایتون

پایتون برای کار با فایل‌ها (مثل فایل‌های متنی `.txt`) یک دستور بسیار ساده و قدرتمند به اسم `open()` داره. با این دستور می‌تونیم فایل‌ها رو باز کنیم، داخلشون بنویسیم، یا اطلاعاتشون رو بخونیم.

#### سه حالت اصلی باز کردن فایل

| حالت | نام | کاری که می‌کنه |
|------|-----|----------------|
| `'r'` | Read (خواندن) | فایل رو برای **خوندن** باز می‌کنه. اگه فایل نباشه خطا میده! |
| `'w'` | Write (نوشتن) | فایل رو برای **نوشتن** باز می‌کنه. اگه فایل باشه، محتویات قبلی رو **پاک** می‌کنه! |
| `'a'` | Append (افزودن) | فایل رو برای **افزودن** باز می‌کنه. نوشته‌های جدید رو به **انتهای** فایل اضافه می‌کنه. |

> **💡 نکته:** حتماً `encoding="utf-8"` رو اضافه کن تا پایتون بتونه فارسی رو بدون مشکل ذخیره کنه.

---

### ۱. نوشتن در فایل (Writing)

#### حالت `'w'` (نوشتن از صفر)

اگه فایل وجود نداشته باشه، ساخته میشه. اگه وجود داشته باشه، محتویات قبلی **کاملاً پاک** میشه:

```python
# نوشتن در فایل (محتوای قبلی پاک میشه!)
with open("report.txt", "w", encoding="utf-8") as file:
    file.write("گزارش عملکرد سیستم\n")
    file.write("همه چیز مرتب است.\n")
    file.write("تاریخ: ۱۴۰۳/۰۷/۱۵\n")
```

#### حالت `'a'` (افزودن به انتهای فایل)

محتویات جدید رو به **انتهای** فایل اضافه می‌کنه، بدون اینکه محتوای قبلی رو پاک کنه:

```python
# افزودن به انتهای فایل (محتوای قبلی حفظ میشه)
with open("report.txt", "a", encoding="utf-8") as file:
    file.write("خط جدید اضافه شد.\n")
    file.write("این خط بعد از خطوط قبلی قرار می‌گیرد.\n")
```

### ۲. خواندن از فایل (Reading)

#### روش‌های مختلف خواندن

```python
# روش ۱: خواندن کل فایل با read()
with open("report.txt", "r", encoding="utf-8") as file:
    content = file.read()
    print("محتویات کامل فایل:")
    print(content)

# روش ۲: خواندن خط به خط با readline()
with open("report.txt", "r", encoding="utf-8") as file:
    line1 = file.readline()  # خط اول
    line2 = file.readline()  # خط دوم
    print(f"خط اول: {line1}")
    print(f"خط دوم: {line2}")

# روش ۳: خواندن همه خطوط در یک لیست با readlines()
with open("report.txt", "r", encoding="utf-8") as file:
    lines = file.readlines()  # لیستی از همه خطوط
    for i, line in enumerate(lines, 1):
        print(f"خط {i}: {line.strip()}")  # strip() برای حذف \n
```

#### پیمایش خطوط با حلقه `for`

```python
# بهترین روش برای فایل‌های بزرگ (حافظه کمتری مصرف می‌کنه)
with open("report.txt", "r", encoding="utf-8") as file:
    for line in file:
        print(f"> {line.strip()}")
```

### 🔧 ساختار `with open()` (توضیح کامل)

```python
with open("filename.txt", "mode", encoding="utf-8") as file_variable:
    # کار با فایل
    file_variable.write("متن")
    # ...
# اینجا فایل خودبه‌خود بسته میشه
```

> **📌 چرا `with`؟**
> - فایل رو **خودبه‌خود** می‌بنده (حتی اگه خطا رخ بده)
> - کد رو **تمیزتر** و **خواناتر** می‌کنه
> - از **نشت حافظه (Memory Leak)** جلوگیری می‌کنه

> **⚠️ اگه از `with` استفاده نکنی، باید خودت فایل رو ببندی:**
```python
file = open("file.txt", "w")
file.write("متن")
file.close()  # حتماً باید ببندی!
```

### 🛠️ متدهای پرکاربرد فایل

| متد | کاربرد | مثال |
|-----|--------|------|
| `read()` | خواندن کل فایل | `content = file.read()` |
| `readline()` | خواندن یک خط | `line = file.readline()` |
| `readlines()` | خواندن همه خطوط در لیست | `lines = file.readlines()` |
| `write()` | نوشتن متن در فایل | `file.write("متن")` |
| `writelines()` | نوشتن لیستی از خطوط | `file.writelines(["خط۱\n", "خط۲\n"])` |
| `close()` | بستن فایل | `file.close()` |

### ⚠️ خطاهای رایج در کار با فایل‌ها

1. **فایل وجود نداره (حالت `'r'`):**
   ```python
   with open("not_exist.txt", "r") as file:  # ❌ FileNotFoundError!
       content = file.read()
   ```

2. **نوشتن با `'w'` باعث پاک شدن محتوای قبلی میشه:**
   ```python
   # اگر فایل قبلاً محتوایی داشته، پاک میشه!
   with open("important.txt", "w") as file:
       file.write("متن جدید")  # ❌ محتوای قبلی از بین رفت!
   ```

3. **فراموش کردن `\n` برای خط جدید:**
   ```python
   # همه چیز توی یه خط نوشته میشه
   with open("file.txt", "w") as file:
       file.write("خط اول")
       file.write("خط دوم")  # خروجی: "خط اولخط دوم"
   
   # درست
   with open("file.txt", "w") as file:
       file.write("خط اول\n")
       file.write("خط دوم\n")
   ```

### 📌 اشتباهات رایج در این درس

> **🔴 فراموش کردن `encoding="utf-8"` برای فارسی:**
```python
with open("file.txt", "w") as file:  # ❌ ممکنه فارسی خراب بشه
    file.write("سلام")

with open("file.txt", "w", encoding="utf-8") as file:  # ✅ درسته
    file.write("سلام")
```

> **🟡 استفاده از `'w'` به جای `'a'` برای اضافه کردن:**
```python
with open("file.txt", "w") as file:  # ❌ محتوای قبلی پاک میشه!
    file.write("متن جدید")

with open("file.txt", "a") as file:  # ✅ به انتها اضافه میشه
    file.write("متن جدید\n")
```

> **🟢 فراموش کردن `\n` برای خط جدید:**
```python
file.write("خط اول")
file.write("خط دوم")  # ❌ توی یه خط میشه

file.write("خط اول\n")
file.write("خط دوم\n")  # ✅ درسته
```

> **🟣 بستن فایل با `close()` در `with`:**
```python
with open("file.txt", "w") as file:
    file.write("متن")
    file.close()  # ❌ غیرضروری! with خودش می‌بنده
```

### 🛠️ نوبت توئه: چالش دفترچه یادداشت روزانه!

بیا برنامه‌ای بنویسیم که مثل یک مینی‌دفترچه یادداشت کار کنه و یادداشت‌های ما رو توی یک فایل متنی ذخیره کنه بدون اینکه یادداشت‌های قبلی پاک بشن.

**صورت مسئله:**

1. با استفاده از `input()`، یک یادداشت جدید از کاربر دریافت کن (مثلاً: `"امروز کار روی فصل ۵ پایتون رو شروع کردم."`).
2. فایل متنی به نام `diary.txt` را در حالت **Append (پیوست)** باز کن.
3. یادداشت کاربر را به همراه یک کاراکتر خط جدید (`\n`) انتهای آن، داخل فایل بنویس تا یادداشت بعدی در خط جدید ثبت بشه.
4. در نهایت، فایل را در حالت **Read (خواندن)** باز کن و کل محتویات دفترچه یادداشت رو روی صفحه چاپ کن تا ببینی یادداشت جدیدت اضافه شده یا نه.

کدت رو بنویس و خروجی رو تست کن. (بعد از اجرا، فایل `diary.txt` رو در کنار فایل کدت توی VS Code می‌بینی).

### 💪 چالش دوم (اختیاری - برای مدیران داده!)

حالا که با فایل‌ها آشنا شدی، یه سیستم **مدیریت لیست خرید** کامل بساز:

1. برنامه‌ای بنویس که یک منوی ساده داشته باشه:

```
=== سیستم مدیریت لیست خرید ===
1. نمایش لیست خرید
2. اضافه کردن کالا
3. حذف کالا (با شماره)
4. پاک کردن کل لیست
5. خروج
```

2. لیست خرید توی یه فایل به اسم `shopping_list.txt` ذخیره بشه (هر کالا یک خط).

3. هر گزینه رو با توابع جداگانه پیاده‌سازی کن:
   - **نمایش لیست:** فایل رو بخونه و کالاها رو به صورت شماره‌دار چاپ کنه
   - **اضافه کردن:** از کاربر اسم کالا رو بگیره و به انتهای فایل اضافه کنه
   - **حذف کردن:** شماره کالا رو از کاربر بگیره و اون خط رو حذف کنه (با بازنویسی کل فایل)
   - **پاک کردن:** فایل رو با حالت `'w'` باز کنه تا خالی بشه
   - **خروج:** برنامه رو تموم کنه

4. اگه فایل وجود نداشته باشه، برنامه خطا نده و بگه `"لیست خرید خالی است"`.

> **💡 نکته:** برای حذف یک کالا، کل فایل رو بخون، کالای مورد نظر رو حذف کن و دوباره کل فایل رو بنویس. این روش ساده‌ترین راهه!
