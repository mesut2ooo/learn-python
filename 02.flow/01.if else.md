# 📙 فصل دوم: فرمانروایی بر کد (تصمیم‌گیری و تکرار)

## 🎯 درس ۲.۱: دستورات شرطی (`if`، `elif`، `else`)

---

### 🧠 چرا به شرط‌ها نیاز داریم؟

در دنیای واقعی، ما مدام بر اساس شرایط مختلف تصمیم می‌گیریم. مثلاً: «**اگر** بارون بیاد، چتر می‌برم، **در غیر این صورت** چتر نمی‌برم.»

برنامه‌ها هم قراره جای ما تصمیم بگیرن. برای همین باید بهشون یاد بدیم چطور شرایط رو بررسی کنن و بر اساس اون‌ها واکنش نشون بدن. در برنامه‌نویسی این کار رو با **دستورات شرطی** انجام می‌دیم.

> **📌 نکته:** دستورات شرطی به برنامه‌ها **هوش مصنوعی** نمی‌دن! ولی بهشون **هوش تصمیم‌گیری** می‌دن. فرقش رو به خاطر بسپار.

---

### 🚦 ساختار شرط در پایتون

در پایتون تصمیم‌گیری‌ها با سه کلمه کلیدی انجام میشن:

| کلمه کلیدی | معنی | توضیح |
|------------|------|--------|
| `if` | اگر | شرط اصلی رو بررسی می‌کنه. اگر درست بود، کدهای داخلش اجرا میشن. |
| `elif` | یا اگر | مخفف `else if` هست. اگر شرط اول درست نبود، این شرط رو بررسی می‌کنه. می‌تونه چندتا باشه. |
| `else` | در غیر این صورت | اگر هیچ‌کدام از شرط‌های بالا درست نبودند، کدهای این بخش اجرا میشن. |

**نکته:** `if` همیشه اول میاد، بعد `elif` (هر تعداد که لازم باشه)، و در آخر `else` (اختیاری).

```python
score = 85

if score >= 90:
    print("عالی! الف گرفتید.")
elif score >= 75:
    print("خوب! ب گرفتید.")
elif score >= 60:
    print("متوسط! ج گرفتید.")
else:
    print("نیاز به تلاش بیشتر.")
```

> **💡** توی این مثال، چون `score` برابر ۸۵ هست، شرط دوم (`score >= 75`) درسته و فقط همون اجرا میشه. بقیه‌ی شرط‌ها نادیده گرفته میشن.

### 🛑 یک قانون حیاتی: دندانه‌گذاری (Indentation)

اگه به کد بالا دقت کنی، کدهای بعد از علامت `:` کمی جلوتر نوشته شده‌اند (معمولاً با ۴ بار زدن دکمه Space یا ۱ بار دکمه Tab).

در پایتون، این فاصله‌ی شروع خطوط به شدت حیاتیه. پایتون با این فاصله‌ها می‌فهمه کدوم خط کد متعلق به کدوم شرطه.

```python
# ✅ درست
if age >= 18:
    print("شما بزرگسال هستید")  # ۴ فاصله جلوتر
    print("می‌توانید رای دهید")  # همینجا ادامه داره
print("برنامه پایان یافت")  # این دیگه داخل شرط نیست

# ❌ غلط (ارور IndentationError)
if age >= 18:
print("شما بزرگسال هستید")  # خطا! باید جلوتر باشه
```

> **⚠️ قانون طلایی:** همه‌ی خطوطی که داخل یک شرط هستن، باید دقیقاً به یک اندازه جلوتر باشن. معمولاً از ۴ فاصله (Space) یا ۱ تب (Tab) استفاده می‌کنن، ولی مهم اینه که در کل برنامه یکنواخت باشه.

### 🔍 عملگرهای مقایسه‌ای (مرور سریع)

برای نوشتن شرط‌ها، نیاز داریم مقادیر رو با هم مقایسه کنیم. از درس ۱.۵ یادتونه:

| عملگر | معنی | مثال |
|--------|-------|---------|
| `==` | مساوی | `age == 18` |
| `!=` | نامساوی | `age != 18` |
| `<` | کوچک‌تر | `age < 18` |
| `>` | بزرگ‌تر | `age > 18` |
| `<=` | کوچک‌تر یا مساوی | `age <= 18` |
| `>=` | بزرگ‌تر یا مساوی | `age >= 18` |

---

### 🎯 ترکیب شرط‌ها با عملگرهای منطقی

گاهی نیاز داریم چند شرط رو همزمان بررسی کنیم. اینجا عملگرهای `and`، `or` و `not` به کار میان:

```python
age = 22
is_student = True

# هر دو شرط باید درست باشه
if age >= 18 and is_student:
    print("تخفیف دانشجویی تعلق می‌گیرد.")

# حداقل یکی از شرط‌ها درست باشه
if age < 18 or age > 65:
    print("تخفیف ویژه سالمندان یا کودکان.")

# برعکس کردن یک شرط
if not is_student:
    print("کاربر دانشجو نیست.")
```

### 💡 نکات حرفه‌ای برای نوشتن شرط‌های تمیز

1. **شرط‌های ساده رو مستقیم بنویس:**
   ```python
   # ❌ بد
   if is_available == True:
   
   # ✅ خوب
   if is_available:
   ```

2. **از پرانتز برای خوانایی بیشتر استفاده کن:**
   ```python
   # ❌ سخت‌خون
   if age >= 18 and has_license or is_emergency:
   
   # ✅ خوانا
   if (age >= 18 and has_license) or is_emergency:
   ```

3. **شرط‌های تودرتو رو تا حد ممکن ساده کن:**
   ```python
   # ❌ بد (تودرتو)
   if age >= 18:
       if has_license:
           print("می‌توانید رانندگی کنید")
   
   # ✅ خوب (مسطح)
   if age >= 18 and has_license:
       print("می‌توانید رانندگی کنید")
   ```

### 📌 اشتباهات رایج در این درس

> **🔴 فراموش کردن دو نقطه (`:`) آخر `if`:**
```python
if age >= 18  # ❌ خطا! دو نقطه فراموش شده
if age >= 18:  # ✅ درسته
```

> **🟡 قاطی کردن `=` با `==` در شرط‌ها:**
```python
if age = 18:  # ❌ خطا! این مقداردهی هست، مقایسه نیست
if age == 18:  # ✅ درسته
```

> **🟢 دندانه‌گذاری نامنظم:**
```python
if age >= 18:
    print("بزرگسال")  # ۴ فاصله
    print("می‌تواند رای دهد")  # ❌ خطا! دندانه‌گذاری نامنظم
```

> **🟣 فراموش کردن تبدیل نوع برای `input()`:**
```python
age = input("سن: ")
if age >= 18:  # ❌ خطا! age متن هست
	age = int(input("سن: "))  # ✅ درسته
```

> **🔵 نوشتن شرط‌های اضافی:**
```python
# ❌ بد
if is_available == True:

# ✅ خوب
if is_available:
```

### 🛠️ نوبت توئه: چالش چراغ راهنمای هوشمند!

فرض کن می‌خواهیم سیستم پردازش تصویر یک تقاطع هوشمند شهری رو شبیه‌سازی کنیم. برنامه‌ای بنویس که رنگ چراغ راهنما رو از کاربر بگیره و تصمیم درست رو چاپ کنه.

**صورت مسئله:**

1. با استفاده از `input()` رنگ فعلی چراغ (سبز، زرد یا قرمز) رو از کاربر دریافت کن.
2. اگر کاربر نوشت `"red"` یا `"قرمز"`، برنامه چاپ کند: `"ایست کامل! جریمه در انتظار شماست."`
3. اگر کاربر نوشت `"yellow"` یا `"زرد"`، برنامه چاپ کند: `"احتیاط! سرعت را کم کنید و آماده ایست شوید."`
4. اگر کاربر نوشت `"green"` یا `"سبز"`، برنامه چاپ کند: `"مسیر باز است، حرکت کنید."`
5. اگر کاربر هر چیز دیگری نوشت، برنامه چاپ کند: `"رنگ وارد شده نامعتبر است!"`

### 💪 چالش دوم (اختیاری - برای طراحان سیستم‌های واقعی!)

حالا که با شرط‌ها آشنا شدی، یه سیستم **صدور گواهینامه رانندگی** هوشمند بساز:

1. از کاربر سه تا اطلاعات بگیر:
   - سن (عدد صحیح)
   - آیا آزمون کتبی رو قبول شده؟ (کاربر `True` یا `False` وارد کنه)
   - آیا آزمون عملی رو قبول شده؟ (کاربر `True` یا `False` وارد کنه)

2. بر اساس این قوانین، گواهینامه صادر کن:
   - اگر سن کمتر از ۱۸ سال باشه: `"متاسفم! برای گواهینامه باید حداقل ۱۸ سال داشته باشید."`
   - اگر سن بیشتر یا مساوی ۱۸ باشه و هر دو آزمون قبول شده باشن: `"تبریک! گواهینامه شما صادر شد."`
   - اگر سن بیشتر یا مساوی ۱۸ باشه ولی آزمون کتبی قبول نشده: `"شما نیاز به بازآموزی کتبی دارید."`
   - اگر سن بیشتر یا مساوی ۱۸ باشه ولی آزمون عملی قبول نشده: `"شما نیاز به تمرین عملی بیشتر دارید."`
   - اگر سن بیشتر یا مساوی ۱۸ باشه و هیچ‌کدوم از آزمون‌ها قبول نشده: `"شما باید هر دو آزمون رو دوباره بدید."`

> **💡 نکته برای گرفتن `True`/`False` از کاربر:**
```python
written = input("آزمون کتبی رو قبول شدید؟ (True/False): ")
written = written == "True"  # تبدیل به بولین
```
