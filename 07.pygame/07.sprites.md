### 🖼️ اسپرایت (Sprite) یعنی چی؟

در دنیای بازی‌سازی دو بعدی، به هر تصویری که در بازی استفاده میشه (کاراکترها، اشیاء، پس‌زمینه‌ها) **اسپرایت (Sprite)** می‌گن. استفاده از تصاویر واقعی به جای اشکال ساده، بازی رو زنده‌تر و جذاب‌تر می‌کنه.

پایتون برای بارگذاری تصاویر از متد `pygame.image.load()` استفاده می‌کند. برای اینکه تصاویر بازی‌مان روان اجرا شوند و لبه‌های شفاف آن‌ها بدون مشکل نشان داده شوند، معمولاً از فرمت **PNG** استفاده می‌کنیم.

> **📌 نکته:** فرمت PNG از شفافیت (Alpha Channel) پشتیبانی می‌کنه، پس برای اسپرایت‌هایی که شکل‌های غیرمستطیلی دارن عالیه!

---

### 📥 پیدا کردن تصاویر برای بازی

برای اجرای این کد، به دو تصویر ساده با فرمت PNG در کنار فایل اصلی کدت نیاز داری:

1. تصویر بازیکن به نام `player.png` (مثلاً تصویر یک سفینه فضایی یا یک کاراکتر بامزه)
2. تصویر سکه به نام `coin.png` (تصویر یک سکه طلایی)
3. تصویر پس‌زمینه به نام `background.png` (اختیاری)

### 💻 بیدار کردن گرافیک بازی با تصاویر واقعی

بیا کدهای بازی‌مان را برداریم و این بار به جای کشیدن مستطیل‌های رنگی، تصاویر واقعی را روی صفحه نقاشی کنیم:

```python
import pygame
import sys
import random

pygame.init()
pygame.mixer.init()

SCREEN_WIDTH = 800
SCREEN_HEIGHT = 600
screen = pygame.display.set_mode((SCREEN_WIDTH, SCREEN_HEIGHT))
pygame.display.set_caption("بازی جمع‌آوری سکه با گرافیک واقعی")

# تعریف رنگ‌ها برای متن‌ها
WHITE = (255, 255, 255)

# --- بارگذاری و تنظیم تصاویر (Sprites) ---
try:
    # ۱. بارگذاری تصویر بازیکن و تغییر اندازه آن به ۵۰ در ۵۰ پیکسل
    player_img = pygame.image.load("player.png").convert_alpha()
    player_image = pygame.transform.scale(player_img, (50, 50))
    
    # ۲. بارگذاری تصویر سکه و تغییر اندازه آن به ۳۰ در ۳۰ پیکسل
    coin_img = pygame.image.load("coin.png").convert_alpha()
    coin_image = pygame.transform.scale(coin_img, (30, 30))
    
    # ۳. بارگذاری تصویر پس‌زمینه (اختیاری)
    try:
        bg_image = pygame.image.load("background.png").convert()
        bg_image = pygame.transform.scale(bg_image, (SCREEN_WIDTH, SCREEN_HEIGHT))
        has_background = True
    except:
        has_background = False
        print("⚠️ فایل background.png پیدا نشد. از رنگ پس‌زمینه استفاده می‌شود.")
    
    print("✅ تصاویر با موفقیت بارگذاری شدند.")
except Exception as e:
    print(f"❌ خطا در بارگذاری تصاویر! {e}")
    print("مطمئن شو فایل‌های player.png و coin.png در پوشه بازی هستند.")
    # تعریف اسپرایت‌های فرضی ساده در صورت نبودن فایل‌ها برای جلوگیری از کرش
    player_image = pygame.Surface((50, 50))
    player_image.fill((0, 255, 0))
    coin_image = pygame.Surface((30, 30))
    coin_image.fill((255, 215, 0))
    has_background = False

# استفاده از Rect برای مدیریت راحت‌تر موقعیت و برخوردها
player_rect = player_image.get_rect()
player_rect.x = 100
player_rect.y = 275

coin_rect = coin_image.get_rect()
coin_rect.x = 400
coin_rect.y = 300

player_speed = 7
score = 0
game_font = pygame.font.Font(None, 36)

# بارگذاری صداها
coin_sound = None
try:
    coin_sound = pygame.mixer.Sound("coin.wav")
except:
    pass

start_ticks = pygame.time.get_ticks()
GAME_DURATION = 30
last_second = -1

clock = pygame.time.Clock()
is_running = True

while is_running:
    clock.tick(60)
    
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            is_running = False

    # زمان باقی‌مانده
    seconds_passed = (pygame.time.get_ticks() - start_ticks) / 1000
    time_left = GAME_DURATION - int(seconds_passed)

    if time_left <= 0:
        print(f"🎮 بازی تمام شد! امتیاز نهایی: {score}")
        is_running = False
        break

    # حرکت بازیکن با کیبورد
    keys = pygame.key.get_pressed()
    if keys[pygame.K_LEFT]:
        player_rect.x -= player_speed
    if keys[pygame.K_RIGHT]:
        player_rect.x += player_speed
    if keys[pygame.K_UP]:
        player_rect.y -= player_speed
    if keys[pygame.K_DOWN]:
        player_rect.y += player_speed

    # محدود کردن حرکت بازیکن در صفحه
    if player_rect.left < 0:
        player_rect.left = 0
    if player_rect.right > SCREEN_WIDTH:
        player_rect.right = SCREEN_WIDTH
    if player_rect.top < 0:
        player_rect.top = 0
    if player_rect.bottom > SCREEN_HEIGHT:
        player_rect.bottom = SCREEN_HEIGHT

    # بررسی برخورد
    if player_rect.colliderect(coin_rect):
        score += 1
        if coin_sound:
            coin_sound.play()
        coin_rect.x = random.randint(50, SCREEN_WIDTH - 50)
        coin_rect.y = random.randint(50, SCREEN_HEIGHT - 50)

    # --- نقاشی روی صفحه ---
    # ۴. کشیدن پس‌زمینه (تصویر یا رنگ)
    if has_background:
        screen.blit(bg_image, (0, 0))
    else:
        screen.fill((30, 30, 40))  # یک رنگ پس‌زمینه سرمه‌ای تیره و شیک
    
    # ۵. چسباندن تصاویر بازیکن و سکه در موقعیت Rectها
    screen.blit(player_image, player_rect)
    screen.blit(coin_image, coin_rect)

    # رندر و نمایش متن‌ها
    score_text = game_font.render(f"⭐ Score: {score}", True, WHITE)
    time_text = game_font.render(f"⏱️ Time: {time_left}s", True, WHITE)
    
    # تغییر رنگ تایمر در ثانیه‌های آخر
    if time_left <= 5:
        time_text = game_font.render(f"⏱️ Time: {time_left}s", True, (255, 0, 0))
    
    screen.blit(score_text, (10, 10))
    screen.blit(time_text, (SCREEN_WIDTH - 180, 10))

    pygame.display.flip()

pygame.quit()
sys.exit()
```

### 🔍 متد جادویی `.get_rect()` چیست؟

وقتی یک تصویر را در Pygame بارگذاری می‌کنی، متد `get_rect()` یک مستطیل نامرئی با همان طول و عرض دقیق تصویر برایت می‌سازد. از این به بعد، به جای اینکه موقعیت تصویر را دستی کنترل کنی، مختصات این مستطیل فرضی را تغییر می‌دهی و پایتون تصویر را دقیقاً روی آن می‌چسباند. این بهترین ترفند برای تشخیص برخورد تصاویر است!

```python
# بارگذاری تصویر
image = pygame.image.load("player.png").convert_alpha()

# گرفتن مستطیل تصویر
rect = image.get_rect()
rect.x = 100
rect.y = 200

# حالا می‌تونی برخورد رو با rect بررسی کنی
if rect.colliderect(other_rect):
    print("برخورد!")

# و تصویر رو در موقعیت rect بچسبونی
screen.blit(image, rect)
```

### 🎨 تبدیل و تغییر اندازه تصاویر (`transform`)

پایتون ابزارهای قدرتمندی برای تغییر تصاویر داره:

```python
# تغییر اندازه
scaled = pygame.transform.scale(image, (100, 100))

# چرخش تصویر (با زاویه)
rotated = pygame.transform.rotate(image, 45)  # ۴۵ درجه

# آینه‌ای کردن
flipped = pygame.transform.flip(image, True, False)  # افقی
flipped = pygame.transform.flip(image, False, True)  # عمودی

# ترکیب چند تغییر
combined = pygame.transform.scale(
    pygame.transform.rotate(image, 90),
    (50, 50)
)
```

### 📌 اشتباهات رایج در این درس

> **🔴 فراموش کردن `.convert_alpha()` برای تصاویر با شفافیت:**
```python
# ❌ تصویر با لبه‌های سفید یا شفافیت نادرست
image = pygame.image.load("player.png")

# ✅ برای تصاویر PNG با شفافیت
image = pygame.image.load("player.png").convert_alpha()

# ✅ برای تصاویر بدون شفافیت (JPG)
image = pygame.image.load("bg.jpg").convert()
```

> **🟡 فراموش کردن به‌روزرسانی Rect بعد از تغییر تصویر:**
```python
# ❌ بعد از چرخش، مستطیل قدیمی‌ست
rotated = pygame.transform.rotate(image, 45)
screen.blit(rotated, rect)  # موقعیت اشتباه

# ✅ مستطیل جدید بگیر
rotated = pygame.transform.rotate(image, 45)
new_rect = rotated.get_rect(center=rect.center)
screen.blit(rotated, new_rect)
```

> **🟢 استفاده از تصاویر با اندازه‌ی خیلی بزرگ:**
```python
# ❌ تصویر ۴۰۰۰×۴۰۰۰ باعث کندی میشه
image = pygame.image.load("huge.png")

# ✅ حتماً اندازه رو تغییر بده
image = pygame.transform.scale(image, (50, 50))
```

### 🛠️ نوبت توئه: چالش پس‌زمینه فضایی بازی!

بیا آخرین قطعه از پازل بازی‌سازی‌مان را هم حل کنیم تا اولین مینی‌بازی کامل، صدادار و گرافیکی‌ات را تحویل بگیری.

**صورت مسئله:**

1. کدهای بالا را به همراه تصاویر بازیکن و سکه اجرا کن و از دیدن گرافیک جدید بازی لذت ببر.
2. یک تصویر پس‌زمینه زیبا (مثلاً یک تصویر از کهکشان یا آسمان پر از ستاره) با ابعاد ۸۰۰×۶۰۰ پیکسل به نام `background.png` پیدا کن.
3. این تصویر را در کدت بارگذاری کن (مثلاً به نام `bg_image`).
4. در بخش نقاشی، به جای پاک کردن صفحه با رنگ ساده (`screen.fill`), تصویر پس‌زمینه را در مختصات `(0, 0)` روی صفحه بچسبان (`blit`).

### 💪 چالش دوم (اختیاری - برای هنرمندان بازی‌سازی!)

حالا که با تصاویر آشنا شدی، یه **بازی کامل با شخصیت‌های متحرک** بساز:

1. **سه کاراکتر مختلف:**
   - بازیکن (با تصویر سفینه یا کاراکتر اصلی)
   - سکه‌های طلایی (با تصویر سکه)
   - دشمنان (با تصویر دشمن - ۳ تا دشمن در صفحه حرکت کنن)

2. **چرخش و انیمیشن ساده:**
   - سکه‌ها هر فریم ۵ درجه بچرخن (با `pygame.transform.rotate()`)
   - دشمن‌ها بالا و پایین برن (حرکت موجی با `math.sin()`)

3. **جلوه‌های ویژه:**
   - وقتی بازیکن سکه می‌گیره، سکه با انیمیشن ناپدید بشه (با کاهش اندازه)
   - وقتی بازیکن به دشمن می‌خوره، یک جان کم بشه

4. **سیستم جان‌ها با نمایش قلب:**
   - ۳ جان با نمایش قلب ❤️❤️❤️ روی صفحه
   - با هر برخورد با دشمن، یک قلب کم بشه

5. **پس‌زمینه‌ی متحرک:**
   - ستاره‌های کوچک با سرعت کم حرکت کنن (با استفاده از لیستی از ستاره‌ها)

> **💡 نکته:** برای چرخش سکه‌ها:
```python
# در هر فریم
coin_angle += 5
rotated_coin = pygame.transform.rotate(coin_image, coin_angle)
new_rect = rotated_coin.get_rect(center=coin_rect.center)
screen.blit(rotated_coin, new_rect)
```
