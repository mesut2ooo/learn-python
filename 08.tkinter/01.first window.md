# 🖥️ فصل هشتم: برنامه‌های دسکتاپ با Tkinter

## 🎯 درس ۸.۱: اولین پنجره (First Window)

---

### 🪟 Tkinter چیست و چرا از آن استفاده می‌کنیم؟

تا الان تمام برنامه‌هایی که نوشتیم، فقط توی ترمینال (همون صفحه‌ی سیاه و سفید) اجرا می‌شدن. ولی توی دنیای واقعی، کاربران با **برنامه‌های گرافیکی (GUI)** سروکار دارن؛ برنامه‌هایی که پنجره دارن، دکمه دارن، فیلد ورودی دارن و با کلیک و تایپ کار می‌کنن.

**Tkinter** یکی از کتابخانه‌های استاندارد پایتونه که بهت اجازه می‌ده برنامه‌های گرافیکی (دسکتاپ) با ظاهر حرفه‌ای بسازی. بهترین بخشش اینه که **همراه با خود پایتون نصب می‌شه** و نیازی به نصب جداگانه نداره!

> **📌 نکته:** Tkinter شاید جدیدترین و زیباترین کتابخانه‌ی GUI نباشه، ولی به خاطر سادگی، همراه بودن با پایتون و فراگیری، بهترین انتخاب برای شروع هست.

---

### 💻 ساختن اولین پنجره

بیا ساده‌ترین برنامه‌ی گرافیکی ممکن رو بنویسیم؛ یک پنجره‌ی خالی که فقط وجود داره!

```python
# وارد کردن کتابخانه Tkinter
import tkinter as tk

# ساختن یک پنجره (نمونه‌ای از کلاس Tk)
window = tk.Tk()

# تنظیم عنوان پنجره
window.title("اولین پنجره من")

# تنظیم اندازه پنجره (عرض x ارتفاع)
window.geometry("400x300")

# اجرای حلقه‌ی اصلی برنامه (تا زمانی که کاربر پنجره رو نبنده)
window.mainloop()
```

**خروجی:** یک پنجره‌ی خالی با عنوان "اولین پنجره من" و اندازه‌ی ۴۰۰ در ۳۰۰ پیکسل.

> **📌 نکته:** خط `window.mainloop()` خیلی مهمه! این خط برنامه رو در یک حلقه‌ی بی‌نهایت نگه می‌داره تا پنجره باز بمونه. بدون این خط، پنجره برای کسری از ثانیه باز میشه و می‌بنده!

---

### 🧩 اجزای اصلی Tkinter

هر برنامه‌ی Tkinter از سه بخش اصلی تشکیل شده:

| بخش | توضیح | مثال در کد |
|-----|-------|-----------|
| **پنجره (Window)** | ظرف اصلی برنامه | `window = tk.Tk()` |
| **ویجت‌ها (Widgets)** | اجزای داخل پنجره (دکمه، برچسب، ورودی...) | `label = tk.Label(window, text="سلام")` |
| **مدیریت چیدمان (Layout)** | چطور ویجت‌ها رو مرتب کنیم | `label.pack()` |

### 🎨 تنظیمات پایه‌ی پنجره

#### ۱. تغییر عنوان پنجره

```python
window.title("عنوان دلخواه شما")
```

#### ۲. تغییر اندازه‌ی پنجره

```python
# اندازه ثابت (عرض x ارتفاع)
window.geometry("500x400")

# اندازه با موقعیت (عرض x ارتفاع + موقعیت x + موقعیت y)
window.geometry("500x400+100+50")  # ۱۰۰ پیکسل از چپ، ۵۰ پیکسل از بالا
```

#### ۳. غیرقابل تغییر کردن اندازه

```python
window.resizable(False, False)  # عرض و ارتفاع قابل تغییر نیست
# window.resizable(True, False) # فقط عرض قابل تغییره
# window.resizable(False, True) # فقط ارتفاع قابل تغییره
```

#### ۴. تغییر رنگ پس‌زمینه

```python
window.configure(bg="lightblue")  # با نام رنگ
# یا با کد هگزادسیمال
window.configure(bg="#FF5733")
```

### 📝 مثال کامل: پنجره‌ی خوش‌آمدگویی

```python
import tkinter as tk

# ساخت پنجره
window = tk.Tk()

# تنظیمات پنجره
window.title("برنامه خوش‌آمدگویی")
window.geometry("400x200")
window.configure(bg="#f0f0f0")
window.resizable(False, False)

# اضافه کردن یک برچسب (Label)
label = tk.Label(
    window, 
    text="به برنامه‌ی من خوش آمدید!", 
    font=("Arial", 16),
    bg="#f0f0f0",
    fg="#333333"
)
label.pack(pady=50)  # pady = فاصله از بالا و پایین

# اضافه کردن یک دکمه (Button)
button = tk.Button(
    window,
    text="بستن",
    command=window.quit,  # وقتی کلیک شد، پنجره بسته میشه
    width=15,
    height=2
)
button.pack()

# اجرای برنامه
window.mainloop()
```

### 📌 اشتباهات رایج در این درس

> **🔴 فراموش کردن `window.mainloop()`:**
```python
window = tk.Tk()
window.title("پنجره")
# ❌ هیچ mainloop ای وجود نداره! پنجره فوری بسته میشه
```

> **🟡 فراموش کردن `import tkinter as tk`:**
```python
# ❌ خطا! tk تعریف نشده
window = tk.Tk()

import tkinter as tk  # ✅ باید اول وارد کنی
```

> **🟢 استفاده از `pack()` بعد از `mainloop()`:**
```python
window.mainloop()
label.pack()  # ❌ این خط هرگز اجرا نمیشه!
```

> **🟣 فراموش کردن `window` به عنوان والد (parent) ویجت‌ها:**
```python
label = tk.Label(text="سلام")  # ❌ به پنجره وصل نشده
label = tk.Label(window, text="سلام")  # ✅ درسته
```

### 🛠️ نوبت توئه: چالش طراحی پنجره‌ی پروفایل کاربر!

بیا یک پنجره‌ی ساده برای نمایش اطلاعات یک کاربر طراحی کنیم.

**صورت مسئله:**

1. یک پنجره با عنوان `"پروفایل کاربر"` بساز.
2. اندازه‌ی پنجره رو `500x300` تنظیم کن.
3. پس‌زمینه‌ی پنجره رو به رنگ `#e8f4f8` (آبی روشن) تنظیم کن.
4. پنجره رو غیرقابل تغییر اندازه کن.
5. یک برچسب (Label) با متن `"سلام! من احمد هستم"` با فونت `("Arial", 18)` و رنگ `#2c3e50` به پنجره اضافه کن.
6. یک برچسب دیگه با متن `"علاقه‌مند به برنامه‌نویسی پایتون"` با فونت `("Arial", 12)` و رنگ `#7f8c8d` اضافه کن.
7. از `pack()` با `pady=10` برای فاصله‌گذاری استفاده کن.
8. یک دکمه با متن `"خروج"` اضافه کن که با کلیک، پنجره رو ببنده.

### 💪 چالش دوم (اختیاری - برای طراحان رابط کاربری!)

حالا که با پنجره‌ها آشنا شدی، یه پنجره‌ی **داشبورد مدیریت** طراحی کن:

1. پنجره با عنوان `"داشبورد مدیریت"` و اندازه `800x500`.

2. سه بخش اصلی در پنجره داشته باش:
   - **هد (Header):** در بالا با عنوان `"سیستم مدیریت فروش"` با رنگ پس‌زمینه‌ی تیره و متن سفید
   - **منو (Menu):** در سمت چپ با چند دکمه (هر کدوم یه کار مجازی انجام بدن)
   - **محتوای اصلی (Content):** در سمت راست با اطلاعات نمایشی

3. رنگ‌ها و فونت‌ها رو به‌گونه‌ای انتخاب کن که حرفه‌ای به نظر برسه.

4. از `pack()` یا `grid()` برای چیدمان استفاده کن.

**راهنمایی:** می‌تونی از `Frame` برای گروه‌بندی بخش‌های مختلف استفاده کنی:

```python
# ایجاد یک فریم برای هدر
header = tk.Frame(window, bg="#2c3e50", height=80)
header.pack(fill="x")  # عرض کامل

# ایجاد یک فریم برای محتوای اصلی
content = tk.Frame(window, bg="#ecf0f1")
content.pack(fill="both", expand=True)  # کل فضای باقی‌مونده
```
