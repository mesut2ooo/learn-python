### 📦 دو ساختار داده‌ی جدید برای موقعیت‌های خاص

تا اینجا با دو تا از پرکاربردترین ابزارهای پایتون یعنی لیست‌ها (که مرتب و تغییرپذیر بودن) و دیکشنری‌ها (که بر اساس کلید و مقدار کار می‌کردن) آشنا شدی.

حالا بیا با دو تا ساختار داده‌ی دیگه آشنا بشیم که شاید کمتر از اون دو تا استفاده بشن، اما برای موقعیت‌های خاص حیاتی هستن: **تاپل‌ها (Tuples)** و **مجموعه‌ها (Sets)**.

---

### ۱. تاپل (Tuple) - لیست‌های غیرقابل تغییر!

تاپل‌ها خیلی شبیه لیست‌ها هستن با این تفاوت بزرگ که **بعد از ساخته شدن، دیگر نمی‌توانی اعضای آن‌ها را تغییر دهی، حذف کنی یا عضو جدیدی به آن‌ها اضافه کنی.** به این ویژگی در برنامه‌نویسی می‌گیم غیرقابل تغییر بودن یا *Immutable*.

#### تعریف تاپل

به جای براکت، از پرانتز معمولی `( )` استفاده می‌کنه:

```python
# تعریف مختصات یک نقطه (طول و عرض جغرافیایی)
location = (35.6892, 51.3890)

# تعریف رنگ RGB (سه مقدار بین ۰ تا ۲۵۵)
rgb_color = (255, 128, 0)

# تعریف روزهای هفته
week_days = ("شنبه", "یکشنبه", "دوشنبه", "سه‌شنبه", "چهارشنبه", "پنجشنبه", "جمعه")

# تاپل با یک عضو (کاما رو یادت نره!)
single_tuple = (5,)  # اگه کاما نذاری، فقط یه عدد هست نه تاپل!
```

#### دسترسی به اعضا

دقیقاً مثل لیست با اندیس انجام میشه:

```python
location = (35.6892, 51.3890)
print(location[0])  # خروجی: 35.6892 (طول)
print(location[1])  # خروجی: 51.3890 (عرض)

# اندیس‌های منفی هم مثل لیست کار می‌کنن
print(location[-1])  # خروجی: 51.3890
```

#### چرا تاپل؟ (مزایا)

1. **امنیت:** داده‌های حساس رو از تغییر تصادفی محافظت می‌کنه
2. **سرعت:** چون غیرقابل‌تغییره، پایتون می‌تونه سریع‌تر باهاش کار کنه
3. **کاربرد به عنوان کلید در دیکشنری:** چون غیرقابل‌تغییره، می‌تونه کلید دیکشنری باشه (لیست‌ها نمی‌تونن!)

#### کاربردهای واقعی تاپل

```python
# مختصات GPS
gps_coords = (35.6892, 51.3890)

# تنظیمات ثابت برنامه
config = ("production", "https://api.site.com", 443)

# تاریخ (سال، ماه، روز)
today = (1403, 7, 15)

# دیکشنری با کلید تاپل (ذخیره دمای هر نقطه)
temperatures = {
    (35.6892, 51.3890): 22.5,
    (35.7000, 51.4000): 23.1
}
```

### ۲. مجموعه (Set) - بدون تکرار و بی‌نظم!

مجموعه در پایتون دقیقاً مثل مجموعه در ریاضیه. دو تا ویژگی خیلی خاص داره:

1. **عضو تکراری قبول نمی‌کنه:** اگر ۱۰ بار هم یک عضو رو بهش اضافه کنی، فقط یک‌بار نگهش می‌داره.
2. **ترتیب نداره (Unordered):** اعضا اندیس ندارن (نمی‌تونی بگی عضو اول رو بده) و جاشون مدام تغییر می‌کنه.

#### تعریف مجموعه

از آکارد `{ }` استفاده می‌کنه (اما مثل دیکشنری جفتِ کلید-مقدار نیست، فقط مقادیر تکی هستن):

```python
# تعریف یک مجموعه از اعداد
numbers_set = {1, 2, 3, 4, 5}

# تعریف مجموعه از رشته‌ها
fruits_set = {"apple", "banana", "cherry"}

# مجموعه خالی (نکته: {} دیکشنریه، برای مجموعه خالی از set() استفاده کن)
empty_set = set()
# empty_dict = {}  # این دیکشنریه، نه مجموعه!
```

#### ویژگی حذف تکراری‌ها

```python
# تعریف یک مجموعه با اعداد تکراری
numbers_set = {1, 2, 2, 3, 4, 4, 5}
print(numbers_set)  # خروجی: {1, 2, 3, 4, 5} (تکراری‌ها حذف شدن)

# اضافه کردن عضو تکراری
numbers_set.add(2)  # تاثیری نداره چون ۲ وجود داره
print(numbers_set)  # خروجی: {1, 2, 3, 4, 5}
```

#### عملیات‌های مجموعه‌ای (مثل ریاضی!)

```python
set_a = {1, 2, 3, 4}
set_b = {3, 4, 5, 6}

# اجتماع (Union) - همه اعضای هر دو مجموعه
print(set_a | set_b)  # خروجی: {1, 2, 3, 4, 5, 6}

# اشتراک (Intersection) - اعضای مشترک
print(set_a & set_b)  # خروجی: {3, 4}

# تفاضل (Difference) - اعضای set_a که در set_b نیستن
print(set_a - set_b)  # خروجی: {1, 2}

# تفاضل متقارن (Symmetric Difference) - اعضایی که فقط در یکی هستن
print(set_a ^ set_b)  # خروجی: {1, 2, 5, 6}
```

### 🆚 مقایسه چهار ساختار داده

| ویژگی | لیست (List) | تاپل (Tuple) | دیکشنری (Dict) | مجموعه (Set) |
|--------|-------------|--------------|----------------|--------------|
| ساختار | `[1, 2, 3]` | `(1, 2, 3)` | `{"a": 1}` | `{1, 2, 3}` |
| تغییرپذیر | ✅ بله | ❌ نه | ✅ بله | ✅ بله |
| ترتیبی | ✅ بله | ✅ بله | ❌ نه (از ۳.۷ به بعد بله) | ❌ نه |
| اندیس/کلید | اندیس عددی | اندیس عددی | کلید | بدون اندیس |
| اعضای تکراری | ✅ مجاز | ✅ مجاز | کلیدها منحصر | ❌ مجاز نیست |
| کاربرد اصلی | داده‌های ترتیبی | داده‌های ثابت | داده‌های برچسب‌دار | حذف تکراری‌ها |

---

### 🛠️ متدهای پرکاربرد مجموعه

| متد | کاربرد | مثال |
|-----|--------|------|
| `add(x)` | اضافه کردن عضو | `s.add(5)` |
| `remove(x)` | حذف عضو (خطا اگر نباشه) | `s.remove(5)` |
| `discard(x)` | حذف عضو (خطا نمیده اگه نباشه) | `s.discard(5)` |
| `x in s` | بررسی عضویت | `5 in s` |
| `len(s)` | تعداد اعضا | `len(s)` |
| `s1 \| s2` | اجتماع | `s1 \| s2` |
| `s1 & s2` | اشتراک | `s1 & s2` |
| `s1 - s2` | تفاضل | `s1 - s2` |

### 📌 اشتباهات رایج در این درس

> **🔴 فراموش کردن کاما در تاپل یک عضوی:**
```python
t = (5)    # ❌ این یه int هست، تاپل نیست!
t = (5,)   # ✅ درسته، یه تاپل با یک عضو
```

> **🟡 قاطی کردن مجموعه با دیکشنری:**
```python
s = {}     # ❌ این یه دیکشنریه، نه مجموعه!
s = set()  # ✅ درسته، مجموعه خالی
s = {1, 2} # ✅ درسته، مجموعه با دو عضو
```

> **🟢 تلاش برای دسترسی به اندیس در مجموعه:**
```python
s = {1, 2, 3}
print(s[0])  # ❌ خطا! مجموعه اندیس نداره
print(1 in s)  # ✅ درسته: عضویت رو بررسی کن
```

> **🟣 تلاش برای تغییر تاپل:**
```python
t = (1, 2, 3)
t[0] = 5   # ❌ خطا! تاپل غیرقابل‌تغییره
```

### 🛠️ نوبت توئه: چالش پاک‌سازی کدهای رهگیری!

فرض کن در بخش پردازش داده یک سیستم فروشگاهی کار می‌کنی و لیستی از کدهای رهگیری مرسوله‌ها بهت داده شده که به دلیل خطای سیستم، بعضی از کدها دو یا چند بار ثبت شدن. وظیفه تو اینه که کدهای تکراری رو حذف کنی.

**صورت مسئله:**

1. این لیست که حاوی کدهای تکراری هست رو تعریف کن:
   `tracking_ids = ["TRK102", "TRK205", "TRK102", "TRK309", "TRK205"]`

2. با استفاده از تبدیل نوع (شبیه کاری که با `int` و `str` می‌کردیم)، این لیست رو به یک مجموعه (`set`) تبدیل کن تا تکراری‌هاش خودبه‌خود پاک بشن. نتیجه رو توی یک متغیر جدید ذخیره کن.

3. در نهایت، با استفاده از `len()`، تعداد کدهای بی‌تکرار و منحصربه‌فرد رو چاپ کن.

### 💪 چالش دوم (اختیاری - برای تحلیلگران داده!)

حالا که با تاپل و مجموعه آشنا شدی، یه سیستم **تحلیل فروش** بساز:

1. یک لیست از فروش‌های روزانه داشته باش:
   `daily_sales = [120, 85, 120, 95, 85, 110, 95, 130, 120, 85]`

2. با استفاده از مجموعه، مبالغ منحصربه‌فرد فروش رو پیدا کن و چاپ کن.

3. با استفاده از تاپل، سه مقدار زیر رو ذخیره کن:
   - بیشترین فروش (با `max()`)
   - کمترین فروش (با `min()`)
   - میانگین فروش (با `sum() / len()`)

4. با حلقه `for` و مجموعه، تعداد روزهایی که فروش تکراری بوده رو حساب کن:
   - راهنمایی: فروش‌های تکراری یعنی مبالغی که بیش از یک بار تکرار شدن
   - مثلاً اگر فروش ۱۲۰ سه بار تکرار شده، یعنی ۳ روز فروش تکراری داشته‌ایم

5. خروجی رو به این شکل چاپ کن:

```text
لیست فروش: [120, 85, 120, 95, 85, 110, 95, 130, 120, 85]
مبالغ منحصربه‌فرد: {130, 95, 85, 110, 120}
بیشترین فروش: 130
کمترین فروش: 85
میانگین فروش: 104.5
تعداد روزهای با فروش تکراری: 7 روز
```

> **💡 نکته:** برای پیدا کردن مبالغ تکراری، می‌تونی از دو مجموعه استفاده کنی: یکی برای دیدن مبالغ، و یکی برای مبالغ تکراری. یا از روش شمارش با دیکشنری استفاده کنی.
