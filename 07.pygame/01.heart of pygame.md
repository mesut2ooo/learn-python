### 🎮 حلقه بازی یعنی چی؟

در تمام بازی‌های کامپیوتری، از ساده‌ترین بازی‌ها مثل Tetris گرفته تا سنگین‌ترین بازی‌های سه بعدی، یک مفهوم مشترک به نام **حلقه بازی (Game Loop)** وجود دارد.

یک بازی زنده است چون مدام در حال تکرار یک چرخه سه مرحله‌ای با سرعت بسیار بالا (مثلاً ۶۰ بار در ثانیه یا همان 60 FPS) است:

```
  ┌────────────────────────────────────────┐
  ▼                                        │
[۱. گرفتن ورودی‌های کاربر] -> [۲. به روز رسانی بازی] -> [۳. نقاشی مجدد صفحه]
(کلیک موس، دکمه‌های کیبورد)     (حرکت دشمن، محاسبه امتیاز)    (کشیدن تصاویر جدید)
```

> **📌 نکته:** اگر این حلقه ثانیه‌ای متوقف شود، بازی شما اصطلاحاً «فریز» یا کرش می‌کند. به همین دلیل، همیشه باید حلقه‌ی بازی رو با دقت طراحی کنی.

### 🏗️ ساختار پایه هر بازی Pygame

حالا که Pygame نصب شد، کدهای زیر رو در یک فایل جدید به نام `main.py` بنویس تا ساختار پایه و اسکلت اصلی تمام بازی‌های Pygame رو با هم بسازیم:

```python
import pygame
import sys

# ۱. راه‌اندازی و بیدار کردن تمام بخش‌های Pygame
pygame.init()

# ۲. تنظیمات صفحه نمایش (طول و عرض پنجره به پیکسل)
SCREEN_WIDTH = 800
SCREEN_HEIGHT = 600
screen = pygame.display.set_mode((SCREEN_WIDTH, SCREEN_HEIGHT))
pygame.display.set_caption("My First Pygame!")  # عنوان پنجره

# ۳. متغیر کنترل کننده حلقه اصلی بازی
is_running = True

# ۴. شروع حلقه تپنده بازی (Game Loop)
while is_running:
    
    # --- بخش اول: مدیریت رویدادها (Event Handling) ---
    # پایتون تمام کارهایی که کاربر انجام میده (مثل تکان دادن موس یا فشردن کلید) را در یک صف نگه می‌داره
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            # اگر کاربر دکمه ضربدر قرمز پنجره را زد
            is_running = False

    # --- بخش دوم: به روز رسانی منطق بازی (Update) ---
    # فعلاً تغییری در موقعیت اجسام نداریم...

    # --- بخش سوم: نقاشی روی صفحه (Render / Draw) ---
    # رنگ‌آمیزی پس‌زمینه با رنگ مشکی (سیستم رنگی RGB)
    screen.fill((0, 0, 0)) 

    # به روز رسانی و نمایش تمام تغییرات روی مانیتور کاربر
    pygame.display.flip()

# ۵. خروج ایمن از بازی در صورت بسته شدن حلقه
pygame.quit()
sys.exit()
```

---

### 🔍 کدهای بالا چطور کار می‌کنند؟

| بخش                                | توضیح                                                                                                                   |
| ---------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| **`pygame.init()`**                | موتور بازی‌سازی را استارت می‌زند. بدون این خط، بخش‌هایی مثل صدا یا گرافیک کار نخواهند کرد.                              |
| **`pygame.display.set_mode()`**    | پنجره‌ی بازی رو با اندازه‌ی مشخص می‌سازه.                                                                               |
| **`pygame.display.set_caption()`** | عنوانی که بالای پنجره نشون داده میشه رو تنظیم می‌کنه.                                                                   |
| **`pygame.event.get()`**           | لیست تمام کارهایی که کاربر در آن لحظه انجام داده (کلیک‌ها، فشردن دکمه‌ها) را بررسی می‌کند.                              |
| **`event.type == pygame.QUIT`**    | چک می‌کنه که آیا کاربر روی دکمه ضربدر (خروج) کلیک کرده یا نه.                                                           |
| **`screen.fill((R, G, B))`**       | صفحه را با رنگ مشخص پاک می‌کند. سیستم رنگی RGB (قرمز، سبز، آبی) با مقادیر ۰ تا ۲۵۵.                                     |
| **`pygame.display.flip()`**        | مثل ورق زدن یک دفترچه نقاشی متحرک است. تمام کارهایی که در پس‌زمینه کشیده‌ایم را یک‌جا روی مانیتور به کاربر نشان می‌دهد. |
| **`pygame.quit()`**                | تمیز کردن و خروج ایمن از تمام بخش‌های Pygame.                                                                           |

### 🎨 سیستم رنگی RGB در Pygame

در کامپیوتر، هر رنگ از ترکیب سه رنگ اصلی ساخته میشه:

| رنگ        | مقدار RGB         | مثال |
| ---------- | ----------------- | ---- |
| سیاه       | `(0, 0, 0)`       | 🌑   |
| سفید       | `(255, 255, 255)` | ☁️   |
| قرمز       | `(255, 0, 0)`     | ❤️   |
| سبز        | `(0, 255, 0)`     | 🌿   |
| آبی        | `(0, 0, 255)`     | 💧   |
| زرد        | `(255, 255, 0)`   | 🌟   |
| بنفش       | `(255, 0, 255)`   | 🟣   |
| آبی آسمانی | `(135, 206, 235)` | 🌤️  |
| نارنجی     | `(255, 165, 0)`   | 🍊   |

```python
# مثال‌های رنگ در کد
screen.fill((0, 0, 0))           # سیاه
screen.fill((255, 255, 255))     # سفید
screen.fill((135, 206, 235))     # آبی آسمانی
screen.fill((255, 0, 0))         # قرمز
screen.fill((0, 255, 0))         # سبز
```

### 📌 اشتباهات رایج در این درس

> **🔴 فراموش کردن `pygame.init()`:**
```python
import pygame
screen = pygame.display.set_mode((800, 600))  # ❌ خطا! pygame.init() نشده
```

> **🟡 فراموش کردن `pygame.display.flip()`:**
```python
while running:
    screen.fill((0, 0, 0))
    # ❌ flip() فراموش شده → صفحه سیاه می‌مونه
```

> **🟢 فراموش کردن `pygame.quit()`:**
```python
# ❌ وقتی برنامه بسته میشه، منابع آزاد نمیشن
pygame.quit()  # ✅ همیشه در انتها فراموش نکن
```

> **🟣 استفاده از حلقه‌های سنگین داخل Game Loop:**
```python
while running:
    # ❌ حلقه‌های سنگین مثل time.sleep() باعث لگ بازی میشن
    time.sleep(1)  # بازی رو به شدت کند می‌کنه!
```

### 🛠️ نوبت توئه: چالش تغییر رنگ پس‌زمینه!

بیا اولین تغییر شخصی‌سازی شده‌ات را روی موتور بازی‌ات اعمال کنی.

**صورت مسئله:**

1. کدهای بالا را به طور کامل در یک فایل کپی و اجرا کن تا مطمئن شوی پنجره سیاه رنگ بازی بدون مشکل باز می‌شود.
2. با دستکاری مقدار داخل متد `screen.fill()`، رنگ پس‌زمینه بازی را به یک **آبی آسمانی ملایم** یا **قرمز پررنگ** تغییر بده.
   *(راهنمایی: سیستم رنگی RGB مقادیری بین 0 تا 255 می‌گیرد. مثلاً `(255, 0, 0)` رنگ قرمز خالص و `(0, 0, 255)` رنگ آبی خالص است).*
3. عنوان پنجره بازی را از `"My First Pygame!"` به `"پروژه بازی‌سازی من"` تغییر بده.

### 💪 چالش دوم (اختیاری - برای طراحان بازی!)

حالا که با حلقه بازی آشنا شدی، یه پنجره با مشخصات زیر بساز:

1. اندازه‌ی پنجره: ۱۰۲۴ × ۷۶۸ پیکسل
2. عنوان: `"ماجراجویی پایتون"`
3. رنگ پس‌زمینه: یه رنگ **بنفش تیره** یا **سبز جنگلی** (خودت انتخاب کن)

4. یه متغیر به اسم `frame_count` تعریف کن که هر بار حلقه اجرا میشه، یکی بهش اضافه بشه.

5. توی بخش Update، هر ۶۰ بار که حلقه اجرا شد (یعنی هر ۱ ثانیه)، یه پیام توی ترمینال چاپ کن:
   ```
   🔄 حلقه شماره 60: بازی در حال اجراست...
   ```

> **💡 نکته:** برای تشخیص ۶۰ بار، از `%` (باقیمانده) استفاده کن:
```python
frame_count = 0
while running:
    frame_count += 1
    if frame_count % 60 == 0:
        print("1 ثانیه گذشت!")
```
