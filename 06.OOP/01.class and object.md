# 🎥 فصل ششم: شی‌گرایی (OOP)

## 🎯 درس ۶.۱: مفهوم کلاس (Class) و شیء (Object)

---

### 🏗️ کلاس و شیء یعنی چی؟

توی دنیای واقعی، ما دور و برمون کلی «شیء» می‌بینیم؛ مثل گوشی تلفن، ماشین، یا حتی خودِ انسان‌ها. هر کدوم از این‌ها از روی یک نقشه یا قالب خاص ساخته شدن.

برای درک بهتر، این دو اصطلاح کلیدی رو به ذهن بسپار:

| مفهوم | تعریف | مثال |
|-------|-------|------|
| **کلاس (Class)** | قالب، نقشه ساختمانی یا دستورالعمل ساخت یک چیز | نقشه‌ی فنی یک خودرو |
| **شیء (Object)** | محصول واقعی و فیزیکی که از روی اون نقشه ساخته شده | خودروی پراید سفید رونمایی‌شده |

> **📌 تشبیه ساده:** 
> - کلاس مثل **قالب کلوچه** هست. خود قالب کلوچه نیست، ولی شکل کلوچه رو مشخص می‌کنه.
> - شیء مثل **خود کلوچه‌ای** هست که با اون قالب پخته شده. هر کلوچه ممکنه کمی با بقیه فرق داشته باشه (مثلاً یکی بیشتر پخته شده باشه)، ولی همه از یه قالب ساخته شدن.

---

### 💻 چطور در پایتون یک کلاس بسازیم؟

برای تعریف کلاس از کلمه کلیدی `class` استفاده می‌کنیم. بر اساس یک استاندارد جهانی، اسم کلاس‌ها رو با حرف بزرگ شروع می‌کنیم (کدنویسی پاسکال - PascalCase).

```python
# تعریف نقشه یا همان کلاس خودرو
class Car:
    pass  # کلمه pass یعنی فعلاً کدی اینجا نیست و پایتون ارور نمیده
```

> **💡 نکته:** `pass` یک کلمه کلیدی در پایتونه که یعنی «هیچ کاری نکن». ازش وقتی استفاده می‌کنیم که می‌خوایم یه بلوک کد خالی داشته باشیم (مثلاً کلاسی که هنوز تکمیل نشده).

---

### 🏗️ چطور از روی کلاس، شیء بسازیم؟

حالا چطور از روی این نقشه، یک خودروی واقعی (شیء) بسازیم؟ کافیه اسم کلاس رو بنویسیم و جلوش پرانتز باز و بسته بذاریم:

```python
# ساختن دو خودروی واقعی از روی نقشه Car
car_one = Car()
car_two = Car()

print(type(car_one))  # خروجی: <class '__main__.Car'>
print(type(car_two))  # خروجی: <class '__main__.Car'>
```

الان ما دو تا خودروی کاملاً مستقل توی حافظه سیستم داریم که از روی نقشه `Car` ساخته شدن.

---

### 🆚 تفاوت کلاس و شیء (در یک نگاه)

| ویژگی | کلاس (Class) | شیء (Object) |
|--------|--------------|---------------|
| تعریف | نقشه و قالب | محصول نهایی |
| وجود | انتزاعی (در کد) | واقعی (در حافظه) |
| تعداد | یک بار تعریف میشه | بی‌نهایت می‌تونه ساخته بشه |
| مثال | `class Car:` | `my_car = Car()` |
| حافظه | اشغال نمی‌کنه | حافظه اشغال می‌کنه |

---

### 🎯 شیءها کاملاً مستقل هستن!

هر شیء که از یک کلاس ساخته میشه، کاملاً مستقل از شیءهای دیگه‌ست. تغییر در یکی، روی دیگری تأثیری نداره:

```python
class Car:
    pass

# ساختن دو خودرو
car1 = Car()
car2 = Car()

# هر کدوم یک آدرس حافظه‌ی متفاوت دارن
print(id(car1))  # خروجی: یک عدد مثل 140234567890
print(id(car2))  # خروجی: یک عدد متفاوت مثل 140234567999
```

### 📌 اشتباهات رایج در این درس

> **🔴 فراموش کردن دو نقطه (`:`) بعد از اسم کلاس:**
```python
class Car  # ❌ خطا! دو نقطه فراموش شده
class Car:  # ✅ درسته
```

> **🟡 نوشتن اسم کلاس با حرف کوچک:**
```python
class car:  # ❌ بر خلاف استاندارد (باید با حرف بزرگ باشه)
class Car:  # ✅ استاندارد (PascalCase)
```

> **🟢 فراموش کردن `()` موقع ساختن شیء:**
```python
my_car = Car  # ❌ این فقط اسم کلاس رو کپی می‌کنه، شیء نمی‌سازه!
my_car = Car()  # ✅ درسته
```

> **🟣 گذاشتن `pass` بیرون از کلاس:**
```python
class Car:
    # pass  # ❌ pass باید توی بدنه باشه
pass  # ❌ اینجا pass ربطی به کلاس نداره
```

### 🛠️ نوبت توئه: چالش نقشه ساخت خانه!

بیا اولین کلاس خودت رو طراحی کنی تا منطق ساخت شیء از روی نقشه برات کاملاً جا بیفته.

**صورت مسئله:**

1. یک کلاس (نقشه) به نام `House` (با حرف H بزرگ) تعریف کن. داخل بدنه کلاس فقط کلمه `pass` رو بنویس.
2. بیرون از کلاس، سه شیء (خانه واقعی) به نام‌های زیر از روی این کلاس بساز:
   - `house_a`
   - `house_b`
   - `house_c`
3. با استفاده از دستور `print` و `type()`، جنسِ متغیر `house_a` رو چاپ کن تا ببینی پایتون چطور اون رو به عنوان یک شیء از کلاس `House` می‌شناسه.

### 💪 چالش دوم (اختیاری - برای معماران نرم‌افزار!)

حالا که با کلاس و شیء آشنا شدی، دو کلاس بساز و از هر کدوم چند شیء تولید کن:

1. **کلاس `Book`** (نقشه‌ی کتاب)
   - فقط `pass` داخلش بذار

2. **کلاس `Laptop`** (نقشه‌ی لپ‌تاپ)
   - فقط `pass` داخلش بذار

3. از کلاس `Book` سه شیء بساز:
   - `book1`، `book2`، `book3`

4. از کلاس `Laptop` دو شیء بساز:
   - `laptop1`، `laptop2`

5. با `print` و `type()`، نوع هر دو شیء رو چاپ کن و ببین چطور پایتون اون‌ها رو تشخیص میده.

6. با `print(id())`، آدرس حافظه‌ی همه‌ی اشیاء رو چاپ کن و ببین که هر کدوم یه آدرس متفاوت دارن.

**نمونه خروجی:**
```text
نوع book1: <class '__main__.Book'>
نوع book2: <class '__main__.Book'>
نوع book3: <class '__main__.Book'>
نوع laptop1: <class '__main__.Laptop'>
نوع laptop2: <class '__main__.Laptop'>

آدرس حافظه book1: 140234567890
آدرس حافظه book2: 140234567999
آدرس حافظه book3: 140234568001
آدرس حافظه laptop1: 140234568123
آدرس حافظه laptop2: 140234568456
```

> **💡 نکته:** `id()` آدرس حافظه‌ی یک شیء رو نشون میده. هر شیء آدرس منحصربه‌فرد خودش رو داره.
