### 📦 JSON یعنی چی؟

JSON (مخفف JavaScript Object Notation) یک فرمت سبک و پرکاربرد برای تبادل داده بین برنامه‌هاست. تقریباً همه‌ی APIهای مدرن از JSON برای ارسال و دریافت داده استفاده می‌کنن.

> **📌 تشبیه:** JSON مثل یک جعبه‌ی استاندارده که همه‌ی برنامه‌ها (پایتون، جاوااسکریپت، جاوا و...) می‌تونن باهاش کار کنن. توی پایتون، JSON خیلی شبیه به دیکشنری‌ها و لیست‌هاست!

---

### 🆚 مقایسه JSON و دیکشنری پایتون

**دیکشنری پایتون:**
```python
user = {
    "name": "احمد",
    "age": 25,
    "city": "تهران"
}
```

**JSON معادل:**
```json
{
    "name": "احمد",
    "age": 25,
    "city": "تهران"
}
```

> **💡 نکته:** تفاوت اصلی اینه که JSON یک **رشته (String)** هست، در حالی که دیکشنری یک **شیء (Object)** در پایتونه!

---

### 💻 تبدیل دیکشنری به JSON و برعکس

پایتون یک ماژول داخلی به اسم `json` داره که کار تبدیل رو انجام میده:

```python
import json

# ========== ۱. تبدیل دیکشنری به JSON (json.dumps) ==========
user_dict = {
    "name": "احمد",
    "age": 25,
    "city": "تهران",
    "is_active": True,
    "scores": [18, 19, 17]
}

# تبدیل به JSON (رشته)
json_string = json.dumps(user_dict, ensure_ascii=False, indent=2)
print("📤 دیکشنری به JSON:")
print(json_string)

print("\n" + "="*50 + "\n")

# ========== ۲. تبدیل JSON به دیکشنری (json.loads) ==========
json_data = '{"name": "سارا", "age": 30, "city": "اصفهان"}'

# تبدیل به دیکشنری
python_dict = json.loads(json_data)
print("📥 JSON به دیکشنری:")
print(python_dict)
print(f"نام: {python_dict['name']}")
print(f"سن: {python_dict['age']}")
```

---

### 🔍 پارامترهای مهم `json.dumps()`

| پارامتر | توضیح | مثال |
|---------|-------|------|
| `ensure_ascii=False` | پشتیبانی از فارسی و یونیکد | `json.dumps(data, ensure_ascii=False)` |
| `indent=2` | فرمت‌دهی زیبا با تورفتگی | `json.dumps(data, indent=2)` |
| `sort_keys=True` | مرتب‌سازی کلیدها | `json.dumps(data, sort_keys=True)` |

### 💾 ذخیره و خواندن JSON از فایل

```python
import json

# ========== ذخیره دیکشنری در فایل JSON ==========
data = {
    "users": [
        {"name": "احمد", "age": 25},
        {"name": "سارا", "age": 30},
        {"name": "علی", "age": 22}
    ],
    "total": 3
}

# نوشتن در فایل
with open("data.json", "w", encoding="utf-8") as file:
    json.dump(data, file, ensure_ascii=False, indent=2)

print("✅ داده‌ها در فایل data.json ذخیره شد.")

# ========== خواندن JSON از فایل ==========
with open("data.json", "r", encoding="utf-8") as file:
    loaded_data = json.load(file)

print("\n📥 داده‌های خوانده شده:")
for user in loaded_data["users"]:
    print(f"👤 {user['name']} - {user['age']} سال")
```

### 📌 اشتباهات رایج در این درس

> **🔴 فراموش کردن `ensure_ascii=False` برای فارسی:**
```python
# ❌ فارسی خراب میشه: {"name": "\u0627\u062d\u0645\u062f"}
json.dumps({"name": "احمد"})

# ✅ فارسی درست: {"name": "احمد"}
json.dumps({"name": "احمد"}, ensure_ascii=False)
```

> **🟡 فراموش کردن `encoding="utf-8"` در فایل:**
```python
# ❌ ممکنه فارسی خراب بشه
with open("data.json", "w") as file:

# ✅ درسته
with open("data.json", "w", encoding="utf-8") as file:
```

> **🟢 قاطی کردن `json.dump()` با `json.dumps()`:**
```python
# json.dump: نوشتن در فایل
json.dump(data, file)

# json.dumps: تبدیل به رشته
json_string = json.dumps(data)
```

> **🟣 قاطی کردن `json.load()` با `json.loads()`:**
```python
# json.load: خواندن از فایل
data = json.load(file)

# json.loads: خواندن از رشته
data = json.loads(json_string)
```

### 🛠️ نوبت توئه: مدیریت داده‌های کاربران با JSON!

بیا یک برنامه‌ی ساده برای ذخیره و بازیابی اطلاعات کاربران با JSON بنویسیم.

**صورت مسئله:**

1. یک دیکشنری از اطلاعات ۳ کاربر بساز (نام، سن، ایمیل).

2. با `json.dumps()` دیکشنری رو به JSON تبدیل کن و چاپ کن (با فرمت‌دهی زیبا و پشتیبانی از فارسی).

3. JSON رو توی فایل `users.json` ذخیره کن.

4. فایل رو بخون و با `json.loads()` دوباره به دیکشنری تبدیل کن.

5. نام و سن همه‌ی کاربران رو چاپ کن.

### 💪 چالش دوم (اختیاری - برای توسعه‌دهندگان API!)

حالا که با JSON آشنا شدی، یه **سیستم مدیریت تنظیمات** با JSON بساز:

1. یک فایل `config.json` با این محتوا بساز:
   ```json
   {
       "app_name": "MyApp",
       "version": "1.0.0",
       "theme": "dark",
       "language": "fa",
       "notifications": true,
       "users": [
           {"username": "admin", "role": "admin"},
           {"username": "guest", "role": "user"}
       ]
   }
   ```

2. یک برنامه بنویس که:
   - فایل `config.json` رو بخونه
   - وضعیت فعلی رو نمایش بده
   - از کاربر یک تنظیم جدید بگیره (مثلاً `theme` رو به `light` تغییر بده)
   - تنظیمات جدید رو توی فایل ذخیره کنه
   - دوباره فایل رو بخونه و تغییرات رو نمایش بده

3. از `json.load()` و `json.dump()` برای کار با فایل استفاده کن.
