### 🎨 نمایش متن در Pygame

در پایتون، نوشتن متن روی صفحه یک فرآیند ۳ مرحله‌ای است:

1. **ساخت فونت (Font Object):** انتخاب فونت و سایز آن.
2. **رندر کردن متن (Render):** تبدیل متن متنی به یک تصویر پیکسلی در حافظه (چون Pygame متن رو مستقیم نمی‌کشه، اول اون رو به تصویر تبدیل می‌کنه).
3. **چسباندن به صفحه (Blit):** انداختن آن تصویر روی مختصات دلخواه در صفحه بازی.

```
  متن ("Score: 10")
       ↓
  [رندر کردن] → تصویر پیکسلی
       ↓
  [screen.blit()] → چسباندن روی صفحه
```

---

### 💻 چطور امتیاز را روی صفحه نشان دهیم؟

بیا کدهای بازی جمع‌آوری سکه‌ات رو برداریم و سیستم نمایش امتیاز رو بهش اضافه کنیم:

```python
import pygame
import sys
import random

pygame.init()

SCREEN_WIDTH = 800
SCREEN_HEIGHT = 600
screen = pygame.display.set_mode((SCREEN_WIDTH, SCREEN_HEIGHT))
pygame.display.set_caption("بازی جمع‌آوری سکه با امتیاز")

# تعریف رنگ‌ها
BLACK = (0, 0, 0)
GREEN = (0, 255, 0)
YELLOW = (255, 215, 0)  # رنگ طلایی برای سکه
WHITE = (255, 255, 255)

# تعریف بازیکن و سکه
player_rect = pygame.Rect(100, 275, 50, 50)
coin_rect = pygame.Rect(400, 300, 20, 20)
player_speed = 7

# ۱. متغیر امتیاز
score = 0

# ۲. ایجاد فونت در پایتون (فونت پیش‌فرض سیستم با سایز ۳۶)
# پارامتر اول نام فونت است؛ None یعنی از فونت پیش‌فرض استفاده کن.
game_font = pygame.font.Font(None, 36)

clock = pygame.time.Clock()

is_running = True
while is_running:
    clock.tick(60)
    
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            is_running = False

    # حرکت بازیکن
    keys = pygame.key.get_pressed()
    if keys[pygame.K_LEFT]:
        player_rect.x -= player_speed
    if keys[pygame.K_RIGHT]:
        player_rect.x += player_speed
    if keys[pygame.K_UP]:
        player_rect.y -= player_speed
    if keys[pygame.K_DOWN]:
        player_rect.y += player_speed

    # محدودیت مرزهای صفحه
    if player_rect.left < 0:
        player_rect.left = 0
    if player_rect.right > SCREEN_WIDTH:
        player_rect.right = SCREEN_WIDTH
    if player_rect.top < 0:
        player_rect.top = 0
    if player_rect.bottom > SCREEN_HEIGHT:
        player_rect.bottom = SCREEN_HEIGHT

    # بررسی برخورد با سکه
    if player_rect.colliderect(coin_rect):
        score += 1
        # فرستادن سکه به یک مختصات تصادفی جدید
        coin_rect.x = random.randint(50, SCREEN_WIDTH - 50)
        coin_rect.y = random.randint(50, SCREEN_HEIGHT - 50)

    # --- نقاشی روی صفحه ---
    screen.fill(BLACK)
    
    # کشیدن بازیکن و سکه
    pygame.draw.rect(screen, GREEN, player_rect)
    pygame.draw.ellipse(screen, YELLOW, coin_rect)  # سکه رو به شکل بیضی/دایره می‌کشیم

    # ۳. رندر کردن متن امتیاز (تبدیل به تصویر)
    # پارامترها: متن، آنتی‌الیاسینگ (نرم کردن لبه‌ها)، رنگ متن
    score_text = game_font.render(f"Score: {score}", True, WHITE)
    
    # ۴. چسباندن تصویر متن روی صفحه در مختصات (10, 10) گوشه بالا سمت چپ
    screen.blit(score_text, (10, 10))

    pygame.display.flip()

pygame.quit()
sys.exit()
```

---

### 🔍 دستور جادویی `screen.blit` چیه؟

در دنیای گرافیک کامپیوتری، **Blit** مخفف Bit-Block Transfer است. به زبان ساده یعنی کپی کردن سریع پیکسل‌های یک تصویر روی یک تصویر دیگر. ما با این دستور، تصویرِ متنِ `score_text` رو روی تصویر اصلی بازی (`screen`) می‌چسبانیم.

### 📍 موقعیت‌دهی متن‌ها

برای موقعیت‌دهی دقیق متن، از `get_rect()` استفاده کن:

```python
# رندر کردن متن
text = font.render("Game Over!", True, RED)

# گرفتن مستطیل متن برای موقعیت‌دهی دقیق
text_rect = text.get_rect()
text_rect.center = (SCREEN_WIDTH // 2, SCREEN_HEIGHT // 2)

# چسباندن در مرکز صفحه
screen.blit(text, text_rect)
```

### 📌 اشتباهات رایج در این درس

> **🔴 فراموش کردن `screen.blit()` بعد از `render()`:**
```python
text = font.render("Hello", True, WHITE)
# ❌ text ساخته شده ولی روی صفحه نیست!
screen.blit(text, (10, 10))  # ✅ باید این کار رو انجام بدی
```

> **🟡 رندر کردن متن در هر فریم (کند شدن):**
```python
while running:
    # ❌ هر فریم متن رندر میشه (کند)
    text = font.render(f"Score: {score}", True, WHITE)

# ✅ بهتره فقط وقتی تغییر کرد، رندر کنی
```

> **🟢 فراموش کردن `pygame.display.flip()` بعد از `blit`:**
```python
screen.blit(text, (10, 10))
# ❌ flip() فراموش شده → متن دیده نمیشه
pygame.display.flip()  # ✅ باید باشه
```

> **🟣 استفاده از فونت ناموجود:**
```python
# ❌ اگه فونت وجود نداشته باشه خطا میده
font = pygame.font.Font("not_exists.ttf", 36)

# ✅ از None برای فونت پیش‌فرض استفاده کن
font = pygame.font.Font(None, 36)
```

### 🛠️ نوبت توئه: چالش شمارش معکوس و اتمام بازی!

بیا یک چالش هیجان‌انگیز به بازی اضافه کنیم تا تبدیل به یک مینی‌بازی کامل زمان‌دار بشه. می‌خوایم یک تایمر ۳۰ ثانیه‌ای بذاریم که ثانیه‌به‌ثانیه کم بشه و وقتی به صفر رسید، بازی تموم بشه.

**صورت مسئله:**

1. کدهای بالا رو اجرا کن و مطمئن شو امتیاز روی صفحه به خوبی نمایش داده میشه.
2. بیرون از حلقه بازی، یک متغیر برای ثبت زمان شروع به صورت میلی‌ثانیه تعریف کن:
   `start_ticks = pygame.time.get_ticks()`
3. داخل حلقه بازی، زمان باقی‌مانده رو بر حسب ثانیه حساب کن:
   `seconds_passed = (pygame.time.get_ticks() - start_ticks) / 1000`
   `time_left = 30 - int(seconds_passed)`
4. متن تایمر رو رندر کن (مثلاً: `f"Time: {time_left}"`) و با دستور `screen.blit` در بالا سمت راست صفحه (مثلاً مختصات `(650, 10)`) چاپ کن.
5. یک شرط بزرگ بنویس: **اگر** `time_left <= 0` شد، بازی به پایان برسه. (می‌تونی حلقه رو بشکنی `is_running = False` یا یک پیام `"Game Over!"` گنده وسط صفحه نمایش بدی!).

### 💪 چالش دوم (اختیاری - برای طراحان UI!)

حالا که با نمایش متن آشنا شدی، یه سیستم **HUD کامل** برای بازی بساز:

1. **امتیاز:** در گوشه‌ی بالا-چپ با رنگ سفید
2. **زمان باقی‌مانده:** در گوشه‌ی بالا-راست با رنگ زرد (اگه کمتر از ۵ ثانیه مونده، قرمز بشه)
3. **تعداد سکه‌های جمع‌آوری‌شده:** با آیکون سکه 🪙 (با استفاده از ایموجی یا شکلک)
4. **راهنما:** در پایین صفحه بنویس `"از کلیدهای جهت‌نما برای حرکت استفاده کنید"`
5. **صفحه‌ی Game Over:** وقتی بازی تموم شد، یک صفحه با این مشخصات نشون بده:
   - پس‌زمینه‌ی نیمه‌شفاف (با استفاده از `pygame.Surface` و `set_alpha()`)
   - متن `"GAME OVER"` با رنگ قرمز و سایز بزرگ
   - امتیاز نهایی
   - پیام `"برای شروع مجدد کلید R را فشار دهید"`

6. دکمه‌ی ریست (R) رو هم اضافه کن که بازی رو از اول شروع کنه.

**نمونه خروجی:**
```
Score: 5    🪙 5 coins    ⏱️ 23s
[بازیکن سبز] ←→ [سکه زرد]

از کلیدهای جهت‌نما برای حرکت استفاده کنید
```

> **💡 نکته:** برای صفحه‌ی Game Over، از `game_over = True` استفاده کن و توی حلقه، اگه `game_over` بود، صفحه‌ی مخصوص رو نشون بده.
