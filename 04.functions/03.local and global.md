## 🎯 درس ۴.۳: متغیرهای محلی (Local) و سراسری (Global)

---

### 🌍 قلمرو متغیرها یعنی چی؟

برای درک راحت این موضوع، یک سازمان رو تصور کن. بعضی از قوانین فقط مخصوص یک اتاق خاص هستن (محلی)، اما بعضی قوانین در کل ساختمان سازمان اجرا میشن (سراسری). متغیرها هم دقیقاً همین‌طور عمل می‌کنن.

> **📌 تعریف رسمی:** **قلمرو (Scope)** به این اشاره داره که یک متغیر در کدوم بخش‌های برنامه قابل دسترسی و مشاهده هست. پایتون دو نوع قلمرو اصلی داره: **محلی (Local)** و **سراسری (Global)**.

---

### ۱. متغیرهای محلی (Local Variables)

هر متغیری که **داخل یک تابع** تعریف بشه، یک متغیر محلیه. این متغیر فقط و فقط تا زمانی زنده هست که تابع در حال اجراست. به محض اینکه کار تابع تموم بشه، این متغیر هم از حافظه کامپیوتر پاک میشه و بیرون از تابع هیچ‌کس بهش دسترسی نداره.

```python
def set_score():
    score = 100  # این یک متغیر محلیه
    print("داخل تابع:", score)

set_score()  # خروجی: داخل تابع: 100

# تلاش برای چاپ متغیر بیرون از تابع
print("بیرون از تابع:", score)  
# ❌ خطا! NameError: name 'score' is not defined
```

> **💡 نکته:** متغیرهای محلی برای هر بار صدا زدن تابع، **جدید** ساخته میشن. یعنی دو بار که تابع رو صدا می‌زنی، دو متغیر محلی مجزا ساخته میشه.

```python
def show_number():
    x = 10
    print(x)

show_number()  # خروجی: 10
show_number()  # خروجی: 10 (متغیر دوباره ساخته شد)
```

### ۲. متغیرهای سراسری (Global Variables)

متغیرهایی که **بیرون از تمام توابع** (در بدنه اصلی کد) تعریف میشن، سراسری هستن. همه جای برنامه، حتی داخل توابع، می‌تونن مقدار این متغیر رو بخونن.

```python
gold_coins = 50  # این یک متغیر سراسریه

def show_wallet():
    # داخل تابع به متغیر سراسری دسترسی داریم (فقط خوندن)
    print("تعداد سکه‌های شما:", gold_coins)

show_wallet()  # خروجی: تعداد سکه‌های شما: 50
print("بیرون تابع:", gold_coins)  # خروجی: بیرون تابع: 50
```

---

### ⚠️ چطور یک متغیر سراسری را داخل تابع تغییر دهیم؟ (`global`)

اگر بخوایم مقدار یک متغیر سراسری رو **داخل یک تابع تغییر بدیم**، پایتون به صورت پیش‌فرض اجازه نمیده و فکر می‌کنه می‌خوایم یک متغیر محلی جدید همنام با اون بسازیم.

```python
counter = 0  # متغیر سراسری

def wrong_update():
    counter = counter + 1  # ❌ خطا! پایتون فکر می‌کنه counter محلی هست
    print(counter)

# wrong_update()  # UnboundLocalError!

def correct_update():
    global counter  # به پایتون می‌گیم می‌خوایم روی همین متغیر سراسری کار کنیم
    counter = counter + 1
    print("داخل تابع:", counter)

correct_update()  # خروجی: داخل تابع: 1
print("بیرون تابع:", counter)  # خروجی: بیرون تابع: 1
```

> **🔑 قانون طلایی:** 
> - برای **خوندن** متغیر سراسری داخل تابع، نیازی به `global` نیست
> - برای **تغییر دادن** متغیر سراسری داخل تابع، حتماً باید از `global` استفاده کنی

---

### ۳. اولویت متغیرها (محلی بر سراسری)

اگه داخل تابع یک متغیر محلی با همین اسم متغیر سراسری تعریف کنی، پایتون **متغیر محلی رو اولویت** میده:

```python
name = "علی"  # متغیر سراسری

def show_name():
    name = "احمد"  # متغیر محلی (همنام با سراسری)
    print("داخل تابع:", name)

show_name()  # خروجی: داخل تابع: احمد
print("بیرون تابع:", name)  # خروجی: بیرون تابع: علی (سراسری تغییر نکرده)
```

---

### 🆚 مقایسه متغیرهای محلی و سراسری

| ویژگی | محلی (Local) | سراسری (Global) |
|--------|--------------|-----------------|
| محل تعریف | داخل تابع | بیرون از همه توابع |
| دسترسی | فقط داخل همون تابع | همه‌جای برنامه |
| طول عمر | تا پایان اجرای تابع | تا پایان اجرای برنامه |
| تغییر از داخل تابع | مستقیم امکان‌پذیر | نیاز به `global` داره |
| اولویت | بالاتر از سراسری همنام | پایین‌تر از محلی همنام |
| کاربرد | داده‌های موقتی و خصوصی | داده‌های مشترک بین توابع |

### 🎯 نکات حرفه‌ای و بهترین‌عمل‌ها

1. **تا حد امکان از متغیرهای محلی استفاده کن:**
   ```python
   # ✅ خوب
   def calculate():
       x = 10
       y = 20
       return x + y
   
   # ❌ بد (استفاده از متغیر سراسری بی‌دلیل)
   x = 10
   y = 20
   def calculate():
       global x, y
       return x + y
   ```

2. **از `global` فقط در صورت ضرورت استفاده کن:**
   - زیاد استفاده از `global` کد رو پیچیده و باگ‌زا می‌کنه
   - بهتره داده‌ها رو با پارامتر و `return` منتقل کنی

3. **اسم‌های متغیرهای محلی و سراسری رو متفاوت بذار:**
   ```python
   # ✅ خوب
   GLOBAL_CONFIG = "production"  # سراسری با حروف بزرگ
   local_var = "test"            # محلی با حروف کوچک
   ```

4. **متغیرهای سراسری رو برای داده‌های واقعاً سراسری استفاده کن:**
   - تنظیمات برنامه
   - شمارنده‌های کلی
   - وضعیت‌های عمومی

### 📌 اشتباهات رایج در این درس

> **🔴 فراموش کردن `global` برای تغییر متغیر سراسری:**
```python
counter = 0
def increment():
    counter = counter + 1  # ❌ خطا! UnboundLocalError

def increment():
    global counter  # ✅ درسته
    counter = counter + 1
```

> **🟡 فکر کردن اینکه `global` برای خوندن لازمه:**
```python
name = "علی"
def show():
    global name  # ❌ غیرضروری
    print(name)  # نیازی به global نداره

def show():
    print(name)  # ✅ درسته
```

> **🟢 تعریف متغیر محلی همنام با سراسری:**
```python
total = 100
def calculate():
    total = 50  # این یه متغیر محلی جدید هست
    print(total)  # خروجی: 50

calculate()
print(total)  # خروجی: 100 (سراسری تغییر نکرده)
```

> **🟣 استفاده از متغیر محلی خارج از تابع:**
```python
def create():
    x = 10

create()
print(x)  # ❌ خطا! x محلی هست و بیرون وجود نداره
```

### 🛠️ نوبت توئه: چالش مدیریت ظرفیت سالن سینما!

بیا برنامه‌ای بنویسیم که ظرفیت صندلی‌های یک سالن سینما رو مدیریت می‌کنه.

**صورت مسئله:**

1. یک متغیر سراسری به نام `free_seats` (صندلی‌های خالی) تعریف کن و مقدار اولیه آن را `120` بذار.
2. یک تابع به نام `reserve_ticket` (رزرو بلیط) بنویس که یک ورودی به نام `count` (تعداد بلیط درخواستی) بگیره.
3. داخل تابع، با استفاده از کلمه کلیدی `global` مشخص کن که می‌خوای متغیر سراسری `free_seats` رو تغییر بدی.
4. سپس تعداد بلیط‌های درخواستی (`count`) رو از `free_seats` کم کن.
5. بیرون از تابع، ابتدا تابع رو صدا بزن و `4` تا بلیط رزرو کن.
6. در نهایت، متغیر سراسری `free_seats` رو چاپ کن تا مطمئن بشی ظرفیت سالن به `116` کاهش پیدا کرده.

### 💪 چالش دوم (اختیاری - برای مدیران سیستم!)

حالا که با متغیرهای محلی و سراسری آشنا شدی، یه سیستم **مدیریت موجودی انبار** کامل بساز:

1. یک متغیر سراسری به نام `inventory` (موجودی انبار) تعریف کن و مقدارش رو `1000` بذار.

2. سه تابع بنویس:

   **تابع اول: `add_stock(amount)`**
   - ورودی: تعداد کالاهایی که به انبار اضافه میشن
   - با `global` موجودی رو افزایش بده
   - پیام `"افزایش موجودی: +{amount} - موجودی فعلی: {inventory}"` رو چاپ کن

   **تابع دوم: `remove_stock(amount)`**
   - ورودی: تعداد کالاهایی که از انبار خارج میشن
   - با `global` موجودی رو کاهش بده
   - اگر موجودی کافی نباشه، پیام `"موجودی کافی نیست!"` رو چاپ کن و موجودی رو تغییر نده
   - در غیر این صورت، پیام `"کاهش موجودی: -{amount} - موجودی فعلی: {inventory}"` رو چاپ کن

   **تابع سوم: `show_inventory()`**
   - موجودی فعلی رو چاپ کن

3. بیرون از توابع، این عملیات‌ها رو اجرا کن:
   - موجودی فعلی رو نشون بده
   - ۲۰۰ تا کالا اضافه کن
   - ۵۰ تا کالا بردار
   - ۳۰۰ تا کالا بردار
   - ۲۰۰۰ تا کالا بردار (باید پیام خطا بده)
   - موجودی نهایی رو نشون بده

**خروجی نمونه:**

```text
موجودی فعلی: 1000
افزایش موجودی: +200 - موجودی فعلی: 1200
کاهش موجودی: -50 - موجودی فعلی: 1150
کاهش موجودی: -300 - موجودی فعلی: 850
موجودی کافی نیست!
موجودی نهایی: 850
```

> **💡 نکته:** توی تابع `remove_stock` از یه متغیر محلی برای چک کردن موجودی استفاده کن و فقط اگه کافی بود، موجودی رو کاهش بده.
