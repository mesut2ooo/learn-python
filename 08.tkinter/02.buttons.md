# 🖥️ فصل هشتم: طراحی رابط کاربری (GUI) با Tkinter

## 🎯 درس ۸.۲: دکمه‌ها (`Button`) و جادوی اکشن‌ها

---

### 🎮 دکمه‌ها یعنی چی؟

در Tkinter برای ساخت دکمه از ویجت `Button` استفاده می‌کنیم. اما یک دکمه بدون داشتن رفتار، فقط یک شکل بی‌مصرفه. برای اینکه به دکمه بگیم با کلیک شدنش چه کاری انجام بده، از پارامتری به نام `command` استفاده می‌کنیم.

پارامتر `command` نام یک **تابع** را می‌گیرد و هر زمان کاربر روی دکمه کلیک کند، پایتون آن تابع را اجرا می‌کند.

> **📌 نکته مهم:** جلوی نام تابع در `command` نباید پرانتز (`()`) بذاری! فقط اسم تابع کافیه. `command=say_hello` ✅ درسته، `command=say_hello()` ❌ اشتباه (تابع همون موقع اجرا میشه!).

---

### 💻 اتصال دکمه به تابع در پایتون

به این سناریو دقت کن: می‌خوایم دکمه‌ای بسازیم که با هر بار کلیک روی اون، متنِ یک لِیبل تغییر کنه و به کاربر خوش‌آمد بگه:

```python
import tkinter as tk

# ۱. تعریف تابعی که قرار است هنگام کلیک روی دکمه اجرا شود
def say_hello():
    # تغییر دادن ویژگی‌های یک ویجت بعد از ساخته شدن با متد config
    my_label.config(text="دکمه کلیک شد! روزت بخیر دوست من 🌟", fg="green")

window = tk.Tk()
window.title("کار با دکمه‌ها در Tkinter")
window.geometry("400x300")

# ساخت برچسب متنی اولیه
my_label = tk.Label(window, text="منتظر کلیک شما هستم...", font=("Tahoma", 14))
my_label.pack(pady=20)

# ۲. ساخت دکمه و متصل کردن آن به تابع say_hello
# توجه: جلوی نام تابع در command نباید پرانتز () بذاری! فقط نام تابع کافیه.
my_button = tk.Button(
    window, 
    text="منو کلیک کن!", 
    font=("Tahoma", 12), 
    command=say_hello,
    bg="#4CAF50",  # پس‌زمینه سبز
    fg="white",    # متن سفید
    width=15,
    height=2
)
my_button.pack(pady=10)

window.mainloop()
```

---

### 🔍 چرا جلوی تابع در `command` پرانتز نمی‌ذاریم؟

این یکی از رایج‌ترین خطاهای تازه‌کارهاست!

```python
# ❌ اشتباه
my_button = tk.Button(window, text="کلیک کن", command=say_hello())
# پایتون همون لحظه تابع رو اجرا می‌کنه و نتیجه رو توی دکمه می‌ذاره!

# ✅ درسته
my_button = tk.Button(window, text="کلیک کن", command=say_hello)
# پایتون آدرس تابع رو به دکمه می‌ده تا هر وقت کلیک شد، خودش اون رو صدا بزنه
```

> **💡 تشبیه:** `command=say_hello` یعنی «به دکمه می‌گی هر وقت کلیک شد، برو این شماره رو بگیر و باهاش تماس بگیر». `command=say_hello()` یعنی «همین الان با این شماره تماس بگیر و نتیجه رو به من بگو!»

---

### 🎨 تنظیمات ظاهری دکمه

| پارامتر | توضیح | مثال |
|---------|-------|------|
| `text` | متن روی دکمه | `text="کلیک کن"` |
| `font` | فونت و اندازه | `font=("Arial", 14)` |
| `bg` | رنگ پس‌زمینه | `bg="#4CAF50"` (سبز) |
| `fg` | رنگ متن | `fg="white"` |
| `width` | عرض دکمه (به تعداد کاراکتر) | `width=15` |
| `height` | ارتفاع دکمه (به تعداد خط) | `height=2` |
| `state` | وضعیت دکمه | `state="disabled"` (غیرفعال) |
| `relief` | نوع حاشیه | `relief="raised"` (برجسته) |

### 🎯 مثال کامل: دکمه با چندین رفتار

```python
import tkinter as tk

def reset():
    label.config(text="متن بازنشانی شد!", fg="blue")
    button_reset.config(state="disabled")  # غیرفعال کردن دکمه

def change_text():
    label.config(text="متن تغییر کرد! 🔄", fg="green")

def change_color():
    current_color = label.cget("fg")  # گرفتن رنگ فعلی
    if current_color == "red":
        label.config(fg="blue")
    else:
        label.config(fg="red")

window = tk.Tk()
window.title("دکمه‌های چندکاره")
window.geometry("500x400")

label = tk.Label(window, text="این یک برچسب است", font=("Arial", 18))
label.pack(pady=20)

# دکمه تغییر متن
btn_text = tk.Button(window, text="تغییر متن", command=change_text)
btn_text.pack(pady=5)

# دکمه تغییر رنگ
btn_color = tk.Button(window, text="تغییر رنگ", command=change_color)
btn_color.pack(pady=5)

# دکمه بازنشانی
btn_reset = tk.Button(window, text="بازنشانی", command=reset)
btn_reset.pack(pady=5)

window.mainloop()
```

### 📌 اشتباهات رایج در این درس

> **🔴 گذاشتن پرانتز جلوی تابع در `command`:**
```python
# ❌ اشتباه
btn = tk.Button(window, text="کلیک", command=my_function())

# ✅ درسته
btn = tk.Button(window, text="کلیک", command=my_function)
```

> **🟡 فراموش کردن `global` برای تغییر متغیر سراسری:**
```python
count = 0
def increment():
count += 1  # ❌ خطا! count محلی هست

def increment():
global count  # ✅ درسته
count += 1
```

> **🟢 فراموش کردن `config()` برای به‌روزرسانی برچسب:**
```python
label = tk.Label(window, text="متن اولیه")

def update():
label = "متن جدید"  # ❌ این یک متغیر جدید می‌سازه، برچسب رو تغییر نمی‌ده
label.config(text="متن جدید")  # ✅ درسته
```

> **🟣 استفاده از `window.quit()` به جای `window.destroy()`:**
```python
# window.quit()  # فقط حلقه رو متوقف می‌کنه
window.destroy()  # پنجره رو کامل می‌بنده (بهتره)
```

### 🛠️ نوبت توئه: چالش شمارنده دسکتاپ!

بیا یک برنامه کوچک دسکتاپ بسازیم که با کلیک روی دکمه، یک عدد رو افزایش بده (مثل صلوات‌شمار یا کلیک‌شمار).

**صورت مسئله:**

1. یک متغیر بیرون از توابع به نام `count = 0` بساز.
2. یک پنجره جدید با Tkinter بالا بیار.
3. یک برچسب (`Label`) روی صفحه بذار که مقدار متغیر `count` رو نشون بده (مثلاً در ابتدا بنویسه: `"تعداد کلیک: 0"`).
4. یک تابع به نام `increase_counter` بساز. داخل این تابع:
   - با استفاده از کلمه کلیدی `global count` دسترسی به متغیر سراسری بیرون تابع ایجاد کن.
   - یک واحد به `count` اضافه کن.
   - متن برچسب رو به روز رسانی کن تا مقدار جدید رو نشون بده (مثلاً: `f"تعداد کلیک: {count}"`).
5. یک دکمه (`Button`) به پنجره اضافه کن که با کلیک روی آن، تابع `increase_counter` اجرا شود.

کدت رو با دقت بنویس و چند بار دکمه رو کلیک کن تا ببینی چطور عدد روی صفحه میره بالا.

### 💪 چالش دوم (اختیاری - برای توسعه‌دهندگان ابزارهای تعاملی!)

حالا که با دکمه‌ها آشنا شدی، یه **ماشین‌حساب تعاملی** ساده با دو دکمه بساز:

1. یک پنجره با عنوان `"ماشین‌حساب ساده"` بساز.

2. سه برچسب داشته باش:
   - برای نمایش عدد اول (پیش‌فرض: ۰)
   - برای نمایش عدد دوم (پیش‌فرض: ۰)
   - برای نمایش نتیجه (پیش‌فرض: ۰)

3. چهار دکمه داشته باش:
   - `"افزایش عدد اول"`: عدد اول رو +۱ کنه
   - `"افزایش عدد دوم"`: عدد دوم رو +۱ کنه
   - `"جمع"`: حاصل‌جمع دو عدد رو محاسبه و نمایش بده
   - `"بازنشانی"`: هر دو عدد و نتیجه رو به ۰ برگردونه

4. برای هر عمل یک تابع جداگانه بنویس.

5. از `global` برای دسترسی به متغیرها استفاده کن.

**نمونه خروجی تعامل:**
```text
عدد اول: 5
عدد دوم: 3
نتیجه: 8
```
