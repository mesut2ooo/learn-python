### 📚 کتابخانه یعنی چی و چرا بهش نیاز داریم؟

حالا که یاد گرفتی چطور کدهات رو مدیریت کنی و جلوی خطاهای احتمالی رو بگیری، وقتشه با یکی از بزرگ‌ترین رازهای برنامه‌نویس‌های حرفه‌ای آشنا بشی: **«نیازی نیست چرخ رو از اول اختراع کنی!»**

در دنیای پایتون، هزاران ابزار و کدهای فوق‌العاده قدرتمند از قبل توسط دیگران نوشته شده که ما می‌توانیم خیلی راحت آن‌ها را به کدمون اضافه کنیم. به این کدهای آماده، **کتابخانه (Library)** یا **ماژول (Module)** می‌گیم.

> **📌 مثال دنیای واقعی:** فرض کن می‌خوای یه بازی تاس بسازی. به جای اینکه خودت الگوریتم تولید عدد تصادفی رو از صفر بنویسی، از کتابخانه‌ی `random` استفاده می‌کنی که این کار رو برات انجام میده!

### 📥 چطور یک کتابخانه را وارد کدمان کنیم؟ (`import`)

برای استفاده از یک کتابخانه، از کلمه کلیدی `import` در اولین خط کدمون استفاده می‌کنیم:

```python
# روش ۱: import کامل
import math

# حالا می‌توانیم از ابزارهای داخل آن استفاده کنیم
result = math.sqrt(16)  # جذر ۱۶
print(result)  # خروجی: 4.0

print(math.pi)  # مقدار عدد پی
print(math.factorial(5))  # فاکتوریل ۵ = ۱۲۰
```

### ✨ روش‌های مختلف `import`

#### ۱. `import` کامل (معمول‌ترین روش)

```python
import math
import random
import os

# استفاده با نام کامل کتابخانه
print(math.sqrt(25))  # خروجی: 5.0
print(random.randint(1, 10))  # عدد تصادفی بین ۱ تا ۱۰
```

#### ۲. `import` با نام مستعار (`as`)

برای کتابخانه‌هایی که اسم بلندی دارن یا خیلی استفاده میشن:

```python
import math as m
import random as rnd

print(m.sqrt(49))  # خروجی: 7.0
print(rnd.randint(1, 10))
```

#### ۳. `from ... import` (وارد کردن بخش خاص)

اگه فقط به یک یا دو تابع از کتابخانه نیاز داری:

```python
from math import sqrt, pi, factorial
from random import randint, choice

# دیگه نیازی به نوشتن math. نیست!
print(sqrt(36))  # خروجی: 6.0
print(pi)  # خروجی: 3.1415...
print(randint(1, 100))  # عدد تصادفی بین ۱ تا ۱۰۰
print(choice(["apple", "banana", "cherry"]))  # انتخاب تصادفی
```

#### ۴. `from ... import *` (وارد کردن همه چیز - **توصیه نمی‌شه!**)

```python
from math import *  # ❌ همه‌چیز رو وارد می‌کنه (نام‌ها ممکنه تداخل کنن)

# توصیه نمی‌شه چون نمی‌دونی دقیقاً چه چیزی وارد شد
```

### 🎲 کتابخانه `random` (تولید اعداد و انتخاب تصادفی)

یکی از پرکاربردترین کتابخانه‌های استاندارد پایتون، `random` هست که برای تولید اعداد تصادفی یا انتخاب‌های تصادفی به کار میره.

```python
import random

# تولید یک عدد تصادفی بین ۱ تا ۱۰ (خود ۱۰ هم شامل میشه)
lucky_number = random.randint(1, 10)
print("عدد شانس شما:", lucky_number)

# انتخاب تصادفی از یک لیست
colors = ["red", "green", "blue", "yellow"]
selected = random.choice(colors)
print("رنگ انتخاب شده:", selected)

# انتخاب چند عضو تصادفی از لیست
random_colors = random.sample(colors, 2)
print("دو رنگ تصادفی:", random_colors)

# تصادفی کردن ترتیب لیست
random.shuffle(colors)
print("لیست به هم ریخته:", colors)

# تولید عدد اعشاری تصادفی بین ۰ و ۱
random_float = random.random()
print("عدد اعشاری تصادفی:", random_float)
```

### 🔢 کتابخانه `math` (محاسبات پیشرفته)

```python
import math

# توابع ریاضی
print(math.sqrt(64))          # جذر: 8.0
print(math.pow(2, 3))         # توان: 8.0
print(math.factorial(5))      # فاکتوریل: 120
print(math.ceil(4.2))         # گرد کردن به بالا: 5
print(math.floor(4.8))        # گرد کردن به پایین: 4
print(math.pi)                # عدد پی: 3.14159...

# محاسبات مثلثاتی
print(math.sin(math.pi / 2))  # سینوس ۹۰ درجه: 1.0
print(math.cos(0))            # کسینوس ۰ درجه: 1.0
```

### 📅 کتابخانه `datetime` (تاریخ و زمان)

```python
import datetime

# تاریخ و زمان فعلی
now = datetime.datetime.now()
print("همین الان:", now)

# فقط تاریخ امروز
today = datetime.date.today()
print("امروز:", today)

# ساخت یک تاریخ دلخواه
birthday = datetime.date(1400, 5, 10)  # سال، ماه، روز
print("تاریخ تولد:", birthday)

# تفاوت دو تاریخ
delta = today - birthday
print("تعداد روز:", delta.days)
```

### 🗂️ کتابخانه `os` (سیستم‌عامل)

```python
import os

# دیدن مسیر فعلی
print("مسیر فعلی:", os.getcwd())

files = os.listdir(".")

if not os.path.exists("new_folder"):

    print("پوشه ساخته شد!")
```

### 🛠️ نوبت توئه: چالش بازی حدس عدد!

بیا یک بازی واقعی و بسیار جذاب بنویسیم که از کتابخانه `random` استفاده می‌کنه. برنامه‌نویسی این بازی، پرونده‌ی فصل پنجم رو با موفقیت می‌بنده.

**صورت مسئله:**

1. کتابخانه `random` را در خط اول کدت وارد (`import`) کن.
2. با استفاده از `random.randint(1, 20)` یک عدد تصادفی بین ۱ تا ۲۰ تولید کن و در متغیری به نام `secret_number` ذخیره کن.
3. یک حلقه بنویس که به کاربر **۵ بار** فرصت بده تا عدد را حدس بزند.
4. در هر دور حلقه، حدس کاربر را با `input` بگیر و به عدد تبدیل کن.
5. **اگر** حدس کاربر درست بود، چاپ کن: `"تبریک! شما عدد شانس را حدس زدید!"` و با دستور `break` از حلقه خارج شو.
6. **اگر** حدس کاربر بزرگتر از عدد مخفی بود، چاپ کن: `"خیلی بزرگ گفتید! عدد کوچکتری بگو."`
7. **اگر** حدس کاربر کوچکتر از عدد مخفی بود، چاپ کن: `"خیلی کوچک گفتید! عدد بزرگتری بگو."`
8. اگر کاربر بعد از ۵ بار نتوانست حدس بزند، بیرون از حلقه عدد مخفی را چاپ کن تا بداند چه عددی بود.

### 💪 چالش دوم (اختیاری - برای توسعه‌دهندگان بازی!)

حالا که با کتابخانه‌ها آشنا شدی، بازی **«سنگ، کاغذ، قیچی»** رو با استفاده از `random` بساز:

1. سه گزینه به کاربر نشون بده:
   ```
   === بازی سنگ، کاغذ، قیچی ===
   2. سنگ 🪨
   3. کاغذ 📄
   4. قیچی ✂️
   انتخاب کنید (1-3):
   ```

5. انتخاب کاربر رو بگیر و به یکی از سه حالت تبدیل کن:
   - ۱ → سنگ
   - ۲ → کاغذ
   - ۳ → قیچی

3. با `random.randint(1, 3)` انتخاب کامپیوتر رو تولید کن.

4. بر اساس قوانین بازی، برنده رو مشخص کن:
   - سنگ → قیچی رو می‌بره
   - کاغذ → سنگ رو می‌بره
   - قیچی → کاغذ رو می‌بره
   - اگر هر دو یکسان باشن → مساوی

5. نتیجه رو چاپ کن.

6. از کاربر بپرس: "دوباره بازی می‌کنید؟ (y/n)" و اگه `y` بود، دوباره بازی رو شروع کن.

> **💡 نکته:** برای نمایش ایموجی‌ها می‌تونی از این‌ها استفاده کنی: 🪨 📄 ✂️

### 📌 اشتباهات رایج در این درس

> **🔴 فراموش کردن `import` قبل از استفاده:**
```python
print(random.randint(1, 10))  # ❌ خطا! random تعریف نشده

import random  # ✅ باید اول وارد کنی
print(random.randint(1, 10))
```

> **🟡 قاطی کردن اسم کتابخانه با اسم توابع:**
```python
import math
print(math.pi)  # ✅ درسته
print(math.PI)  # ❌ خطا! باید با حروف کوچک باشه
```

> **🟢 استفاده از `*` در `import` (روش بد):**
```python
from math import *  # ❌ همه‌چیز رو وارد می‌کنه، باعث تداخل میشه

from math import sqrt, pi  # ✅ فقط چیزایی که نیاز داری
```

> **🟣 وارد کردن کتابخانه‌ای که وجود نداره:**
```python
import unknown_library  # ❌ خطا! ModuleNotFoundError
```
