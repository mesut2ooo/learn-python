## 🎯 درس ۴.۵: توابع با تعداد آرگومان متغیر (`*args` و `**kwargs`)

---

### 🎯 چرا به آرگومان‌های متغیر نیاز داریم؟

تا الان توابعی نوشتی که تعداد مشخصی آرگومان داشتن. مثلاً تابع `add(a, b)` دقیقاً دو تا آرگومان می‌گیره. اما توی دنیای واقعی، گاهی نمی‌دونیم چند تا آرگومان به تابع می‌رسه!

به این تابع فکر کن:
- تابع `print()` می‌تونه هر تعداد آرگومان بگیره: `print(1, 2, 3, "سلام", True)`
- تابع `max()` می‌تونه هر تعداد عدد بگیره: `max(1, 5, 3, 9, 2)`

چطور چنین توابعی ساخته شدن؟ با استفاده از `*args` و `**kwargs`!

> **📌 تشبیه:** `*args` مثل یه کیسه‌ست که هر تعداد چیزی می‌تونی توش بندازی. `**kwargs` مثل یه جعبه‌ی برچسب‌داره که هر تعداد برچسب-مقدار می‌تونی توش بذاری.

---

### 📦 `*args` (Argument Sequence)

`*args` به تابع اجازه می‌ده هر تعداد آرگومان **بدون نام** (positional) دریافت کنه. این آرگومان‌ها به صورت یک **تاپل (tuple)** داخل تابع ذخیره می‌شن.

```python
def sum_all(*args):
    """جمع هر تعداد عدد که به تابع داده بشه"""
    total = 0
    for num in args:
        total += num
    return total

# تست با تعداد آرگومان‌های مختلف
print(sum_all(1, 2, 3))        # خروجی: 6
print(sum_all(10, 20, 30, 40)) # خروجی: 100
print(sum_all(5, 10))          # خروجی: 15
print(sum_all())               # خروجی: 0 (بدون آرگومان)
```

> **💡 نکته:** اسم `*args` یه قرارداد هست. می‌تونی از هر اسمی استفاده کنی، ولی `args` متداوله. مهم اینه که `*` جلوی اسم باشه.

---

### 📖 `**kwargs` (Keyword Arguments)

`**kwargs` به تابع اجازه می‌ده هر تعداد آرگومان **با نام** (keyword) دریافت کنه. این آرگومان‌ها به صورت یک **دیکشنری (dict)** داخل تابع ذخیره می‌شن.

```python
def print_user_info(**kwargs):
    """چاپ اطلاعات کاربر با هر تعداد ویژگی"""
    print("👤 اطلاعات کاربر:")
    for key, value in kwargs.items():
        print(f"  {key}: {value}")

# تست با تعداد آرگومان‌های مختلف
print_user_info(name="احمد", age=25, city="تهران")
print_user_info(name="سارا", email="sara@mail.com", is_active=True)
print_user_info(product="لپ‌تاپ", price=25000000, brand="Dell", in_stock=True)
```

**خروجی:**
```text
👤 اطلاعات کاربر:
  name: احمد
  age: 25
  city: تهران
👤 اطلاعات کاربر:
  name: سارا
  email: sara@mail.com
  is_active: True
👤 اطلاعات کاربر:
  product: لپ‌تاپ
  price: 25000000
  brand: Dell
  in_stock: True
```

### 🎯 ترکیب `*args` و `**kwargs`

می‌تونی هر دو رو با هم استفاده کنی. ترتیب مهمه: اول `*args`، بعد `**kwargs`:

```python
def flexible_function(name, *args, **kwargs):
    """
    تابعی که همه چیز رو می‌گیره!
    - name: آرگومان اجباری
    - *args: آرگومان‌های اضافی بدون نام
    - **kwargs: آرگومان‌های اضافی با نام
    """
    print(f"👤 نام: {name}")
    
    if args:
        print(f"📦 آرگومان‌های اضافی: {args}")
    
    if kwargs:
        print(f"📋 ویژگی‌های اضافی: {kwargs}")

# تست
flexible_function("احمد", 25, "تهران", "برنامه‌نویس", 
                  email="ahmad@mail.com", phone="09121112222")

# خروجی:
# 👤 نام: احمد
# 📦 آرگومان‌های اضافی: (25, 'تهران', 'برنامه‌نویس')
# 📋 ویژگی‌های اضافی: {'email': 'ahmad@mail.com', 'phone': '09121112222'}
```

### 🔍 کاربردهای واقعی

#### ۱. ساخت تابع `logger` (ثبت رویدادها)

```python
def log_event(event_type, *messages, **details):
    """ثبت یک رویداد با پیام‌ها و جزئیات متغیر"""
    print(f"[{event_type.upper()}]", end=" ")
    
    # چاپ پیام‌ها
    for msg in messages:
        print(msg, end=" ")
    
    # چاپ جزئیات
    if details:
        print("\n  📋 جزئیات:", end=" ")
        for key, value in details.items():
            print(f"{key}={value}", end=" ")
    
    print()  # خط جدید

# استفاده
log_event("info", "کاربر", "وارد", "سیستم", "شد", user="احمد", ip="192.168.1.1")
log_event("error", "خطا در اتصال", code=404, server="api.example.com")
```

#### ۲. شبیه‌سازی `print()` با `*args`

```python
def my_print(*args, sep=" ", end="\n"):
    """شبیه‌سازی ساده‌ی تابع print"""
    result = sep.join(str(arg) for arg in args)
    print(result, end=end)  # از print داخلی استفاده می‌کنیم

# استفاده
my_print("سلام", "دنیا", sep=" - ")  # خروجی: سلام - دنیا
my_print("این", "یک", "تست", "است", sep="*")  # خروجی: این*یک*تست*است
```

### 📌 اشتباهات رایج در این درس

> **🔴 فراموش کردن `*` قبل از `args`:**
```python
def sum_all(args):  # ❌ فقط یک آرگومان می‌گیره
    return sum(args)

def sum_all(*args):  # ✅ هر تعداد آرگومان می‌گیره
    return sum(args)
```

> **🟡 قاطی کردن `*args` و `**kwargs`:**
```python
# *args: برای آرگومان‌های بی‌نام (تاپل)
# **kwargs: برای آرگومان‌های با نام (دیکشنری)

def test(*args, **kwargs):
    print(args)   # تاپل
    print(kwargs) # دیکشنری
```

> **🟢 استفاده از اسم‌های غیراستاندارد:**
```python
# می‌تونی اسم دلخواه بذاری، ولی استاندارد نیست
def test(*numbers, **info):  # درسته ولی کمتر استفاده میشه

def test(*args, **kwargs):  # ✅ استاندارد
```

> **🟣 ترتیب اشتباه آرگومان‌ها:**
```python
# ترتیب درست:
def func(a, b, *args, **kwargs):  # ✅

# ترتیب غلط:
def func(a, *args, b, **kwargs):  # ❌ خطا! b باید قبل از *args باشه
```

### 🛠️ نوبت توئه: تابع جمع با تعداد آرگومان متغیر!

بیا یک تابع انعطاف‌پذیر برای جمع کردن اعداد با قابلیت‌های مختلف بنویسیم.

**صورت مسئله:**

1. تابعی به نام `calculate` بنویس که:
   - آرگومان اول: `operation` (نوع عملیات: `"sum"` یا `"multiply"`)
   - `*args`: لیستی از اعداد
   - `**kwargs`: تنظیمات اضافی (مثل `round_digits` برای گرد کردن)

2. بر اساس `operation`:
   - `"sum"`: مجموع اعداد رو حساب کنه
   - `"multiply"`: حاصل‌ضرب اعداد رو حساب کنه

3. اگه `round_digits` در `kwargs` بود، نتیجه رو به اون تعداد رقم اعشار گرد کنه.

4. تابع رو با آرگومان‌های مختلف تست کن.

**نمونه خروجی:**
```text
calculate("sum", 1, 2, 3, 4) = 10
calculate("multiply", 2, 3, 4) = 24
calculate("sum", 1.5, 2.5, 3.5, round_digits=1) = 7.5
calculate("multiply", 2.5, 3.5, round_digits=2) = 8.75
```

### 💪 چالش دوم (اختیاری - برای معماران توابع!)

حالا که با `*args` و `**kwargs` آشنا شدی، یه **تابع فرمت‌کننده‌ی داده** کامل بساز:

1. تابعی به نام `format_data` بنویس که:
   - آرگومان اول: `style` (نوع فرمت: `"json"`، `"csv"` یا `"table"`)
   - `*args`: مقادیر مختلف (هر نوعی می‌تونن باشن)
   - `**kwargs`: تنظیمات مثل `separator`، `indent` و `headers`

2. خروجی‌های مختلف بر اساس `style`:
   - `"json"`: یک دیکشنری به JSON تبدیل کنه (با `json.dumps`)
   - `"csv"`: مقادیر رو با جداکننده (مثلاً کاما) به هم بچسبونه
   - `"table"`: یک جدول ساده با خطوط جداکننده بسازه

3. با `**kwargs` تنظیمات رو دریافت کن:
   - `separator`: جداکننده (پیش‌فرض: `", "`)
   - `indent`: تعداد فاصله برای تورفتگی (پیش‌فرض: ۲)
   - `headers`: لیست عنوان‌های ستون‌ها (برای table)

4. تابع رو با داده‌های مختلف تست کن.

**نمونه استفاده:**
```python
# تست JSON
print(format_data("json", name="احمد", age=25, city="تهران"))
# خروجی: {"name": "احمد", "age": 25, "city": "تهران"}

# تست CSV
print(format_data("csv", "احمد", 25, "تهران", separator=","))
# خروجی: احمد,25,تهران

# تست Table
print(format_data("table", "احمد", 25, "تهران", headers=["نام", "سن", "شهر"]))
# خروجی:
# نام | سن | شهر
# ----+----+-----
# احمد | 25 | تهران
```
