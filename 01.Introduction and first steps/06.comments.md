### 💬 کامنت یعنی چی و چرا مهمه؟

کامنت‌ها **توضیحاتی هستن که توی کد می‌نویسی ولی پایتون اون‌ها رو نادیده می‌گیره**. یعنی اجرا نمیشن و فقط برای خوندن کد توسط انسان‌ها (خودت یا دیگران) هستن.

بیا صادق باشیم؛ برنامه‌نویسی فقط نوشتن کد نیست که به درد کامپیوتر بخوره. **۵۰٪ برنامه‌نویسی، نوشتن کدی هست که انسان‌ها هم بتونن بخوننش!**

کامنت‌گذاری خوب بهت کمک می‌کنه:

- بعد از چند ماه که به کد خودت نگاه می‌کنی، یادت بیاد چرا اینطوری نوشتی
- تیم‌های برنامه‌نویسی بتونن با هم همکاری کنن
- باگ‌ها رو راحت‌تر پیدا کنی
- حرفه‌ای‌تر به نظر بیای (واقعاً!)

### 📝 دو نوع کامنت در پایتون

#### ۱. کامنت تک‌خطی (با `#`)

با علامت `#` شروع میشه و تا آخر همون خط رو توضیح می‌ده.

```python
# این یک کامنت است و پایتون آن را نادیده می‌گیرد
price = 12000  # این کامنت کنار کد هست

# معمولاً کامنت رو بالای خطی که توضیح می‌ده می‌نویسن
user_age = 25  # این روش هم درسته ولی کمتر رایجه
```

#### ۲. کامنت چندخطی (با `"""` یا `'''`)

برای توضیحات بلندتر یا مستندسازی توابع از سه کوتیشن استفاده می‌کنیم:

```python
"""
این یک کامنت چندخطی هست.
می‌تونی چندین خط توضیح بدی.
پایتون این رو نادیده می‌گیره.
"""

def calculate_tax(price):
    """
    این تابع مالیات رو محاسبه می‌کنه.
    ورودی: قیمت (عدد)
    خروجی: مالیات (عدد)
    """
    return price * 0.09
```

### 🏷️ قراردادهای نام‌گذاری و سبک نوشتن (PEP 8)

پایتون یک مستند رسمی به اسم **PEP 8** داره که قراردادهای کدنویسی رو مشخص می‌کنه. چند مورد مهم:

```python
# ✅ نام متغیرها با حروف کوچک و خط زیرین
user_name = "احمد"
total_price = 12500

# ✅ یک فاصله بعد از کاما
print(user_name, total_price)

# ✅ یک فاصله قبل و بعد از عملگرها
age = 18
is_adult = age >= 18

# ✅ یک خط خالی بین بخش‌های مختلف کد
def calculate(price):
    return price * 2

# اینجا یک خط خالی
def main():
    print("شروع برنامه")
```

> **💡 نکته:** رعایت این قراردادها باعث میشه کدت حرفه‌ای‌تر به نظر بیاد و بقیه برنامه‌نویس‌ها راحت‌تر کدتو بخونن.

### 🛠️ نوبت توئه: چالش مستندسازی یک برنامه‌ی واقعی!

فرض کن یک برنامه‌ی ساده برای محاسبه‌ی قیمت نهایی با تخفیف نوشتی. حالا می‌خوایم این برنامه رو با کامنت‌های حرفه‌ای مستند کنیم.

**صورت مسئله:**

برنامه‌ی زیر رو کپی کن و حداقل **۵ کامنت معنی‌دار** بهش اضافه کن:

```python
price = float(input("قیمت کالا: "))
discount_percent = int(input("درصد تخفیف: "))
discount_amount = (price * discount_percent) / 100
final_price = price - discount_amount
is_expensive = final_price > 100000
print(f"قیمت نهایی: {final_price}")
print(f"گران هست؟ {is_expensive}")
```

**راهنمایی برای کامنت‌ها:**
- توضیح بده هر خط چه کاری انجام می‌ده
- توضیح بده چرا از `float` و `int` استفاده کردی
- یک کامنت هشدار بذار که اگر کاربر درصد رو اشتباه وارد کنه چه میشه
- یک کامنت بالای برنامه بذار که توضیح بده برنامه چیه

### 💪 چالش دوم (اختیاری - برای حرفه‌ای‌های واقعی!)

یه برنامه‌ی کامل‌تر برای محاسبه‌ی **شاخص توده بدنی (BMI)** بنویس و با کامنت‌های حرفه‌ای مستندش کن:

1. از کاربر وزن (کیلوگرم) و قد (متر) بگیر
2. BMI رو حساب کن: `weight / (height ** 2)`
3. با عملگرهای مقایسه وضعیت رو مشخص کن:
   - کمتر از ۱۸.۵: "کم‌وزن"
   - ۱۸.۵ تا ۲۴.۹: "نرمال"
   - ۲۵ تا ۲۹.۹: "اضافه‌وزن"
   - ۳۰ به بالا: "چاق"
4. حداقل ۸ کامنت معنی‌دار بذار که توضیح بده:
   - هر بخش چه کاری می‌کنه
   - چرا از هر عملگری استفاده کردی
   - هشدارهای مربوط به ورودی کاربر

> **💡 نکته:** BMI رو بعداً با `if` می‌نویسی، فعلاً فقط محاسبه کن و چاپ کن.
