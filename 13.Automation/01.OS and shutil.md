### 🎯 اتوماسیون یعنی چی؟

تا الان یاد گرفتی چطور برنامه‌هایی بنویسی که کاربر باهاشون تعامل کنه. اما یه دنیای دیگه از برنامه‌نویسی وجود داره که توش **برنامه‌ها خودشون کارها رو انجام می‌دن** بدون اینکه کسی پشتشون بشینه!

**اتوماسیون (Automation)** یعنی نوشتن برنامه‌ای که کارهای تکراری و خسته‌کننده رو به جای انسان انجام بده. مثلاً:
- مرتب کردن فایل‌های پوشه‌ها بر اساس تاریخ
- پشتیبان‌گیری خودکار از پروژه‌ها
- تغییر نام دسته‌جمعی فایل‌ها
- ارسال خودکار ایمیل‌ها

> **📌 قانون طلایی:** اگه کاری رو مجبوری ۳ بار انجام بدی، حتماً یک اسکریپت براش بنویس!

### 📂 کتابخانه `os` (سیستم‌عامل)

کتابخانه `os` بهت اجازه میده با سیستم‌عامل ارتباط برقرار کنی و کارهایی مثل:
- دیدن مسیر فعلی
- لیست فایل‌های یک پوشه
- ساخت و حذف پوشه
- تغییر نام فایل‌ها
- اجرای دستورات سیستم

انجام بدی.

```python
import os

# ========== اطلاعات پایه ==========
print(f"📁 مسیر فعلی: {os.getcwd()}")

# ========== لیست فایل‌های پوشه ==========
files = os.listdir(".")
print(f"\n📄 فایل‌های پوشه فعلی:")
for f in files:
    print(f"  - {f}")

# ========== ساخت پوشه ==========
if not os.path.exists("new_folder"):
    os.mkdir("new_folder")
    print("\n✅ پوشه 'new_folder' ساخته شد!")

# ========== بررسی وجود فایل ==========
if os.path.exists("data.txt"):
    print("\n✅ فایل data.txt وجود دارد!")
else:
    print("\n❌ فایل data.txt وجود ندارد!")

# ========== اطلاعات فایل ==========
file_path = "data.txt"
if os.path.exists(file_path):
    print(f"\n📊 اطلاعات فایل {file_path}:")
    print(f"  - اندازه: {os.path.getsize(file_path)} بایت")
    print(f"  - تاریخ تغییر: {os.path.getmtime(file_path)}")
```

### 🗂️ کتابخانه `shutil` (عملیات پیشرفته فایل)

`shutil` برای کارهای سنگین‌تر مثل کپی و جابه‌جایی فایل‌هاست:

```python
import shutil
import os

# ========== کپی فایل ==========
if os.path.exists("source.txt"):
    shutil.copy("source.txt", "backup.txt")
    print("✅ فایل کپی شد!")

# ========== کپی کل پوشه ==========
if os.path.exists("my_folder"):
    shutil.copytree("my_folder", "my_folder_backup")
    print("✅ پوشه کامل کپی شد!")

# ========== جابه‌جایی فایل ==========
if os.path.exists("old_name.txt"):
    shutil.move("old_name.txt", "new_location/old_name.txt")
    print("✅ فایل جابه‌جا شد!")

# ========== حذف پوشه و محتویات ==========
if os.path.exists("temp_folder"):
    shutil.rmtree("temp_folder")
    print("✅ پوشه و محتویاتش حذف شد!")
```

### 🎯 مثال عملی: مرتب‌سازی فایل‌ها بر اساس پسوند

بیا یه برنامه بنویسیم که فایل‌های یه پوشه رو بر اساس پسوند دسته‌بندی کنه:

```python
import os
import shutil

def organize_files(folder_path):
    """
    مرتب‌سازی فایل‌های یک پوشه بر اساس پسوند
    """
    # پوشه‌های مقصد برای هر نوع فایل
    categories = {
        "Images": [".jpg", ".jpeg", ".png", ".gif", ".bmp"],
        "Documents": [".pdf", ".doc", ".docx", ".txt", ".xlsx"],
        "Archives": [".zip", ".rar", ".7z", ".tar.gz"],
        "Videos": [".mp4", ".avi", ".mkv", ".mov"],
        "Music": [".mp3", ".wav", ".flac"],
        "Code": [".py", ".js", ".html", ".css", ".cpp", ".java"]
    }
    
    # ساخت پوشه‌های دسته‌بندی
    for category in categories:
        category_path = os.path.join(folder_path, category)
        if not os.path.exists(category_path):
            os.mkdir(category_path)
            print(f"📁 پوشه {category} ساخته شد")
    
    # مرتب‌سازی فایل‌ها
    moved_count = 0
    for filename in os.listdir(folder_path):
        file_path = os.path.join(folder_path, filename)
        
        # رد شدن از پوشه‌ها
        if os.path.isdir(file_path):
            continue
        
        # پیدا کردن پسوند فایل
        _, extension = os.path.splitext(filename)
        extension = extension.lower()
        
        # پیدا کردن دسته‌ی مناسب
        moved = False
        for category, extensions in categories.items():
            if extension in extensions:
                dest_path = os.path.join(folder_path, category, filename)
                shutil.move(file_path, dest_path)
                moved_count += 1
                moved = True
                print(f"✅ {filename} → {category}")
                break
        
        # اگر دسته‌ای پیدا نشد، توی Others بره
        if not moved:
            others_path = os.path.join(folder_path, "Others")
            if not os.path.exists(others_path):
                os.mkdir(others_path)
            shutil.move(file_path, os.path.join(others_path, filename))
            print(f"❓ {filename} → Others")
    
    print(f"\n🎯 {moved_count} فایل مرتب‌سازی شد!")

# استفاده
organize_files(".")  # پوشه فعلی
```

### 📌 اشتباهات رایج در این درس

> **🔴 فراموش کردن `os.path.join()`:**
```python
# ❌ ممکنه در سیستم‌عامل‌های مختلف کار نکنه
path = folder + "/" + filename

# ✅ در همه‌ی سیستم‌عامل‌ها کار می‌کنه
path = os.path.join(folder, filename)
```

> **🟡 اشتباه گرفتن `os.remove()` با `shutil.rmtree()`:**
```python
os.remove("file.txt")      # حذف یک فایل
shutil.rmtree("folder")    # حذف پوشه و همه محتویات
```

> **🟢 فراموش کردن `os.path.exists()` قبل از حذف:**
```python
os.remove("file.txt")  # ❌ اگه فایل نباشه خطا میده

if os.path.exists("file.txt"):  # ✅ اول چک کن
os.remove("file.txt")
```

> **🟣 استفاده از مسیرهای مطلق به جای نسبی:**
```python
# ❌ فقط روی سیستم خودت کار می‌کنه
path = "C:/Users/Ahmad/Documents/project"

# ✅ روی همه سیستم‌ها کار می‌کنه
path = os.path.join(os.getcwd(), "project")
```

### 🛠️ نوبت توئه: ساخت پشتیبان خودکار!

بیا یک برنامه‌ی ساده برای پشتیبان‌گیری از پروژه‌های پایتون بنویسیم.

**صورت مسئله:**

1. برنامه‌ای بنویس که:
   - از کاربر مسیر یک پوشه (مثلاً پروژه‌ات) رو بگیره
   - یک پوشه‌ی `backup` در مسیر فعلی بسازه
   - تمام فایل‌های `.py` رو از پوشه‌ی اصلی به پوشه‌ی `backup` کپی کنه
   - تعداد فایل‌های کپی شده رو چاپ کنه

2. از `os.listdir()`، `shutil.copy()` و `os.path.join()` استفاده کن.

3. اگه پوشه‌ی `backup` وجود نداشت، بسازش.

4. در پایان، پیام `"✅ پشتیبان‌گیری با موفقیت انجام شد!"` رو چاپ کن.

### 💪 چالش دوم (اختیاری - برای اتوماسیون‌بازهای حرفه‌ای!)

حالا که با `os` و `shutil` آشنا شدی، یه **سیستم پاک‌سازی خودکار** کامل بساز:

1. برنامه‌ای بنویس که پوشه‌ی `Downloads` رو اسکن کنه و:
   - فایل‌های بزرگتر از ۱۰۰ مگابایت رو پیدا کنه
   - فایل‌هایی که بیش از ۳۰ روز از آخرین تغییرشون گذشته رو پیدا کنه
   - فایل‌های تکراری (همنام) رو پیدا کنه

2. یک گزارش به این شکل چاپ کن:
   ```
   📊 گزارش پاک‌سازی Downloads
   ====================================
   
   🔴 فایل‌های بزرگ (> 100 MB):
      - video_2024.mp4 (250 MB) - 15 روز پیش
      - setup.exe (180 MB) - 45 روز پیش
      مجموع: 2 فایل - 430 MB
   
   🟡 فایل‌های قدیمی (> 30 روز):
      - old_report.pdf (2 MB) - 35 روز پیش
      - temp_data.csv (5 MB) - 60 روز پیش
      مجموع: 2 فایل - 7 MB
   
   🔵 فایل‌های تکراری:
      - document.pdf (2 نسخه)
      - photo.jpg (3 نسخه)
   
   💾 فضای قابل آزادسازی: 437 MB
   ====================================
   ```

3. از کاربر بپرس: `"آیا می‌خواهید فایل‌های قدیمی و بزرگ حذف شوند؟ (y/n)"`
   - اگه `y` بود، فایل‌ها رو حذف کن و گزارش نهایی بده
   - اگه `n` بود، فقط گزارش رو نمایش بده

> **💡 نکته:** برای پیدا کردن فایل‌های تکراری، از دیکشنری استفاده کن که اسم فایل رو کلید و تعدادش رو مقدار بذاری.
