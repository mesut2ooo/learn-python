### 🎨 چرا CustomTkinter؟

بیایید با هم روراست باشیم؛ ظاهر خاکستری و کلاسیک ویندوز ۹۵ در Tkinter استاندارد، کمی قدیمی و بی‌روح به نظر می‌رسه. برای پروژه‌ی مدرنی مثل پیام‌رسان ناشناس تو یعنی **Anonyma**، ما نیاز به یک ظاهر شیک، یکدست، دکمه‌های گردتر و تم‌های مدرن (مثل حالت تاریک یا Dark Mode) داریم.

اینجاست که با نسل جدید رابط کاربری در پایتون یعنی **CustomTkinter** آشنا می‌شیم!

> **📌 CustomTkinter چیست؟**
> کتابخانه‌ی **CustomTkinter** یک پوسته‌ی مدرن و فوق‌العاده زیبا روی همان Tkinter سنتی می‌کشه. این ابزار به طور پیش‌فرض از حالت‌های Dark (تاریک) و Light (روشن) پشتیبانی می‌کنه و ویجت‌های بسیار چشم‌نوازی در اختیارت می‌ذاره.

---

### 💻 نصب و راه‌اندازی CustomTkinter

#### مرحله ۱: نصب

ترمینال VS Code رو باز کن و این دستور رو اجرا کن:

```bash
pip install customtkinter
```

#### مرحله ۲: اولین پنجره مدرن

```python
import customtkinter as ctk

# ۱. تنظیم تم رنگی و حالت صفحه (Dark یا Light)
ctk.set_appearance_mode("dark")  # حالت‌های ممکن: "system", "light", "dark"
ctk.set_default_color_theme("blue")  # تم‌های پیش‌فرض: "blue", "green", "dark-blue"

# ۲. ساخت پنجره اصلی به جای tk.Tk از ctk.CTk استفاده می‌کنیم
app = ctk.CTk()
app.title("پروژه مدرن Anonyma")
app.geometry("400x300")

# ۳. ساخت یک لِیبل مدرن
title_label = ctk.CTkLabel(
    app, 
    text="به Anonyma خوش آمدید", 
    font=("Tahoma", 18, "bold"),
    text_color="cyan"
)
title_label.pack(pady=30)

# ۴. ساخت یک کادر ورودی مدرن با گوشه‌های گرد
user_entry = ctk.CTkEntry(
    app, 
    placeholder_text="نام کاربری ناشناس خود را وارد کنید", 
    width=250,
    height=40,
    corner_radius=10
)
user_entry.pack(pady=10)

# ۵. ساخت یک دکمه مدرن، شیک و رنگی
def show_message():
    name = user_entry.get()
    if name.strip():
        result_label.configure(text=f"سلام {name}! به دنیای ناشناس خوش آمدید! 🌟")
    else:
        result_label.configure(text="لطفاً نام خود را وارد کنید! ⚠️")

submit_button = ctk.CTkButton(
    app, 
    text="ورود به دنیای ناشناس", 
    corner_radius=10,
    command=show_message,
    width=250,
    height=45
)
submit_button.pack(pady=20)

result_label = ctk.CTkLabel(app, text="", font=("Tahoma", 12))
result_label.pack(pady=10)

app.mainloop()
```

### 🔍 تفاوت‌های اصلی با Tkinter معمولی

| ویژگی | Tkinter معمولی | CustomTkinter |
|-------|---------------|---------------|
| ظاهر | کلاسیک ویندوز ۹۵ | مدرن و زیبا |
| حالت تاریک | ندارد (با کد سخت) | پشتیبانی پیش‌فرض |
| انیمیشن هاور | ندارد | دارد (تغییر رنگ ملایم) |
| گوشه‌های گرد | ندارد | دارد (`corner_radius`) |
| متن راهنما | ندارد (با کد سخت) | دارد (`placeholder_text`) |
| ویجت‌ها | `tk.Label`, `tk.Button` | `CTkLabel`, `CTkButton` |

### 🎨 تنظیمات اصلی CustomTkinter

#### تنظیم حالت رنگ

```python
# سه حالت مختلف
ctk.set_appearance_mode("system")  # مطابق با سیستم‌عامل
ctk.set_appearance_mode("light")   # حالت روشن
ctk.set_appearance_mode("dark")    # حالت تاریک
```

#### تنظیم تم رنگی

```python
# تم‌های پیش‌فرض
ctk.set_default_color_theme("blue")       # آبی
ctk.set_default_color_theme("green")      # سبز
ctk.set_default_color_theme("dark-blue")  # آبی تیره

# یا تم سفارشی
ctk.set_default_color_theme("custom_theme.json")
```

#### تغییر اندازه و فونت

```python
# تغییر اندازه فونت عمومی
ctk.set_widget_scaling(1.0)  # 1.0 = اندازه معمولی، 1.2 = ۲۰٪ بزرگتر
```

### 🎯 ویجت‌های اصلی CustomTkinter

| ویجت | معادل Tkinter | توضیح |
|------|---------------|-------|
| `CTk` | `Tk` | پنجره اصلی |
| `CTkLabel` | `Label` | برچسب متنی |
| `CTkButton` | `Button` | دکمه |
| `CTkEntry` | `Entry` | کادر ورودی |
| `CTkFrame` | `Frame` | فریم برای گروه‌بندی |
| `CTkSwitch` | - | دکمه‌ی روشن/خاموش |
| `CTkSlider` | - | نوار لغزنده |

### 💻 مثال کامل: فرم ثبت‌نام مدرن

```python
import customtkinter as ctk

def register_user():
    name = name_entry.get()
    email = email_entry.get()
    password = password_entry.get()
    
    if not name or not email or not password:
        result_label.configure(text="❌ همه فیلدها را پر کنید!", text_color="red")
        return
    
    if len(password) < 4:
        result_label.configure(text="❌ رمز عبور حداقل ۴ کاراکتر!", text_color="red")
        return
    
    result_label.configure(text=f"✅ ثبت‌نام {name} موفق بود!", text_color="green")
    name_entry.delete(0, "end")
    email_entry.delete(0, "end")
    password_entry.delete(0, "end")

# تنظیمات تم
ctk.set_appearance_mode("dark")
ctk.set_default_color_theme("blue")

# پنجره اصلی
app = ctk.CTk()
app.title("فرم ثبت‌نام مدرن")
app.geometry("500x450")

# عنوان
title = ctk.CTkLabel(
    app, 
    text="📝 فرم ثبت‌نام کاربر", 
    font=("Arial", 20, "bold"),
    text_color="cyan"
)
title.pack(pady=15)

# فریم برای فیلدها
frame = ctk.CTkFrame(app)
frame.pack(pady=10, padx=20, fill="both", expand=True)

# فیلد نام
ctk.CTkLabel(frame, text="نام کامل:", font=("Arial", 12)).grid(row=0, column=0, padx=10, pady=10, sticky="w")
name_entry = ctk.CTkEntry(frame, placeholder_text="نام خود را وارد کنید", width=250)
name_entry.grid(row=0, column=1, padx=10, pady=10)

# فیلد ایمیل
ctk.CTkLabel(frame, text="ایمیل:", font=("Arial", 12)).grid(row=1, column=0, padx=10, pady=10, sticky="w")
email_entry = ctk.CTkEntry(frame, placeholder_text="ایمیل خود را وارد کنید", width=250)
email_entry.grid(row=1, column=1, padx=10, pady=10)

# فیلد رمز عبور
ctk.CTkLabel(frame, text="رمز عبور:", font=("Arial", 12)).grid(row=2, column=0, padx=10, pady=10, sticky="w")
password_entry = ctk.CTkEntry(frame, placeholder_text="رمز عبور (حداقل ۴ کاراکتر)", width=250, show="*")
password_entry.grid(row=2, column=1, padx=10, pady=10)

# دکمه ثبت‌نام
register_btn = ctk.CTkButton(
    app, 
    text="ثبت‌نام", 
    command=register_user,
    corner_radius=15,
    width=200,
    height=45,
    font=("Arial", 14, "bold")
)
register_btn.pack(pady=15)

# نمایش نتیجه
result_label = ctk.CTkLabel(app, text="", font=("Arial", 12, "bold"))
result_label.pack(pady=10)

app.mainloop()
```


> **🟡 قاطی کردن ویجت‌های Tkinter با CustomTkinter:**
```python

from tkinter import Label
import customtkinter as ctk

label = tk.Label(app, text="سلام")  # ظاهر قدیمی
label = ctk.CTkLabel(app, text="سلام")  # ظاهر مدرن
```

> **🟢 فراموش کردن تنظیم `appearance_mode`:**
```python

ctk.set_appearance_mode("dark")  # بهتره تنظیم کنی
```

> **🟣 استفاده از `pack()` با `grid()` در CustomTkinter:**

```python
# مثل Tkinter معمولی، نمی‌تونی هر دو رو باهم استفاده کنی
```

### 🛠️ نوبت توئه: چالش بازطراحی صفحه فرود Anonyma!

بیا با هم اولین قطعه پازل رابط کاربری برنامه‌ی خودت یعنی **Anonyma** رو به زیباترین شکل ممکن بسازیم.

**صورت مسئله:**

1. یک فایل جدید به نام `anonyma_gui.py` بساز.
2. کتابخانه‌ی `customtkinter` را نصب و وارد کدت کن.
3. یک پنجره‌ی مدرن با ابعاد **۴۵۰ در ۳۵۰** پیکسل طراحی کن و تم آن را روی `"dark"` قرار بده.
4. با استفاده از سیستم شبکه‌ای (`grid`) یا چیدمان عمودی (`pack`)، موارد زیر را روی صفحه بچین:
   - یک عنوان بزرگ با متن `"Anonyma Messenger"` و رنگ متن جذاب (می‌توانی از ویژگی `text_color="cyan"` استفاده کنی).
   - یک کادر ورودی مدرن با متن راهنمای `"کد اتاق گفت‌وگو (مثلاً: 1209)"`.
   - یک دکمه با گوشه‌های بسیار گرد (`corner_radius=20`) و متن `"ورود به اتاق"` که وقتی روی آن کلیک می‌شود، یک پیغام خوش‌آمدگویی ساده در یک لِیبل در پایین صفحه نشان دهد.

### 💪 چالش دوم (اختیاری - برای طراحان رابط کاربری حرفه‌ای!)

حالا که با CustomTkinter آشنا شدی، یه **داشبورد مدیریت** مدرن و زیبا طراحی کن:

1. پنجره با عنوان `"📊 داشبورد مدیریت"` و اندازه `800x600`.

2. این بخش‌ها رو طراحی کن:
   - **هدر بالا:** لوگو و عنوان با `CTkLabel` بزرگ
   - **ستون کناری:** یک `CTkFrame` با دکمه‌های منو (داشبورد، کاربران، محصولات، گزارشات)
   - **بخش اصلی:** سه کارت اطلاعاتی با `CTkFrame`:
     - تعداد کاربران
     - درآمد امروز
     - سفارشات جدید
   - **پایین:** یک جدول ساده با `CTkFrame` و لیبل‌ها

3. از تم `"dark-blue"` استفاده کن.

4. دکمه‌ها رو با `corner_radius=10` گرد کن.

5. از `grid` برای چیدمان دقیق استفاده کن.

**راهنمایی:** برای کارت‌های اطلاعاتی از `CTkFrame` با `fg_color="gray25"` استفاده کن تا برجسته بشن.
