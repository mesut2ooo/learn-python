## 🎯 درس ۴.۲: ورودی‌ها (Arguments) و خروجی‌ها (`return`)

---

### 📦 تابع با ورودی و خروجی یعنی چی؟

یک کارخونه یا دستگاه رو در نظر بگیر؛ شما بهش مواد اولیه می‌دی (ورودی) و اون بعد از پردازش، بهت محصول نهایی رو تحویل میده (خروجی).

تا الان توابعی که نوشتیم فقط یه کار ثابت رو انجام می‌دادن و هیچ ورودی یا خروجی نداشتن. ولی توی دنیای واقعی، توابع باید **انعطاف‌پذیر** باشن و بتونن با داده‌های مختلف کار کنن.

> **📌 سه بخش اصلی هر تابع:**
> 1. **ورودی (Input/Parameter):** داده‌هایی که به تابع می‌دی
> 2. **پردازش (Processing):** کاری که تابع روی ورودی‌ها انجام میده
> 3. **خروجی (Output/Return):** نتیجه‌ای که تابع بهت برمی‌گردونه

---

### ۱. فرستادن ورودی به تابع (Parameters & Arguments)

برای اینکه به تابع ورودی بدیم، متغیرهای موردنیازمون رو داخل پرانتز تعریف می‌کنیم. به این متغیرها می‌گیم **پارامتر (Parameter)**. موقع صدا زدن تابع، مقدار واقعی رو داخل پرانتز براش می‌فرستیم که بهش می‌گیم **آرگومان (Argument)**.

```python
# تعریف تابع با یک ورودی به نام name
def greet_user(name):
    print(f"سلام {name}! به سیستم خوش آمدید.")

# صدا زدن تابع با مقادیر مختلف
greet_user("امیر")    # خروجی: سلام امیر! به سیستم خوش آمدید.
greet_user("سارا")    # خروجی: سلام سارا! به سیستم خوش آمدید.
greet_user("علی")     # خروجی: سلام علی! به سیستم خوش آمدید.
```

#### چند ورودی به تابع

می‌تونی چند تا ورودی به تابع بدی؛ کافیه اون‌ها رو با کاما از هم جدا کنی:

```python
def print_sum(a, b):
    result = a + b
    print(f"جمع دو عدد {a} و {b} برابر است با: {result}")

print_sum(10, 5)   # خروجی: جمع دو عدد 10 و 5 برابر است با: 15
print_sum(7, 3)    # خروجی: جمع دو عدد 7 و 3 برابر است با: 10
print_sum(100, 50) # خروجی: جمع دو عدد 100 و 50 برابر است با: 150
```

#### انواع مختلف پارامترها

```python
# پارامترهای با انواع مختلف
def show_user_info(name, age, is_active, salary):
    print(f"نام: {name}")
    print(f"سن: {age}")
    print(f"وضعیت: {'فعال' if is_active else 'غیرفعال'}")
    print(f"حقوق: {salary:,} تومان")

show_user_info("احمد", 25, True, 15000000)
# خروجی:
# نام: احمد
# سن: 25
# وضعیت: فعال
# حقوق: 15,000,000 تومان
```

### ۲. گرفتن خروجی از تابع (`return`)

توی تابع `print_sum` ما فقط نتیجه رو چاپ کردیم. اما در ۹۰٪ مواقع در برنامه‌نویسی، ما نمی‌خوایم تابع چیزی رو چاپ کنه! بلکه می‌خوایم محاسبات رو انجام بده و **نتیجه رو به ما پس بده** تا بتونیم در ادامه برنامه‌مون از اون نتیجه استفاده کنیم (مثلاً بریزیمش توی یک متغیر دیگه یا روش محاسبات بیشتری انجام بدیم).

برای پس دادن مقدار از کلمه کلیدی `return` استفاده می‌کنیم:

```python
def calculate_area(width, height):
    area = width * height
    return area  # نتیجه رو پس بده به جایی که تابع صدا زده شده

# حالا نتیجه رو می‌گیریم و توی یک متغیر ذخیره می‌کنیم
my_room_area = calculate_area(5, 4)
print(f"مساحت اتاق من: {my_room_area}")  # خروجی: 20

# می‌تونیم مستقیم هم ازش استفاده کنیم
print(f"مساحت زمین: {calculate_area(10, 12)}")  # خروجی: 120

# می‌تونیم توی محاسبات دیگه استفاده کنیم
total_area = calculate_area(5, 4) + calculate_area(3, 2)
print(f"مجموع مساحت دو اتاق: {total_area}")  # خروجی: 26
```

### 🔄 تفاوت `print` و `return`

این یکی از مهم‌ترین مفاهیم تابع‌هاست:

| ویژگی | `print()` | `return` |
|-------|-----------|----------|
| کاری که می‌کنه | مقدار رو **نمایش** میده | مقدار رو **برمی‌گردونه** |
| قابل استفاده در ادامه؟ | ❌ نه | ✅ بله |
| نوع خروجی | `None` (هیچی) | مقدار مشخص |
| محل استفاده | فقط برای نمایش | برای ذخیره، محاسبه و استفاده |

```python
# تابع با print
def add_print(a, b):
    result = a + b
    print(result)  # فقط نمایش میده

# تابع با return
def add_return(a, b):
    result = a + b
    return result  # برمی‌گردونه

# استفاده از تابع اول
x = add_print(5, 3)  # خروجی: 8
print(x)  # خروجی: None (چون تابع چیزی برنگردوند)

# استفاده از تابع دوم
y = add_return(5, 3)  # هیچی چاپ نمیشه
print(y)  # خروجی: 8 (مقدار برگشتی رو ذخیره کردیم)
```

> **💡 قانون طلایی:** اگه می‌خوای نتیجه‌ی تابع رو توی ادامه‌ی برنامه استفاده کنی، از `return` استفاده کن. اگه فقط می‌خوای چیزی رو به کاربر نشون بدی، از `print` استفاده کن.

### ⚡ توقف تابع با `return`

به محض اینکه پایتون در اجرای تابع به دستور `return` برسه، کار تابع در جا تموم میشه و از تابع خارج میشه. یعنی هر خط کدی که بعد از `return` نوشته بشه، هیچ‌وقت اجرا نمیشه!

```python
def check_age(age):
    if age < 18:
        return "نوجوان"  # اینجا تابع تموم میشه
    if age < 30:
        return "جوان"    # اگه به اینجا برسه، تابع تموم میشه
    return "بزرگسال"     # اگه به اینجا برسه، تابع تموم میشه
    print("این خط هیچوقت اجرا نمیشه!")  # ❌ غیرقابل دسترس

print(check_age(15))  # خروجی: نوجوان
print(check_age(25))  # خروجی: جوان
print(check_age(40))  # خروجی: بزرگسال
```

### 🎯 پارامترهای پیش‌فرض (Default Parameters)

گاهی می‌خوایم برای پارامترها یه مقدار پیش‌فرض تعیین کنیم که اگه کاربر مقداری نفرستاد، از اون استفاده کنه:

```python
def greet_user(name, greeting="سلام"):
    print(f"{greeting} {name}!")

greet_user("احمد")              # خروجی: سلام احمد!
greet_user("سارا", "خوش آمدید") # خروجی: خوش آمدید سارا!
greet_user("علی", "درود")       # خروجی: درود علی!

def calculate_discount(price, discount_percent=10):
    discount = price * discount_percent / 100
    return price - discount

print(calculate_discount(100000))        # خروجی: 90000.0 (تخفیف ۱۰ درصد)
print(calculate_discount(100000, 20))    # خروجی: 80000.0 (تخفیف ۲۰ درصد)
```

### 📌 اشتباهات رایج در این درس

> **🔴 فراموش کردن `return` در تابع:**
```python
def add(a, b):
    result = a + b
    # ❌ فراموش شده: return result

x = add(5, 3)
print(x)  # خروجی: None (چون تابع چیزی برنگردوند)
```

> **🟡 نوشتن کد بعد از `return`:**
```python
def test():
    return 5
    print("این خط هیچوقت اجرا نمیشه")  # ❌ غیرقابل دسترس!
```

> **🟢 قاطی کردن ترتیب پارامترها:**
```python
def divide(a, b):
    return a / b

divide(2, 10)  # خروجی: 0.2 (۲ تقسیم بر ۱۰)
divide(10, 2)  # خروجی: 5.0 (۱۰ تقسیم بر ۲)
```

> **🟣 فراموش کردن تبدیل نوع ورودی:**
```python
price = input("قیمت: ")  # این یه str هست
tax = calculate_tax(price, 0.09)  # ❌ خطا! price باید عدد باشه
price = float(input("قیمت: "))  # ✅ درسته
```

### 🛠️ نوبت توئه: چالش محاسبه مالیات فاکتور!

بیا یک تابع کاربردی برای سیستم‌های فروشگاهی بنویسیم که مالیات بر ارزش افزوده رو برای یک کالا محاسبه می‌کنه.

**صورت مسئله:**

1. یک تابع به نام `calculate_tax` بنویس که دو تا ورودی بگیره: `price` (قیمت کالا) و `tax_rate` (نرخ مالیات به صورت اعشاری، مثلاً `0.09` برای ۹ درصد).
2. داخل تابع، مبلغ مالیات رو حساب کن (قیمت ضربدر نرخ مالیات).
3. مبلغ مالیات محاسبه شده رو با استفاده از `return` از تابع پس بفرست.
4. بیرون از تابع، قیمت یک کالا (`500000`) و نرخ مالیات (`0.09`) رو به تابع بده و خروجی رو توی یک متغیر به نام `tax_amount` ذخیره کن.
5. در نهایت با دستور `print`، مبلغ مالیات محاسبه شده رو در خروجی چاپ کن.

---

### 💪 چالش دوم (اختیاری - برای تحلیلگران مالی!)

حالا که با پارامترها و return آشنا شدی، یه سیستم **محاسبه قیمت نهایی** کامل بساز:

1. سه تابع بنویس:

   **تابع اول: `calculate_discount(price, discount_percent)`**
   - ورودی: قیمت اصلی و درصد تخفیف
   - خروجی: مبلغ تخفیف (قیمت × درصد ÷ ۱۰۰)
   - برگردون با `return`

   **تابع دوم: `calculate_tax(price, tax_rate)`**
   - ورودی: قیمت و نرخ مالیات
   - خروجی: مبلغ مالیات (قیمت × نرخ)
   - برگردون با `return`

   **تابع سوم: `calculate_final_price(price, discount_percent, tax_rate)`**
   - ورودی: قیمت اصلی، درصد تخفیف و نرخ مالیات
   - از دو تابع بالا برای محاسبه تخفیف و مالیات استفاده کن
   - قیمت نهایی = قیمت اصلی - تخفیف + مالیات
   - برگردون با `return`

2. بیرون از توابع، این کارها رو انجام بده:
   - قیمت اصلی رو از کاربر بگیر
   - درصد تخفیف رو از کاربر بگیر
   - نرخ مالیات رو از کاربر بگیر
   - با توابع، قیمت نهایی رو محاسبه کن
   - نتیجه رو به این شکل چاپ کن:

```text
قیمت اصلی: 500,000 تومان
درصد تخفیف: 15%
مبلغ تخفیف: 75,000 تومان
مالیات (9%): 38,250 تومان
قیمت نهایی: 463,250 تومان
```

> **💡 نکته:** برای تبدیل ورودی کاربر به عدد از `float()` یا `int()` استفاده کن. برای نمایش اعداد با جداکننده هزارتا، می‌تونی از `f"{number:,}"` استفاده کنی.
