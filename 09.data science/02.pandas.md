### 🐼 پانداس یعنی چی؟

اگر کار با فایل‌های اکسل (`Excel`) یا جدول‌های بانک اطلاعاتی رو دوست داری، پانداس برای تو مثل یک معجزه خواهد بود. این کتابخانه به ما اجازه میده فایل‌های بزرگ داده (مثل فایل‌های `CSV` یا `Excel`) رو لود کنیم، روی آن‌ها فیلترهای پیشرفته بذاریم و مثل یک اکسل فوق‌سریع و برنامه‌نویسی‌شده باهاشون رفتار کنیم.

در پانداس دو ساختار داده بسیار مهم داریم:

| ساختار | توضیح | مثال |
|--------|-------|------|
| **Series (سری)** | یک ستون تک‌بعدی از داده‌ها | ستون "سن" در یک جدول |
| **DataFrame (دیتا فریم)** | یک جدول دوبعدی متشکل از سطرها و ستون‌ها | کل جدول کاربران |

> **📌 تشبیه:** اگه Excel رو در نظر بگیری، یک `Series` مثل یک ستون توی اکسل هست و یک `DataFrame` مثل کل شیت (Sheet) اکسل.

### 💻 اولین دیتای جدولی شما با DataFrame

بیا یک جدول اطلاعاتی کوچک از مشخصات چند کاربر پیام‌رسان ناشناس (`Anonyma`) بسازیم و ببینیم چطور پانداس اون رو به شکل یک جدول شیک و ساختاریافته به ما نشون میده:

```python
import pandas as pd  # معمولاً pandas را به صورت pd وارد می‌کنیم

# ۱. ساخت دیتای اولیه به صورت دیکشنری پایتون
data = {
    "Username": ["Silent_Ninja", "Ghost_Coder", "Masked_Hero", "Shadow_Dev"],
    "Age": [22, 28, 19, 31],
    "Room_Code": [1209, 1209, 2050, 1209],
    "Messages_Sent": [45, 120, 8, 89]
}

# ۲. تبدیل دیکشنری به یک DataFrame (جدول پانداس)
df = pd.DataFrame(data)

# ۳. نمایش کل جدول روی صفحه
print("--- جدول اطلاعات کاربران ---")
print(df)
print("\n---------------------------\n")

# ۴. فیلتر کردن هوشمند داده‌ها!
# بیا فقط کاربرانی رو پیدا کنیم که بیشتر از ۴۰ پیام فرستادن
active_users = df[df["Messages_Sent"] > 40]

print("--- کاربران فعال (پیام بیشتر از ۴۰) ---")
print(active_users)
```

**خروجی:**
```text

0  Silent_Ninja   22       1209             45
1   Ghost_Coder   28       1209            120

3   Shadow_Dev    31       1209             89

--- کاربران فعال (پیام بیشتر از ۴۰) ---
       Username  Age  Room_Code  Messages_Sent
0  Silent_Ninja   22       1209             45
1   Ghost_Coder   28       1209            120
3   Shadow_Dev    31       1209             89
```

### 🔍 ترفندهای جادویی پانداس برای تحلیل سریع

وقتی با یک جدول بزرگ کار می‌کنی، این متدها در ثانیه بهت گزارش میدن:

#### ۱. مشاهده بخشی از داده‌ها

```python
# ۵ سطر اول
print(df.head())      # پیش‌فرض ۵ سطر
print(df.head(2))     # ۲ سطر اول

# ۵ سطر آخر
print(df.tail())      # پیش‌فرض ۵ سطر
print(df.tail(2))     # ۲ سطر آخر

# اطلاعات کلی جدول
print(df.info())      # تعداد سطرها، نوع ستون‌ها، مقدارهای خالی

# آمار توصیفی (فقط ستون‌های عددی)
print(df.describe())  # میانگین، انحراف معیار، درصدها
```

#### ۲. دسترسی به ستون‌ها و سطرها

```python
# دسترسی به یک ستون
print(df["Username"])        # سری (Series)
print(df.Username)           # همینطور (با نقطه)

# دسترسی به چند ستون
print(df[["Username", "Age"]])

# دسترسی به یک سطر با ایندکس
print(df.iloc[0])            # سطر اول (با ایندکس عددی)
print(df.iloc[1:3])          # سطرهای ۱ تا ۲

# دسترسی به یک سطر با نام ایندکس
print(df.loc[0])             # سطر با ایندکس ۰
```

#### ۳. فیلتر کردن داده‌ها

```python
# فیلتر ساده
active = df[df["Messages_Sent"] > 40]

# فیلتر با چند شرط
active_young = df[(df["Messages_Sent"] > 40) & (df["Age"] < 30)]

# فیلتر با isin
rooms = df[df["Room_Code"].isin([1209, 2050])]

# فیلتر با not
not_room_1209 = df[df["Room_Code"] != 1209]
```

#### ۴. عملیات‌های محاسباتی

```python
# جمع یک ستون
total_messages = df["Messages_Sent"].sum()
print(f"مجموع پیام‌ها: {total_messages}")  # 262

# میانگین یک ستون
avg_age = df["Age"].mean()
print(f"میانگین سن: {avg_age:.1f}")  # 25.0

# تعداد اعضای هر اتاق
room_counts = df["Room_Code"].value_counts()
print(room_counts)
# 1209    3
# 2050    1

# مرتب‌سازی
sorted_by_age = df.sort_values("Age", ascending=False)
print(sorted_by_age)  # از بزرگ به کوچک
```

### 💻 مثال کامل: تحلیل داده‌های فروش

```python
import pandas as pd

# داده‌های فروش
sales_data = {
    "Product": ["لپ‌تاپ", "موبایل", "هدفون", "تبلت", "ساعت"],
    "Price": [25000000, 15000000, 3000000, 12000000, 8000000],
    "Quantity_Sold": [45, 80, 120, 30, 55],
    "Category": ["الکترونیک", "الکترونیک", "لوازم جانبی", "الکترونیک", "لوازم جانبی"]
}

df = pd.DataFrame(sales_data)

# محاسبه درآمد کل
df["Total_Revenue"] = df["Price"] * df["Quantity_Sold"]

print("📊 جدول فروش:")
print(df)

print("\n📈 آمار فروش:")
print(df.describe())

print("\n🏆 پرفروش‌ترین محصول:")
best_product = df.loc[df["Quantity_Sold"].idxmax()]
print(f"محصول: {best_product['Product']} با {best_product['Quantity_Sold']} عدد")

print("\n💰 مجموع درآمد هر دسته:")
category_revenue = df.groupby("Category")["Total_Revenue"].sum()
print(category_revenue)

print("\n📊 محصولات با درآمد بالای ۵۰۰ میلیون:")
high_revenue = df[df["Total_Revenue"] > 500000000]
print(high_revenue[["Product", "Total_Revenue"]])
```

### 📌 اشتباهات رایج در این درس

> **🔴 فراموش کردن `import pandas as pd`:**
```python
df = pd.DataFrame(data)  # ❌ خطا! pd تعریف نشده

import pandas as pd  # ✅ باید اول وارد کنی
```

> **🟡 قاطی کردن `.iloc` با `.loc`:**
```python
# iloc: برای ایندکس عددی
df.iloc[0]     # سطر اول

# loc: برای ایندکس نام‌گذاری شده
df.loc["row1"] # سطر با نام row1
```

> **🟢 فراموش کردن `[]` برای دسترسی به چند ستون:**
```python
df["Name", "Age"]  # ❌ اشتباه! دو ستون با کاما
df[["Name", "Age"]]  # ✅ درسته (لیست داخل براکت)
```

> **🟣 استفاده از حلقه به جای عملیات برداری:**
```python
# ❌ روش کند
for i in range(len(df)):
df.loc[i, "New_Column"] = df.loc[i, "A"] + df.loc[i, "B"]

# ✅ روش سریع
df["New_Column"] = df["A"] + df["B"]
```

2. این تحلیل‌ها رو انجام بده:
   - تعداد کل دانشجویان

   - بالاترین و پایین‌ترین معدل
   - دانشجویان با معدل بالای ۱۸

   - معدل بالای ۱۸ = `"عالی"`
