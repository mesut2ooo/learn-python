# 🐍 دوره آموزشی جامع پایتون (Python)

![Python Version](https://img.shields.io/badge/python-3.8%2B-blue)
![License](https://img.shields.io/badge/license-MIT-green)
![Status](https://img.shields.io/badge/status-completed-brightgreen)

سلام! این یه دوره **رایگان** و **متن‌محور** برای یادگیری پایتون از صفر تا مباحث پیشرفته‌ست. 
همه فایل‌ها به صورت درس‌به‌درس و همراه با مثال‌های عملی آماده شدن.

---

## 📚 سرفصل‌های دوره

- **بخش اول**: مبانی پایتون (متغیرها، حلقه‌ها، شرط‌ها، توابع)
- **بخش دوم**: کار با لیست‌ها، دیکشنری‌ها و تاپل‌ها
- **بخش سوم**: برنامه‌نویسی شی‌گرا (کلاس و آبجکت)
- **بخش چهارم**: کار با فایل‌ها و مدیریت استثناها
- **بخش پنجم**: آشنایی با کتابخانه‌های محبوب (Requests, Pandas, Matplotlib)
- **بخش ششم**: پروژه عملی (ساخت یک اپلیکیشن خط فرمان)

---

## 🚀 نحوه استفاده

1. ریپازیتوری رو کلون کن:
   ```bash
   git clone https://github.com/username/Python-Course.git
   ```
2. وارد پوشه بشو:
   ```bash
   cd Python-Course
   ```
3. فایل‌های هر درس رو به ترتیب شماره مطالعه کن.

> **نکته**: برای اجرای کدها، پایتون نسخه ۳.۸ یا بالاتر رو نصب داشته باش.
