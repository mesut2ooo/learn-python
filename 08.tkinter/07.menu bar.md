# 🖥️ فصل هشتم: طراحی رابط کاربری (GUI) با Tkinter

## 🎯 درس ۸.۷: ساخت منوی بالایی دسکتاپ (`Menu Bar`)

---

### 📋 منوی بالایی یعنی چی؟

حالا که یاد گرفتی چطور ویجت‌های مختلف را با این استایل مدرن روی صفحه بچینی، وقتش رسیده که به برنامه‌مان یک بخش ناوبری و هدایتگر اضافه کنیم. در برنامه‌های دسکتاپ، یکی از اصلی‌ترین راه‌ها برای دسترسی به تنظیمات، راهنما یا خروج، **منوی بالایی یا همان Menu Bar** است.

در این درس یاد می‌گیریم چطور یک منوی استاندارد و منظم بالای پنجره‌مان بسازیم.

> **📌 نکته:** اگرچه برای بدنه اصلی برنامه از `customtkinter` استفاده می‌کنیم، اما برای ساخت منوی سیستم‌عامل دسکتاپ همچنان از ابزار بومی و قدرتمند خود `tkinter` کمک می‌گیریم، چون این ابزار به طور خودکار خودش را با نوار بالای پنجره سیستم‌عامل (ویندوز یا مک) هماهنگ می‌کند.

---

### 💻 ساختار منو در Tkinter

منوها در Tkinter از سه بخش اصلی تشکیل شدن:

| بخش | توضیح | مثال |
|-----|-------|------|
| **Menu Bar** | نوار اصلی منو در بالای پنجره | `menu_bar = tk.Menu(app)` |
| **Menu** | زیرمنوهای کشویی | `file_menu = tk.Menu(menu_bar, tearoff=0)` |
| **Command** | آیتم‌های قابل کلیک در منو | `file_menu.add_command(label="خروج", command=exit_app)` |

---

### 💻 چطور یک منوی چند گزینه‌ای بسازیم؟

بیا کدهای پروژه مدرن `Anonyma` را برداریم و یک منوی شیک بالای آن بسازیم که شامل بخش‌های «فایل» و «تنظیمات» باشد:

```python
import tkinter as tk
import customtkinter as ctk
from tkinter import messagebox

# تنظیم تم برنامه
ctk.set_appearance_mode("dark")
ctk.set_default_color_theme("blue")

# توابع مربوط به گزینه‌های منو
def show_about():
    messagebox.showinfo(
        "درباره Anonyma", 
        "اپلیکیشن پیام‌رسان ناشناس نسخه 1.0.0\n"
        "طراحی شده با پایتون و CustomTkinter 🚀\n"
        "✅ ارسال پیام ناشناس\n"
        "✅ اتاق‌های گفت‌وگو\n"
        "✅ رابط کاربری مدرن"
    )

def change_theme_light():
    ctk.set_appearance_mode("light")
    messagebox.showinfo("تغییر پوسته", "حالت روشن فعال شد! ☀️")

def change_theme_dark():
    ctk.set_appearance_mode("dark")
    messagebox.showinfo("تغییر پوسته", "حالت تاریک فعال شد! 🌙")

def change_theme_system():
    ctk.set_appearance_mode("system")
    messagebox.showinfo("تغییر پوسته", "حالت سیستمی فعال شد! 💻")

def exit_app():
    if messagebox.askyesno("خروج", "آیا مطمئن هستید که می‌خواهید خارج شوید؟"):
        app.destroy()

# ساخت پنجره اصلی
app = ctk.CTk()
app.title("Anonyma Messenger")
app.geometry("450x400")

# ================= ساخت منو بار =================
# ۱. ساخت نوار منوی اصلی
menu_bar = tk.Menu(app)

# ۲. ساخت زیرمنوی "فایل" (File Menu)
file_menu = tk.Menu(menu_bar, tearoff=0)
file_menu.add_command(label="📄 جدید", command=lambda: messagebox.showinfo("جدید", "پنجره جدید باز شد!"))
file_menu.add_separator()  # خط جداکننده
file_menu.add_command(label="🚪 خروج از برنامه", command=exit_app)

# ۳. ساخت زیرمنوی "پوسته" (Theme Menu)
theme_menu = tk.Menu(menu_bar, tearoff=0)
theme_menu.add_command(label="☀️ حالت روشن", command=change_theme_light)
theme_menu.add_command(label="🌙 حالت تاریک", command=change_theme_dark)
theme_menu.add_command(label="💻 حالت سیستمی", command=change_theme_system)

# ۴. ساخت زیرمنوی "درباره ما" (About Menu)
about_menu = tk.Menu(menu_bar, tearoff=0)
about_menu.add_command(label="ℹ️ درباره نرم‌افزار", command=show_about)
about_menu.add_command(label="📖 راهنما", command=lambda: messagebox.showinfo("راهنما", "راهنمای برنامه در حال آماده‌سازی..."))

# ۵. اضافه کردن زیرمنوها به نوار اصلی با عنوان دلخواه
menu_bar.add_cascade(label="فایل", menu=file_menu)
menu_bar.add_cascade(label="پوسته", menu=theme_menu)
menu_bar.add_cascade(label="راهنما", menu=about_menu)

# ۶. معرفی نوار منو به عنوان منوی اصلی پنجره
app.config(menu=menu_bar)
# ===============================================

# بدنه اصلی برنامه
title_label = ctk.CTkLabel(
    app, 
    text="💬 Anonyma Messenger", 
    font=("Tahoma", 24, "bold"), 
    text_color="cyan"
)
title_label.pack(pady=40)

subtitle_label = ctk.CTkLabel(
    app, 
    text="پیام‌رسان ناشناس و امن", 
    font=("Tahoma", 14), 
    text_color="gray70"
)
subtitle_label.pack(pady=5)

room_entry = ctk.CTkEntry(
    app, 
    placeholder_text="کد اتاق گفت‌وگو (مثلاً: 1209)", 
    width=280,
    height=45,
    corner_radius=12
)
room_entry.pack(pady=20)

def join_room():
    room_code = room_entry.get()
    if room_code.strip():
        messagebox.showinfo("ورود به اتاق", f"✅ وارد اتاق {room_code} شدید!")
    else:
        messagebox.showwarning("خطا", "لطفاً کد اتاق را وارد کنید!")

join_button = ctk.CTkButton(
    app, 
    text="🚪 ورود به اتاق", 
    corner_radius=12,
    width=280,
    height=45,
    font=("Tahoma", 14, "bold"),
    command=join_room
)
join_button.pack(pady=10)

status_label = ctk.CTkLabel(app, text="وضعیت: آفلاین", font=("Tahoma", 12), text_color="gray50")
status_label.pack(pady=20)

app.mainloop()
```

### 🔍 کدهای بالا چطور کار می‌کنند؟

| بخش | توضیح |
|-----|-------|
| **`tk.Menu(app)`** | نوار خالی منو را تعریف می‌کند |
| **`add_cascade()`** | مانند یک لولا عمل کرده و زیرمنوها را به نوار اصلی وصل می‌کند |
| **`add_command()`** | آیتم‌های قابل کلیک درون هر منوی کشویی را می‌سازد |
| **`add_separator()`** | یک خط جداکننده بین آیتم‌های منو اضافه می‌کند |
| **`app.config(menu=menu_bar)`** | نوار منو را به عنوان منوی اصلی پنجره تنظیم می‌کند |
| **`tearoff=0`** | کاربر نمی‌تونه منو رو از پنجره جدا کنه |

---

### 🎨 آیتم‌های ویژه در منو

#### ۱. خط جداکننده (`add_separator`)

```python
file_menu.add_command(label="ذخیره", command=save_file)
file_menu.add_separator()  # خط جداکننده
file_menu.add_command(label="خروج", command=exit_app)
```

#### ۲. منوی تودرتو (زیرمنو در زیرمنو)

```python
sub_menu = tk.Menu(theme_menu, tearoff=0)
sub_menu.add_command(label="آبی", command=lambda: set_color("blue"))
sub_menu.add_command(label="سبز", command=lambda: set_color("green"))

theme_menu.add_cascade(label="انتخاب رنگ", menu=sub_menu)
```

#### ۳. استفاده از `lambda` برای توابع سریع

```python
# برای توابع ساده‌ای که فقط یک خط کد دارن
file_menu.add_command(label="سلام", command=lambda: print("سلام!"))
```

### 📌 اشتباهات رایج در این درس

> **🔴 فراموش کردن `app.config(menu=menu_bar)`:**
```python
menu_bar = tk.Menu(app)
file_menu = tk.Menu(menu_bar, tearoff=0)
menu_bar.add_cascade(label="فایل", menu=file_menu)
# ❌ فراموش شده: app.config(menu=menu_bar)
```

> **🟡 قاطی کردن `add_command` با `add_cascade`:**
```python
# add_command برای آیتم‌های قابل کلیک
file_menu.add_command(label="خروج", command=exit_app)

# add_cascade برای زیرمنوها
menu_bar.add_cascade(label="فایل", menu=file_menu)
```

> **🟢 فراموش کردن `tearoff=0`:**
```python
# ❌ منو قابل جداشدن از پنجره میشه
file_menu = tk.Menu(menu_bar)

# ✅ منو قابل جداشدن نیست
file_menu = tk.Menu(menu_bar, tearoff=0)
```

> **🟣 استفاده از `tk.Menu` برای CustomTkinter:**
```python
# درست: منوها همیشه با tk.Menu ساخته میشن
menu_bar = tk.Menu(app)  # ✅ درسته

# غلط: CustomTkinter برای منو پشتیبانی نداره
menu_bar = ctk.CTkMenu(app)  # ❌ خطا!
```

### 🛠️ نوبت توئه: چالش شخصی‌سازی منوی Anonyma!

بیا منوی این پیام‌رسان را غنی‌تر کنیم و چند قابلیت کاربردی و جالب به آن اضافه کنیم.

**صورت مسئله:**

1. کدهای بالا را به طور کامل در ادیتورت کپی و اجرا کن تا نوار منو را در بالای پنجره‌ات ببینی.
2. با کلیک روی گزینه‌های منو مطمئن شو که حالت تاریک/روشن و پنجره پاپ‌آپ درباره ما به درستی کار می‌کنند.
3. حالا تغییرات زیر را اعمال کن:
   - زیرمنوی جدیدی به نام **"تنظیمات اتاق"** بساز و به منوبار اصلی اضافه‌اش کن.
   - داخل این منوی جدید، دو گزینه (Command) قرار بده:
     1. `"پاک کردن پیام‌ها"` (وقتی کلیک شد، یک پیغام `messagebox.showinfo` با متن `"تمام پیام‌ها پاکسازی شدند."` نشان دهد).
     2. `"تغییر نام مستعار"` (وقتی کلیک شد، پیغامی نشان دهد که بگوید `"این قابلیت در نسخه‌های بعدی فعال می‌شود"`).

### 💪 چالش دوم (اختیاری - برای توسعه‌دهندگان نرم‌افزارهای حرفه‌ای!)

حالا که با منوها آشنا شدی، یه **سیستم مدیریت پروژه** با منوی کامل طراحی کن:

1. یک برنامه با عنوان `"مدیریت پروژه"` بساز.

2. منوی کامل زیر رو پیاده‌سازی کن:

   **منوی `"پروژه"`:**
   - `"جدید"` → پیام `"پروژه جدید ایجاد شد"`
   - `"باز کردن"` → پیام `"پروژه باز شد"`
   - `"ذخیره"` → پیام `"پروژه ذخیره شد"`
   - `"-----"` (خط جداکننده)
   - `"خروج"` → با تأیید از کاربر خارج بشه

   **منوی `"ویرایش"`:**
   - `"برش"` → پیام `"برش انجام شد"`
   - `"کپی"` → پیام `"کپی انجام شد"`
   - `"چسباندن"` → پیام `"چسباندن انجام شد"`

   **منوی `"نمایش"`:**
   - `"حالت تاریک"` → تغییر به dark mode
   - `"حالت روشن"` → تغییر به light mode
   - `"حالت سیستمی"` → تغییر به system mode

   **منوی `"راهنما"`:**
   - `"راهنما"` → پیام `"راهنما در حال آماده‌سازی"`
   - `"درباره"` → پیام با اطلاعات کامل برنامه

3. از `add_separator()` برای خطوط جداکننده استفاده کن.

4. از `lambda` برای توابع ساده استفاده کن.

5. برای خروج حتماً از `askyesno` تأیید بگیر.
