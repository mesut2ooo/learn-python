# 📓 فصل پنجم: ورود به دنیای واقعی (فایل‌ها و خطایابی)

## 🎯 درس ۵.۴: نصب کتابخانه‌ها (`pip`) و محیط‌های مجازی (`venv`)

---

### 📦 چطور کتابخانه‌های خارجی رو نصب کنیم؟

تا الان با کتابخانه‌های استاندارد پایتون کار کردیم که همراه خود پایتون نصب شدن. اما دنیای واقعی پر از کتابخانه‌های فوق‌العاده‌ست که باید خودمون نصبشون کنیم.

برای نصب کتابخانه‌های خارجی، پایتون یک ابزار قدرتمند به اسم **`pip`** (مخفف Pip Installs Packages) داره.

> **📌 `pip` چیست؟**
> `pip` یک مدیر بسته (Package Manager) برای پایتونه. با اون می‌تونی کتابخانه‌های خارجی رو نصب، بروزرسانی یا حذف کنی.

---

### 🛠️ دستورات پایه `pip`

#### نصب یک کتابخانه

```bash
pip install package_name
```

مثال‌ها:
```bash
pip install pygame          # نصب pygame برای بازی‌سازی
pip install pandas          # نصب pandas برای تحلیل داده
pip install numpy           # نصب numpy برای محاسبات عددی
pip install requests        # نصب requests برای کار با API
```

#### نصب نسخه‌ی خاص

```bash
pip install package_name==1.2.3
```

#### دیدن کتابخانه‌های نصب‌شده

```bash
pip list                    # لیست همه کتابخانه‌ها
pip show package_name       # اطلاعات یک کتابخانه خاص
```

#### حذف یک کتابخانه

```bash
pip uninstall package_name
```

#### بروزرسانی یک کتابخانه

```bash
pip install --upgrade package_name
```

### 🏠 محیط مجازی (Virtual Environment) چیست؟

فرض کن داری روی دو پروژه‌ی مختلف کار می‌کنی:
- **پروژه‌ی A:** با `pygame 2.0.0` کار می‌کنه
- **پروژه‌ی B:** با `pygame 2.5.0` کار می‌کنه

اگه هر دو رو روی سیستم نصب کنی، ممکنه تداخل ایجاد بشه و یکی از پروژه‌ها کار نکنه!

اینجاست که **محیط مجازی (Virtual Environment)** به کمکمون میاد. محیط مجازی مثل یک **جعبه‌ی جداگانه** برای هر پروژه‌ست که کتابخانه‌های مخصوص خودش رو داره و با بقیه پروژه‌ها تداخل نداره.

> **📌 تشبیه ساده:** محیط مجازی مثل یه اتاق مجزا در خونه‌ست. هر اتاق وسایل خودش رو داره و با اتاق دیگه قاطی نمیشه!

---

### 💻 ساخت محیط مجازی با `venv`

پایتون یک ابزار داخلی به اسم `venv` داره که با اون می‌تونی محیط مجازی بسازی.

#### ۱. ساخت محیط مجازی

```bash
python -m venv myenv
```

این دستور یک پوشه به اسم `myenv` می‌سازه که محیط مجازی شما توش قرار داره.

#### ۲. فعال‌سازی محیط مجازی

**ویندوز:**
```bash
myenv\Scripts\activate
```

**مک/لینوکس:**
```bash
source myenv/bin/activate
```

وقتی محیط مجازی فعال باشه، اسمش رو جلوی ترمینال می‌بینی:
```text
(myenv) C:\Users\YourName>
```

#### ۳. نصب کتابخانه در محیط مجازی

حالا هر کتابخانه‌ای که با `pip` نصب کنی، فقط توی همین محیط مجازی نصب میشه:

```bash
pip install pygame
pip install pandas
```

#### ۴. خروج از محیط مجازی

```bash
deactivate
```

---

### 📋 فایل `requirements.txt` (مدیریت وابستگی‌ها)

وقتی یه پروژه رو با دیگران به اشتراک می‌ذاری، باید بهشون بگی چه کتابخانه‌هایی نیاز دارن. این کار با فایل `requirements.txt` انجام میشه.

#### ایجاد فایل requirements.txt

```bash
pip freeze > requirements.txt
```

این دستور لیست همه کتابخانه‌های نصب‌شده در محیط مجازی فعلی رو توی فایل `requirements.txt` ذخیره می‌کنه.

#### نصب کتابخانه‌ها از روی requirements.txt

```bash
pip install -r requirements.txt
```

این دستور همه کتابخانه‌های موجود در فایل رو نصب می‌کنه.

### 🎯 یک مثال عملی کامل

بیا یه پروژه‌ی کوچیک با کتابخانه‌ی خارجی `emoji` بسازیم که ایموجی‌ها رو در پایتون فعال می‌کنه:

#### مرحله ۱: ساخت محیط مجازی

```bash
# ساخت محیط
python -m venv emoji_project

# فعال‌سازی (ویندوز)
emoji_project\Scripts\activate

# فعال‌سازی (مک/لینوکس)
source emoji_project/bin/activate
```

#### مرحله ۲: نصب کتابخانه

```bash
pip install emoji
```

#### مرحله ۳: نوشتن کد

```python
# emoji_demo.py
import emoji

# استفاده از ایموجی‌ها
print(emoji.emojize("سلام دنیا! :earth_americas:"))
print(emoji.emojize("پایتون عالیه! :snake:"))
print(emoji.emojize("حال و هوای امروز :sun_with_face:"))

# خروجی:
# سلام دنیا! 🌎
# پایتون عالیه! 🐍
# حال و هوای امروز 🌞
```

#### مرحله ۴: ذخیره وابستگی‌ها

```bash
pip freeze > requirements.txt
```

#### مرحله ۵: خروج از محیط

```bash
deactivate
```

### 📊 مقایسه کتابخانه‌های استاندارد و خارجی

| ویژگی | استاندارد | خارجی |
|--------|-----------|-------|
| نصب | همراه پایتون | نیاز به `pip` |
| مثال | `math`, `random`, `os` | `pygame`, `pandas`, `numpy` |
| استفاده | `import math` | `pip install pandas` + `import pandas` |
| به‌روزرسانی | با آپدیت پایتون | با `pip install --upgrade` |

### 📌 اشتباهات رایج در این درس

> **🔴 فراموش کردن فعال‌سازی محیط مجازی:**
```bash
# ❌ کتابخانه توی محیط مجازی نصب میشه ولی فعال نیست
python -m venv myenv
pip install pygame  # توی سیستم نصب میشه نه محیط مجازی!

# ✅ باید اول فعال کنی
python -m venv myenv
myenv\Scripts\activate  # ویندوز
pip install pygame      # حالا توی محیط مجازی نصب میشه
```

> **🟡 فراموش کردن `requirements.txt` برای اشتراک‌گذاری:**
```bash
# ❌ به بقیه نمی‌دونی چه کتابخانه‌هایی لازمه

# ✅ باید لیست رو ذخیره کنی
pip freeze > requirements.txt
```

> **🟢 نصب کتابخانه در محیط مجازی ولی استفاده در خارج از اون:**
```bash
# ❌ کتابخانه توی محیط مجازی نصب شده ولی از بیرون صدا زده میشه
python my_script.py  # خطا! کتابخانه پیدا نمیشه

# ✅ باید داخل محیط مجازی باشی
myenv\Scripts\activate
python my_script.py  # درسته
```

> **🟣 قاطی کردن `pip list` با `pip freeze`:**
```bash
pip list      # نمایش همه کتابخانه‌ها (قابل خوندن برای انسان)
pip freeze    # نمایش همه کتابخانه‌ها (قابل استفاده برای requirements.txt)
```

### 🛠️ نوبت توئه: چالش نصب و استفاده از کتابخانه‌ی `colorama`!

`colorama` یک کتابخانه‌ی خارجی هست که بهت اجازه میده توی ترمینال رنگ‌دار بنویسی! بیا با نصب و استفاده از اون آشنا بشیم.

**صورت مسئله:**

1. یک محیط مجازی جدید به اسم `color_project` بساز و فعالش کن.

2. کتابخانه‌ی `colorama` رو با `pip` نصب کن.

3. یک فایل پایتون جدید بساز و کد زیر رو توش بنویس:

```python
from colorama import Fore, Back, Style, init

# مقداردهی اولیه (برای ویندوز)
init()

# چاپ متن‌های رنگی
print(Fore.RED + "این متن قرمز است!")
print(Fore.GREEN + "این متن سبز است!")
print(Fore.YELLOW + "این متن زرد است!")
print(Fore.BLUE + "این متن آبی است!")

# پس‌زمینه رنگی
print(Back.CYAN + "پس‌زمینه‌ی این متن فیروزه‌ای است!")

# بازگشت به حالت عادی
print(Style.RESET_ALL + "این متن عادی است.")
```

4. برنامه رو اجرا کن و از خروجی رنگ‌دار لذت ببر!

5. بعد از اجرا، با `pip freeze > requirements.txt` فایل وابستگی‌ها رو ذخیره کن.

6. در نهایت از محیط مجازی خارج شو.
