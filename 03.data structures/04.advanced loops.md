### 🧩 چرا به داده‌های پیچیده نیاز داریم؟

تا الان یاد گرفتی چطور با لیست‌ها، دیکشنری‌ها، تاپل‌ها و مجموعه‌ها کار کنی. ولی توی دنیای واقعی، داده‌ها به این سادگی‌ها نیستن. معمولاً با **داده‌های تو در تو (Nested Data)** سر و کار داری؛ یعنی لیستی از دیکشنری‌ها، دیکشنری از لیست‌ها، یا حتی ترکیب‌های پیچیده‌تر.

> **📌 مثال دنیای واقعی:** یه فروشگاه اینترنتی رو در نظر بگیر. هر کاربر یه دیکشنریه با اطلاعات شخصی، و هر کاربر یه لیست از سفارشات داره، و هر سفارش هم یه لیست از کالاهاست! این یعنی داده‌های تو در تو در چندین لایه.

### ۱. لیست‌های تو در تو (Nested Lists)

لیست‌ها می‌تونن داخل خودشون لیست‌های دیگه داشته باشن. این خیلی کاربردی‌ست برای ذخیره‌سازی داده‌های جدولی مثل ماتریس‌ها:

```python
# یک ماتریس ۳×۳ (جدول ۳ در ۳)
matrix = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
]

# دسترسی به عضو سطر ۱، ستون ۲ (دقت کن اندیس‌ها از ۰ شروع میشن)
print(matrix[1][2])  # خروجی: 6 (سطر دوم، ستون سوم)

# دسترسی به سطر اول
print(matrix[0])  # خروجی: [1, 2, 3]

# دسترسی به ستون اول (همه سطرها، اندیس ۰)
for row in matrix:
    print(row[0])  # خروجی: 1, 4, 7
```

#### پیمایش لیست‌های تو در تو با حلقه‌های تو در تو

```python
matrix = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
]

# روش ۱: پیمایش با دو حلقه for
for row in matrix:
    for item in row:
        print(item, end=" ")  # end=" " یعنی به جای خط جدید، فاصله بذار
    print()  # بعد از هر سطر یه خط جدید

# خروجی:
# 1 2 3
# 4 5 6
# 7 8 9

# روش ۲: پیمایش با اندیس
for i in range(len(matrix)):
    for j in range(len(matrix[i])):
        print(f"matrix[{i}][{j}] = {matrix[i][j]}")
```

#### کاربرد واقعی: جدول نمرات دانشجویان

```python
# هر سطر = یک دانشجو، هر ستون = نمرات درس‌های مختلف
grades = [
    ["احمد", 18, 15, 19],
    ["سارا", 20, 17, 18],
    ["علی", 14, 16, 15]
]

# چاپ نمرات هر دانشجو
for student in grades:
    name = student[0]
    scores = student[1:]  # از اندیس ۱ تا آخر
    avg = sum(scores) / len(scores)
    print(f"{name}: میانگین = {avg:.2f}")

# خروجی:
# احمد: میانگین = 17.33
# سارا: میانگین = 18.33
# علی: میانگین = 15.00
```

### ۲. دیکشنری‌های تو در تو (Nested Dictionaries)

دیکشنری‌ها می‌تونن داخل خودشون دیکشنری‌های دیگه داشته باشن. این برای ذخیره‌سازی داده‌های سلسله‌مراتبی عالیه:

```python
# اطلاعات یک شرکت با چندین کارمند
company = {
    "name": "تکنولوژی نوین",
    "year": 2010,
    "ceo": {
        "name": "علی محمدی",
        "age": 45,
        "email": "ali@company.com"
    },
    "employees": {
        "emp1": {
            "name": "احمد رضایی",
            "position": "توسعه‌دهنده",
            "salary": 15000000
        },
        "emp2": {
            "name": "سارا کریمی",
            "position": "طراح",
            "salary": 12000000
        }
    }
}

# دسترسی به اطلاعات تو در تو
print(company["ceo"]["name"])  # خروجی: علی محمدی
print(company["employees"]["emp1"]["position"])  # خروجی: توسعه‌دهنده

# پیمایش دیکشنری تو در تو
for emp_id, emp_info in company["employees"].items():
    print(f"{emp_id}: {emp_info['name']} - {emp_info['position']}")
# خروجی:
# emp1: احمد رضایی - توسعه‌دهنده
# emp2: سارا کریمی - طراح
```

### ۳. لیستی از دیکشنری‌ها (List of Dictionaries)

این الگو خیلی پرکاربرده! مثلاً لیست کاربران، لیست محصولات، یا لیست سفارشات:

```python
# لیست کاربران (هر کاربر یه دیکشنریه)
users = [
    {
        "id": 1,
        "name": "احمد رضایی",
        "email": "ahmad@email.com",
        "age": 25,
        "is_active": True
    },
    {
        "id": 2,
        "name": "سارا محمدی",
        "email": "sara@email.com",
        "age": 30,
        "is_active": False
    },
    {
        "id": 3,
        "name": "علی کریمی",
        "email": "ali@email.com",
        "age": 22,
        "is_active": True
    }
]

# پیمایش لیست کاربران
for user in users:
    print(f"{user['name']} ({user['age']} سال) - {user['email']}")

# پیدا کردن کاربر فعال
active_users = []
for user in users:
    if user["is_active"]:
        active_users.append(user["name"])
print(f"کاربران فعال: {active_users}")  # خروجی: ['احمد رضایی', 'علی کریمی']

# محاسبه میانگین سن
total_age = sum(user["age"] for user in users)
avg_age = total_age / len(users)
print(f"میانگین سن: {avg_age:.1f}")  # خروجی: 25.7
```

### ۴. دیکشنری از لیست‌ها (Dictionary of Lists)

این الگو برای دسته‌بندی داده‌ها عالیه:

```python
# دسته‌بندی محصولات بر اساس گروه
products = {
    "الکترونیک": ["لپ‌تاپ", "موبایل", "هدفون"],
    "کتاب‌ها": ["رمان", "علمی", "تاریخی"],
    "پوشاک": ["تی‌شرت", "شلوار", "کت"]
}

# دسترسی به محصولات یک گروه
print(products["الکترونیک"])  # خروجی: ['لپ‌تاپ', 'موبایل', 'هدفون']

# اضافه کردن محصول جدید به یک گروه
products["الکترونیک"].append("تبلت")
print(products["الکترونیک"])  # خروجی: ['لپ‌تاپ', 'موبایل', 'هدفون', 'تبلت']

# پیمایش همه گروه‌ها و محصولات
for category, items in products.items():
    print(f"\n{category}:")
    for item in items:
        print(f"  - {item}")

# خروجی:
# الکترونیک:
#   - لپ‌تاپ
#   - موبایل
#   - هدفون
#   - تبلت
# کتاب‌ها:
#   - رمان
#   - علمی
#   - تاریخی
# پوشاک:
#   - تی‌شرت
#   - شلوار
#   - کت
```

### ۵. مفهوم کپی کردن در لیست‌ها (مرجع در برابر کپی)

این یه بخش مهمه که خیلی از تازه‌کارها رو به دردسر می‌اندازه:

```python
# همه چیز در پایتون با مرجع (Reference) کار می‌کنه
list1 = [1, 2, 3]
list2 = list1  # ❌ این کپی نمی‌کنه! هر دو به یک لیست اشاره می‌کنن

list2.append(4)
print(list1)  # خروجی: [1, 2, 3, 4] (list1 هم تغییر کرده!)
print(list2)  # خروجی: [1, 2, 3, 4]

# برای کپی کردن، باید از روش‌های زیر استفاده کنی:
# روش ۱: استفاده از [:]
list3 = list1[:]  # ✅ کپی واقعی

# روش ۲: استفاده از list()
list4 = list(list1)  # ✅ کپی واقعی

# روش ۳: استفاده از copy()
list5 = list1.copy()  # ✅ کپی واقعی

list3.append(5)
print(list1)  # خروجی: [1, 2, 3, 4] (تغییر نکرده)
print(list3)  # خروجی: [1, 2, 3, 4, 5]
```

### 🛠️ نوبت توئه: چالش سیستم مدیریت فروشگاه!

فرض کن مسئول بخش فناوری اطلاعات یک فروشگاه زنجیره‌ای هستی و می‌خوای سیستم مدیریت محصولات رو طراحی کنی.

**صورت مسئله:**

1. یک لیست از دیکشنری‌ها بساز که اطلاعات ۳ محصول رو ذخیره کنه. هر محصول شامل:
   - `"id"` (عدد)
   - `"name"` (متن)
   - `"price"` (عدد اعشاری)
   - `"category"` (متن)
   - `"in_stock"` (بولین)

2. با یک حلقه `for`، همه‌ی محصولات رو با این فرمت چاپ کن:
   ```
   محصول: لپ‌تاپ | قیمت: 25,500,000 تومان | موجود: بله
   ```

3. با یک حلقه `for`، مجموع قیمت همه‌ی محصولات رو حساب کن و چاپ کن.

4. با یک حلقه `for`، محصولاتی که موجودی دارن (`in_stock == True`) رو توی یه لیست جدید جمع کن و تعدادشون رو چاپ کن.

5. از کاربر یک نام دسته‌بندی (مثلاً `"الکترونیک"`) بگیر و همه‌ی محصولات اون دسته رو چاپ کن.

### 📌 اشتباهات رایج در این درس

> **🔴 فراموش کردن عمق کپی در لیست‌های تو در تو:**
```python
matrix = [[1, 2, 3], [4, 5, 6]]
copy = matrix[:]  # ❌ این فقط کپی سطحی (shallow copy) هست
copy[0][0] = 99
print(matrix[0][0])  # خروجی: 99 (matrix هم تغییر کرده!)

# برای کپی عمیق (deep copy) از copy.deepcopy استفاده کن
import copy
deep = copy.deepcopy(matrix)
deep[0][0] = 100
print(matrix[0][0])  # خروجی: 99 (تغییر نکرده)
```

> **🟡 اشتباه در دسترسی به دیکشنری‌های تو در تو:**
```python
data = {"user": {"name": "احمد"}}
print(data["user"]["name"])  # ✅ درسته
print(data["user"]["age"])   # ❌ خطا! کلید age وجود نداره
print(data.get("user", {}).get("age", "نامشخص"))  # ✅ درسته
```

> **🟢 فراموش کردن اندیس‌ها در پیمایش لیست‌های تو در تو:**
```python
matrix = [[1, 2, 3], [4, 5, 6]]
for i in range(len(matrix)):
    for j in range(len(matrix[i])):
        print(matrix[i][j])  # ✅ درسته
```

> **🟣 استفاده از `=` برای کپی لیست‌ها:**
```python
list1 = [1, 2, 3]
list2 = list1   # ❌ این کپی نیست! هر دو به یک جا اشاره می‌کنن
list2 = list1[:]  # ✅ درسته: کپی واقعی
```

### 💪 چالش دوم (اختیاری - برای تحلیلگران ارشد داده!)

حالا که با داده‌های پیچیده آشنا شدی، یه سیستم **تحلیل فروش** پیشرفته بساز:

1. این دیکشنری از لیست‌ها رو داشته باش:
   ```python
   sales_data = {
       "محصولات": ["لپ‌تاپ", "موبایل", "هدفون", "تبلت", "ساعت هوشمند"],
       "فروش_روزانه": [
           [120, 85, 45, 30, 15],  # روز اول
           [95, 110, 40, 25, 20],  # روز دوم
           [130, 95, 55, 35, 10],  # روز سوم
           [105, 100, 50, 28, 18]  # روز چهارم
       ]
   }
   ```

2. با استفاده از حلقه‌های تو در تو، این تحلیل‌ها رو انجام بده:
   - مجموع فروش هر محصول در ۴ روز
   - میانگین فروش روزانه برای هر محصول
   - محصول پرفروش (با بیشترین مجموع فروش)
   - روزی که بیشترین فروش کل داشته

3. خروجی رو به این شکل چاپ کن:

```text
گزارش فروش ۴ روزه:

محصولات:
لپ‌تاپ: مجموع 450 عدد | میانگین 112.5 عدد
موبایل: مجموع 390 عدد | میانگین 97.5 عدد
هدفون: مجموع 190 عدد | میانگین 47.5 عدد
تبلت: مجموع 118 عدد | میانگین 29.5 عدد
ساعت هوشمند: مجموع 63 عدد | میانگین 15.8 عدد

محصول پرفروش: لپ‌تاپ با 450 عدد
روز پرفروش: روز سوم با 325 عدد
```

> **💡 نکته:** برای پیدا کردن روز پرفروش، باید مجموع فروش هر روز رو حساب کنی (جمع اون سطر) و بعد بزرگترینش رو پیدا کنی.
