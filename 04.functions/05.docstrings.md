# 📗 فصل چهارم: کارخونه کدسازی (توابع)

## 🎯 درس ۴.۵: مستندسازی توابع (Docstrings)

---

### 📝 چرا مستندسازی مهمه؟

تا الان یاد گرفتی چطور توابع بنویسی. ولی یه سوال مهم: **چطور می‌تونیم به بقیه (یا حتی به خودمون در آینده) بفهمونیم که این تابع دقیقاً چیکار می‌کنه؟**

فرض کن ۶ ماه دیگه به یه کد قدیمی که خودت نوشتی برمی‌گردی. اگه مستند نباشه، باید خط به خط کد رو بخونی تا بفهمی تابع چیکار می‌کنه! اینجاست که **مستندسازی (Documentation)** به کمکمون میاد.

> **📌 تفاوت کامنت و داک‌استرینگ:**
> - **کامنت (`#`)** : برای توضیح کوتاه داخل کد. پایتون اون رو نادیده می‌گیره.
> - **داک‌استرینگ (`""" """`)** : یک متن مستند در ابتدای تابع. پایتون اون رو ذخیره می‌کنه و ابزارها می‌تونن ازش استفاده کنن.

---

### 💻 چطور داک‌استرینگ بنویسیم؟

یک داک‌استرینگ، یک رشته‌ی چندخطی هست که **بلافاصله بعد از خط `def`** قرار می‌گیره:

```python
def calculate_area(width, height):
    """
    محاسبه مساحت یک مستطیل.
    
    این تابع با گرفتن عرض و ارتفاع، مساحت مستطیل را محاسبه می‌کند.
    """
    return width * height
```

### 📋 ساختار استاندارد داک‌استرینگ (PEP 257)

پایتون یک مستند رسمی به اسم **PEP 257** داره که استاندارد نوشتن داک‌استرینگ رو مشخص می‌کنه. ساختار پیشنهادی:

```python
def function_name(parameters):
    """
    توضیح مختصر (یک خطی) درباره کاری که تابع انجام می‌دهد.
    
    توضیح بلندتر (اختیاری) که جزئیات بیشتری در مورد رفتار تابع،
    نکات خاص، یا مثال‌های استفاده ارائه می‌دهد.
    
    Args:
        param1 (نوع): توضیح درباره پارامتر اول.
        param2 (نوع): توضیح درباره پارامتر دوم.
    
    Returns:
        نوع: توضیح درباره مقدار برگشتی.
    
    Raises (اختیاری):
        خطا: توضیح درباره خطاهایی که ممکن است رخ دهد.
    
    Examples (اختیاری):
        >>> function_name(5, 3)
        15
    """
    # بدنه تابع
    pass
```

### ✍️ مثال‌های عملی

#### مثال ۱: تابع ساده

```python
def greet_user(name, greeting="سلام"):
    """
    به کاربر خوش‌آمد می‌گوید.
    
    این تابع یک پیام خوش‌آمدگویی با نام کاربر چاپ می‌کند.
    
    Args:
        name (str): نام کاربر.
        greeting (str, optional): متن خوش‌آمدگویی. پیش‌فرض: "سلام".
    
    Returns:
        None: این تابع فقط چاپ می‌کند و مقداری برنمی‌گرداند.
    
    Examples:
        >>> greet_user("احمد")
        سلام احمد! به سیستم خوش آمدید.
        
        >>> greet_user("سارا", "خوش آمدید")
        خوش آمدید سارا! به سیستم خوش آمدید.
    """
    print(f"{greeting} {name}! به سیستم خوش آمدید.")
```

#### مثال ۲: تابع با محاسبه

```python
def calculate_discount(price, discount_percent):
    """
    محاسبه قیمت نهایی با اعمال تخفیف.
    
    Args:
        price (float): قیمت اصلی کالا.
        discount_percent (float): درصد تخفیف (مثلاً 15 برای ۱۵٪).
    
    Returns:
        float: قیمت نهایی پس از اعمال تخفیف.
    
    Examples:
        >>> calculate_discount(100000, 10)
        90000.0
        
        >>> calculate_discount(25000, 20)
        20000.0
    """
    discount_amount = price * discount_percent / 100
    return price - discount_amount
```

#### مثال ۳: تابع با شرط و خطا

```python
def divide_numbers(a, b):
    """
    تقسیم دو عدد بر هم.
    
    Args:
        a (float): عدد اول (صورت).
        b (float): عدد دوم (مخرج).
    
    Returns:
        float: حاصل تقسیم a بر b.
    
    Raises:
        ZeroDivisionError: اگر b برابر صفر باشد.
    
    Examples:
        >>> divide_numbers(10, 2)
        5.0
        
        >>> divide_numbers(7, 3)
        2.3333333333333335
    """
    if b == 0:
        raise ZeroDivisionError("مخرج نمی‌تواند صفر باشد!")
    return a / b
```

### 🔍 دیدن داک‌استرینگ در عمل

پایتون یک ابزار جذاب داره که می‌تونه داک‌استرینگ توابع رو نمایش بده:

```python
def calculate_area(width, height):
    """محاسبه مساحت مستطیل با عرض و ارتفاع."""
    return width * height

# دیدن داک‌استرینگ با help()
help(calculate_area)
# خروجی: محاسبه مساحت مستطیل با عرض و ارتفاع.

# دیدن داک‌استرینگ با __doc__
print(calculate_area.__doc__)
# خروجی: محاسبه مساحت مستطیل با عرض و ارتفاع.
```

> **💡 نکته:** ابزارهای حرفه‌ای مثل Sphinx می‌تونن از داک‌استرینگ‌ها، مستندات HTML برای کتابخانه‌هات تولید کنن!

### 📊 مقایسه کامنت با داک‌استرینگ

| ویژگی | کامنت (`#`) | داک‌استرینگ (`""" """`) |
|--------|-------------|------------------------|
| محل قرارگیری | هرجای کد | ابتدای تابع (بلافاصله بعد از `def`) |
| ذخیره توسط پایتون | ❌ نه | ✅ بله (توی `__doc__`) |
| نمایش با `help()` | ❌ نه | ✅ بله |
| استفاده توسط ابزارها | ❌ نه | ✅ بله (Sphinx, IDE, ...) |
| کاربرد اصلی | توضیح بخش‌های خاص کد | مستندسازی کلی تابع |
| مثال | `# اینجا قیمت رو حساب می‌کنیم` | `"""محاسبه قیمت نهایی"""` |

### 🎯 بهترین‌عمل‌ها در مستندسازی

1. **همیشه برای توابع عمومی داک‌استرینگ بنویس:**
   - توابعی که قراره از جای دیگه صدا زده بشن
   - توابعی که بقیه قراره استفاده کنن

2. **توضیح بده چرا، نه فقط چی:**
   ```python
   # ❌ بد
   def calculate(x, y):
       """محاسبه x و y."""
       return x * y
   
   # ✅ خوب
   def calculate(price, quantity):
       """محاسبه قیمت کل با ضرب قیمت در تعداد."""
       return price * quantity
   ```

3. **نوع پارامترها و خروجی رو مشخص کن:**
   ```python
   def get_user(name, age):
       """
       Args:
           name (str): نام کاربر
           age (int): سن کاربر
       
       Returns:
           dict: اطلاعات کاربر
       """
       return {"name": name, "age": age}
   ```

4. **مثال‌های استفاده رو اضافه کن:**
   - این کار کمک می‌کنه بقیه سریع‌تر بفهمن تابع چطور کار می‌کنه

5. **برای تغییرات مهم، تاریخ و دلیل رو بنویس:**
   ```python
   def old_function():
       """
       این تابع قدیمی هست و به زودی حذف می‌شود.
       
       Deprecated: از تابع new_function() استفاده کنید.
       """
       pass
   ```

### 📌 اشتباهات رایج در این درس

> **🔴 داک‌استرینگ رو با کامنت قاطی کردن:**
```python
# ❌ این فقط یه کامنته، داک‌استرینگ نیست
# محاسبه مساحت
def area(w, h):
    return w * h

# ✅ این یه داک‌استرینگ درسته
def area(w, h):
    """محاسبه مساحت مستطیل."""
    return w * h
```

> **🟡 داک‌استرینگ رو جای اشتباه نوشتن:**
```python
def area(w, h):
    return w * h
"""محاسبه مساحت."""  # ❌ داک‌استرینگ باید بلافاصله بعد از def باشه
```

> **🟢 اطلاعات ناقص توی داک‌استرینگ:**
```python
# ❌ نوع پارامترها مشخص نیست
def calculate(x, y):
    """محاسبه."""
    return x * y

# ✅ کامل
def calculate(x, y):
    """
    محاسبه حاصلضرب دو عدد.
    
    Args:
        x (float): عدد اول
        y (float): عدد دوم
    
    Returns:
        float: حاصلضرب x و y
    """
    return x * y
```

### 🛠️ نوبت توئه: چالش مستندسازی سیستم مدیریت کتابخانه!

بیا توابعی که توی درس‌های قبلی نوشتی رو با داک‌استرینگ‌های حرفه‌ای مستند کنیم.

**صورت مسئله:**

1. سه تابع زیر رو با داک‌استرینگ‌های کامل مستند کن:

   **تابع اول: `add_book(title, author, year)`**
   - ورودی: عنوان کتاب (متن)، نویسنده (متن)، سال نشر (عدد)
   - خروجی: پیام موفقیت
   - کار: اضافه کردن کتاب به لیست (فرض کن لیست سراسری داریم)

   **تابع دوم: `search_book(title)`**
   - ورودی: عنوان کتاب (متن)
   - خروجی: اطلاعات کتاب (دیکشنری) یا `None` اگر پیدا نشد
   - کار: جستجوی کتاب در لیست

   **تابع سوم: `count_books_by_year(year)`**
   - ورودی: سال نشر (عدد)
   - خروجی: تعداد کتاب‌های چاپ شده در آن سال (عدد)
   - کار: شمارش کتاب‌ها بر اساس سال

2. هر داک‌استرینگ باید شامل:
   - توضیح مختصر
   - توضیح بلندتر (اختیاری)
   - `Args:` با نوع و توضیح هر پارامتر
   - `Returns:` با نوع و توضیح
   - `Examples:` با دو مثال مختلف

3. بعد از نوشتن توابع، با `help()` داک‌استرینگ یکی از توابع رو نمایش بده.

### 💪 چالش دوم (اختیاری - برای مستندسازان حرفه‌ای!)

حالا که با داک‌استرینگ آشنا شدی، یه تابع پیچیده‌تر برای **سیستم تبدیل دما** بنویس و کامل مستندش کن:

1. تابعی به نام `convert_temperature(value, from_unit, to_unit)` بنویس که:
   - دما رو از یک واحد به واحد دیگه تبدیل کنه
   - واحدهای پشتیبانی‌شده: `"C"` (سلسیوس)، `"F"` (فارنهایت)، `"K"` (کلوین)

2. فرمول‌های تبدیل:
   - سلسیوس به فارنهایت: `(C * 9/5) + 32`
   - فارنهایت به سلسیوس: `(F - 32) * 5/9`
   - سلسیوس به کلوین: `C + 273.15`
   - کلوین به سلسیوس: `K - 273.15`
   - فارنهایت به کلوین: `(F - 32) * 5/9 + 273.15`
   - کلوین به فارنهایت: `(K - 273.15) * 9/5 + 32`

3. داک‌استرینگ کامل بنویس شامل:
   - توضیح کامل
   - تمام پارامترها با نوع و توضیح
   - خروجی با نوع و توضیح
   - خطاهای ممکن (Raises)
   - حداقل ۳ مثال

**مثال استفاده:**
```python
result = convert_temperature(25, "C", "F")
print(result)  # خروجی: 77.0

result = convert_temperature(100, "C", "K")
print(result)  # خروجی: 373.15

result = convert_temperature(32, "F", "C")
print(result)  # خروجی: 0.0
```
