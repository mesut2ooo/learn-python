### 🎯 تشخیص برخورد یعنی چی؟

در یک بازی، وقتی بازیکن به سکه می‌خوره باید امتیاز بگیره، وقتی به دشمن می‌خوره باید ببازه، و وقتی به دیوار می‌خوره باید متوقف بشه. همه‌ی این‌ها بر اساس یک منطق ریاضی ساده اما بسیار حیاتی کار می‌کنن که بهش می‌گیم **تشخیص برخورد (Collision Detection)**.

> **📌 مثال دنیای واقعی:** وقتی دو ماشین به هم می‌رسن، برخورد تشخیص داده میشه. توی بازی هم همینطور! فقط اینجا با مستطیل‌ها و دایره‌ها سروکار داریم.

---

### 📐 `pygame.Rect` چیست؟

پایتون برای مدیریت راحت‌ترِ مستطیل‌ها و تشخیص برخورد، یک ابزار فوق‌العاده به اسم `pygame.Rect` داره. اگر شکل‌های بازی رو به صورت شیء `Rect` تعریف کنیم، پایتون خودش متدی به اسم `colliderect()` داره که چک می‌کنه آیا دو تا مستطیل با هم برخورد داشتن یا نه.

```python
# تعریف دو مستطیل
rect1 = pygame.Rect(10, 10, 50, 50)  # (X, Y, Width, Height)
rect2 = pygame.Rect(30, 30, 50, 50)

# بررسی برخورد
if rect1.colliderect(rect2):
    print("برخورد! 💥")
```

### 💻 چطور برخورد را شبیه‌سازی کنیم؟

بیا برنامه‌ای بنویسیم که یک بازیکن (مربع سبز) و یک مانع ثابت (مربع قرمز) روی صفحه داشته باشه. هر وقت بازیکن با مانع برخورد کرد، رنگ مانع به زرد تغییر کنه:

```python
import pygame
import sys

pygame.init()

SCREEN_WIDTH = 800
SCREEN_HEIGHT = 600
screen = pygame.display.set_mode((SCREEN_WIDTH, SCREEN_HEIGHT))
pygame.display.set_caption("تشخیص برخورد در بازی")

# تعریف رنگ‌ها
BLACK = (0, 0, 0)
GREEN = (0, 255, 0)
RED = (255, 0, 0)
YELLOW = (255, 255, 0)

# تعریف سرعت بازیکن
player_speed = 7

# تعریف بازیکن و مانع با استفاده از pygame.Rect
# ساختار: (X, Y, Width, Height)
player_rect = pygame.Rect(100, 275, 50, 50)
obstacle_rect = pygame.Rect(500, 250, 100, 100)

# رنگ فعلی مانع
obstacle_color = RED

clock = pygame.time.Clock()

is_running = True
while is_running:
    clock.tick(60)
    
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            is_running = False

    # --- حرکت بازیکن با کیبورد ---
    keys = pygame.key.get_pressed()
    if keys[pygame.K_LEFT]:
        player_rect.x -= player_speed
    if keys[pygame.K_RIGHT]:
        player_rect.x += player_speed
    if keys[pygame.K_UP]:
        player_rect.y -= player_speed
    if keys[pygame.K_DOWN]:
        player_rect.y += player_speed

    # --- محدود کردن بازیکن داخل کادر صفحه ---
    if player_rect.left < 0:
        player_rect.left = 0
    if player_rect.right > SCREEN_WIDTH:
        player_rect.right = SCREEN_WIDTH
    if player_rect.top < 0:
        player_rect.top = 0
    if player_rect.bottom > SCREEN_HEIGHT:
        player_rect.bottom = SCREEN_HEIGHT

    # --- بررسی برخورد ---
    # متد colliderect اگر دو مستطیل با هم تلاقی داشته باشن True برمی‌گردونه
    if player_rect.colliderect(obstacle_rect):
        obstacle_color = YELLOW
    else:
        obstacle_color = RED

    # --- نقاشی روی صفحه ---
    screen.fill(BLACK)
    
    # برای کشیدن Rectها کافیه خود شیء Rect رو به تابع پاس بدیم
    pygame.draw.rect(screen, GREEN, player_rect)
    pygame.draw.rect(screen, obstacle_color, obstacle_rect)
    
    pygame.display.flip()

pygame.quit()
sys.exit()
```

---

### 🔍 بررسی ویژگی‌های `pygame.Rect`

| ویژگی | توضیح | مثال |
|-------|-------|------|
| `x` | موقعیت افقی (سمت چپ) | `rect.x = 100` |
| `y` | موقعیت عمودی (سمت بالا) | `rect.y = 100` |
| `width` | عرض مستطیل | `rect.width = 50` |
| `height` | ارتفاع مستطیل | `rect.height = 50` |
| `left` | لبه‌ی چپ | `rect.left` |
| `right` | لبه‌ی راست | `rect.right` |
| `top` | لبه‌ی بالا | `rect.top` |
| `bottom` | لبه‌ی پایین | `rect.bottom` |
| `center` | مرکز مستطیل | `rect.center = (400, 300)` |

### 🎯 برخورد با دایره‌ها

برای برخورد دایره‌ها، از `math.hypot()` استفاده می‌کنیم:

```python
import math

# موقعیت و شعاع دو دایره
circle1 = (100, 100, 20)  # (x, y, radius)
circle2 = (150, 100, 20)

# محاسبه فاصله بین دو مرکز
distance = math.hypot(circle1[0] - circle2[0], circle1[1] - circle2[1])

# اگر فاصله کمتر از مجموع شعاع‌ها بود، برخورد
if distance < circle1[2] + circle2[2]:
    print("برخورد دایره‌ها! ⚪💥")
```

### 📌 اشتباهات رایج در این درس

> **🔴 فراموش کردن به‌روزرسانی موقعیت `Rect`:**
```python
player_x = 100
player_y = 100
player_rect = pygame.Rect(player_x, player_y, 50, 50)

# ❌ بعد از تغییر player_x، rect به‌روز نمیشه!
player_x += 5

# ✅ باید rect رو هم به‌روز کنی یا مستقیم از rect استفاده کنی
player_rect.x += 5
```

> **🟡 استفاده از `==` برای بررسی برخورد:**
```python
# ❌ این فقط برابری دقیق موقعیت رو چک می‌کنه
if player_rect == obstacle_rect:

# ✅ از colliderect استفاده کن
if player_rect.colliderect(obstacle_rect):
```

> **🟢 اشتباه در محدوده‌ی تصادفی:**
```python
# ❌ ممکنه سکه از صفحه خارج بشه
coin_rect.x = random.randint(0, 800)

# ✅ محدوده رو با اندازه‌ی سکه تنظیم کن
coin_rect.x = random.randint(0, SCREEN_WIDTH - coin_rect.width)
```

### 🛠️ نوبت توئه: چالش سیستم جمع‌آوری سکه!

بیا این منطق برخورد رو تبدیل به یک مینی‌بازی واقعی کنیم: «جمع کردن سکه و افزایش امتیاز»!

**صورت مسئله:**

1. کدهای بالا رو کپی و اجرا کن تا تغییر رنگ مانع هنگام برخورد رو ببینی.
2. حالا تغییرات زیر رو اعمال کن تا شبیه یک بازی واقعی بشه:
   - یک متغیر برای امتیاز بیرون از حلقه به نام `score = 0` بساز.
   - اندازه مانع سرخ رو کوچکتر کن تا شبیه یک سکه بشه (مثلاً `20` در `20` پیکسل) و اسم متغیرش رو بذار `coin_rect`.
   - شرط برخورد رو طوری تغییر بده که **وقتی بازیکن با سکه برخورد کرد**:
     1. یک امتیاز به متغیر `score` اضافه بشه (و با `print(score)` امتیاز رو در ترمینال چاپ کنه).
     2. مکان سکه تغییر کنه و به یک نقطه تصادفی جدید روی صفحه بره تا بازیکن بتونه دوباره بره سمتش.
     *(راهنمایی برای نقطه تصادفی: می‌تونی از کتابخانه `random` که در فصل ۵ یاد گرفتی استفاده کنی؛ مثلاً: `coin_rect.x = random.randint(0, 750)`)*

### 💪 چالش دوم (اختیاری - برای طراحان بازی‌های پلتفرمر!)

حالا که با برخورد آشنا شدی، یه بازی **پلتفرمر ساده** با سکه‌های متعدد بساز:

1. **حداقل ۵ سکه** توی صفحه پخش کن (با موقعیت‌های مختلف).

2. **سیستم امتیازدهی پیشرفته:**
   - هر سکه یک امتیاز داره
   - امتیاز فعلی رو روی پنجره نمایش بده (با `pygame.display.set_caption()`)

3. **سیستم جان‌ها (Lives):**
   - با ۳ جان شروع کن
   - اگه بازیکن به لبه‌ی پایین صفحه برخورد کرد (سقوط)، یک جان کم کن و بازیکن رو به بالا برگردون
   - اگه جان‌ها به صفر رسید، بازی تمام بشه

4. **شروع مجدد:**
   - وقتی بازی تمام شد، با فشردن کلید `R` بازی ریست بشه (همه سکه‌ها برگردن، جان‌ها ۳ بشن، امتیاز صفر بشه)

5. **ساختار سکه‌ها:**
   - سکه‌ها رو توی یه لیست ذخیره کن
   - با یک حلقه همه‌ی سکه‌ها رو بکش
   - با یک حلقه برخورد همه‌ی سکه‌ها رو با بازیکن چک کن

**نمونه خروجی:**
```text
امتیاز: 5 | جان‌ها: 3
(با هر برخورد با سکه، امتیاز زیاد میشه و سکه ناپدید میشه)
(با سقوط از پایین صفحه، جان کم میشه)
```

> **💡 نکته:** برای حذف سکه بعد از برخورد، اون رو از لیست حذف کن (`coins.remove(coin)`).
