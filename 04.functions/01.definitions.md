### 🏭 تابع یعنی چی و به چه دردی می‌خوره؟

یک دستگاه آبمیوه‌گیری رو تصور کن. این دستگاه یک کار مشخص انجام میده: میوه رو می‌گیره، آبش رو تحویل میده. شما نیازی نداری هر بار چرخ‌دنده‌های داخل دستگاه رو از نو بسازی؛ فقط دکمه‌اش رو می‌زنی تا کارش رو انجام بده.

تابع در برنامه‌نویسی دقیقاً همین دستگاهه. یک قطعه کد که کار خاصی رو انجام میده و ما برای اینکه بتونیم بارها ازش استفاده کنیم، بسته‌بندی‌اش می‌کنیم.

> **📌 چرا توابع؟**
> 1. **قابل استفاده مجدد (Reusability):** یه‌بار بنویس، هر بار صدا بزن
> 2. **خوانایی (Readability):** کد تمیزتر و قابل فهم‌تر
> 3. **ماژولار بودن (Modularity):** هر بخش کار خودش رو انجام میده
> 4. **اشکال‌زدایی آسان (Debugging):** باگ رو یه جا پیدا کن و یه جا درستش کن

### 💻 چطور در پایتون تابع بسازیم؟

برای تعریف یک تابع در پایتون، از کلمه کلیدی `def` (مخفف Define به معنی تعریف کردن) استفاده می‌کنیم. بعد از اون اسم تابع رو می‌نویسیم و جلوی اسمش پرانتز باز و بسته و علامت `:` می‌ذاریم.

کدهای داخل تابع هم باید مانند شرط‌ها و حلقه‌ها، **دندانه‌گذاری** (دارای فاصله از لبه خط) باشن.

```python
# تعریف یک تابع ساده که فقط یک پیام چاپ می‌کند
def say_hello():
    print("سلام!")
    print("به بخش مدیریت سیستم خوش آمدید.")

# تعریف یک تابع با چند خط کد
def show_today_task():
    print("=" * 40)
    print("وظایف امروز:")
    print("1. تماس با مشتری")
    print("2. ارسال ایمیل")
    print("3. جلسه تیم")
    print("=" * 40)
```

### 📞 صدا زدن تابع (Calling a Function)

حالا اگر فقط کد بالا رو اجرا کنی، هیچ اتفاقی توی خروجی نمیفته! چرا؟ چون تو فقط دستگاه رو «ساختی»، اما هنوز «روشنش نکردی». برای اجرای تابع، باید اون رو **صدا بزنی (Call)**:

```python
# تعریف تابع
def say_hello():
    print("سلام!")
    print("به بخش مدیریت سیستم خوش آمدید.")

# صدا زدن تابع
say_hello()  # خروجی: سلام! به بخش مدیریت سیستم خوش آمدید.

# می‌تونی هر چند بار که خواستی صدا بزنی
say_hello()
say_hello()
```

هر بار که خط `say_hello()` رو می‌نویسی، پایتون پرش می‌کنه روی کدهای داخل تابع، اون‌ها رو اجرا می‌کنه و دوباره برمی‌گرده به ادامه برنامه.

---

### 🔄 ترتیب اجرای کدها

وقتی تابع تعریف می‌کنی، کدهای داخلش **تا زمانی که صدا زده نشن، اجرا نمیشن**. ترتیب اجرا به این شکله:

```python
print("۱. برنامه شروع شد")  # اول

def my_function():
    print("۳. داخل تابع")  # سوم

print("۲. قبل از صدا زدن تابع")  # دوم

my_function()  # اینجا پرش به تابع

print("۴. بعد از صدا زدن تابع")  # چهارم
```

**خروجی:**

```text
۱. برنامه شروع شد
۲. قبل از صدا زدن تابع
۳. داخل تابع
۴. بعد از صدا زدن تابع
```

### 📝 قوانین نام‌گذاری توابع

قوانین نام‌گذاری توابع دقیقاً مثل متغیرهاست:

1. **با حرف یا `_` شروع بشه** (نه عدد)
2. **فاصله ممنوع** (از `_` استفاده کن)
3. **حساس به بزرگ و کوچکی** هست
4. **اسم‌های معنی‌دار** انتخاب کن

```python
# ✅ درست
def show_report():
def get_user_info():
def calculate_total():

# ❌ غلط
def 1show_report():  # شروع با عدد
def show report():   # فاصله ممنوع
def ShowReport():    # درسته ولی سبک معمول نیست
```

> **💡 نکته حرفه‌ای:** در پایتون، اسم توابع رو با حروف کوچک و با خط زیرین (`_`) بین کلمات می‌نویسن. به این سبک می‌گن `snake_case`. مثلاً: `get_user_data`، `calculate_average`، `show_menu`.

### 🎯 توابع با پارامتر (مقدمه)

گاهی تابع برای انجام کارش به اطلاعاتی نیاز داره. مثلاً تابع جمع کردن دو عدد، باید بدونه اون دو عدد چیا هستن. به این اطلاعات می‌گن **پارامتر (Parameter)**.

```python
# تعریف تابع با دو پارامتر
def greet(name, age):
    print(f"سلام {name}! شما {age} سال دارید.")

# صدا زدن با آرگومان‌های مشخص
greet("احمد", 25)  # خروجی: سلام احمد! شما 25 سال دارید.
greet("سارا", 30)  # خروجی: سلام سارا! شما 30 سال دارید.
```

> **📌 نکته:** پارامترها رو در درس بعدی کامل یاد می‌گیریم. اینجا فقط یه نگاه کلی داشتیم.

### 📊 مزایای استفاده از توابع (در یک نگاه)

| مزیت | توضیح |
|-------|---------|
| **عدم تکرار کد** | یه کار رو یه‌بار می‌نویسی، هر جا خواستی استفاده می‌کنی |
| **تغییر آسان** | اگه نیاز به تغییر داری، فقط یه جا رو عوض می‌کنی |
| **خوانایی بالا** | کدهای کوتاه و خواناتر |
| **مقیاس‌پذیری** | راحت‌تر می‌تونی کدت رو بزرگ کنی |
| **تست‌پذیری** | هر تابع رو جداگانه می‌تونی تست کنی |

### 📌 اشتباهات رایج در این درس

> **🔴 فراموش کردن پرانتز هنگام صدا زدن تابع:**
```python
def say_hello():
    print("سلام!")

say_hello  # ❌ این تابع رو اجرا نمی‌کنه! فقط آدرسش رو نشون میده
say_hello()  # ✅ درسته
```

> **🟡 فراموش کردن دندانه‌گذاری در تابع:**
```python
def say_hello():
print("سلام!")  # ❌ خطا! IndentationError
```

> **🟢 تعریف تابع بعد از صدا زدنش:**
```python
say_hello()  # ❌ خطا! تابع هنوز تعریف نشده

def say_hello():
    print("سلام!")
```

> **🟣 اسم تابع رو اشتباه نوشتن:**
```python
def say_hello():
    print("سلام!")

say_hello()    # ✅ درسته
say_Hello()    # ❌ خطا! پایتون به بزرگ و کوچکی حساسه
```

### 🛠️ نوبت توئه: چالش سیستم گزارش وضعیت سرور!

بیا یک تابع ساده بنویسیم که اطلاعات وضعیت یک سرور مجازی رو با ظاهری مرتب چاپ کنه.

**صورت مسئله:**

1. یک تابع به نام `show_server_status` تعریف کن.
2. داخل این تابع، سه خط کد بنویس که وضعیت فرضی سرور را چاپ کند:
   - خط اول: `"[INFO] Server is running on port 8080"`
   - خط دوم: `"[STATUS] CPU Usage: 42%"`
   - خط سوم: `"[STATUS] RAM Usage: 58%"`
3. بیرون از تابع، آن را **دو بار** پشت سر هم صدا بزن تا گزارش وضعیت دو بار در خروجی چاپ بشه.

### 💪 چالش دوم (اختیاری - برای معماران سیستم!)

حالا که با توابع آشنا شدی، یه سیستم **چندین تابع** برای مدیریت یک کتابخانه بساز:

1. سه تابع مختلف تعریف کن:

   **تابع اول: `show_menu()`** 
   - فقط یک منوی ساده چاپ کنه:
   ```
   ================================
       سیستم مدیریت کتابخانه
   ================================
   1. نمایش کتاب‌ها
   2. اضافه کردن کتاب
   3. خروج
   ================================
   ```

   **تابع دوم: `show_header()`**
   - یک هدر با عنوان کتابخانه چاپ کنه با ستاره‌های تزئینی
   ```
   ********************************
   *    کتابخانه مرکزی دانشگاه    *
   ********************************
   ```

   **تابع سوم: `show_footer()`**
   - یک فوتر با پیام خروج چاپ کنه:
   ```
   ---------------------------------
   از کتابخانه استفاده کردید. خدانگهدار!
   ---------------------------------
   ```

2. تابع `show_header` رو یک بار، `show_menu` رو دو بار، و `show_footer` رو یک بار صدا بزن.

3. خروجی نهایی باید این شکلی باشه:

```
********************************
*    کتابخانه مرکزی دانشگاه    *
********************************
================================
    سیستم مدیریت کتابخانه
================================
1. نمایش کتاب‌ها
2. اضافه کردن کتاب
3. خروج
================================
================================
    سیستم مدیریت کتابخانه
================================
4. نمایش کتاب‌ها
5. اضافه کردن کتاب
6. خروج
================================
---------------------------------
از کتابخانه استفاده کردید. خدانگهدار!
---------------------------------
```

> **💡 نکته:** می‌تونی از کاراکترهای تزئینی مثل `*`، `=` و `-` برای خط‌های جداکننده استفاده کنی.
