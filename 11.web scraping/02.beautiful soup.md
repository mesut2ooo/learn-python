### 🍜 BeautifulSoup یعنی چی؟

توی درس قبل یاد گرفتی چطور با `requests` محتوای یک وب‌سایت رو دریافت کنی. ولی اون محتوا یک متن خام HTML هست که پر از تگ‌های `<div>`، `<p>`، `<a>` و... هست. حالا سوال اینه: چطور از توی این همه کد، دقیقاً داده‌ای که می‌خوایم رو استخراج کنیم؟

اینجاست که **BeautifulSoup** وارد بازی میشه. این کتابخانه مثل یک قیچی هوشمند عمل می‌کنه و بهت اجازه میده توی ساختار HTML بگردی و دقیقاً بخش‌های مورد نظرت رو پیدا کنی.

> **📌 تشبیه:** فرض کن HTML یک جعبه‌ی بزرگ پر از کاغذهای مختلفه. BeautifulSoup مثل دست‌های شماست که می‌تونه بره توی جعبه، کاغذهایی که برچسب خاصی دارن رو پیدا کنه و برات بیاره!

### 💻 ساختار HTML

قبل از اینکه بریم سراغ کدنویسی، باید با ساختار HTML آشنا بشیم. یک صفحه‌ی HTML از تگ‌های تو در تو ساخته میشه:

```html
<html>
    <head>
        <title>عنوان صفحه</title>
    </head>
    <body>
        <h1>یک عنوان بزرگ</h1>
        <p class="description">این یک پاراگراف است.</p>
        <div id="main-content">
            <ul>
                <li>آیتم اول</li>
                <li>آیتم دوم</li>
                <li>آیتم سوم</li>
            </ul>
        </div>
        <a href="https://example.com">لینک به مثال</a>
    </body>
</html>
```

**تگ‌های مهم:**
- `<h1>` تا `<h6>`: عناوین
- `<p>`: پاراگراف
- `<div>`: بخش‌بندی صفحه
- `<a>`: لینک
- `<ul>` / `<ol>`: لیست‌ها
- `<li>`: آیتم لیست
- `class` و `id`: برای شناسایی و گروه‌بندی

### 💻 اولین پارس با BeautifulSoup

```python
import requests
from bs4 import BeautifulSoup

# دریافت محتوای صفحه
url = "https://www.example.com"
response = requests.get(url)

# ایجاد شیء BeautifulSoup
soup = BeautifulSoup(response.text, "html.parser")

# دیدن عنوان صفحه
print(soup.title.text)

# دیدن متن کل صفحه (بدون تگ‌ها)
print(soup.get_text()[:200])  # ۲۰۰ کاراکتر اول
```

### 🔍 پیدا کردن تگ‌ها

#### ۱. پیدا کردن یک تگ (`find()`)

```python
import requests
from bs4 import BeautifulSoup

url = "https://www.example.com"
response = requests.get(url)
soup = BeautifulSoup(response.text, "html.parser")

# پیدا کردن اولین تگ h1
h1_tag = soup.find("h1")
print(h1_tag.text)  # متن داخل تگ

# پیدا کردن اولین تگ با کلاس خاص
p_tag = soup.find("p", class_="description")
print(p_tag.text)

# پیدا کردن تگ با id خاص
div_tag = soup.find("div", id="main-content")
print(div_tag.text)
```

#### ۲. پیدا کردن همه‌ی تگ‌ها (`find_all()`)

```python
# پیدا کردن همه‌ی تگ‌های p
all_paragraphs = soup.find_all("p")
for p in all_paragraphs:
    print(p.text)

# پیدا کردن همه‌ی لینک‌ها
all_links = soup.find_all("a")
for link in all_links:
    print(f"متن: {link.text} | آدرس: {link.get('href')}")

# پیدا کردن همه‌ی تگ‌های با کلاس خاص
items = soup.find_all("li", class_="item")
for item in items:
    print(item.text)
```

#### ۳. ترکیب با CSS Selectors (`select()`)

```python
# انتخاب با استفاده از کلاس
items = soup.select(".item")  # همه تگ‌های با کلاس item

# انتخاب با استفاده از id
main = soup.select("#main-content")  # تگ با id = main-content

# انتخاب ترکیبی
links_in_div = soup.select("div#main-content a")  # همه لینک‌های داخل div با id خاص
```

### 🎯 مثال عملی: استخراج عنوان و لینک‌های یک صفحه

بیا با هم یه صفحه‌ی واقعی رو اسکرپ کنیم و اطلاعاتش رو استخراج کنیم:

```python
import requests
from bs4 import BeautifulSoup

# صفحه‌ای که می‌خوایم اسکرپ کنیم (مثال: صفحه‌ی خبری)
url = "https://www.python.org/blogs/"
response = requests.get(url)
soup = BeautifulSoup(response.text, "html.parser")

# استخراج عناوین بلاگ‌ها
blog_titles = soup.find_all("h2", class_="blog-title")

print("📰 آخرین بلاگ‌های پایتون:")
for i, title in enumerate(blog_titles[:5], 1):
    print(f"{i}. {title.text.strip()}")

# استخراج لینک‌های بلاگ‌ها
blog_links = soup.find_all("a", class_="blog-title-link")
print("\n🔗 لینک‌ها:")
for link in blog_links[:3]:
    print(f"  - {link.get('href')}")
```

### 📌 اشتباهات رایج در این درس

> **🔴 فراموش کردن نصب `beautifulsoup4`:**
```python
from bs4 import BeautifulSoup  # ❌ خطا! ModuleNotFoundError

# باید نصب کنی: pip install beautifulsoup4
```

> **🟡 استفاده از `find` به جای `find_all`:**
```python
# find: فقط اولین مورد رو برمی‌گردونه
first_item = soup.find("li")

# find_all: همه موارد رو برمی‌گردونه (لیست)
all_items = soup.find_all("li")
```

> **🟢 فراموش کردن `.text` برای گرفتن متن:**
```python
title = soup.find("h1")  # ❌ خود تگ رو برمی‌گردونه
title = soup.find("h1").text  # ✅ متن داخل تگ
```

> **🟣 قاطی کردن کلاس با id در CSS Selectors:**
```python
# کلاس: با نقطه
items = soup.select(".item")

# id: با #
main = soup.select("#main-content")
```
