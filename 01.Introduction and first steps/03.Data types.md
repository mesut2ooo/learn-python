# 📕 فصل اول: شروع ماجرا
## 🎯 درس ۱.۳: انواع داده‌های پایه (Data Types)

---

### 🧠 چرا باید نوع داده رو بشناسیم؟

توی درس قبل دیدیم که چطور اطلاعات رو داخل متغیرها (جعبه‌ها) بریزیم. اما پایتون برای اینکه بفهمه با هر جعبه چطور رفتار کنه، باید بدونه داخلش چیه. مثلاً رفتار پایتون با «عدد» با «متن» کاملاً فرق داره (شما می‌تونی دو تا عدد رو با هم جمع کنی، اما جمع کردن دو تا متن معنی دیگه‌ای میده).

> **📌 نکته:** پایتون یه زبان **با نوع‌دهی پویا (Dynamically Typed)** هست. یعنی خودش وقتی به متغیر مقدار می‌دی، نوعش رو تشخیص میده و نیازی نیست بهش بگی از چه نوعی هست. اما این یعنی تو باید حواست باشه چه نوع داده‌ای به متغیر می‌دی.

---

### 📋 چهار نوع داده‌ی اصلی در پایتون

پایتون ۴ نوع داده اصلی و پایه داره که تقریباً ۹۰٪ کارهای ما رو راه می‌ندازن:

---

#### ۱. متن یا رشته (`str` - String)

هر چیزی که داخل کوتیشن منفرد (`'`) یا دبل‌کوتیشن (`"`) قرار بگیره، از نظر پایتون یک متن یا رشته‌ست؛ حتی اگر داخلش عدد بنویسی.

```python
store_name = "HyperMarket"
phone_number = "0218888"  # چون داخل کوتیشنه، پایتون این رو متن می‌بینه، نه عدد!
message = 'سلام دنیا'  # کوتیشن تکی هم درسته
```

> **💡 نکته:** متن‌ها می‌تونن خیلی بلند باشن. حتی می‌تونی با `\n` توش خط جدید ایجاد کنی:
```python
address = "تهران، خیابان ولیعصر\nپلاک ۱۲"
print(address)
```

---

#### ۲. عدد صحیح (`int` - Integer)

اعداد مثبت، منفی یا صفرِ بدون ممیز (اعشار). هر عددی که بدون نقطه نوشته بشه، از نوع `int` هست.

```python
items_sold = 150
temperature = -4
year = 1403
zero = 0
```

---

#### ۳. عدد اعشاری (`float` - Floating Point)

اعداد دارای بخش اعشاری. در پایتون برای اعشار از نقطه (`.`) استفاده می‌کنیم. پایتون هر عددی که نقطه داشته باشه رو `float` در نظر می‌گیره.

```python
tax_rate = 0.09
product_weight = 1.25
price = 12500.0  # اینم یه float هست، حتی اگه مقدارش ۱۲۵۰۰ باشه
```

> **⚠️ توجه:** بعضی از زبان‌ها از کاما (`,`) برای اعشار استفاده می‌کنن، اما پایتون فقط نقطه (`.`) رو قبول داره.

---

#### ۴. بله و خیر (`bool` - Boolean)

این نوع داده فقط و فقط دو مقدار می‌پذیره: درست (`True`) یا غلط (`False`). دقت کن که حرف اولشون باید بزرگ باشه. از این داده برای تصمیم‌گیری‌ها و شرط‌ها استفاده می‌کنیم.

```python
is_open = True
has_discount = False
is_available = True
```

> **📌 مهم:** `True` و `False` حتماً با حرف بزرگ نوشته میشن. `true` یا `false` با حروف کوچک رو پایتون نمی‌شناسه و ارور میده.

---

### 🔍 چطور بفهمیم نوع یک متغیر چیه؟ (`type()`)

پایتون یک دستور کاربلد به اسم `type()` داره. کافیه متغیرت رو بذاری داخل پرانتزش تا بهت بگه جنسش از چیه:

```python
x = 20.5
print(type(x))  # خروجی: <class 'float'>

name = "پایتون"
print(type(name))  # خروجی: <class 'str'>

is_active = True
print(type(is_active))  # خروجی: <class 'bool'>

count = 10
print(type(count))  # خروجی: <class 'int'>
```

---

### 🔄 تبدیل نوع داده‌ها (Type Conversion)

گاهی پیش میاد که بخوایم یک نوع داده رو به نوع دیگه تبدیل کنیم. مثلاً عددی که به صورت متن دریافت کردیم رو به عدد واقعی تبدیل کنیم تا بتونیم باهاش محاسبه کنیم:

```python
# تبدیل متن به عدد صحیح
age_str = "25"
age_int = int(age_str)  # تبدیل به int
print(age_int + 5)  # خروجی: 30

# تبدیل عدد به متن
price = 12500
price_str = str(price)  # تبدیل به str
print("قیمت: " + price_str)  # خروجی: قیمت: 12500

# تبدیل عدد اعشاری به صحیح (بخش اعشار حذف میشه)
pi = 3.14
pi_int = int(pi)  # خروجی: 3 (اعشار حذف میشه)
```

> **⚠️ توجه:** همه‌ی تبدیل‌ها ممکن نیست! مثلاً نمی‌تونی متن `"سلام"` رو به عدد تبدیل کنی:
> ```python
int("سلام")  # ❌ خطا! پایتون نمی‌دونه چطور "سلام" رو به عدد تبدیل کنه
```

---

### 📊 جدول جمع‌بندی نوع داده‌ها

| نوع داده | نام انگلیسی | مثال | توضیح |
|----------|-------------|------|-------|
| متن | `str` | `"سلام"`، `'123'` | هر چیزی داخل کوتیشن |
| عدد صحیح | `int` | `25`، `-10`، `0` | اعداد بدون اعشار |
| عدد اعشاری | `float` | `3.14`، `-0.5`، `2.0` | اعداد با اعشار |
| بولین | `bool` | `True`، `False` | فقط درست یا غلط |

### 📌 اشتباهات رایج در این درس

> **🔴 کوتیشن فراموش شده برای متن:**
```python
name = احمد  # ❌ خطا! پایتون فکر می‌کنه احمد یه متغیره
name = "احمد"  # ✅ درسته
```

> **🟡 قاطی کردن `True`/`False` با `true`/`false`:**
```python
is_ok = true  # ❌ خطا! true تعریف نشده
is_ok = True  # ✅ درسته
```

> **🟢 اشتباه در تشخیص نوع داده:**
```python
price = "12500"  # این یه str هست، نه int
total = price + 500  # ❌ خطا! نمی‌تونی متن رو با عدد جمع کنی
total = int(price) + 500  # ✅ درسته
```

> **🟣 استفاده از کاما برای اعشار:**
```python
pi = 3,14  # ❌ این یه tuple هست، نه float!
pi = 3.14  # ✅ درسته
```

### 🛠️ نوبت توئه: چالش سیستم فاکتوردهی!

فرض کن می‌خوایم سیستم صدور فاکتور یک سوپرمارکت رو کدنویسی کنیم.

**صورت مسئله:**
پنج متغیر بساز که مشخصات یک خرید واقعی رو تو خودشون نگه دارن:

1. نام خریدار (متن)
2. تعداد اقلام خریداری شده (عدد صحیح)
3. قیمت نهایی فاکتور (عدد اعشاری)
4. آیا فاکتور پرداخت شده یا نه؟ (بولین - بله/خیر)
5. آدرس فروشگاه (متن)

بعد از تعریف متغیرها، با استفاده از دستور `type()` جنس هر کدوم رو توی خروجی چاپ کن تا مطمئن بشی پایتون درست تشخیصشون داده.

---

### 💪 چالش دوم (اختیاری - برای مدیران مالی!)

حالا که با نوع داده‌ها آشنا شدی، فرض کن یه گزارش مالی می‌خوای از فروش روزانه بدی:

1. سه متغیر از نوع `int` بساز: `daily_sales`، `daily_costs`، `daily_profit` (سود روزانه)
2. سه متغیر از نوع `str` بساز: `product_name`، `category`، `sale_date`
3. سه متغیر از نوع `float` بساز: `avg_price`، `discount_rate`، `tax_amount`
4. یک متغیر `bool` بساز که مشخص کنه امروز روز سودده بود یا نه
5. تمام متغیرها رو با `print` و `type()` چاپ کن
