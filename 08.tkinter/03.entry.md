# 🖥️ فصل هشتم: طراحی رابط کاربری (GUI) با Tkinter

## 🎯 درس ۸.۳: گرفتن ورودی از کاربر (`Entry`)

---

### 📝 کادر ورودی یعنی چی؟

حالا فرض کن می‌خواهیم برنامه‌ای بسازیم که فراتر از کلیک ساده باشد؛ مثلاً برنامه‌ای که نام کاربر، ایمیل یا یک پیام مخفی را دریافت کند. در دنیای ویندوز، به کادرهای خالی که کاربر می‌تواند داخل آن‌ها متن تایپ کند، **کادر ورودی (Input Box)** می‌گوییم. در کتابخانه Tkinter، این ابزار جادویی با نام ویجت **`Entry`** شناخته می‌شود.

> **📌 تفاوت `Entry` با `Label`:** `Label` فقط متن رو **نمایش** میده، اما `Entry` به کاربر اجازه می‌ده **متن بنویسد** و ما با `.get()` اون رو بخونیم.

---

### 💻 چطور ورودی کاربر را بگیریم و پردازش کنیم؟

ویجت `Entry` یک کادر تک‌خطی برای تایپ متن در اختیار کاربر قرار می‌دهد. برای اینکه متنی را که کاربر داخل این کادر تایپ کرده بخوانیم، از متد `.get()` استفاده می‌کنیم.

```python
import tkinter as tk

def register_user():
    # ۱. خواندن متن داخل کادر ورودی با استفاده از متد .get()
    user_input = name_entry.get()
    
    # ۲. بررسی اینکه آیا کاربر چیزی تایپ کرده یا کادر خالی است
    if user_input.strip() != "":
        welcome_label.config(text=f"خوش آمدی {user_input} عزیز! 🎉", fg="blue")
    else:
        welcome_label.config(text="لطفاً ابتدا نام خود را وارد کنید! ⚠️", fg="red")

window = tk.Tk()
window.title("دریافت ورودی در Tkinter")
window.geometry("400x300")

# برچسب راهنما برای کادر ورودی
prompt_label = tk.Label(window, text="نام خود را وارد کنید:", font=("Tahoma", 12))
prompt_label.pack(pady=10)

# ۳. ساخت کادر ورودی (Entry)
name_entry = tk.Entry(window, font=("Tahoma", 12), width=25)
name_entry.pack(pady=5)

# دکمه ثبت
submit_button = tk.Button(window, text="ثبت نام", font=("Tahoma", 11), command=register_user)
submit_button.pack(pady=10)

# برچسب نمایش نتیجه نهایی
welcome_label = tk.Label(window, text="", font=("Tahoma", 14, "bold"))
welcome_label.pack(pady=20)

window.mainloop()
```

---

### 🎨 تنظیمات ظاهری `Entry`

| پارامتر | توضیح | مثال |
|---------|-------|------|
| `width` | عرض کادر (به تعداد کاراکتر) | `width=30` |
| `font` | فونت و اندازه | `font=("Arial", 12)` |
| `bg` | رنگ پس‌زمینه | `bg="#f0f0f0"` |
| `fg` | رنگ متن | `fg="#333333"` |
| `show` | نمایش کاراکتر خاص (برای رمز) | `show="*"` |
| `state` | وضعیت کادر | `state="disabled"` (غیرفعال) |

---

### 🔍 متدهای پرکاربرد `Entry`

| متد | کاربرد | مثال |
|-----|--------|------|
| `.get()` | خواندن متن کادر | `text = entry.get()` |
| `.delete(start, end)` | حذف متن از start تا end | `entry.delete(0, tk.END)` (پاک کردن کل) |
| `.insert(index, text)` | درج متن در موقعیت خاص | `entry.insert(0, "متن اولیه")` |
| `.config()` | تغییر تنظیمات | `entry.config(state="disabled")` |

---

### 🔐 کادر ورودی رمز عبور (پنهان کردن کاراکترها)

اگر بخواهی کاربر هنگام تایپ رمز عبور، ستاره (`*`) ببیند، کافی است ویژگی `show` را به این صورت تنظیم کنی:

```python
password_entry = tk.Entry(window, show="*", font=("Tahoma", 12), width=20)
```

---

### 🧹 پاک کردن کادر ورودی

برای خالی کردن کادر پس از فشردن دکمه، از دستور زیر استفاده کن:

```python
name_entry.delete(0, tk.END)  # از کاراکتر اول تا آخر را پاک می‌کند
```

### 📝 مثال کامل: فرم ثبت‌نام

```python
import tkinter as tk

def register():
    # گرفتن مقادیر از کادرها
    name = name_entry.get()
    email = email_entry.get()
    password = password_entry.get()
    
    # اعتبارسنجی
    if name.strip() == "" or email.strip() == "" or password.strip() == "":
        result_label.config(text="❌ لطفاً همه فیلدها را پر کنید!", fg="red")
        return
    
    if len(password) < 4:
        result_label.config(text="❌ رمز عبور حداقل ۴ کاراکتر باشد!", fg="red")
        return
    
    # ثبت موفق
    result_label.config(text=f"✅ ثبت‌نام {name} با موفقیت انجام شد!", fg="green")
    
    # پاک کردن کادرها
    name_entry.delete(0, tk.END)
    email_entry.delete(0, tk.END)
    password_entry.delete(0, tk.END)

window = tk.Tk()
window.title("فرم ثبت‌نام")
window.geometry("450x400")

# عنوان
title = tk.Label(window, text="فرم ثبت‌نام کاربر", font=("Arial", 18, "bold"))
title.pack(pady=10)

# فیلد نام
tk.Label(window, text="نام کامل:", font=("Arial", 11)).pack(anchor="w", padx=50)
name_entry = tk.Entry(window, font=("Arial", 11), width=30)
name_entry.pack(pady=5)

# فیلد ایمیل
tk.Label(window, text="ایمیل:", font=("Arial", 11)).pack(anchor="w", padx=50)
email_entry = tk.Entry(window, font=("Arial", 11), width=30)
email_entry.pack(pady=5)

# فیلد رمز عبور
tk.Label(window, text="رمز عبور:", font=("Arial", 11)).pack(anchor="w", padx=50)
password_entry = tk.Entry(window, font=("Arial", 11), width=30, show="*")
password_entry.pack(pady=5)

# دکمه ثبت‌نام
register_btn = tk.Button(window, text="ثبت‌نام", font=("Arial", 12), command=register, bg="#4CAF50", fg="white")
register_btn.pack(pady=10)

# نمایش نتیجه
result_label = tk.Label(window, text="", font=("Arial", 12, "bold"))
result_label.pack(pady=10)

window.mainloop()
```

### 📌 اشتباهات رایج در این درس

> **🔴 فراموش کردن `.get()` برای خواندن ورودی:**
```python
user_input = name_entry  # ❌ این خود شیء Entry رو برمی‌گردونه، نه متن
user_input = name_entry.get()  # ✅ درسته
```

> **🟡 فراموش کردن `strip()` برای حذف فاصله‌ها:**
```python
if name_entry.get() == "":  # ❌ اگه کاربر فاصله بزنه، خالی نیست
if name_entry.get().strip() == "":  # ✅ درسته
```

> **🟢 فراموش کردن `tk.END` در `delete()`:**
```python
entry.delete(0, END)  # ❌ END تعریف نشده
entry.delete(0, tk.END)  # ✅ درسته
```

> **🟣 استفاده از `show="*"` برای فیلدهای غیررمز:**
```python
# ❌ برای نام کاربری نیازی نیست
username_entry = tk.Entry(window, show="*")
```

### 🛠️ نوبت توئه: چالش نمونه اولیه سیستم ورود Anonyma!

بیا با استفاده از آموخته‌هایت، یک فرم ورود (Login) بسیار شیک و ساده شبیه‌سازی کنیم که اولین قدم برای پروژه پیام‌رسان ناشناس تو (`Anonyma`) باشد.

**صورت مسئله:**

1. یک پنجره جدید با Tkinter بساز.
2. **دو عدد کادر ورودی (`Entry`)** روی صفحه قرار بده:
   - کادر اول برای **نام کاربری (Username)**.
   - کادر دوم برای **کلمه عبور (Password)** (دقت کن که کلمه عبور باید پنهان باشد و کاراکترهای تایپ شده را به صورت `*` نشان دهد).
3. برای هر کدام از کادرها، یک لِیبل راهنما بالای آن قرار بده تا کاربر بداند چه چیزی را باید وارد کند.
4. یک دکمه به نام **"ورود"** بساز که به تابعی به نام `check_login` متصل باشد.
5. داخل تابع `check_login` منطق زیر را پیاده‌سازی کن:
   - **اگر** نام کاربری برابر با `"admin"` و کلمه عبور برابر با `"1234"` بود، یک لِیبل پیام سبز رنگ نشان دهد: `"ورود با موفقیت انجام شد! 🔓"`.
   - **در غیر این صورت**، پیام قرمز رنگ نشان دهد: `"نام کاربری یا کلمه عبور اشتباه است! ❌"`.

### 💪 چالش دوم (اختیاری - برای توسعه‌دهندگان فرم‌های حرفه‌ای!)

حالا که با `Entry` آشنا شدی، یه فرم **ثبت سفارش** کامل طراحی کن:

1. پنجره با عنوان `"فرم ثبت سفارش"` و اندازه `500x400`.

2. این فیلدها رو داشته باش (همگی با برچسب راهنما):
   - نام مشتری (Entry)
   - نام محصول (Entry)
   - تعداد (Entry - فقط عدد)
   - قیمت واحد (Entry - فقط عدد)
   - تخفیف درصدی (Entry - فقط عدد، پیش‌فرض: ۰)

3. دکمه `"محاسبه قیمت نهایی"` که:
   - تعداد و قیمت رو از کادرها بخونه
   - تخفیف رو اعمال کنه
   - قیمت نهایی رو محاسبه و نمایش بده

4. دکمه `"ثبت سفارش"` که:
   - همه اطلاعات رو بخونه
   - یک پیام تأیید کامل چاپ کنه
   - همه کادرها رو پاک کنه

5. اعتبارسنجی انجام بده:
   - هیچ کادری خالی نباشه
   - تعداد و قیمت عدد مثبت باشن
   - تخفیف بین ۰ تا ۱۰۰ باشه

**نمونه خروجی:**
