### 🧠 چرا NumPy؟

در پایتون، ما لیست‌ها (`list`) رو داریم. لیست‌ها عالی هستن، اما وقتی حجم داده‌ها به میلیون‌ها رکورد برسه، لیست‌های معمولی پایتون بسیار کند و سنگین میشن.

اینجاست که کتابخانه **NumPy** (مخفف Numerical Python) وارد میدان میشه. نام‌پای یک ساختار داده جدید به نام **آرایه (ndarray)** معرفی می‌کنه که:

1. سرعت پردازش آن **تا ۵۰ برابر سریع‌تر** از لیست‌های معمولی پایتونه! (چون در زبان C نوشته شده)
2. حافظه بسیار کمتری مصرف می‌کنه
3. انجام محاسبات ریاضی روی کل داده‌ها رو در یک خط کد ممکن می‌کنه

> **📌 مثال واقعی:** یه لیست پایتونی با ۱ میلیون عدد رو در نظر بگیر. جمع کردن همه‌ی اون‌ها با `sum()` ممکنه چند ثانیه طول بکشه، اما با NumPy این کار در کسری از ثانیه انجام میشه!

### 💻 تفاوت لیست پایتون با آرایه NumPy در عمل

فرض کن لیستی از قیمت‌های ۵ کالا داری و می‌خوای قیمت همه‌ی آن‌ها رو دو برابر کنی. در پایتون معمولی باید حلقه بنویسی، اما در NumPy این کار مثل آب خوردنه:

```python
import numpy as np  # معمولاً numpy را به صورت خلاصه np وارد می‌کنیم

# ۱. تعریف یک لیست معمولی پایتون
python_list = [10, 20, 30, 40, 50]

# ۲. تبدیل لیست پایتون به آرایه نام‌پای
np_array = np.array(python_list)

# ۳. عملیات ریاضی همزمان روی تمام اعضا (بدون نیاز به حلقه!)
doubled_array = np_array * 2

print("آرایه اولیه:", np_array)        # خروجی: [10 20 30 40 50]
print("آرایه دوبار شده:", doubled_array) # خروجی: [20 40 60 80 100]
print("نوع داده:", type(np_array))     # خروجی: <class 'numpy.ndarray'>
```

### 🎯 عملیات‌های پایه در NumPy

#### ۱. ساخت آرایه

```python
import numpy as np

# از لیست پایتون
arr1 = np.array([1, 2, 3, 4, 5])

# آرایه‌ای از صفرها (۵ عضو)
arr2 = np.zeros(5)  # خروجی: [0. 0. 0. 0. 0.]

# آرایه‌ای از یک‌ها (۵ عضو)
arr3 = np.ones(5)   # خروجی: [1. 1. 1. 1. 1.]

# آرایه‌ای از اعداد با فاصله مشخص
arr4 = np.arange(0, 10, 2)  # خروجی: [0 2 4 6 8]

# آرایه‌ای از اعداد با تعداد مشخص بین دو مقدار
arr5 = np.linspace(0, 1, 5)  # خروجی: [0.   0.25 0.5  0.75 1.  ]
```

#### ۲. عملیات ریاضی روی آرایه‌ها

```python
arr = np.array([1, 2, 3, 4, 5])

# جمع با عدد
print(arr + 10)   # خروجی: [11 12 13 14 15]

# ضرب در عدد
print(arr * 3)    # خروجی: [3 6 9 12 15]

# توان
print(arr ** 2)   # خروجی: [1 4 9 16 25]

# جمع دو آرایه
arr2 = np.array([10, 20, 30, 40, 50])
print(arr + arr2) # خروجی: [11 22 33 44 55]

# توابع ریاضی
print(np.sqrt(arr))  # جذر: [1.         1.41421356 1.73205081 2.         2.23606798]
print(np.sum(arr))   # جمع کل: 15
print(np.mean(arr))  # میانگین: 3.0
print(np.std(arr))   # انحراف معیار: 1.41421356
```

#### ۳. آمار پایه

```python
data = np.array([12, 18, 9, 15, 17, 8, 20, 14, 11, 16])

print(f"میانگین: {np.mean(data):.2f}")     # 14.00
print(f"میانه: {np.median(data):.2f}")    # 14.50
print(f"بیشترین: {np.max(data)}")         # 20
print(f"کمترین: {np.min(data)}")          # 8
print(f"دامنه: {np.ptp(data)}")           # 12 (max - min)
print(f"انحراف معیار: {np.std(data):.2f}") # 3.74
```

### 🧮 آرایه‌های دو بعدی (ماتریس‌ها)

یکی از قشنگی‌های نام‌پای، کار راحت با ماتریس‌ها یا آرایه‌های دو بعدی (سطر و ستون) است:

```python
# ساخت یک ماتریس ۲ در ۳ (۲ سطر و ۳ ستون)
matrix = np.array([
    [1, 2, 3],
    [4, 5, 6]
])

print("ابعاد ماتریس:", matrix.shape)  # خروجی: (2, 3)
print("تعداد عناصر:", matrix.size)    # خروجی: 6
print("تعداد ابعاد:", matrix.ndim)    # خروجی: 2

# دسترسی به عناصر
print(matrix[0, 0])  # خروجی: 1 (سطر اول، ستون اول)
print(matrix[1, 2])  # خروجی: 6 (سطر دوم، ستون سوم)

# عملیات روی ماتریس
print(np.mean(matrix))  # میانگین کل: 3.5
print(np.sum(matrix, axis=0))  # جمع ستون‌ها: [5 7 9]
print(np.sum(matrix, axis=1))  # جمع سطرها: [6 15]

# ضرب ماتریس‌ها
matrix2 = np.array([
    [7, 8],
    [9, 10],
    [11, 12]
])
result = np.dot(matrix, matrix2)  # ضرب ماتریسی
print(result)
# خروجی:
# [[ 58  64]
#  [139 154]]
```

### 🎯 فیلتر کردن و شرط‌ها در NumPy

```python
data = np.array([12, 18, 9, 15, 17, 8, 20, 14, 11, 16])

# فیلتر کردن: نمرات بالای ۱۵
high_scores = data[data > 15]
print("نمرات بالای ۱۵:", high_scores)  # خروجی: [18 17 20 16]

# تعداد نمرات بالای ۱۵
count = np.sum(data > 15)
print("تعداد:", count)  # خروجی: 4

# نمرات بین ۱۰ تا ۱۵
middle_scores = data[(data >= 10) & (data <= 15)]
print("نمرات بین ۱۰ تا ۱۵:", middle_scores)  # خروجی: [12 15 14 11]

# جایگزینی شرطی
data[data < 10] = 10  # نمرات زیر ۱۰ رو به ۱۰ تبدیل کن
print("پس از اصلاح:", data)  # خروجی: [12 18 10 15 17 10 20 14 11 16]
```

```python

arr = np.array([1, 2, 3, 4, 5])
for i in range(len(arr)):

arr = arr * 2
```

**صورت مسئله:**

### 💪 چالش دوم (اختیاری - برای تحلیلگران داده!)

حالا که با NumPy آشنا شدی، یه **تحلیل فروش ماهانه** کامل انجام بده:

1. یک آرایه ۲ بعدی از فروش ۴ محصول در ۷ روز هفته بساز:
   ```python
   sales = np.array([
       [120, 85, 90, 95, 110, 130, 105],   # محصول ۱
       [80, 75, 95, 100, 85, 90, 110],     # محصول ۲
       [150, 140, 160, 135, 145, 155, 170], # محصول ۳
       [60, 55, 70, 65, 80, 75, 90]        # محصول ۴
   ])
   ```

2. این تحلیل‌ها رو انجام بده:
   - مجموع فروش هر محصول در کل هفته (`axis=1`)
   - مجموع فروش هر روز برای همه محصولات (`axis=0`)
   - میانگین فروش روزانه کل فروشگاه
   - محصول پرفروش (با بیشترین مجموع)
   - روز پرفروش (با بیشترین مجموع)
   - فروش‌های بالای ۱۰۰ واحد رو فیلتر کن

3. نتایج رو با فرمت مناسب چاپ کن.
