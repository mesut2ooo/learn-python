# 📘 فصل سوم: دسته‌بندی اطلاعات (ساختارهای داده)

## 🎯 درس ۳.۲: دیکشنری‌ها (Dictionaries)

---

### 📚 دیکشنری یعنی چی و به چه دردی می‌خوره؟

فرض کن می‌خوایم اطلاعات یک کاربر رو ذخیره کنیم؛ مثلاً نام، سن، ایمیل و شماره تلفن. اگر این‌ها رو توی لیست بریزیم، یادمون می‌ره کدوم شماره اندیس مال چی بود (مثلاً اندیس ۱ سن بود یا شماره تلفن؟).

اینجاست که **دیکشنری‌ها (Dictionaries)** وارد بازی می‌شن و مثل یک نجات‌دهنده عمل می‌کنن.

یک دیکشنری واقعی رو تصور کن؛ شما یک کلمه (مثلاً *Book*) رو جستجو می‌کنی و در مقابلش معنی اون کلمه (یعنی *کتاب*) رو پیدا می‌کنی.

در پایتون هم دیکشنری دقیقاً همین‌طور کار می‌کنه. به جای استفاده از شماره اندیس (0, 1, 2, ...)، ما برای هر عضو یک **کلید (Key)** تعریف می‌کنیم و در مقابلش یک **مقدار (Value)** قرار می‌دیم. به این ترکیب می‌گیم جفتِ **کلید-مقدار (Key-Value Pair)**.

> **📌 تعریف رسمی:** دیکشنری یک **ساختار داده‌ی کلید-مقداری (Key-Value)** هست که هر کلید منحصر‌به‌فرد (Unique) هست و بهش یک مقدار نسبت داده میشه. دیکشنری‌ها **تغییرپذیر (Mutable)** هستن و می‌تونیم بعد از ساخته شدن، کلیدها و مقدارها رو تغییر بدیم یا کلیدهای جدید اضافه کنیم.

---

### 🆚 مقایسه لیست و دیکشنری

| ویژگی | لیست | دیکشنری |
|--------|---------|-----------|
| ساختار | `[value1, value2, ...]` | `{key1: value1, key2: value2, ...}` |
| دسترسی | با اندیس عددی (`[0]`, `[1]`, ...) | با کلید (`["name"]`, `["age"]`, ...) |
| ترتیب | ترتیبی (Sequential) | کلید-مقداری (Key-Value) |
| کاربرد | لیست کردن موارد مشابه | ذخیره‌سازی اطلاعات با برچسب‌های مشخص |

---

### 💻 چطور در پایتون دیکشنری بسازیم؟

برای ساختن دیکشنری از آکارد یا همان براکت مجعد (`{ }`) استفاده می‌کنیم. بین کلید و مقدار علامت دو نقطه (`:`) می‌ذاریم و اعضا رو با کاما (`,`) جدا می‌کنیم:

```python
# تعریف یک دیکشنری برای مشخصات یک کالا در انبار
product = {
    "title": "Monitor 24 inch",
    "price": 180,
    "brand": "Dell",
    "is_available": True
}

# دیکشنری برای اطلاعات یک کاربر
user = {
    "name": "احمد رضایی",
    "age": 25,
    "email": "ahmad@email.com",
    "is_active": True
}

# دیکشنری خالی
empty_dict = {}
```

> **💡 نکته مهم:** کلیدها در دیکشنری باید **غیرقابل‌تغییر (Immutable)** باشن. یعنی معمولاً از `str`، `int`، `float`، `bool` یا `tuple` استفاده میشه. ولی مقدارها می‌تونن هر چیزی باشن (حتی لیست یا دیکشنری دیگه!).

### 🔑 دسترسی و تغییر اطلاعات در دیکشنری

برای دسترسی به مقادیر، کافیه اسم کلید رو داخل براکت (`[ ]`) جلوی اسم دیکشنری بنویسیم:

```python
product = {
    "title": "Monitor 24 inch",
    "price": 180,
    "brand": "Dell",
    "is_available": True
}

# دسترسی به قیمت کالا
print(product["price"])  # خروجی: 180

# دسترسی به برند
print(product["brand"])  # خروجی: Dell

# تغییر دادن مقدار یک کلید (قیمت رو به روز کردیم)
product["price"] = 195
print(product["price"])  # خروجی: 195

# اضافه کردن یک کلید و مقدار جدید به دیکشنری
product["warranty_months"] = 18
print(product)
# خروجی: {'title': 'Monitor 24 inch', 'price': 195, 'brand': 'Dell', 'is_available': True, 'warranty_months': 18}
```

### 🛠️ ابزارهای پرکاربرد کار با دیکشنری

#### ۱. دسترسی ایمن با `get()`

اگه کلیدی وجود نداشته باشه و با `[]` دسترسی پیدا کنی، پایتون ارور میده. اما `get()` به جای ارور، `None` برمی‌گردونه (یا مقدار پیش‌فرض دلخواه):

```python
user = {"name": "احمد", "age": 25}

# دسترسی با [] (اگه کلید نباشه ارور میده)
print(user["name"])     # خروجی: احمد
# print(user["email"])  # ❌ خطا! KeyError

# دسترسی با get() (ایمن‌تر)
print(user.get("email"))          # خروجی: None
print(user.get("email", "ندارد")) # خروجی: ندارد (مقدار پیش‌فرض)
```

#### ۲. گرفتن همه‌ی کلیدها (`keys()`)

```python
user = {"name": "احمد", "age": 25, "email": "a@b.com"}
print(user.keys())  # خروجی: dict_keys(['name', 'age', 'email'])

# می‌تونی توی حلقه استفاده کنی
for key in user.keys():
    print(key)
```

#### ۳. گرفتن همه‌ی مقدارها (`values()`)

```python
user = {"name": "احمد", "age": 25, "email": "a@b.com"}
print(user.values())  # خروجی: dict_values(['احمد', 25, 'a@b.com'])

# می‌تونی توی حلقه استفاده کنی
for value in user.values():
    print(value)
```

#### ۴. گرفتن همه‌ی کلید-مقدارها (`items()`)

```python
user = {"name": "احمد", "age": 25, "email": "a@b.com"}
print(user.items())  # خروجی: dict_items([('name', 'احمد'), ('age', 25), ('email', 'a@b.com')])

# پیمایش جفت‌های کلید-مقدار
for key, value in user.items():
    print(f"{key}: {value}")
# خروجی:
# name: احمد
# age: 25
# email: a@b.com
```

#### ۵. حذف یک کلید (`pop()`)

```python
user = {"name": "احمد", "age": 25, "email": "a@b.com"}
removed = user.pop("email")  # کلید email رو حذف کن و مقدارش رو برگردون
print(removed)  # خروجی: a@b.com
print(user)     # خروجی: {'name': 'احمد', 'age': 25}
```

### 🔄 پیمایش دیکشنری با حلقه `for`

```python
user = {
    "name": "احمد رضایی",
    "age": 25,
    "email": "ahmad@email.com",
    "is_active": True
}

# روش ۱: پیمایش کلیدها
for key in user:
    print(f"کلید: {key}")

# روش ۲: پیمایش کلیدها و مقدارها با items()
for key, value in user.items():
    print(f"{key} = {value}")
# خروجی:
# name = احمد رضایی
# age = 25
# email = ahmad@email.com
# is_active = True
```

### 📊 دیکشنری‌های تو در تو (Nested Dictionaries)

دیکشنری‌ها می‌تونن داخل خودشون دیکشنری‌های دیگه داشته باشن:

```python
company = {
    "name": "تکنولوژی نوین",
    "year": 2010,
    "ceo": {
        "name": "علی محمدی",
        "age": 45
    },
    "products": ["نرم‌افزار", "سخت‌افزار", "مشاوره"]
}

# دسترسی به اطلاعات تو در تو
print(company["ceo"]["name"])  # خروجی: علی محمدی
print(company["products"][0])  # خروجی: نرم‌افزار
```

---

### 📋 جدول جمع‌بندی متدهای دیکشنری

| متد | کاربرد | مثال |
|-----|--------|------|
| `dict[key]` | دسترسی به مقدار | `user["name"]` |
| `dict.get(key, default)` | دسترسی ایمن با مقدار پیش‌فرض | `user.get("email", "ندارد")` |
| `dict.keys()` | گرفتن همه‌ی کلیدها | `user.keys()` |
| `dict.values()` | گرفتن همه‌ی مقدارها | `user.values()` |
| `dict.items()` | گرفتن همه‌ی جفت‌های کلید-مقدار | `user.items()` |
| `dict.pop(key)` | حذف کلید و برگردوندن مقدارش | `user.pop("email")` |
| `key in dict` | بررسی وجود کلید در دیکشنری | `"name" in user` |
| `len(dict)` | تعداد کلیدها | `len(user)` |

### 📌 اشتباهات رایج در این درس

> **🔴 دسترسی به کلید ناموجود با `[]`:**
```python
user = {"name": "احمد"}
print(user["age"])  # ❌ خطا! KeyError: 'age'
print(user.get("age", "نامشخص"))  # ✅ درسته
```

> **🟡 فراموش کردن دو نقطه (`:`) بین کلید و مقدار:**
```python
user = {"name", "احمد"}  # ❌ این یه set هست، نه دیکشنری!
user = {"name": "احمد"}  # ✅ درسته
```

> **🟢 استفاده از کلیدهای تکراری:**
```python
user = {"name": "احمد", "name": "علی"}  # ❌ کلید تکراری! مقدار آخر جایگزین میشه
# خروجی: {'name': 'علی'} (دومی جای اولی رو گرفته)
```

> **🟣 قاطی کردن دیکشنری با لیست:**
```python
# لیست برای داده‌های مشابه و ترتیبی
colors = ["red", "green", "blue"]

# دیکشنری برای داده‌های برچسب‌دار
user = {"name": "احمد", "age": 25}
```

### 🛠️ نوبت توئه: چالش شناسنامه قطعات سیستم!

بیا یک برنامه کوچک بنویسیم که مشخصات فنی یک کامپیوتر یا دستگاه هوشمند رو در قالب دیکشنری مدیریت کنه.

**صورت مسئله:**

1. یک دیکشنری به نام `device` بساز که مشخصات زیر رو داخلش داشته باشه:
   - کلید `"cpu"` با مقدار `"Core i7"`
   - کلید `"ram_gb"` با مقدار عدد صحیح `16`
   - کلید `"storage_gb"` با مقدار عدد صحیح `512`
   - کلید `"is_ssd"` با مقدار بولین `True`

2. با یک دستور `print` ساده، مقدار رم دستگاه رو چاپ کن.

3. حالا فرض کن رم سیستم رو ارتقا دادیم. مقدار کلید `"ram_gb"` رو در کد به عدد `32` تغییر بده.

4. در نهایت، کل دیکشنری رو چاپ کن تا ببینی تغییرات با موفقیت ثبت شده یا نه.

### 💪 چالش دوم (اختیاری - برای تحلیلگران داده!)

حالا که با دیکشنری‌ها آشنا شدی، یه سیستم **مدیریت دانشجویان** بساز:

1. یک دیکشنری خالی به اسم `students` بساز.

2. از کاربر بپرس: «چند تا دانشجو می‌خواهی وارد کنی؟» (عدد صحیح)

3. با استفاده از حلقه `for` به تعداد دانشجوها، این اطلاعات رو از کاربر بگیر و به دیکشنری اضافه کن:
   - شماره دانشجویی (کلید، از ۱ شروع میشه و هر بار یکی زیاد میشه)
   - نام دانشجو (مقدار)

4. بعد از گرفتن همه‌ی اطلاعات، دیکشنری کامل رو چاپ کن.

5. از کاربر یک شماره دانشجویی بگیر و نام اون دانشجو رو چاپ کن (با `get()` و پیام مناسب اگر پیدا نشد).

6. با حلقه `for` و `items()`، لیست کامل دانشجوها رو به این شکل چاپ کن:

```text
لیست دانشجویان:
شماره ۱: احمد رضایی
شماره ۲: سارا محمدی
شماره ۳: علی کریمی
```

> **💡 نکته:** کلیدها می‌تونن عددی باشن! مثلاً `students[1] = "احمد رضایی"` کاملاً درسته.
