### 🗣️ چرا برنامه‌های تعاملی مهم‌ان؟

تا الان یاد گرفتیم چطور داده‌ها رو خودمون توی کد تعریف کنیم و خروجی بگیریم. ولی یه برنامه‌ی واقعی وقتی جذاب میشه که بتونه با کاربر حرف بزنه؛ یعنی ازش سوال بپرسه، جواب‌هاش رو بگیره و بر اساس اون‌ها واکنش نشون بده.

برای اینکه یک برنامه زنده و پویا داشته باشیم، باید بتونیم از کاربر اطلاعات بگیریم. در پایتون، این کار با دستور جادویی `input()` انجام میشه.

---

### 📥 گرفتن ورودی با `input()`

وقتی پایتون به دستور `input` می‌رسه، کار رو متوقف می‌کنه و منتظر می‌مونه تا کاربر چیزی تایپ کنه و دکمه Enter رو بزنه.

```python
# گرفتن نام کاربر و ذخیره آن در متغیر
user_name = input("لطفاً نام خود را وارد کنید: ")

# چاپ خوش‌آمدگویی به کاربر
print("خوش آمدید", user_name)
```

> **💡 نکته:** متنی که داخل پرانتز `input` می‌نویسی، به عنوان **پیام راهنما (Prompt)** به کاربر نشون داده میشه تا بدونه چه چیزی باید وارد کنه. این پیام کاملاً اختیاریه، ولی خیلی کاربردی‌ست.

---

### ⚠️ یک تله بزرگ: همه چیز متن است!

این بخش خیلی مهمه و بیشتر تازه‌کارها رو به دردسر می‌اندازه. **دستور `input()` هر چیزی که کاربر تایپ کنه رو به عنوان «رشته» (متن یا همان `str`) دریافت می‌کنه.** حتی اگر کاربر عدد تایپ کنه!

به این کد دقت کن:

```python
age = input("سن خود را وارد کنید: ")
# اگر کاربر عدد 20 را وارد کند، مقدار متغیر age در واقع "20" (یک متن) است، نه عدد 20!

print(type(age))  # خروجی: <class 'str'>
```

اگر بخواهیم روی این سن عملیات ریاضی انجام بدیم (مثلاً بگیم ۱۰ سال دیگه چند ساله میشه)، پایتون ارور میده چون نمی‌تونه یک متن رو با عدد جمع کنه.

```python
age = input("سن خود را وارد کنید: ")
next_age = age + 10  # ❌ خطا! نمی‌تونی متن رو با عدد جمع کنی
```

---

### 🔄 تبدیل انواع داده (Type Casting) در ورودی

برای حل این مشکل، باید جنس داده رو تغییر بدیم. به این کار می‌گیم **تبدیل نوع (Type Casting)**. پایتون برای این کار چند ابزار ساده به ما میده:

* `int()`: تبدیل متن یا عدد اعشاری به عدد صحیح
* `float()`: تبدیل متن یا عدد به عدد اعشاری  
* `str()`: تبدیل عدد به متن

حالا بیا فرمول درست گرفتن عدد از کاربر رو ببینیم:

```python
# گرفتن سن به عنوان متن و تبدیل فوری آن به عدد صحیح
age = int(input("سن خود را وارد کنید: "))

# حالا می‌توانیم با آن محاسبات ریاضی انجام دهیم
next_year_age = age + 1
print("سال آینده شما", next_year_age, "ساله خواهید بود.")
```

> **📌 روش استاندارد:** معمولاً تبدیل نوع رو دقیقاً در همان خطی که `input` گرفتی انجام می‌دن تا کد تمیزتر و خوانا‌تر باشه.

### 🎨 چاپ پیشرفته با `print()`

تا الان دیدیم که `print` می‌تونه چند تا متغیر رو با کاما جدا کنه و چاپ کنه. ولی روش‌های پیشرفته‌تری هم داره:

#### روش اول: استفاده از کاما (`,`) - ساده و سریع

```python
name = "احمد"
age = 25
print("نام:", name, "سن:", age)
# خروجی: نام: احمد سن: 25
```

> پایتون خودش بین هر کدوم یه فاصله می‌ذاره.

#### روش دوم: استفاده از `+` برای چسبوندن (Concatenation)

```python
name = "احمد"
age = 25
print("نام: " + name + " سن: " + str(age))
# خروجی: نام: احمد سن: 25
```

> ⚠️ یادت باشه برای چسبوندن متن با `+`، همه‌ی بخش‌ها باید متن باشن. به همین دلیل `age` رو با `str()` به متن تبدیل کردیم.

#### روش سوم: استفاده از f-string (نحوه‌ی مدرن و خوانا) - پیشنهادی

```python
name = "احمد"
age = 25
print(f"نام: {name} سن: {age}")
# خروجی: نام: احمد سن: 25
```

> **💡** با گذاشتن حرف `f` قبل از کوتیشن، می‌تونی داخل متن، متغیرها رو با `{}` بنویسی و پایتون خودش مقدارشون رو جایگزین می‌کنه. این روش خیلی خوانا‌تر و مدرن‌تره.

### 📌 اشتباهات رایج در این درس

> **🔴 فراموش کردن تبدیل نوع:**
```python
age = input("سن: ")
print(age + 5)  # ❌ خطا! age متن هست
age = int(input("سن: "))  # ✅ درسته
```

> **🟡 فراموش کردن تبدیل عدد به متن در چسبوندن:**
```python
price = 15000
print("قیمت: " + price)  # ❌ خطا! نمی‌تونی متن رو با عدد جمع کنی
print("قیمت: " + str(price))  # ✅ درسته
```

> **🟢 استفاده از کاما به جای نقطه برای اعشار در ورودی:**
```python
price = float(input("قیمت: "))  # کاربر باید 2.5 رو وارد کنه، نه 2,5
```

### 🛠️ نوبت توئه: چالش مبدل ارز خودکار!

فرض کن می‌خواهیم یک برنامه صرافی ساده بنویسیم که دلار را به ریال تبدیل می‌کند.

**صورت مسئله:**

1. برنامه در ابتدا از کاربر بپرسد: «قیمت روز دلار به ریال چقدر است؟» و کاربر یک عدد صحیح وارد کند (مثلاً ۵۰۰۰۰۰). *راهنمایی: باید ورودی را به عدد تبدیل کنی.*
2. سپس بپرسد: «چند دلار می‌خواهی تبدیل کنی؟» و کاربر یک عدد اعشاری یا صحیح وارد کند (مثلاً ۲.۵). *راهنمایی: این بار ورودی را به اعشاری تبدیل کن.*
3. در نهایت، برنامه مقدار ریالی معادل را حساب کند (قیمت دلار ضربدر مقدار دلار) و نتیجه را در خروجی چاپ کند.

> **نکته برای ضرب:** در پایتون از علامت ستاره `*` برای ضرب استفاده می‌کنیم.

### 💪 چالش دوم (اختیاری - برای برنامه‌نویسان حرفه‌ای!)

حالا که با ورودی و خروجی آشنا شدی، یه برنامه‌ی کامل‌تر بنویس که این کارها رو انجام بده:

1. از کاربر **سه** اطلاعات زیر رو بگیر:
   - اسم کاربر (متن)
   - حقوق ماهیانه به تومان (عدد صحیح)
   - درصد مالیات (عدد اعشاری، مثلاً ۰.۱۵ برای ۱۵ درصد)

2. محاسبه کن:
   - مالیات سالانه = حقوق ماهیانه × ۱۲ × درصد مالیات
   - حقوق خالص سالانه = (حقوق ماهیانه × ۱۲) - مالیات سالانه

3. با استفاده از f-string، این خروجی رو دقیقاً با همین فرمت چاپ کن:

```text
کاربر: احمد رضایی
حقوق ماهیانه: 15,000,000 تومان
مالیات سالانه: 27,000,000 تومان
حقوق خالص سالانه: 153,000,000 تومان
```

> **💡 نکته:** برای نمایش اعداد با جداکننده هزارتا می‌تونی از `{number:,}` داخل f-string استفاده کنی:
```python
print(f"{15000000:,}")  # خروجی: 15,000,000
```
