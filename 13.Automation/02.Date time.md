### ⏰ چرا به تاریخ و زمان نیاز داریم؟

توی دنیای اتوماسیون، کار با تاریخ و زمان یه نیاز ضروریه:
- **پشتیبان‌گیری:** اسم فایل‌های پشتیبان رو به تاریخ امروز بزنی
- **گزارش‌ها:** گزارش‌های روزانه، هفتگی و ماهانه تولید کنی
- **برنامه‌ریزی:** کارها رو برای زمان مشخصی برنامه‌ریزی کنی
- **تحلیل داده:** داده‌های تاریخی رو با هم مقایسه کنی

> **📌 مثال واقعی:** فرض کن هر روز یه گزارش فروش می‌گیری. با `datetime` می‌تونی اسم فایل رو `report_2024-01-15.csv` بذاری و دیگه هیچوقت تاریخ‌ها رو قاطی نمی‌کنی!

---

### 📅 کتابخانه `datetime`

پایتون یک کتابخانه‌ی استاندارد به اسم `datetime` داره که کار با تاریخ و زمان رو خیلی راحت می‌کنه:

```python
import datetime

# ========== تاریخ و زمان فعلی ==========
now = datetime.datetime.now()
print(f"📅 الآن: {now}")

# ========== فقط تاریخ امروز ==========
today = datetime.date.today()
print(f"📆 امروز: {today}")

# ========== فقط زمان فعلی ==========
current_time = datetime.datetime.now().time()
print(f"⏰ ساعت: {current_time}")

# ========== سال، ماه، روز ==========
print(f"سال: {today.year}")
print(f"ماه: {today.month}")
print(f"روز: {today.day}")

# ========== ساعت، دقیقه، ثانیه ==========
print(f"ساعت: {current_time.hour}")
print(f"دقیقه: {current_time.minute}")
print(f"ثانیه: {current_time.second}")
```

### 🗓️ ساخت تاریخ دلخواه

```python
import datetime

# ========== ساخت یک تاریخ خاص ==========
birthday = datetime.date(2000, 5, 15)  # سال، ماه، روز
print(f"🎂 تاریخ تولد: {birthday}")

# ========== ساخت یک زمان خاص ==========
meeting_time = datetime.time(14, 30, 0)  # ساعت، دقیقه، ثانیه
print(f"📅 زمان جلسه: {meeting_time}")

# ========== ساخت تاریخ و زمان با هم ==========
event = datetime.datetime(2024, 12, 25, 18, 0, 0)
print(f"🎄 رویداد: {event}")
```

### 🔄 محاسبه اختلاف زمان (Timedelta)

با `timedelta` می‌تونی به راحتی تاریخ‌ها رو با هم جمع و تفریق کنی:

```python
import datetime

today = datetime.date.today()
print(f"📆 امروز: {today}")

# ========== ۱۰ روز بعد ==========
ten_days_later = today + datetime.timedelta(days=10)
print(f"📅 ۱۰ روز بعد: {ten_days_later}")

# ========== ۱ هفته قبل ==========
one_week_ago = today - datetime.timedelta(weeks=1)
print(f"📅 ۱ هفته قبل: {one_week_ago}")

# ========== ۳۰ روز بعد ==========
one_month_later = today + datetime.timedelta(days=30)
print(f"📅 ۳۰ روز بعد: {one_month_later}")

# ========== محاسبه اختلاف دو تاریخ ==========
birthday = datetime.date(2000, 5, 15)
age = today - birthday
print(f"🎂 سن شما: {age.days} روز")
print(f"🎂 سن شما: {age.days // 365} سال")
```

### 🎨 فرمت‌دهی تاریخ (`strftime` و `strptime`)

#### ۱. تبدیل تاریخ به رشته (`strftime`)

```python
import datetime

now = datetime.datetime.now()

# فرمت‌های مختلف
formats = [
    ("%Y-%m-%d", "YYYY-MM-DD"),
    ("%d/%m/%Y", "DD/MM/YYYY"),
    ("%B %d, %Y", "ماه روز, سال"),
    ("%A, %B %d", "روز هفته, ماه روز"),
    ("%H:%M:%S", "ساعت:دقیقه:ثانیه"),
    ("%I:%M %p", "ساعت:دقیقه AM/PM"),
    ("%Y-%m-%d %H:%M:%S", "YYYY-MM-DD HH:MM:SS")
]

print("📅 فرمت‌های مختلف:")
for format_code, description in formats:
    formatted = now.strftime(format_code)
    print(f"  {description}: {formatted}")
```

#### ۲. تبدیل رشته به تاریخ (`strptime`)

```python
import datetime

# تبدیل رشته به تاریخ
date_string = "2024-01-15"
date_obj = datetime.datetime.strptime(date_string, "%Y-%m-%d")
print(f"📅 رشته به تاریخ: {date_obj}")
print(f"   سال: {date_obj.year}, ماه: {date_obj.month}, روز: {date_obj.day}")

# تبدیل رشته با فرمت دیگه
date_string2 = "15/01/2024"
date_obj2 = datetime.datetime.strptime(date_string2, "%d/%m/%Y")
print(f"📅 رشته به تاریخ (فرمت دیگه): {date_obj2}")
```

### 🎯 مثال عملی: ایجاد نام فایل بر اساس تاریخ

```python
import datetime
import os

def create_backup_filename(base_name, extension=".zip"):
    """
    ایجاد نام فایل پشتیبان با تاریخ امروز
    """
    today = datetime.date.today()
    date_str = today.strftime("%Y-%m-%d")
    return f"{base_name}_backup_{date_str}{extension}"

# استفاده
backup_name = create_backup_filename("project")
print(f"📦 نام فایل پشتیبان: {backup_name}")
# خروجی: project_backup_2024-01-15.zip

backup_name2 = create_backup_filename("database", ".sql")
print(f"📦 نام فایل پشتیبان: {backup_name2}")
# خروجی: database_backup_2024-01-15.sql
```

### 📌 اشتباهات رایج در این درس

> **🔴 فراموش کردن `import datetime`:**
```python
today = date.today()  # ❌ خطا! date تعریف نشده

import datetime
today = datetime.date.today()  # ✅ درسته
```

> **🟡 قاطی کردن `datetime.date` با `datetime.datetime`:**
```python
# date: فقط تاریخ (سال، ماه، روز)
d = datetime.date(2024, 1, 15)

# datetime: تاریخ و زمان
dt = datetime.datetime(2024, 1, 15, 14, 30)
```

> **🟢 استفاده از فرمت اشتباه در `strptime`:**
```python
# ❌ فرمت با رشته تطابق نداره
date_string = "2024-01-15"
date_obj = datetime.datetime.strptime(date_string, "%d/%m/%Y")

# ✅ فرمت درسته
date_obj = datetime.datetime.strptime(date_string, "%Y-%m-%d")
```

> **🟣 فراموش کردن `timedelta` برای محاسبات:**
```python
# ❌ نمی‌تونی مستقیم جمع کنی
tomorrow = today + 1  # خطا!

# ✅ باید از timedelta استفاده کنی
from datetime import timedelta
tomorrow = today + timedelta(days=1)
```

### 🛠️ نوبت توئه: ماشین‌حساب روزهای زندگی!

بیا یک برنامه بنویسیم که تاریخ تولد کاربر رو بگیره و اطلاعات جالبی درباره‌ی عمرش محاسبه کنه!

**صورت مسئله:**

1. از کاربر تاریخ تولدش رو بگیر (سال، ماه، روز).

2. با `datetime.date()` تاریخ تولد رو بساز.

3. تاریخ امروز رو بگیر.

4. این اطلاعات رو محاسبه کن:
   - سن به روز
   - سن به سال
   - تعداد روز تا تولد بعدی
   - روز هفته‌ای که به دنیا اومدی

5. خروجی به این شکل باشه:
   ```
   🎂 گزارش تولد شما:
   ============================
   📅 تاریخ تولد: 2000-05-15
   📆 امروز: 2024-01-15
   
   ⏳ سن شما: 23 سال و 245 روز
   📅 روز تولد: دوشنبه
   🎉 تا تولد بعدی: 121 روز
   ============================
   ```

**راهنمایی برای روز تولد:**
```python
birthday = datetime.date(2000, 5, 15)
weekday = birthday.strftime("%A")  # روز هفته به انگلیسی
```

### 💪 چالش دوم (اختیاری - برای اتوماسیون‌بازهای حرفه‌ای!)

حالا که با `datetime` آشنا شدی، یه **سیستم گزارش‌گیری خودکار** کامل بساز:

1. برنامه‌ای بنویس که هر روز یه گزارش جدید بسازه:
   - اسم فایل: `report_YYYY-MM-DD.txt`
   - محتوا: تاریخ، روز هفته، و یک پیام دلخواه

2. این قابلیت‌ها رو اضافه کن:
   - **گزارش امروز:** فایل گزارش امروز رو بساز
   - **گزارش هفته:** جمع‌آوری ۷ گزارش آخر و نمایش خلاصه
   - **گزارش ماه:** جمع‌آوری گزارش‌های ماه جاری

3. از کاربر بپرس که چه نوع گزارشی می‌خواد:
   ```
   📊 سیستم گزارش‌گیری خودکار
   ============================
   ۱. گزارش امروز
   ۲. گزارش هفته
   ۳. گزارش ماه
   ۴. خروج
   ============================
   ```

4. برای هر گزینه، گزارش مناسب رو تولید کن.

**راهنمایی برای گزارش هفته:**
```python
today = datetime.date.today()
one_week_ago = today - datetime.timedelta(days=7)
# فایل‌های بین این دو تاریخ رو پیدا کن و بخون
```
