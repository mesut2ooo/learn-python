## 🎯 درس ۸.۵: هشدارهای پاپ‌آپ (`messagebox`)

---

### 🛑 پنجره‌های پاپ‌آپ یعنی چی؟

حالا فرض کن کاربر در ماشین‌حساب تو، عدد دوم را `0` وارد کند و دکمه تقسیم (`/`) را بزند! در ریاضی این کار تعریف‌نشده است و برنامه در پس‌زمینه با خطای تداخل محاسباتی روبه‌رو می‌شود. یا فرض کن کاربر فیلدی را خالی بگذارد. در این مواقع، چطور باید یک هشدار رسمی ویندوزی به کاربر نشان دهیم تا متوجه اشتباهش بشود؟

اینجاست که با پنجره‌های پاپ‌آپ و هشدار یا همان **MessageBox** آشنا می‌شویم.

در Tkinter ماژولی به نام `messagebox` وجود دارد که به ما اجازه می‌دهد پیام‌های مختلفی (هشدار، خطا، اطلاعات یا حتی سوالات بله/خیر) را در قالب پنجره‌های کوچک و استاندارد سیستم‌عامل به کاربر نشان دهیم.

> **📌 نکته:** `messagebox` یک ماژول جداگانه در Tkinter هست و باید جداگانه وارد بشه: `from tkinter import messagebox`

---

### 💻 انواع پیام‌های پاپ‌آپ

| نوع | متد | کاربرد | آیکون |
|-----|-----|--------|-------|
| **اطلاع‌رسانی** | `showinfo()` | نمایش اطلاعات عمومی | ℹ️ |
| **هشدار** | `showwarning()` | نمایش هشدارها | ⚠️ |
| **خطا** | `showerror()` | نمایش خطاهای سیستمی | ❌ |
| **سوال** | `askquestion()` | پرسیدن سوال بله/خیر | ❓ |
| **سوال با گزینه‌ها** | `askyesno()` | بله/خیر | ❓ |
| **سوال با OK/Cancel** | `askokcancel()` | تأیید/لغو | ❓ |
| **سوال با Retry/Cancel** | `askretrycancel()` | دوباره تلاش/لغو | ❓ |

### 💻 کد نمونه: انواع پیام‌ها

```python
import tkinter as tk
from tkinter import messagebox

def show_info():
    messagebox.showinfo("موفقیت", "عملیات با موفقیت انجام شد! 🎉")

def show_warn():
    messagebox.showwarning("توجه", "لطفاً تمام فیلدها را پر کنید! ⚠️")

def show_err():
    messagebox.showerror("خطای سیستمی", "امکان تقسیم بر صفر وجود ندارد! ❌")

def ask_yes_no():
    result = messagebox.askyesno("تأیید", "آیا از حذف این مورد مطمئن هستید؟")
    if result:
        result_label.config(text="✅ حذف تأیید شد!", fg="green")
    else:
        result_label.config(text="❌ حذف لغو شد!", fg="red")

def ask_question():
    result = messagebox.askquestion("سوال", "آیا ادامه می‌دهید؟")
    if result == "yes":
        result_label.config(text="✅ ادامه دادید!", fg="green")
    else:
        result_label.config(text="❌ ادامه ندادید!", fg="red")

window = tk.Tk()
window.title("کار با MessageBox")
window.geometry("350x350")

# دکمه‌ها
btn1 = tk.Button(window, text="پیام موفقیت", command=show_info, width=20)
btn1.pack(pady=5)

btn2 = tk.Button(window, text="پیام هشدار", command=show_warn, width=20)
btn2.pack(pady=5)

btn3 = tk.Button(window, text="پیام خطا", command=show_err, width=20)
btn3.pack(pady=5)

btn4 = tk.Button(window, text="سوال بله/خیر", command=ask_yes_no, width=20)
btn4.pack(pady=5)

btn5 = tk.Button(window, text="سوال با OK/Cancel", command=ask_question, width=20)
btn5.pack(pady=5)

# نمایش نتیجه سوالات
result_label = tk.Label(window, text="", font=("Arial", 12, "bold"))
result_label.pack(pady=20)

window.mainloop()
```

### 🔍 دریافت پاسخ از کاربر با `messagebox`

برخی از پیام‌ها (مثل `askyesno`) یک مقدار `True` یا `False` برمی‌گردونن که می‌تونیم ازش استفاده کنیم:

```python
# askyesno -> True اگر کاربر "بله" رو زده باشه
result = messagebox.askyesno("تأیید", "آیا مطمئن هستید؟")
if result:
    print("کاربر بله گفت")
else:
    print("کاربر نه گفت")

# askquestion -> "yes" یا "no" برمی‌گردونه
result = messagebox.askquestion("سوال", "آیا ادامه می‌دهید؟")
if result == "yes":
    print("کاربر بله گفت")
else:
    print("کاربر نه گفت")

# askokcancel -> True اگر OK زده باشه
result = messagebox.askokcancel("تأیید", "آیا می‌خواهید ادامه دهید؟")
if result:
    print("کاربر OK گفت")
else:
    print("کاربر Cancel گفت")
```

### 📌 اشتباهات رایج در این درس

> **🔴 فراموش کردن `import` ماژول `messagebox`:**
```python
messagebox.showinfo("موفق", "پیام")  # ❌ خطا! messagebox تعریف نشده

from tkinter import messagebox  # ✅ باید اول وارد کنی
```

> **🟡 گذاشتن پیام خیلی طولانی در `messagebox`:**
```python
# ❌ پیام خیلی طولانی، پنجره بزرگ و زشت میشه
messagebox.showinfo("عنوان", "این یک پیام خیلی خیلی خیلی طولانی است که ...")

# ✅ پیام رو به چند بخش تقسیم کن
messagebox.showinfo("عنوان", "این یک پیام طولانی است.\nاما با خط جدید خوانا‌تر شده.")
```

> **🟢 اشتباه گرفتن `askyesno` با `askquestion`:**
```python
# askyesno -> True/False برمی‌گردونه
if messagebox.askyesno("تأیید", "ادامه؟"):
print("بله")

# askquestion -> "yes"/"no" برمی‌گردونه
result = messagebox.askquestion("تأیید", "ادامه؟")
if result == "yes":
print("بله")
```

> **🟣 استفاده از `messagebox` بدون تعیین عنوان:**
```python
# ❌ عنوان خالی، پنجره بی‌عنوان میشه
messagebox.showinfo("", "پیام")

# ✅ عنوان مشخص
messagebox.showinfo("اطلاعیه", "پیام")
```

### 🛠️ نوبت توئه: ایمن‌سازی ماشین‌حساب دسکتاپ!

بیا کدهای ماشین‌حسابی را که در درس قبل ساختی، برداری و با استفاده از `messagebox` آن را در برابر باگ‌ها کاملاً ضدضربه (محکم) کنی!

**صورت مسئله:**

1. کدهای ماشین‌حساب قبلی‌ات را باز کن.
2. بخش تقسیم (`/`) را طوری ارتقا بده که **اگر عدد دوم برابر با صفر بود**، محاسباتی انجام ندهد؛ در عوض یک `messagebox.showerror` باز کند و به کاربر بگوید: `"خطا: تقسیم بر صفر ممکن نیست!"`.
3. یک سیستم امنیتی دیگر هم اضافه کن: برای تمام دکمه‌ها (`+`, `-`, `*`, `/`) ابتدا بررسی کن که آیا کاربر اصلاً عددی تایپ کرده است یا نه. **اگر یکی از کادرهای ورودی خالی بود**، یک `messagebox.showwarning` نشان دهد و بگوید: `"لطفاً ابتدا هر دو عدد را وارد کنید!"`.
   *راهنمایی:* می‌توانی با متد `.get()` ورودی را بگیری و با شرط `if not entry.get():` خالی بودن آن را چک کنی.

### 💪 چالش دوم (اختیاری - برای توسعه‌دهندگان نرم‌افزارهای امن!)

حالا که با `messagebox` آشنا شدی، یه **سیستم مدیریت کاربران** کامل با تأییدیه‌های پاپ‌آپ بساز:

1. پنجره با عنوان `"مدیریت کاربران"` و اندازه `500x400`.

2. این بخش‌ها رو با `grid` طراحی کن:
   - **بالا:** عنوان `"👥 مدیریت کاربران"` 
   - **وسط:** یک لیست‌باکس (`Listbox`) برای نمایش لیست کاربران
   - **پایین:** سه دکمه `"افزودن"`، `"ویرایش"`، `"حذف"`

3. **دکمه افزودن:**
   - با `simpledialog` (ماژول دیگه‌ای در Tkinter) از کاربر نام جدید بگیره
   - به لیست اضافه کنه
   - پیام `showinfo` موفقیت نشون بده

4. **دکمه حذف:**
   - کاربر رو انتخاب کنه (از لیست)
   - با `askyesno` تأیید بگیره
   - اگر تأیید شد، حذف کنه و پیام موفقیت نشون بده
   - اگر نه، پیام `showinfo` بده `"حذف لغو شد"`

5. **دکمه ویرایش:**
   - کاربر رو انتخاب کنه
   - با `simpledialog` نام جدید بگیره
   - با `askyesno` تأیید بگیره
   - اگر تأیید شد، ویرایش کنه

**راهنمایی برای `Listbox` و `simpledialog`:**

```python
from tkinter import Listbox, simpledialog

# ساخت لیست‌باکس
listbox = Listbox(window, height=10, font=("Arial", 11))
listbox.grid(row=1, column=0, padx=20, pady=10)

# افزودن آیتم
listbox.insert(tk.END, "احمد")

# گرفتن آیتم انتخاب‌شده
selected = listbox.curselection()  # اندیس انتخاب‌شده
name = listbox.get(selected)       # نام انتخاب‌شده

# گرفتن ورودی با simpledialog
new_name = simpledialog.askstring("ورودی", "نام جدید را وارد کنید:")
```
