## 🎯 درس ۸.۴: چیدمان منظم با سیستم شبکه‌ای (`grid`)

---

### 🧩 سیستم شبکه‌ای یعنی چی؟

تا اینجای کار، ما برای چیدن تمام ویجت‌ها روی صفحه از متد `.pack()` استفاده می‌کردیم. این متد مثل یک چسب قطره‌ای ساده، ابزارها را یکی پس از دیگری به صورت عمودی (زیر هم) روی صفحه می‌چسباند. اما اگر بخواهی در برنامه‌ات چیدمان‌های مرتب‌تر و شبکه‌ای بسازی (مثلاً قرار دادن یک لِیبل و کادر ورودی دقیقاً روبه‌روی هم، یا ساختن یک ماشین‌حساب)، متد `.pack()` دیگر به کار نمی‌آید.

اینجاست که با قدرتمندترین و پرکاربردترین سیستم چیدمان در Tkinter آشنا می‌شویم: **سیستم شبکه‌ای (Grid Layout)**.

سیستم شبکه‌ای یا همان `grid`، پنجره‌ی برنامه‌ی شما را به یک جدول نامرئی متشکل از **سطرها (Rows)** و **ستون‌ها (Columns)** تقسیم می‌کند (دقیقاً مثل جدول اکسل). مختصات هر خانه از سطر و ستون صفر شروع می‌شود:

```text
               Column 0          Column 1
            ┌───────────────┬───────────────┐
   Row 0    │   (row=0)     │   (row=0)     │
            │   col=0       │   col=1       │
            ├───────────────┼───────────────┤
   Row 1    │   (row=1)     │   (row=1)     │
            │   col=0       │   col=1       │
            └───────────────┴───────────────┘
```

> **📌 تفاوت `pack()` و `grid()`:**
> - **`pack()`:** ویجت‌ها رو به صورت عمودی (یا افقی) پشت سر هم می‌چینه (ساده ولی محدود)
> - **`grid()`:** ویجت‌ها رو در یک جدول سطر-ستونی مرتب می‌کنه (قدرتمند و دقیق)

---

### 💻 طراحی یک فرم ورود مرتب با `grid`

بیا فرم ورود مرحله قبل را این‌بار با سیستم شبکه‌ای بازنویسی کنیم تا ببینی چقدر مرتب‌تر و شیک‌تر روبه‌روی هم چیده می‌شوند:

```python
import tkinter as tk

def login():
    username = entry_user.get()
    password = entry_pass.get()
    
    if username == "admin" and password == "1234":
        result_label.config(text="✅ ورود موفق!", fg="green")
    else:
        result_label.config(text="❌ اطلاعات نادرست!", fg="red")

window = tk.Tk()
window.title("فرم ورود منظم")
window.geometry("350x200")

# ردیف اول (سطر 0): نام کاربری
lbl_user = tk.Label(window, text="نام کاربری:", font=("Tahoma", 11))
lbl_user.grid(row=0, column=0, padx=10, pady=10, sticky="w")

entry_user = tk.Entry(window, font=("Tahoma", 11), width=20)
entry_user.grid(row=0, column=1, padx=10, pady=10)

# ردیف دوم (سطر 1): کلمه عبور
lbl_pass = tk.Label(window, text="کلمه عبور:", font=("Tahoma", 11))
lbl_pass.grid(row=1, column=0, padx=10, pady=10, sticky="w")

entry_pass = tk.Entry(window, font=("Tahoma", 11), width=20, show="*")
entry_pass.grid(row=1, column=1, padx=10, pady=10)

# ردیف سوم (سطر 2): دکمه ورود و نمایش نتیجه
btn_login = tk.Button(window, text="ورود به سیستم", font=("Tahoma", 11), command=login)
btn_login.grid(row=2, column=0, columnspan=2, pady=10)

result_label = tk.Label(window, text="", font=("Tahoma", 12, "bold"))
result_label.grid(row=3, column=0, columnspan=2, pady=5)

window.mainloop()
```

### 🔍 ویژگی‌های کلیدی در سیستم `grid`

| ویژگی | توضیح | مثال |
|-------|-------|------|
| `row` | شماره سطر (شروع از ۰) | `row=0` |
| `column` | شماره ستون (شروع از ۰) | `column=1` |
| `padx` | فاصله افقی از حاشیه خانه | `padx=10` |
| `pady` | فاصله عمودی از حاشیه خانه | `pady=5` |
| `sticky` | جهت چسبندگی در خانه (`n`, `s`, `e`, `w`) | `sticky="w"` (چپ) |
| `columnspan` | تعداد ستون‌هایی که اشغال می‌کنه | `columnspan=2` |
| `rowspan` | تعداد سطرهایی که اشغال می‌کنه | `rowspan=2` |

> **💡 نکته `sticky`:** 
> - `"w"` (West) = چپ
> - `"e"` (East) = راست
> - `"n"` (North) = بالا
> - `"s"` (South) = پایین
> - ترکیب‌ها: `"ew"` (چپ و راست)، `"ns"` (بالا و پایین)

### 🎯 مثال: فرم پروفایل با `grid`

```python
import tkinter as tk

def show_profile():
    name = name_entry.get()
    age = age_entry.get()
    city = city_entry.get()
    
    if name.strip() and age.strip() and city.strip():
        result_label.config(
            text=f"👤 نام: {name}\n📅 سن: {age}\n📍 شهر: {city}",
            fg="blue"
        )
    else:
        result_label.config(text="❌ همه فیلدها را پر کنید!", fg="red")

window = tk.Tk()
window.title("پروفایل کاربر")
window.geometry("400x300")

# عنوان
title = tk.Label(window, text="اطلاعات پروفایل", font=("Arial", 16, "bold"))
title.grid(row=0, column=0, columnspan=2, pady=10)

# سطر 1: نام
tk.Label(window, text="نام:", font=("Arial", 11)).grid(row=1, column=0, padx=10, pady=5, sticky="w")
name_entry = tk.Entry(window, font=("Arial", 11), width=25)
name_entry.grid(row=1, column=1, padx=10, pady=5)

# سطر 2: سن
tk.Label(window, text="سن:", font=("Arial", 11)).grid(row=2, column=0, padx=10, pady=5, sticky="w")
age_entry = tk.Entry(window, font=("Arial", 11), width=25)
age_entry.grid(row=2, column=1, padx=10, pady=5)

# سطر 3: شهر
tk.Label(window, text="شهر:", font=("Arial", 11)).grid(row=3, column=0, padx=10, pady=5, sticky="w")
city_entry = tk.Entry(window, font=("Arial", 11), width=25)
city_entry.grid(row=3, column=1, padx=10, pady=5)

# سطر 4: دکمه
btn_show = tk.Button(window, text="نمایش پروفایل", font=("Arial", 11), command=show_profile)
btn_show.grid(row=4, column=0, columnspan=2, pady=15)

# سطر 5: نتیجه
result_label = tk.Label(window, text="", font=("Arial", 12, "bold"), justify="left")
result_label.grid(row=5, column=0, columnspan=2, pady=10)

window.mainloop()
```

### 📌 اشتباهات رایج در این درس

> **🔴 قاطی کردن `pack()` و `grid()` برای یک ویجت:**
```python
label = tk.Label(window, text="سلام")
label.pack()
label.grid(row=0, column=0)  # ❌ خطا! نمی‌تونی از هر دو استفاده کنی
```

> **🟡 فراموش کردن `sticky` برای چسبندگی:**
```python
# ❌ ویجت وسط خانه میمونه و کوچیک به نظر میرسه
label.grid(row=0, column=0)

# ✅ با sticky به چپ میچسبه
label.grid(row=0, column=0, sticky="w")
```

> **🟢 استفاده از `columnspan` برای یک ویجت در ستون آخر:**
```python
# ❌ اگر دکمه در ستون ۱ باشه و columnspan=2 باشه، از محدوده خارج میشه
btn.grid(row=2, column=1, columnspan=2)

# ✅ باید از ستون ۰ شروع کنه
btn.grid(row=2, column=0, columnspan=2)
```

> **🟣 فراموش کردن `row` و `column` برای همه ویجت‌ها:**
```python
label1 = tk.Label(window, text="متن")
label1.grid()  # ❌ فراموش شده: مختصات رو مشخص کن
label1.grid(row=0, column=0)  # ✅ درسته
```

### 🛠️ نوبت توئه: چالش ماشین‌حساب دسکتاپ!

بیا یک ماشین‌حساب ساده ۴ کاره (جمع، تفریق، ضرب، تقسیم) با یک ظاهر بسیار تمیز دسکتاپی بسازیم.

**صورت مسئله:**

1. یک پنجره جدید با ابعاد مناسب بساز.
2. با استفاده از سیستم `grid` ویجت‌های زیر را بچین:
   - یک لِیبل و یک کادر ورودی برای **عدد اول** (در سطر 0).
   - یک لِیبل و یک کادر ورودی برای **عدد دوم** (در سطر 1).
   - یک لِیبل برای نمایش **نتیجه** محاسبات (در سطر 2 که می‌تواند ابتدا خالی باشد یا بنویسد `"نتیجه: 0"`).
3. در سطر 3، **۴ عدد دکمه** کنار هم بساز:
   - دکمه `+` (ستون 0)
   - دکمه `-` (ستون 1)
   - دکمه `*` (ستون 2)
   - دکمه `/` (ستون 3)
4. برای هر دکمه، تابعی بنویس که دو عدد ورودی را بگیرد (یادت نرود که ورودی کادر متنی به صورت String است و باید با `float()` یا `int()` به عدد تبدیل شود)، عملیات مربوطه را انجام دهد و حاصل را روی لِیبل نتیجه نمایش دهد.

> **💡 نکته:** برای تقسیم، حتماً خطای تقسیم بر صفر رو مدیریت کن (`try/except`).

### 💪 چالش دوم (اختیاری - برای طراحان رابط کاربری حرفه‌ای!)

حالا که با `grid` آشنا شدی، یه **داشبورد مدیریت فروش** با چیدمان شبکه‌ای پیشرفته طراحی کن:

1. پنجره با عنوان `"داشبورد مدیریت فروش"` و اندازه `700x500`.

2. با `grid` این بخش‌ها رو طراحی کن:
   - **ردیف ۰ (هد):** یک Label با عنوان بزرگ `"📊 داشبورد مدیریت فروش"` که کل ۳ ستون رو اشغال کنه (با پس‌زمینه تیره و متن سفید)
   - **ردیف ۱ (آمار):** سه فریم کنار هم با اطلاعات آماری:
     - ستون ۰: تعداد فروش‌های امروز (مثلاً ۱۵)
     - ستون ۱: درآمد امروز (مثلاً ۱۲,۵۰۰,۰۰۰ تومان)
     - ستون ۲: تعداد مشتریان جدید (مثلاً ۳)
   - **ردیف ۲ (جدول محصولات):** یک عنوان `"لیست محصولات"` که کل ۳ ستون رو اشغال کنه
   - **ردیف ۳ (محصولات):** سه ستون با اطلاعات محصولات مختلف (نام، قیمت، موجودی)

3. از `Frame` برای گروه‌بندی استفاده کن.

4. از `sticky` و `padx`/`pady` برای فاصله‌گذاری مناسب استفاده کن.

**راهنمایی:** می‌تونی از `LabelFrame` برای بخش‌های مختلف استفاده کنی:

```python
import tkinter as tk
from tkinter import LabelFrame

# ساخت یک بخش با حاشیه و عنوان
stats_frame = LabelFrame(window, text="آمار امروز", font=("Arial", 12), padx=10, pady=10)
stats_frame.grid(row=1, column=0, columnspan=3, padx=10, pady=5, sticky="ew")
```
