### 🗺️ سیستم مختصات در Pygame

در دنیای بازی‌های دو بعدی، موقعیت هر چیزی روی صفحه با یک سیستم مختصات دو بعدی $(X, Y)$ مشخص میشه. اما یک تفاوت مهم با ریاضیات مدرسه وجود داره:

* **نقطه $(0, 0)$ دقیقاً گوشه بالا و سمت چپ صفحه است.**
* هر چقدر به سمت راست بریم، مقدار $X$ زیاد میشه.
* هر چقدر به سمت **پایین** بریم، مقدار $Y$ زیاد میشه (برعکس ریاضی مدرسه که پایین رفتن منفی بود!).

```
  (0, 0) ────────── X ──────────►
    │
    │   هر شیء با (x, y) مشخص میشه
    │
    ▼
    Y
```

> **📌 نکته:** مختصات $(X, Y)$ در بازی‌ها، گوشه‌ی **بالا-چپ** شیء رو مشخص می‌کنه، نه مرکزش!

### 📐 اشکال پایه در Pygame

| شکل | دستور | پارامترها |
|------|-------|----------|
| مستطیل | `pygame.draw.rect()` | `(X, Y, WIDTH, HEIGHT)` |
| دایره | `pygame.draw.circle()` | `(X, Y, RADIUS)` |
| خط | `pygame.draw.line()` | `(X1, Y1, X2, Y2)` |
| بیضی | `pygame.draw.ellipse()` | `(X, Y, WIDTH, HEIGHT)` |

### 💻 چطور یک مربع (بازیکن فرضی) روی صفحه بکشیم؟

پایتون برای کشیدن اشکال هندسی یک ابزار به اسم `pygame.draw` داره. برای کشیدن یک مستطیل یا مربع از دستور زیر استفاده می‌کنیم:

```python
pygame.draw.rect(screen, COLOR, (X, Y, WIDTH, HEIGHT))
```

### 🚗 حرکت دادن اشیاء

برای حرکت دادن یک شیء، کافیه موقعیت اون رو در هر فریم تغییر بدیم:

```python
# در هر فریم، ۵ پیکسل به X اضافه کن (حرکت به راست)
player_x += player_speed

# در هر فریم، ۵ پیکسل به Y اضافه کن (حرکت به پایین)
player_y += player_speed
```

### 🎬 کد کامل: حرکت به راست

بیا کدهای درس قبل رو ارتقا بدیم. می‌خوایم یک مربع قرمز رنگ بسازیم و کاری کنیم که در هر فریم بازی، کمی به سمت راست حرکت کنه:

```python
import pygame
import sys

# ۱. راه‌اندازی
pygame.init()

SCREEN_WIDTH = 800
SCREEN_HEIGHT = 600
screen = pygame.display.set_mode((SCREEN_WIDTH, SCREEN_HEIGHT))
pygame.display.set_caption("حرکت دادن اجسام")

# تعریف رنگ‌ها (RGB)
BLACK = (0, 0, 0)
RED = (255, 0, 0)

# ۲. تعریف موقعیت و ابعاد بازیکن (مربع)
player_x = 50
player_y = 250
player_width = 50
player_height = 50
player_speed = 5  # سرعت حرکت در هر فریم

# ۳. ساعت بازی برای کنترل فریم‌ریت (FPS)
clock = pygame.time.Clock()

is_running = True
while is_running:
    
    # کنترل فریم‌ریت روی ۶۰ فریم بر ثانیه
    clock.tick(60)
    
    # --- بخش اول: مدیریت رویدادها ---
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            is_running = False

    # --- بخش دوم: به روز رسانی منطق بازی ---
    # در هر فریم، ۵ پیکسل به موقعیت X اضافه می‌کنیم تا به سمت راست حرکت کند
    player_x += player_speed
    
    # اگر مربع از سمت راست صفحه خارج شد، دوباره از سمت چپ وارد بشه
    if player_x > SCREEN_WIDTH:
        player_x = -player_width

    # --- بخش سوم: نقاشی روی صفحه ---
    screen.fill(BLACK)  # پاک کردن صفحه قدیمی

    # کشیدن بازیکن جدید در موقعیت به روز شده
    pygame.draw.rect(screen, RED, (player_x, player_y, player_width, player_height))

    pygame.display.flip()

pygame.quit()
sys.exit()
```

> **💡 نکته:** اگه خط `screen.fill(BLACK)` رو برداریم، مربع‌ها پشت سر هم کشیده میشن و یه ردپا ایجاد می‌کنن! این خودش یه تکنیک جذاب برای ایجاد جلوه‌های بصری هست.

### 🎯 کنترل حرکت با کیبورد (آماده‌سازی برای درس بعد)

برای حرکت دادن با کیبورد، از رویدادهای `KEYDOWN` استفاده می‌کنیم:

```python
for event in pygame.event.get():
    if event.type == pygame.QUIT:
        is_running = False
    elif event.type == pygame.KEYDOWN:
        if event.key == pygame.K_RIGHT:
            player_x += player_speed
        elif event.key == pygame.K_LEFT:
            player_x -= player_speed
        elif event.key == pygame.K_UP:
            player_y -= player_speed
        elif event.key == pygame.K_DOWN:
            player_y += player_speed
```

> **📌 نکته:** این روش رو توی درس بعدی کامل یاد می‌گیریم.

### 📌 اشتباهات رایج در این درس

> **🔴 فراموش کردن آپدیت موقعیت در هر فریم:**
```python
while running:
    # ❌ player_x هیچوقت تغییر نمی‌کنه!
    pygame.draw.rect(screen, RED, (player_x, player_y, 50, 50))
```

> **🟡 اشتباه در محور Y (پایین رفتن به جای بالا):**
```python
# برای حرکت به پایین: Y باید زیاد بشه
player_y += speed  # ✅ حرکت به پایین
player_y -= speed  # ❌ حرکت به بالا
```

> **🟢 شرط خروج از صفحه اشتباه:**
```python
# ❌ فقط وقتی کامل خارج شد، شرط اجرا میشه
if player_x > SCREEN_WIDTH:

# ✅ بهتره قبل از اینکه کامل خارج بشه، برگردونه
if player_x > SCREEN_WIDTH - player_width:
```

> **🟣 فراموش کردن `clock.tick(60)`:**
```python
while running:
    # ❌ بدون clock.tick، بازی با سرعت متفاوت اجرا میشه
    player_x += 5
```

### 🛠️ نوبت توئه: چالش سقوط آزاد توپ!

بیا به جای حرکت افقی، فیزیک سقوط (جاذبه) رو شبیه‌سازی کنیم.

**صورت مسئله:**

1. کدهای بالا رو کپی و اجرا کن تا حرکت روان مربع قرمز رو ببینی.
2. حالا تغییرات زیر رو اعمال کن تا مربع مثل یک سنگ سقوط کنه:
   - کاری کن موقعیت مربع به جای حرکت به سمت راست، به سمت **پایین** حرکت کنه (کدوم متغیر باید تغییر کنه؟ $X$ یا $Y$؟).
   - شرط انتهای صفحه رو طوری تغییر بده که اگر مربع به کف صفحه (یعنی `SCREEN_HEIGHT`) رسید، موقعیتش دوباره بره به سقف صفحه ($Y = 0$) تا سقوطش تکرار بشه.
3. رنگ مربع رو هم به سبز `(0, 255, 0)` تغییر بده.

---

### 💪 چالش دوم (اختیاری - برای فیزیک‌دان‌های بازی!)

حالا که با حرکت آشنا شدی، یه سیستم **سقوط با شتاب** (جاذبه واقعی) بساز:

1. سه متغیر اضافه کن:
   - `velocity_y = 0` (سرعت عمودی)
   - `gravity = 0.5` (شتاب جاذبه در هر فریم)
   - `jump_strength = -12` (قدرت پرش)

2. در بخش به‌روزرسانی:
   - هر فریم `velocity_y += gravity` (سرعت زیاد میشه → سقوط سریع‌تر)
   - `player_y += velocity_y` (موقعیت به‌روز میشه)

3. اگه بازیکن به کف صفحه رسید:
   - `player_y = SCREEN_HEIGHT - player_height`
   - `velocity_y = 0` (متوقف کن)

4. اگر کاربر کلید Space رو زد (با `KEYDOWN` و `event.key == pygame.K_SPACE`):
   - `velocity_y = jump_strength` (به بالا پرت کن!)

5. این چالش رو می‌تونی با حرکت دادن مربع‌ها امتحان کنی.

**نمونه رفتار:**
- مربع با سرعت کم شروع به سقوط می‌کنه
- هر فریم سرعتش بیشتر میشه (شتاب)
- وقتی به زمین می‌رسه، متوقف میشه
- با زدن Space، به بالا پرت میشه و دوباره سقوط می‌کنه

> **💡 نکته:** `jump_strength` منفی هست چون محور Y به سمت پایین مثبته!
