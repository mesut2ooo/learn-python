### 🔊 صدا در بازی‌ها یعنی چی؟

بازی‌های ویدیویی بدون صدا مثل فیلم‌های صامت هستند؛ نصف جادوی بازی‌سازی در **صداگذاری و موسیقی** نهفته است. صداها در بازی به دو دسته کلی تقسیم می‌شوند:

1. **موسیقی پس‌زمینه (Music):** فایل‌های طولانی (مثل فرمت `.mp3`) که معمولاً به صورت پیوسته و تکرار شونده (Loop) در پس‌زمینه پخش می‌شوند. پایتون این فایل‌ها را به صورت استریم پخش می‌کند تا حافظه رم اشغال نشود.
2. **جلوه‌های صوتی (Sound Effects):** صداهای کوتاه و سریع (مثل فرمت `.wav` یا `.ogg`) مثل صدای پرش، شلیک یا گرفتن سکه که باید بلافاصله و بدون تاخیر با یک اتفاق در بازی پخش شوند.

| نوع صدا | فرمت | حجم | کاربرد |
|----------|------|------|--------|
| موسیقی | `.mp3`, `.ogg` | بزرگ | پس‌زمینه |
| افکت صوتی | `.wav`, `.ogg` | کوچک | رویدادها |

### 📥 چطور فایل صوتی تهیه کنیم؟

قبل از کدنویسی، باید دو فایل صوتی در پوشه بازی‌ات (در کنار فایل `main.py`) داشته باشی:

- یک فایل موسیقی پس‌زمینه به نام `background.mp3`
- یک فایل افکت صوتی کوتاه به نام `coin.wav`

> **💡 نکته:** اگر الآن فایل صوتی آماده روی سیستمت نداری، نگران نباش! پایتون در صورت نبودن فایل‌ها ارور می‌دهد. برای اینکه کدت بدون فایل هم اجرا شود، در بخش زیر کدهای مربوط به صدا را با ساختار `try ... except` می‌نویسیم تا اگر فایل‌ها نبودند، بازی کرش نکند و بتوانی بعداً فایل‌ها را اضافه کنی.

### 💻 اضافه کردن سیستم صوتی به بازی

کدهای بازی قبلی را با سیستم صوتی ارتقا می‌دهیم:

```python
import pygame
import sys
import random

pygame.init()

# راه‌اندازی سیستم صوتی Pygame (بسیار مهم!)
pygame.mixer.init()

SCREEN_WIDTH = 800
SCREEN_HEIGHT = 600
screen = pygame.display.set_mode((SCREEN_WIDTH, SCREEN_HEIGHT))
pygame.display.set_caption("بازی زمان‌دار با صداگذاری")

# رنگ‌ها
BLACK = (0, 0, 0)
GREEN = (0, 255, 0)
YELLOW = (255, 215, 0)
WHITE = (255, 255, 255)

# بازیکن و سکه
player_rect = pygame.Rect(100, 275, 50, 50)
coin_rect = pygame.Rect(400, 300, 20, 20)
player_speed = 7

score = 0
game_font = pygame.font.Font(None, 36)

# --- مدیریت و بارگذاری صداها ---
coin_sound = None
warning_sound = None

try:
    # ۱. بارگذاری موسیقی پس‌زمینه
    pygame.mixer.music.load("background.mp3")
    pygame.mixer.music.set_volume(0.3)  # تنظیم صدای موسیقی (بین 0.0 تا 1.0)
    pygame.mixer.music.play(-1)         # عدد 1- یعنی موسیقی تا ابد تکرار شود

    # ۲. بارگذاری افکت صوتی گرفتن سکه
    coin_sound = pygame.mixer.Sound("coin.wav")
    coin_sound.set_volume(0.5)
    
    # ۳. بارگذاری افکت اخطار (اختیاری)
    warning_sound = pygame.mixer.Sound("warning.wav")
    warning_sound.set_volume(0.7)
    
    print("✅ صداها با موفقیت بارگذاری شدند.")
except Exception as e:
    print(f"⚠️ هشدار: فایل‌های صوتی پیدا نشدند. بازی بدون صدا اجرا می‌شود. (خطا: {e})")

# زمان شروع بازی
start_ticks = pygame.time.get_ticks()
GAME_DURATION = 30  # مدت زمان بازی به ثانیه

# متغیر برای جلوگیری از پخش مکرر اخطار
last_second = -1

clock = pygame.time.Clock()
is_running = True

while is_running:
    clock.tick(60)
    
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            is_running = False

    # محاسبه زمان باقی‌مانده
    seconds_passed = (pygame.time.get_ticks() - start_ticks) / 1000
    time_left = GAME_DURATION - int(seconds_passed)

    # اگر زمان تمام شد
    if time_left <= 0:
        print(f"🎮 بازی تمام شد! امتیاز نهایی شما: {score}")
        is_running = False
        break

    # --- پخش اخطار در ثانیه‌های آخر (هر ثانیه یک بار) ---
    if time_left <= 5 and time_left != last_second:
        if warning_sound:
            warning_sound.play()
            print(f"⏰ هشدار! {time_left} ثانیه باقی مانده!")
        last_second = time_left

    # حرکت بازیکن
    keys = pygame.key.get_pressed()
    if keys[pygame.K_LEFT]:
        player_rect.x -= player_speed
    if keys[pygame.K_RIGHT]:
        player_rect.x += player_speed
    if keys[pygame.K_UP]:
        player_rect.y -= player_speed
    if keys[pygame.K_DOWN]:
        player_rect.y += player_speed

    # محدودیت مرزها
    if player_rect.left < 0:
        player_rect.left = 0
    if player_rect.right > SCREEN_WIDTH:
        player_rect.right = SCREEN_WIDTH
    if player_rect.top < 0:
        player_rect.top = 0
    if player_rect.bottom > SCREEN_HEIGHT:
        player_rect.bottom = SCREEN_HEIGHT

    # برخورد با سکه
    if player_rect.colliderect(coin_rect):
        score += 1
        
        # پخش افکت صوتی گرفتن سکه
        if coin_sound:
            coin_sound.play()
            
        coin_rect.x = random.randint(50, SCREEN_WIDTH - 50)
        coin_rect.y = random.randint(50, SCREEN_HEIGHT - 50)

    # نقاشی
    screen.fill(BLACK)
    pygame.draw.rect(screen, GREEN, player_rect)
    pygame.draw.ellipse(screen, YELLOW, coin_rect)

    # رندر و نمایش متن‌ها
    score_text = game_font.render(f"Score: {score}", True, WHITE)
    time_text = game_font.render(f"Time: {time_left}s", True, WHITE)
    
    # تغییر رنگ تایمر در ثانیه‌های آخر
    if time_left <= 5:
        time_text = game_font.render(f"Time: {time_left}s", True, (255, 0, 0))  # قرمز
    
    screen.blit(score_text, (10, 10))
    screen.blit(time_text, (SCREEN_WIDTH - 150, 10))

    pygame.display.flip()

pygame.quit()
sys.exit()
```

### 🛠️ نوبت توئه: چالش صدای بوق هشدار ثانیه‌های آخر!

بیا یک هیجان صوتی جدید به بازی اضافه کنیم. می‌خواهیم کاری کنیم که وقتی زمان بازی به کمتر از ۵ ثانیه رسید، در هر ثانیه یک صدای اخطار کوتاه پخش شود تا بازیکن بفهمد وقتش رو به اتمام است.

**صورت مسئله:**

1. کدهای بالا را بنویس و تست کن.
2. یک فایل صوتی کوتاه دیگر به نام `warning.wav` (یا هر صدای بوق مانندی) پیدا کن و در کدت بارگذاری کن (مثلاً به عنوان `warning_sound`).
3. در بدنه اصلی حلقه، شرطی بنویس که **اگر زمان باقی‌مانده کمتر یا مساوی ۵ ثانیه شد**، افکت صوتی اخطار پخش شود.
   - *راهنمای بسیار مهم برای جلوگیری از کرش یا سردرد:* اگر این شرط را ساده بنویسی، پایتون در هر فریم (۶۰ بار در ثانیه) این صدا را پخش می‌کند که صدای وحشتناکی تولید خواهد کرد! برای اینکه صدا فقط **یک بار در هر ثانیه** پخش شود، باید بررسی کنی که آیا ثانیه تغییر کرده است یا نه (مثلاً با تعریف یک متغیر به نام `last_checked_second` بیرون از حلقه و مقایسه آن با زمان فعلی).

### 💪 چالش دوم (اختیاری - برای طراحان صوتی بازی!)

حالا که با صدا آشنا شدی، یه سیستم **مدیریت صوتی کامل** با قابلیت‌های زیر بساز:

1. **سه افکت صوتی مختلف:**
   - `coin_sound`: برای گرفتن سکه
   - `warning_sound`: برای هشدار ثانیه‌های آخر
   - `game_over_sound`: برای پایان بازی (صدای باخت یا موفقیت)

2. **تنظیم صدا با کیبورد:**
   - کلیدهای `+` و `-` : افزایش و کاهش صدای موسیقی پس‌زمینه (با `pygame.mixer.music.set_volume()`)
   - کلید `M`: قطع و وصل کردن صدا (Mute/Unmute)

3. **نمایش وضعیت صدا روی صفحه:**
   - آیکون بلندگو 🎵 وقتی صدا روشنه
   - آیکون بی‌صدا 🔇 وقتی صدا خاموشه
   - نمایش میزان صدا به صورت عددی (مثلاً `50%`)

4. **پخش موسیقی ریست:**
   - وقتی بازی ریست میشه، موسیقی هم از اول پخش بشه (با `pygame.mixer.music.rewind()` و `pygame.mixer.music.play()`)

**نمونه خروجی:**
```
🔊 Volume: 30%    🎵
Score: 5    ⏱️ 23s
```

> **💡 نکته:** برای تنظیم صدا با کلیدها:
```python
if keys[pygame.K_EQUALS]:  # کلید +
    current_volume += 0.1
    pygame.mixer.music.set_volume(min(current_volume, 1.0))
if keys[pygame.K_MINUS]:   # کلید -
    current_volume -= 0.1
    pygame.mixer.music.set_volume(max(current_volume, 0.0))
```
