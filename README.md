## 🎯 این دوره چیه و به چه درد می‌خوره؟

سلام به دنیای شگفت‌انگیز پایتون! 🌟

این یه دوره **رایگان** و **کاملاً متن‌محور** برای یادگیری پایتون از صفر تا مباحث پیشرفته‌ست. من این دوره رو طوری طراحی کردم که انگار دارم کنار شما نشستم و قدم‌به‌قدم با زبانی ساده و مثال‌های واقعی، پایتون رو بهت یاد می‌دم.

> **📌 چه فرقی با بقیه دوره‌ها داره؟**
> - **متن‌محور و دقیق:** هیچ ویدیوی بیهوده‌ای نیست! همه چیز رو با متن، مثال و تمرین یاد می‌گیری.
> - **تمرین‌های چالش‌برانگیز:** هر درس تمرین‌های واقعی داره که ذهنت رو درگیر می‌کنه.
> - **پیشروی تدریجی:** از `print("Hello World")` تا ساختن کلاس‌های شی‌گرا و رسم نمودارهای حرفه‌ای.
> - **همه‌چیز عملیه:** هیچ تئوری خشکی توی این دوره نیست، همه چیز با کد و مثال همراهه.

## 🗺️ نقشه راه: از کجا شروع کنیم؟

این دوره به ۱۰ فصل اصلی تقسیم شده که هر کدوم یه مبحث مهم رو پوشش می‌دن. ترتیب خوندن دقیقاً همینه:

| فصل | عنوان | چه چیزهایی یاد می‌گیری؟ |
|------|-------|----------------------|
| **فصل ۱** | شروع ماجرا | نصب پایتون، اولین کد، متغیرها، ورودی/خروجی |
| **فصل ۲** | ساختارهای شرطی و حلقه‌ها | `if`، `for`، `while`، تصمیم‌گیری در کد |
| **فصل ۳** | ساختمان داده‌ها | لیست، دیکشنری، تاپل، ست و روش‌های کار باهاشون |
| **فصل ۴** | توابع و ماژول‌ها | نوشتن توابع، ماژول‌ها، مدیریت خطا |
| **فصل ۵** | کار با فایل‌ها | خواندن و نوشتن فایل‌های متنی و CSV |
| **فصل ۶** | شی‌گرایی (OOP) | کلاس، آبجکت، وراثت، پلی‌مورفیسم |
| **فصل ۷** | کتابخانه‌های استاندارد | `datetime`, `random`, `json`, `os`, `sys` |
| **فصل ۸** | تحلیل داده با Pandas | سری‌ها، دیتافریم‌ها، فیلتر کردن و گروه‌بندی |
| **فصل ۹** | محاسبات عددی با NumPy | آرایه‌ها، عملیات ماتریسی، توابع ریاضی |
| **فصل ۱۰** | مصورسازی داده‌ها | رسم نمودار با Matplotlib، dashboards |

## 🚀 چطور از این دوره استفاده کنم؟

خیلی ساده! کافیه این چند قدم رو انجام بدی:

### قدم ۱: کلون کردن ریپازیتوری

توی ترمینال (یا Command Prompt) این دستور رو بزن:

```bash
git clone https://github.com/mesut2ooo/learn-python.git
cd python-course
```
---
### قدم ۲: نصب پایتون (اگه نداری)

- برو به [python.org](https://www.python.org/)
- آخرین نسخه رو دانلود و نصب کن
- توی ترمینال اجرا کن: `python --version` تا مطمئن بشی درست نصب شده

### قدم ۳: شروع کن به خوندن!
با برنامه obsidian یا هر برنامه ای که بهت اجازه میده فایل های مارک داون را بخونی را نصب کن و این پوشه را داخلش بریز.

> **💡 نکته طلایی:** فقط کدها رو نگاه نکن! حتماً خودت تایپشون کن. تایپ کردن دستی باعث میشه مغزت کد رو بهتر یاد بگیره.

### قدم ۴: تمرین‌ها رو حل کن

آخر هر درس دوتا تمرین هست یکی ساده و دومی چالشی . اولی را حتما حل کن و دومی را هم اگه دوست داری حرفه ای تر بشب حل کن.
