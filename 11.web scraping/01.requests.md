### 💻 اولین درخواست HTTP با `requests`

کتابخانه `requests` بهت اجازه میده مثل یک مرورگر، به وب‌سایت‌ها درخواست بفرستی و محتواشون رو دریافت کنی:

```python
import requests

# ارسال درخواست GET به یک وب‌سایت
response = requests.get("https://www.example.com")

# بررسی وضعیت درخواست (۲۰۰ یعنی موفق)
print(f"وضعیت: {response.status_code}")

# دیدن محتوای صفحه
print(response.text[:500])  # ۵۰۰ کاراکتر اول
```

---

### 🔍 درک وضعیت‌های HTTP

| کد | معنی | توضیح |
|----|------|-------|
| ۲۰۰ | OK | درخواست موفق بود |
| ۳۰۱ | Moved Permanently | صفحه منتقل شده |
| ۴۰۴ | Not Found | صفحه پیدا نشد |
| ۴۰۳ | Forbidden | دسترسی ممنوع |
| ۵۰۰ | Internal Server Error | خطای سرور |

```python
import requests

url = "https://www.example.com"

try:
    response = requests.get(url, timeout=5)
    
    if response.status_code == 200:
        print("✅ صفحه دریافت شد!")
    elif response.status_code == 404:
        print("❌ صفحه پیدا نشد!")
    else:
        print(f"⚠️ وضعیت: {response.status_code}")
        
except requests.exceptions.ConnectionError:
    print("❌ اتصال به اینترنت برقرار نیست!")
except requests.exceptions.Timeout:
    print("❌ زمان درخواست به پایان رسید!")
```

### 🎯 هدرهای درخواست (User-Agent)

بعضی سایت‌ها درخواست‌های غیرمرورگری رو مسدود می‌کنن. برای اینکه مثل یک مرورگر واقعی به نظر برسی، می‌تونی هدرهای درخواست رو تنظیم کنی:

```python
import requests

headers = {
    "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36"
}

response = requests.get("https://www.example.com", headers=headers)
```

### 🛠️ نوبت توئه: دریافت وضعیت یک وب‌سایت!

بیا یک برنامه‌ی ساده بنویسیم که وضعیت یک وب‌سایت رو بررسی کنه.

**صورت مسئله:**

1. کتابخانه `requests` رو نصب و ایمپورت کن.
2. از کاربر یک آدرس وب‌سایت بگیر (مثلاً `https://www.google.com`).
3. به اون آدرس درخواست بفرست و وضعیت رو چاپ کن.
4. اگر وضعیت ۲۰۰ بود، پیام `"✅ وب‌سایت در دسترس است!"` رو چاپ کن.
5. اگر وضعیت ۴۰۴ بود، پیام `"❌ صفحه پیدا نشد!"` رو چاپ کن.
6. اگر خطای اتصال بود، پیام `"❌ اتصال به اینترنت برقرار نیست!"` رو چاپ کن.
7. برای هر وضعیت دیگه‌ای، پیام مناسب چاپ کن.

### 💪 چالش دوم (اختیاری - برای اسکرپرهای حرفه‌ای!)

حالا که با `requests` آشنا شدی، یه برنامه‌ی **چک‌کننده‌ی وضعیت چندین سایت** بنویس:

1. لیستی از چندین وب‌سایت معروف بساز:
   ```python
   sites = [
       "https://www.google.com",

       "https://www.nonexistentsite.xyz"
   ]
   ```

2. با یک حلقه، به همه‌ی سایت‌ها درخواست بفرست و وضعیت هر کدوم رو چاپ کن.

3. گزارش نهایی به این شکل چاپ کن:
   ```

   ✅ https://www.python.org - فعال (200)
   ❌ https://www.nonexistentsite.xyz - غیرفعال (404)
   
   مجموع: ۴ سایت | فعال: ۳ | غیرفعال: ۱
   ```
