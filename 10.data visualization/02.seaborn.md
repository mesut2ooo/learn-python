### 🎨 چرا Seaborn؟

نمودارهای پیش‌فرض **Matplotlib** گاهی اوقات کمی بیش از حد ساده، کلاسیک و دانشگاهی به نظر می‌رسند. برای اینکه نمودارهای شما ظاهر مدرن، تم‌های رنگی بسیار جذاب (مانند رنگ‌های پاستلی یا گرادیان‌های شیک) و تحلیل‌های آماری داخلی داشته باشند، به سراغ پسرخاله‌ی شیک‌پوشِ Matplotlib یعنی **Seaborn** می‌رویم!

کتابخانه **Seaborn** بر پایه‌ی Matplotlib ساخته شده است؛ یعنی کدهای آن را زیباتر و خلاصه‌تر می‌کند تا با نوشتن خطوط کمتر، خروجی‌هایی در سطح مجلات معتبر علمی و تجاری تحویل بگیرید.

> **📌 تفاوت Seaborn با Matplotlib:**
> - **Matplotlib:** قدرت و انعطاف بالا، اما نیاز به تنظیمات زیاد
> - **Seaborn:** زیبایی پیش‌فرض، توابع آماری داخلی، کد کمتر

### 💻 تحلیل رابطه دو متغیر با نمودار و خط روند

بیایید فرض کنیم می‌خواهیم بدانیم آیا کاربران هر چقدر سنشان بالاتر می‌رود، پیام‌های بیشتری در برنامه `Anonyma` می‌فرستند یا نه:

```python
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns  # معمولاً seaborn را به صورت sns وارد می‌کنیم

# ۱. فعال کردن تم زیبای سیبورن به صورت پیش‌فرض
sns.set_theme(style="darkgrid")

# ۲. تعریف داده‌های فرضی در پانداس
data = {
    "Age": [18, 20, 22, 25, 28, 30, 32, 35, 40, 45],
    "Messages_Sent": [150, 120, 280, 210, 300, 350, 290, 410, 380, 500]
}
df = pd.DataFrame(data)

# ۳. رسم نمودار پراکندگی به همراه خط روند (Regression Plot)
# x و y نام ستون‌های جدول ما هستند و data نام خود جدول است
sns.regplot(x="Age", y="Messages_Sent", data=df, color="purple", marker="D", scatter_kws={'s': 80})

# ۴. اضافه کردن عنوان با استفاده از همان دستورات matplotlib
plt.title("رابطه سن کاربران با تعداد پیام‌های ارسالی", fontsize=14, fontweight="bold")
plt.xlabel("سن کاربر", fontsize=12)
plt.ylabel("تعداد پیام‌ها", fontsize=12)

# ۵. نمایش نمودار
plt.show()
```

### 🎯 انواع نمودارهای Seaborn

#### ۱. نمودار میله‌ای با پالت رنگی جذاب

```python
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

# داده‌ها
data = {
    "Product": ["لپ‌تاپ", "موبایل", "هدفون", "تبلت", "ساعت"],
    "Sales": [45, 80, 120, 30, 55]
}
df = pd.DataFrame(data)

# تنظیم تم
sns.set_theme(style="whitegrid")

# نمودار میله‌ای با پالت رنگی
plt.figure(figsize=(10, 6))
sns.barplot(x="Product", y="Sales", data=df, palette="viridis", hue="Product", legend=False)

plt.title("فروش محصولات", fontsize=14, fontweight="bold")
plt.xlabel("محصول", fontsize=12)
plt.ylabel("تعداد فروش", fontsize=12)
plt.show()
```

#### ۲. نمودار جعبه‌ای (Boxplot) برای نمایش توزیع داده‌ها

```python
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns
import numpy as np

# داده‌های تصادفی
np.random.seed(42)
data = {
    "Department": np.repeat(["فروش", "بازاریابی", "توسعه", "پشتیبانی"], 50),
    "Salary": np.concatenate([
        np.random.normal(5000, 1000, 50),
        np.random.normal(4500, 800, 50),
        np.random.normal(6000, 1200, 50),
        np.random.normal(4000, 600, 50)
    ])
}
df = pd.DataFrame(data)

# تنظیم تم
sns.set_theme(style="whitegrid")

# نمودار جعبه‌ای
plt.figure(figsize=(10, 6))
sns.boxplot(x="Department", y="Salary", data=df, palette="Set3", hue="Department", legend=False)

plt.title("توزیع حقوق بر اساس دپارتمان", fontsize=14, fontweight="bold")
plt.xlabel("دپارتمان", fontsize=12)
plt.ylabel("حقوق (دلار)", fontsize=12)
plt.show()
```

#### ۳. هیستوگرام و توزیع چگالی

```python
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns
import numpy as np

# داده‌های نمرات
np.random.seed(42)
data = {
    "Score": np.concatenate([
        np.random.normal(75, 10, 100),
        np.random.normal(60, 8, 50)
    ])
}
df = pd.DataFrame(data)

# تنظیم تم
sns.set_theme(style="darkgrid")

# هیستوگرام و توزیع چگالی
plt.figure(figsize=(10, 6))
sns.histplot(df["Score"], bins=20, kde=True, color="teal", alpha=0.6)

plt.title("توزیع نمرات دانشجویان", fontsize=14, fontweight="bold")
plt.xlabel("نمره", fontsize=12)
plt.ylabel("تعداد دانشجو", fontsize=12)
plt.show()
```

#### ۴. نمودار حرارتی (Heatmap) برای نمایش همبستگی

```python
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns
import numpy as np

# داده‌های تصادفی با همبستگی
np.random.seed(42)
data = {
    "Feature1": np.random.normal(0, 1, 100),
    "Feature2": np.random.normal(0, 1, 100),
    "Feature3": np.random.normal(0, 1, 100),
    "Feature4": np.random.normal(0, 1, 100),
    "Target": np.random.normal(0, 1, 100)
}
df = pd.DataFrame(data)

# محاسبه ماتریس همبستگی
correlation_matrix = df.corr()

# تنظیم تم
sns.set_theme(style="white")

# نمودار حرارتی
plt.figure(figsize=(8, 6))
sns.heatmap(
    correlation_matrix, 
    annot=True,  # نمایش اعداد
    cmap="coolwarm",
    center=0,
    square=True,
    linewidths=0.5,
    cbar_kws={"shrink": 0.8}
)

plt.title("ماتریس همبستگی ویژگی‌ها", fontsize=14, fontweight="bold")
plt.show()
```

#### ۵. نمودار جفتی (Pairplot) برای بررسی چندین متغیر

```python
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns
import numpy as np

# داده‌های تصادفی
np.random.seed(42)
data = {
    "Age": np.random.uniform(18, 65, 100),
    "Experience": np.random.uniform(0, 30, 100),
    "Salary": np.random.normal(50000, 15000, 100),
    "Satisfaction": np.random.uniform(1, 10, 100)
}
df = pd.DataFrame(data)

# تنظیم تم
sns.set_theme(style="ticks")

# نمودار جفتی
sns.pairplot(df, diag_kind="kde", plot_kws={'alpha': 0.6})
plt.suptitle("نمودار جفتی متغیرها", y=1.02, fontsize=14, fontweight="bold")
plt.show()
```

### 🎯 پالت‌های رنگی Seaborn

```python
import seaborn as sns
import matplotlib.pyplot as plt

# نمایش پالت‌های مختلف
palettes = ["deep", "muted", "pastel", "bright", "dark", "colorblind", "viridis", "magma", "coolwarm"]

fig, axes = plt.subplots(3, 3, figsize=(12, 10))

for i, palette in enumerate(palettes):
    row = i // 3
    col = i % 3
    sns.barplot(x=["A", "B", "C"], y=[1, 2, 3], palette=palette, ax=axes[row, col], hue=["A", "B", "C"], legend=False)
    axes[row, col].set_title(palette)
    axes[row, col].set_ylim(0, 4)

plt.tight_layout()
plt.show()
```

### 📌 اشتباهات رایج در این درس

> **🔴 فراموش کردن تنظیم تم با `sns.set_theme()`:**
```python
# ❌ نمودار با تم پیش‌فرض matplotlib رسم میشه
sns.barplot(x="A", y="B", data=df)

# ✅ تم Seaborn فعال میشه
sns.set_theme(style="whitegrid")
sns.barplot(x="A", y="B", data=df)
```

> **🟡 قاطی کردن Matplotlib و Seaborn:**
```python
# ✅ ترکیب هر دو
sns.set_theme(style="whitegrid")
sns.barplot(x="A", y="B", data=df)
plt.title("عنوان")  # از matplotlib
plt.show()          # از matplotlib
```

> **🟢 استفاده از `hue` بدون `legend=False` برای پالت تکی:**
```python
# ❌ افسانه غیرضروری
sns.barplot(x="A", y="B", data=df, palette="viridis", hue="A")

# ✅ حذف افسانه
sns.barplot(x="A", y="B", data=df, palette="viridis", hue="A", legend=False)
```

> **🟣 فراموش کردن تبدیل داده‌ها به DataFrame:**
```python
# ❌ Seaborn با دیکشنری مستقیم کار نمی‌کنه
sns.barplot(x="A", y="B", data={"A": [1,2], "B": [3,4]})

# ✅ باید دیکشنری رو به DataFrame تبدیل کنی
df = pd.DataFrame({"A": [1,2], "B": [3,4]})
sns.barplot(x="A", y="B", data=df)
```

### 🛠️ نوبت توئه: چالش مقایسه درآمد با پالت‌های رنگی پاستلی!

بیا یک نمودار میله‌ای را که در درس قبلی با Matplotlib ساختی، این بار با جادوی Seaborn و یک پالت رنگی بسیار شیک بازنویسی کنی.

**صورت مسئله:**

1. یک فایل جدید پایتون بساز.
2. پانداس و سیبورن را در آن وارد (Import) کن.
3. دیتای زیر را که مربوط به میزان رضایت کاربران از ۳ نسخه مختلف اپلیکیشن توست، تعریف کن:

```python
feedback_data = {
    "Version": ["v1.0 (Old)", "v1.5 (Beta)", "v2.0 (New)"],
    "Satisfaction_Score": [62, 78, 95]  # نمره رضایت از ۱۰۰
}
df_feedback = pd.DataFrame(feedback_data)
```

4. با استفاده از تابع `sns.barplot` یک نمودار میله‌ای برای این داده‌ها رسم کن.
   *راهنمایی:* آرگومان‌های ورودی به این صورت خواهند بود: `sns.barplot(x="Version", y="Satisfaction_Score", data=df_feedback, palette="magma")`

5. عنوان مناسبی برای آن انتخاب کرده و با `plt.show()` خروجی شگفت‌انگیز و خوش‌رنگ آن را تماشا کن!
