# 📙 فصل دوم: فرمانروایی بر کد (تصمیم‌گیری و تکرار)

## 🎯 درس ۲.۳: ترمزهای حلقه (`break` و `continue`)

---

### 🎮 چرا به کنترل حلقه‌ها نیاز داریم؟

حالا که یاد گرفتی چطور حلقه‌ها رو راه بندازی، وقتشه یاد بگیری چطور مثل یک راننده حرفه‌ای کنترلشون کنی. گاهی اوقات وسط اجرای یک حلقه، اتفاقی میفته که مجبوریم ترمز دستی رو بکشیم یا یک دور رو نادیده بگیریم و بریم دور بعدی.

در پایتون دو دستور فوق‌العاده کاربردی داریم که به ما اجازه میدن رفتار حلقه‌ها رو وسط کار تغییر بدیم:

| دستور | کاری که می‌کنه | تشبیه |
|-------|---------------|--------|
| `break` | کل حلقه رو متوقف می‌کنه و ازش خارج میشه | ترمز اضطراری |
| `continue` | فقط دور فعلی رو نادیده می‌گیره و می‌ره دور بعدی | پرش از روی مانع |

---

### ۱. دستور `break` (ترمز کامل و خروج)

این دستور مثل ترمز اضطراری عمل می‌کنه. به محض اینکه برنامه به کلمه `break` برسه، حلقه رو در جا متوقف می‌کنه و ازش می‌پره بیرون؛ حتی اگر شرط حلقه هنوز درست باشه!

**یک مثال واقعی:** فرض کن در حال بررسی فایل‌های سیستم برای پیدا کردن یک ویروس هستی. به محض اینکه اولین فایل آلوده رو پیدا کردی، دیگه نیازی نیست بقیه هزاران فایل رو اسکن کنی؛ کار رو متوقف می‌کنی.

```python
for number in range(1, 10):
    if number == 5:
        print("عدد ۵ پیدا شد! توقف حلقه.")
        break
    print("بررسی عدد:", number)
```

**خروجی:**

```text
بررسی عدد: 1
بررسی عدد: 2
بررسی عدد: 3
بررسی عدد: 4
عدد ۵ پیدا شد! توقف حلقه.
```

> **💡 نکته:** دقت کن که اعداد ۶ تا ۹ هرگز چاپ نشدن، چون حلقه قبل از رسیدن به اون‌ها متوقف شد.

---

#### کاربرد `break` با `while` برای ورودی نامحدود

```python
while True:  # این یه حلقه بی‌نهایت هست!
    command = input("فرمان خود را وارد کنید (یا 'exit' برای خروج): ")
    if command == "exit":
        print("خروج از برنامه...")
        break
    print(f"فرمان '{command}' دریافت شد.")
```

> **📌 الگوی رایج:** استفاده از `while True` و `break` برای ساختن منوهای تعاملی که تا وقتی کاربر نخواد، اجرا میشن.

### ۲. دستور `continue` (رد شدن از دور فعلی)

این دستور مثل یک جهش عمل می‌کنه. وقتی برنامه به کلمه `continue` می‌رسه، بقیه کدهای این دورِ حلقه رو نادیده می‌گیره و سریع می‌ره سراغ دور بعدی.

**یک مثال واقعی:** فرض کن می‌خوای به تمام کارمندها حقوق بدی، اما می‌خوای از کارمندهای آزمایشی رد بشی.

```python
for i in range(1, 6):
    if i == 3:
        print("از مرحله ۳ رد شدیم.")
        continue
    print("انجام کار برای مرحله:", i)
```

**خروجی:**

```text
انجام کار برای مرحله: 1
انجام کار برای مرحله: 2
از مرحله ۳ رد شدیم.
انجام کار برای مرحله: 4
انجام کار برای مرحله: 5
```

*(دقت کن که عدد ۳ چاپ نشد، اما حلقه متوقف هم نشد و کارش رو ادامه داد.)*

---

#### کاربرد `continue` برای فیلتر کردن داده‌ها

```python
# چاپ فقط اعداد زوج از ۱ تا ۱۰
for i in range(1, 11):
    if i % 2 != 0:  # اگر فرد بود
        continue    # ازش رد شو
    print(f"عدد زوج: {i}")
```

**خروجی:**

```text
عدد زوج: 2
عدد زوج: 4
عدد زوج: 6
عدد زوج: 8
عدد زوج: 10
```

---

### 🆚 مقایسه `break` و `continue`

| ویژگی | `break` | `continue` |
|-------|---------|------------|
| چه کاری می‌کنه | از کل حلقه خارج میشه | فقط دور فعلی رو رد میکنه |
| حلقه ادامه پیدا می‌کنه؟ | ❌ نه، کاملاً متوقف میشه | ✅ بله، با دور بعدی ادامه میده |
| مثال استفاده | پیدا کردن چیزی و توقف | فیلتر کردن و رد کردن بعضی موارد |
| با `while` کار می‌کنه؟ | ✅ بله | ✅ بله |
| با `for` کار می‌کنه؟ | ✅ بله | ✅ بله |

---
### 🔄 یه نگاه سریع به حلقه‌های تو در تو

قبل از اینکه بریم سراغ `break` و `continue`، بیایید یه نگاه سریع به **حلقه‌های تو در تو (Nested Loops)** بندازیم. گاهی لازمه یک حلقه رو داخل حلقه‌ی دیگه قرار بدیم. مثلاً برای کار با جدول‌ها یا ماتریس‌ها:

**یک جدول ۳×۳ از اعداد**

```python
for i in range(1, 4):      # حلقه‌ی بیرونی (سطرها)
    for j in range(1, 4):  # حلقه‌ی داخلی (ستون‌ها)
        print(i * j, end=" ")
    print()  # خط جدید بعد از هر سطر
```

**خروجی:**

```text
1 2 3
2 4 6
3 6 9
```

حالا سوال اینه: وقتی توی حلقه‌های تو در تو از break یا continue استفاده می‌کنیم، چه اتفاقی می‌افته؟ این رو توی بخش نکات حرفه‌ای کامل توضیح می‌دیم

---

### 💡 نکات حرفه‌ای

1. **از `break` برای خروج از حلقه‌های بی‌نهایت استفاده کن:**
   ```python
   while True:
       # کاری که تا بی‌نهایت انجام میشه
       if some_condition:
           break  # اما اینجا می‌تونیم ازش خارج بشیم
   ```

2. **از `continue` برای ساده‌تر کردن کد استفاده کن:**
   ```python
   # ❌ بد (تودرتو)
   for item in items:
       if item.is_valid():
           process(item)
   
   # ✅ خوب (با continue)
   for item in items:
       if not item.is_valid():
           continue
       process(item)
   ```

3. **`break` و `continue` فقط روی نزدیک‌ترین حلقه اثر می‌ذارن:**
   ```python
   for i in range(3):
       for j in range(3):
           if j == 1:
               break  # فقط حلقه‌ی داخلی رو متوقف می‌کنه
           print(i, j)
   # حلقه‌ی بیرونی به کار خودش ادامه میده
   ```

4. **حلقه‌ها می‌تونن `else` داشته باشن!**
   ```python
   for i in range(5):
       if i == 10:  # این شرط هیچوقت درست نمیشه
           break
       print(i)
   else:
       print("حلقه بدون break تموم شد!")  # این اجرا میشه
   ```

### 📌 اشتباهات رایج در این درس

> **🔴 فراموش کردن `break` در حلقه‌های بی‌نهایت:**
```python
while True:
    # ❌ خطا! هیچوقت از این حلقه خارج نمیشه
    user_input = input(": ")
    if user_input == "exit":
        break  # ✅ حتماً این رو داشته باش
```

> **🟡 استفاده از `continue` بعد از کارهای مهم:**
```python
for i in range(10):
    if i == 5:
        continue
        print("این خط هیچوقت اجرا نمیشه")  # ❌ غیرقابل دسترس!
```

> **🟢 قاطی کردن `break` و `continue`:**
```python
# می‌خوام از عدد ۵ رد بشم ولی بقیه رو ادامه بدم
if i == 5:
    break  # ❌ اشتباه! کل حلقه متوقف میشه
    continue  # ✅ درسته: فقط از ۵ رد میشه
```

> **🟣 فکر کردن اینکه `break` روی همه‌ی حلقه‌ها اثر می‌ذاره:**
```python
for i in range(3):
    for j in range(3):
        if j == 1:
            break  # فقط حلقه‌ی داخلی رو متوقف می‌کنه
    # حلقه‌ی بیرونی هنوز ادامه داره
```

### 🛠️ نوبت توئه: چالش ورود به سیستم (رمز عبور)!

فرض کن می‌خواهیم سیستم امنیت ورود به یک نرم‌افزار حسابداری رو طراحی کنیم. کاربر فقط **۳ بار** فرصت داره رمز عبور درست رو وارد کنه.

**صورت مسئله:**

1. یک متغیر برای رمز عبور صحیح تعریف کن و مقدارش رو بذار `"1234"`.
2. یک حلقه بنویس که تا حداکثر ۳ بار تکرار بشه.
3. در هر بار تکرار، رمز عبور رو با `input()` از کاربر بگیره.
4. **اگر** رمز درست بود، پیغام `"خوش آمدید! ورود موفقیت‌آمیز بود."` رو چاپ کنه و با دستور مناسب در جا **از حلقه خارج بشه (ترمز کنه)**.
5. **اگر** رمز اشتباه بود، پیغام `"رمز اشتباه است! دوباره تلاش کنید."` رو چاپ کنه.
6. اگر کاربر ۳ بار اشتباه وارد کرد و حلقه تمام شد، در نهایت پیغام `"حساب کاربری شما به دلیل تلاش‌های ناموفق قفل شد!"` رو چاپ کنه.

**راهنمایی برای بخش آخر:** برای اینکه بفهمی کاربر بعد از ۳ بار نتونسته وارد بشه، می‌تونی بیرون از حلقه یک متغیر مثل `success = False` تعریف کنی و اگر رمز درست بود، اون رو `True` کنی. در نهایت بیرون از حلقه بررسی کنی که اگر `success` هنوز `False` بود، پیام قفل شدن رو چاپ کنی.

### 💪 چالش دوم (اختیاری - برای برنامه‌نویسان امنیت!)

حالا که با `break` و `continue` آشنا شدی، یه سیستم **پردازش سفارشات** هوشمند بساز که بدون استفاده از لیست، سفارشات رو یکی یکی از کاربر بگیره:

1. از کاربر بپرس: «چند تا سفارش داری؟» (عدد صحیح)
2. با استفاده از حلقه `for` به تعداد سفارشات، این کارها رو انجام بده:
   - از کاربر مبلغ هر سفارش رو بگیر (عدد صحیح)
   - اگر مبلغ سفارش کمتر یا مساوی صفر بود، با `continue` ازش رد شو و پیام `"سفارش نامعتبر!"` رو چاپ کن
   - اگر مبلغ سفارش بیشتر از ۳۰۰۰۰۰ بود، پیام `"سفارش بزرگ!"` رو چاپ کن
   - اگر مبلغ سفارش دقیقاً ۷۵۰۰۰ بود، با `break` کل حلقه رو متوقف کن و پیام `"سفارش ویژه پیدا شد! پردازش متوقف شد."` رو چاپ کن
   - در غیر این صورت، پیام `"پردازش سفارش با مبلغ {مبلغ}"` رو چاپ کن

3. بعد از پایان حلقه:
   - اگر حلقه با `break` تموم شده، پیام `"پردازش به دلیل سفارش ویژه متوقف شد."` رو چاپ کن
   - اگر حلقه طبیعی تموم شده (همه سفارشات بررسی شدن)، پیام `"همه سفارشات با موفقیت پردازش شد."` رو چاپ کن

> **💡 نکته:** برای تشخیص اینکه حلقه با `break` تموم شده یا نه، از `else` بعد از حلقه استفاده کن! بله، حلقه‌ها توی پایتون می‌تونن `else` داشته باشن که فقط وقتی اجرا میشه که حلقه بدون `break` تموم بشه.
