### 🧮 عملگرها یعنی چی؟

توی درس قبل یاد گرفتی چطور از کاربر عدد بگیری و ضرب کنی. ولی پایتون کلی عملگر دیگه هم داره که بهت کمک می‌کنه محاسبات پیچیده‌تر انجام بدی و مهم‌تر از اون، **بتونی تصمیم‌های منطقی** توی برنامه‌هات بگیری.

به عملگرها مثل **ابزارهای ریاضی و منطقی** نگاه کن. همون‌طور که تو زندگی روزمره از + و - و × استفاده می‌کنی، توی برنامه‌نویسی هم به این ابزارها نیاز داری.

پایتون عملگرها رو به چند دسته تقسیم می‌کنه. ما توی این درس با سه دسته‌ی اصلی آشنا میشیم:

---

### ۱. عملگرهای ریاضی (Mathematical Operators)

این‌ها همون عملگرهایی هستن که برای محاسبات روزمره بهشون نیاز داری:

| عملگر | نام | مثال | خروجی |
|--------|------|---------|--------|
| `+` | جمع | `5 + 3` | `8` |
| `-` | تفریق | `10 - 4` | `6` |
| `*` | ضرب | `6 * 7` | `42` |
| `/` | تقسیم اعشاری | `15 / 4` | `3.75` |
| `//` | تقسیم صحیح (خارج‌قسمت) | `15 // 4` | `3` |
| `%` | باقیمانده (مدulo) | `15 % 4` | `3` |
| `**` | توان | `2 ** 3` | `8` |

بیا با مثال ببینیم:

```python
# جمع و تفریق ساده
price = 12000
tax = 1500
total = price + tax
discount = 2000
final_price = total - discount
print(final_price)  # خروجی: 11500

# تقسیم اعشاری و صحیح
total_items = 17
boxes = 4
per_box = total_items / boxes  # تقسیم اعشاری
print(per_box)  # خروجی: 4.25

per_box_int = total_items // boxes  # تقسیم صحیح (چند تا جعبه کامل پر میشه؟)
print(per_box_int)  # خروجی: 4

remaining = total_items % boxes  # چند تا مونده؟
print(remaining)  # خروجی: 1

# توان (مربع و مکعب)
side = 5
area = side ** 2  # 5 به توان 2 = 25
volume = side ** 3  # 5 به توان 3 = 125
```

> **💡 کاربرد `%` در دنیای واقعی:** فرض کن ۱۷ تا کالا داری و هر جعبه ۴ تا کالا جا می‌گیره. `17 // 4` بهت می‌گه ۴ جعبه پر میشه و `17 % 4` بهت می‌گه ۱ کالا توی جعبه‌ی آخر می‌مونه.

### ۲. عملگرهای مقایسه‌ای (Comparison Operators)

این عملگرها **دوتا مقدار رو با هم مقایسه می‌کنن** و بهت می‌گن که رابطه‌شون چیه. خروجی این عملگرها همیشه `True` (درست) یا `False` (غلط) هست.

| عملگر | معنی | مثال | خروجی |
|--------|-------|---------|--------|
| `==` | مساوی | `5 == 5` | `True` |
| `!=` | نابرابر | `5 != 3` | `True` |
| `>` | بزرگتر | `8 > 5` | `True` |
| `<` | کوچکتر | `3 < 7` | `True` |
| `>=` | بزرگتر یا مساوی | `5 >= 5` | `True` |
| `<=` | کوچکتر یا مساوی | `4 <= 3` | `False` |

```python
# مقایسه اعداد
age = 18
can_vote = age >= 18
print(can_vote)  # خروجی: True

# مقایسه موجودی انبار
stock = 5
min_stock = 10
need_order = stock < min_stock
print(need_order)  # خروجی: True (چون ۵ از ۱۰ کمتره)

# مقایسه متن (حساس به بزرگ و کوچکی)
user_input = "admin"
is_admin = user_input == "admin"
print(is_admin)  # خروجی: True

is_admin = user_input == "Admin"
print(is_admin)  # خروجی: False (چون A بزرگ با a کوچک فرق داره)
```

> **⚠️ تفاوت `=` با `==` رو یادت باشه:** `=` برای مقداردهی به متغیر استفاده میشه، ولی `==` برای مقایسه‌ی دو مقدار.

---

### ۳. عملگرهای منطقی (Logical Operators)

این عملگرها برای **ترکیب چند شرط** استفاده میشن. به‌ت می‌گن اگر چند تا شرط همزمان درست بودن یا نبودن، چه اتفاقی بیفته:

| عملگر | معنی | مثال | خروجی |
|--------|-------|---------|--------|
| `and` | و (هر دو شرط باید درست باشن) | `(5 > 3) and (2 < 4)` | `True` |
| `or` | یا (حداقل یکی از شرط‌ها درست باشه) | `(5 > 3) or (2 > 4)` | `True` |
| `not` | نقیض (برعکس کردن شرط) | `not (5 > 3)` | `False` |

```python
# مثال ترکیبی: تخفیف ویژه
age = 25
is_student = True
has_membership = False

# تخفیف برای دانشجویان بالای ۱۸ سال
student_discount = (age >= 18) and is_student
print(student_discount)  # خروجی: True

# تخفیف ویژه برای دانشجویان یا اعضای ویژه
special_discount = is_student or has_membership
print(special_discount)  # خروجی: True

# بررسی اینکه کاربر دانشجو نیست
not_student = not is_student
print(not_student)  # خروجی: False
```

### 📊 اولویت عملگرها (قوانین ریاضی)

پایتون مثل ریاضی، به ترتیب اولویت عملگرها رو حساب می‌کنه. اولویت از بالا به پایین:

1. `**` (توان)
2. `*`، `/`، `//`، `%` (ضرب و تقسیم)
3. `+`، `-` (جمع و تفریق)
4. عملگرهای مقایسه‌ای (`>`، `<`، `==` و...)
5. `not`
6. `and`
7. `or`

مثل ریاضی، می‌تونی با `()` اولویت رو تغییر بدی:

```python
# بدون پرانتز - ضرب اولویت داره
result1 = 5 + 3 * 2  # خروجی: 11 (چون 3*2=6 و 5+6=11)

# با پرانتز - جمع اول انجام میشه
result2 = (5 + 3) * 2  # خروجی: 16 (چون 5+3=8 و 8*2=16)
```

### 📌 اشتباهات رایج در این درس

> **🔴 قاطی کردن `=` با `==`:**
```python
if age = 18:  # ❌ خطا! این مقداردهی هست، مقایسه نیست
if age == 18:  # ✅ درسته
```

> **🟡 فراموش کردن تبدیل نوع برای ورودی:**
```python
age = input("سن: ")
if age >= 18:  # ❌ خطا! age متن هست، نمی‌تونی با عدد مقایسه کنی
age = int(input("سن: "))  # ✅ درسته
```

> **🟢 اولویت عملگرها رو در نظر نگرفتن:**
```python
# می‌خوای بررسی کنی که سن بین ۱۸ تا ۳۰ هست
if age >= 18 and age <= 30:  # ✅ درسته
if age >= 18 and <= 30:  # ❌ خطا! اینطوری نمیشه
```

> **🟣 نوشتن `&` یا `|` به جای `and` و `or`:**
```python
if age >= 18 & is_student:  # ❌ این عملگرهای بیتی هستن، نه منطقی
if age >= 18 and is_student:  # ✅ درسته
```

### 🛠️ نوبت توئه: چالش سیستم تخفیف فروشگاه!

فرض کن مسئول فروش یک فروشگاه زنجیره‌ای هستی و می‌خوای سیستم محاسبه‌ی قیمت نهایی با تخفیف رو طراحی کنی.

**صورت مسئله:**

1. از کاربر قیمت اصلی کالا رو بگیر (عدد اعشاری)
2. از کاربر درصد تخفیف رو بگیر (عدد صحیح، مثلاً ۱۵ برای ۱۵ درصد)
3. محاسبه کن:
   - مبلغ تخفیف = (قیمت اصلی × درصد تخفیف) / ۱۰۰
   - قیمت نهایی = قیمت اصلی - مبلغ تخفیف
4. با استفاده از عملگرهای مقایسه، بررسی کن:
   - آیا قیمت نهایی کمتر از ۵۰۰۰۰ تومان هست؟ (خروجی `True` یا `False`)
   - آیا قیمت اصلی بیشتر از ۱۰۰۰۰۰ تومان هست؟ (خروجی `True` یا `False`)
5. همه‌ی نتایج رو با `print` نمایش بده

> **راهنمایی:** برای گرفتن عدد اعشاری از `float()` و برای عدد صحیح از `int()` استفاده کن.

### 💪 چالش دوم (اختیاری - برای مدیران باهوش!)

حالا که با عملگرهای منطقی آشنا شدی، یه سیستم تصمیم‌گیری هوشمند برای اعطای وام بساز:

1. از کاربر سه تا اطلاعات بگیر:
   - سن (عدد صحیح)
   - حقوق ماهیانه (عدد صحیح)
   - سابقه‌ی اعتباری خوب داره؟ (کاربر باید `True` یا `False` وارد کنه)

2. با عملگرهای منطقی، سه شرط رو بررسی کن:
   - شرط ۱: سن بیشتر یا مساوی ۱۸ سال باشه
   - شرط ۲: حقوق ماهیانه بیشتر از ۵ میلیون تومان باشه
   - شرط ۳: سابقه‌ی اعتباری خوب داشته باشه

3. وام تعلق می‌گیره اگر **همه‌ی** شرایط بالا برقرار باشن (`and`)
4. وام ویژه تعلق می‌گیره اگر **حداقل یکی** از دو شرط (حقوق بالا یا سابقه خوب) برقرار باشه (`or`)

5. نتیجه رو با `print` به کاربر نشون بده

> **💡 نکته برای گرفتن `True`/`False` از کاربر:**
```python
good_history = input("سابقه اعتباری خوب دارید؟ (True/False): ")
# اما این یه متن هست! باید تبدیلش کنیم:
good_history = good_history == "True"  # اگر کاربر True رو وارد کنه، میشه True
```
