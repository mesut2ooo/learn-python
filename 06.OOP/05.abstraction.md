## 🎯 درس ۶.۵: چندریختی (Polymorphism)

---

### 🎭 چندریختی یعنی چی؟

چندریختی (Polymorphism) یعنی **«یک نام، چند شکل»**. توی برنامه‌نویسی، یعنی متدهای مختلف در کلاس‌های مختلف، با اسم یکسان، کارهای مختلفی انجام می‌دن.

> **📌 مثال دنیای واقعی:**
> به سه حیوان مختلف نگاه کن: سگ، گربه، گاو. همه‌ی اون‌ها یک کار به اسم «صدا درآوردن» رو انجام می‌دن، ولی هر کدوم صدای متفاوتی تولید می‌کنه. این یعنی «صدا درآوردن» یک اسم مشترک، ولی چندین شکل مختلف (چندریختی).

---

### 💻 چندریختی با متدهای همنام

```python
class Dog:
    def sound(self):
        return "هاپ هاپ! 🐕"
    
    def move(self):
        return "چهار پا می‌دود 🏃"

class Cat:
    def sound(self):
        return "میو میو! 🐈"
    
    def move(self):
        return "بی‌صدا راه می‌رود 🐾"

class Cow:
    def sound(self):
        return "ماآآآ! 🐄"
    
    def move(self):
        return "به آرامی راه می‌رود 🚶"

# همه با یک اسم، رفتارهای متفاوت
animals = [Dog(), Cat(), Cow()]

for animal in animals:
    print(animal.sound())  # هر کدوم صدای خودش رو تولید می‌کنه
```

**خروجی:**
```text
هاپ هاپ! 🐕
میو میو! 🐈
ماآآآ! 🐄
```

### 🎯 چندریختی با ارث‌بری

وقتی کلاس‌های فرزند متدهای پدر رو بازنویسی می‌کنن:

```python
class Shape:
    def area(self):
        return 0
    
    def name(self):
        return "شکل هندسی"

class Rectangle(Shape):
    def __init__(self, width, height):
        self.width = width
        self.height = height
    
    def area(self):  # بازنویسی
        return self.width * self.height
    
    def name(self):
        return "مستطیل"

class Circle(Shape):
    def __init__(self, radius):
        self.radius = radius
    
    def area(self):  # بازنویسی
        return 3.14 * self.radius ** 2
    
    def name(self):
        return "دایره"

# تابعی که با هر شکلی کار می‌کنه
def print_area(shape):
    print(f"مساحت {shape.name()}: {shape.area()}")

# استفاده
shapes = [Rectangle(5, 4), Circle(3)]

for shape in shapes:
    print_area(shape)

# خروجی:
# مساحت مستطیل: 20
# مساحت دایره: 28.26
```

### 🛠️ توابع با چندریختی

چندریختی یعنی می‌تونی یک تابع بنویسی که با **هر شیءای** که متد خاصی رو داشته باشه کار کنه:

```python
def make_sound_twice(animal):
    """این تابع با هر شیءای کار می‌کنه که متد sound() داشته باشه"""
    print(animal.sound())
    print(animal.sound())

# با هر حیوانی کار می‌کنه
make_sound_twice(Dog())  # هاپ هاپ! (دو بار)
make_sound_twice(Cat())  # میو میو! (دو بار)
```

### 🆚 چندریختی در مقابل سوئیچ/کیس (اگر)

بدون چندریختی (روش قدیمی):
```python
def animal_sound(animal_type):
    if animal_type == "dog":
        print("هاپ هاپ!")
    elif animal_type == "cat":
        print("میو میو!")
    elif animal_type == "cow":
        print("ماآآآ!")
    # هر حیوان جدید = اضافه کردن شرط جدید
```

با چندریختی (روش حرفه‌ای):
```python
class Animal:
    def sound(self):
        pass

class Dog(Animal):
    def sound(self):
        print("هاپ هاپ!")

class Cat(Animal):
    def sound(self):
        print("میو میو!")

class Cow(Animal):
    def sound(self):
        print("ماآآآ!")

# حیوان جدید = کلاس جدید، بدون تغییر تابع
def make_sound(animal):
    animal.sound()
```

### 🎯 مزایای چندریختی

| مزیت | توضیح |
|-------|-------|
| **کد تمیزتر** | نیاز به `if/elif` زیاد نداریم |
| **توسعه‌پذیر** | کلاس جدید اضافه می‌کنیم، کد قدیمی رو تغییر نمی‌دیم |
| **خوانایی** | کد ساده‌تر و قابل فهم‌تر |
| **قابلیت استفاده مجدد** | یک تابع برای انواع مختلف اشیاء |

### 📌 اشتباهات رایج در این درس

> **🔴 تعریف متد با اسم یکسان ولی پارامترهای متفاوت:**
```python
class Animal:
    def sound(self):
        pass

class Dog(Animal):
    def sound(self, volume):  # ❌ پارامتر اضافه!
        print("هاپ هاپ!")
```

> **🟡 فراموش کردن `self` در متدهای چندریختی:**
```python
class Cat:
    def sound():  # ❌ self فراموش شده
        print("میو میو!")
```

> **🟢 استفاده از `if` به جای چندریختی:**
```python
# ❌ روش بد
def process(animal):
    if isinstance(animal, Dog):
        print("هاپ")
    elif isinstance(animal, Cat):
        print("میو")

# ✅ روش خوب
def process(animal):
    print(animal.sound())
```

4. با یک حلقه `for`، همه‌ی اشیاء رو توی یک لیست بذار و متد `sound()` رو برای همه صدا بزن.

### 💪 چالش دوم (اختیاری - برای معماران سیستم‌های پلاگین!)

حالا که با چندریختی آشنا شدی، یه سیستم **پردازش فایل‌ها** بساز که با هر نوع فایلی کار کنه:

1. کلاس پدر `FileProcessor` با متد `process()` بساز.

2. کلاس‌های فرزند برای انواع فایل‌ها:
   - `TextFileProcessor`: محتویات متن رو چاپ کنه
   - `ImageFileProcessor`: پیام `"پردازش تصویر..."` رو چاپ کنه
   - `MusicFileProcessor`: پیام `"پخش موسیقی..."` رو چاپ کنه
   - `VideoFileProcessor`: پیام `"پخش ویدیو..."` رو چاپ کنه

3. یک تابع به اسم `process_file(file)` بنویس که متد `process()` رو صدا بزنه.

4. یک لیست از انواع فایل‌ها بساز و همه رو پردازش کن.

5. با `super()` متد `__init__` پدر رو فراخوانی کن و یک ویژگی `name` رو مقداردهی کن.
