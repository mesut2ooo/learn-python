## 🎯 درس ۲.۲: حلقه‌ها (`while` و `for`)

---

### 🔄 حلقه‌ها یعنی چی و چرا بهشون نیاز داریم؟

بدون حلقه‌ها، کامپیوترها فرقی با ماشین‌حساب‌های ساده نداشتند. حلقه‌ها به ما اجازه می‌دن یک کار تکراری رو هزاران یا میلیون‌ها بار بدون خسته شدن و با سرعت نور انجام بدیم.

> **💡 مثال دنیای واقعی:** فرض کن می‌خوای ۱۰۰۰ تا ایمیل بفرستی. بدون حلقه باید ۱۰۰۰ بار کد رو کپی کنی! با حلقه، فقط یک بار می‌نویسی و بهش می‌گی "این کار رو ۱۰۰۰ بار انجام بده".

در پایتون دو نوع حلقه اصلی داریم:

| نوع حلقه | کی استفاده میشه؟ |
|----------|-----------------|
| `while` | وقتی تعداد دفعات تکرار رو **نمی‌دونیم** و شرط مشخص می‌کنه کی متوقف بشه |
| `for` | وقتی تعداد دفعات تکرار رو **از قبل می‌دونیم** یا می‌خوایم روی اعضای یک مجموعه حرکت کنیم |

---

### ۱. حلقه `while` (تا زمانی که...)

حلقه `while` مثل یک شرط عمل می‌کنه، اما با یک تفاوت بزرگ: دستور `if` شرط رو بررسی می‌کنه، کدهای داخلش رو **یک‌بار** اجرا می‌کنه و رد میشه. اما حلقه `while` شرط رو بررسی می‌کنه و **تا زمانی که آن شرط درست (True) باشه**، کدهای داخلش رو بارها و بارها تکرار می‌کنه.

```python
# تعریف یک شمارنده
count = 1

# تا زمانی که شمارنده کمتر یا مساوی 5 است، تکرار کن
while count <= 5:
    print("تکرار شماره:", count)
    count = count + 1  # در هر مرحله یکی به شمارنده اضافه می‌کنیم
```

**خروجی:**

```text
تکرار شماره: 1
تکرار شماره: 2
تکرار شماره: 3
تکرار شماره: 4
تکرار شماره: 5
```

> **⚠️ خطر تله‌ی بی‌نهایت!**
> اگر خط آخر (یعنی `count = count + 1`) رو فراموش کنی بنویسی، مقدار `count` همیشه `1` باقی می‌مونه. شرط حلقه هم همیشه درست (`True`) می‌مونه و برنامه تا ابد اجرا میشه. به این حالت می‌گیم **حلقه بی‌نهایت (Infinite Loop)**.

---

#### کاربرد واقعی حلقه `while`: منتظر موندن برای ورودی کاربر

یکی از کاربردهای جالب `while` اینه که برنامه رو متوقف می‌کنه تا کاربر یه ورودی معتبر وارد کنه:

```python
password = ""

# تا وقتی که کاربر کلمه‌ی عبور درست رو وارد نکرده، دوباره بپرس
while password != "1234":
    password = input("رمز عبور را وارد کنید: ")
    if password == "1234":
        print("ورود موفق!")
    else:
        print("رمز اشتباه است، دوباره تلاش کنید.")
```

### ۲. حلقه `for` (روی اعضای یک مجموعه...)

حلقه `for` زمانی استفاده میشه که تعداد دفعات تکرار رو از قبل می‌دونیم، یا می‌خوایم روی تک‌تک اعضای یک مجموعه (مثل یک بازه عددی یا حروف یک کلمه) حرکت کنیم.

#### استفاده با `range()`

برای تولید یک بازه عددی در پایتون از ابزاری به نام `range()` استفاده می‌کنیم.

```python
# تکرار از عدد 0 تا قبل از 5 (یعنی 0، 1، 2، 3، 4)
for i in range(5):
    print("عدد فعلی:", i)
```

**خروجی:**

```text
عدد فعلی: 0
عدد فعلی: 1
عدد فعلی: 2
عدد فعلی: 3
عدد فعلی: 4
```

#### سه شکل مختلف `range()`

```python
# شکل ۱: فقط پایان
range(5)        # 0, 1, 2, 3, 4

# شکل ۲: شروع و پایان
range(1, 6)     # 1, 2, 3, 4, 5

# شکل ۳: شروع، پایان و گام
range(0, 10, 2) # 0, 2, 4, 6, 8
range(10, 0, -1) # 10, 9, 8, ..., 1 (شمارش معکوس)
```

#### استفاده روی متن

حلقه `for` می‌تونه روی تک‌تک کاراکترهای یک متن حرکت کنه:

```python
word = "پایتون"
for letter in word:
    print(letter)
```

**خروجی:**

```text
پ
ا
ی
ت
و
ن
```

### 🆚 مقایسه `while` و `for` (کی از کدوم استفاده کنیم؟)

| معیار | `while` | `for` |
|-------|---------|-------|
| تعداد تکرار نامشخص | ✅ مناسب | ❌ مناسب نیست |
| تعداد تکرار مشخص | ✅ می‌تونه استفاده کنه | ✅ بهترین انتخاب |
| ریسک حلقه بی‌نهایت | 🔴 بالاست (اگه شرط رو فراموش کنی) | 🟢 خیلی کم |
| خوانایی کد | 🟡 متوسط | 🟢 خیلی بالا |
| حرکت روی اعضای یک مجموعه | 🟡 ممکنه ولی پیچیده‌ست | ✅ خیلی ساده‌ست |

> **💡 قانون طلایی:** تا حد امکان از `for` استفاده کن مگر اینکه واقعاً به `while` نیاز داشته باشی. `for` امن‌تر و خوانا‌تره.

### 📌 اشتباهات رایج در این درس

> **🔴 فراموش کردن بروزرسانی شمارنده در `while`:**
```python
count = 1
while count <= 5:
    print(count)
    # ❌ خطا! count هیچوقت عوض نمیشه → حلقه بی‌نهایت
count = count + 1  # ✅ این خط رو حتماً بنویس
```

> **🟡 اشتباه در محدوده‌ی `range()`:**
```python
# می‌خوام ۱ تا ۵ رو چاپ کنم
for i in range(1, 5):  # ❌ این فقط ۱ تا ۴ رو چاپ می‌کنه
for i in range(1, 6):  # ✅ درسته: ۱ تا ۵
```

> **🟢 فراموش کردن تبدیل نوع برای ورودی در حلقه:**
```python
n = input("چند بار تکرار کنم؟ ")
for i in range(n):  # ❌ خطا! n متن هست
n = int(input("چند بار تکرار کنم؟ "))  # ✅ درسته
```

> **🟣 استفاده از `=` به جای `==` در شرط حلقه:**
```python
while count = 5:  # ❌ خطا! این مقداردهی هست
while count == 5:  # ✅ درسته
```

### 🛠️ نوبت توئه: چالش سیستم شمارش معکوس پرتاب فضاپیما!

فرض کن در اتاق کنترل پروژه پرتاب یک فضاپیما هستی و می‌خوای یک شمارش معکوس اتوماتیک طراحی کنی.

**صورت مسئله:**
برنامه‌ای بنویس که:

1. با استفاده از یک حلقه (ترجیحاً `for` یا `while` به انتخاب خودت)، اعداد را از **۱۰ تا ۱** به صورت معکوس در خروجی چاپ کند.
2. پس از پایان حلقه و رسیدن به صفر، جمله زیر را چاپ کند:
`"پرتاب موفقیت‌آمیز انجام شد! 🚀"`

**راهنمایی برای شمارش معکوس با `range`:**
توی دستور `range()` می‌تونی پارامتر سومی هم بدی که گام حرکت رو مشخص کنه. مثلاً `range(10, 0, -1)` یعنی از ۱۰ شروع کن، تا قبل از ۰ برو و در هر مرحله ۱ واحد کم کن (`-1`).

### 💪 چالش دوم (اختیاری - برای مدیران پروژه!)

حالا که با حلقه‌ها آشنا شدی، یه سیستم **مدیریت موجودی انبار** بساز:

1. از کاربر بپرس: «چند تا کالا می‌خواهی وارد کنی؟» (عدد صحیح)
2. با استفاده از حلقه `for`، به تعداد کالاهایی که کاربر گفته، این اطلاعات رو بگیر:
   - نام کالا (متن)
   - تعداد موجودی (عدد صحیح)
   - قیمت واحد (عدد اعشاری)

3. بعد از گرفتن همه‌ی اطلاعات، گزارش زیر رو چاپ کن:
   - تعداد کل کالاها
   - مجموع ارزش موجودی (جمع `تعداد × قیمت` برای همه‌ی کالاها)
   - گران‌ترین قیمت واحد (با استفاده از `max()` یا شرط‌ها)

4. از کاربر بپرس: «آیا می‌خواهید دوباره اطلاعات وارد کنید؟ (yes/no)»
   - اگه کاربر `yes` گفت، کل برنامه دوباره اجرا بشه (با `while`)
   - اگه `no` گفت، برنامه تموم بشه

> **💡 نکته:** برای جمع کردن مقادیر، قبل از حلقه یه متغیر مثل `total_value = 0` بساز و هر بار که اطلاعات کالا رو گرفتی، بهش اضافه کن.
