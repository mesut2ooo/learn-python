# 🖥️ فصل هشتم: طراحی رابط کاربری (GUI) با Tkinter

## 🎯 درس ۸.۹: خروجی گرفتن و ساخت فایل اجرایی (`.exe`)

---

### 📦 چرا به فایل اجرایی نیاز داریم؟

تا اینجای کار، تو برای اجرای برنامه‌هات همیشه دکمه‌ی Run رو توی VS Code می‌زدی یا کدهات رو توی ترمینال با پایتون اجرا می‌کردی. اما کاربران عادی کامپیوتر پایتون نصب ندارند و نمی‌دونند چطور کد اجرا کنند. آن‌ها فقط دوست دارند روی یک فایل **`.exe` (دابل کلیک)** کنند تا برنامه باز بشه.

توی این درس نهایی از فصل دسکتاپ، یاد می‌گیریم چطور تمام کدهامون رو به همراه کتابخانه‌های نصب‌شده (مثل CustomTkinter) و حتی عکس‌ها پکیج کنیم و یک فایل `.exe` تک و مستقل بسازیم!

> **📌 PyInstaller چیست؟**
> برای تبدیل کدهای پایتون به فایل اجرایی ویندوز، از یک ابزار فوق‌العاده قوی و استاندارد به اسم **PyInstaller** استفاده می‌کنیم. این ابزار کدهای تو، مفسر پایتون و تمام کتابخانه‌های مورد نیازت رو درون یک فایل تکی بسته‌بندی می‌کنه.

---

### 💻 قدم به قدم تا ساخت فایل `.exe`

برای پکیج کردن پروژه‌ات، مراحل زیر رو به ترتیب جلو بریم:

---

#### مرحله ۱: نصب PyInstaller

داخل ترمینال VS Code دستور زیر رو بنویس:

```bash
pip install pyinstaller
```

> **💡 نکته:** اگه از محیط مجازی استفاده می‌کنی، مطمئن شو که PyInstaller توی همون محیط مجازی نصب شده.

---

#### مرحله ۲: رفتن به پوشه پروژه

با دستور `cd` مطمئن شو که مسیر ترمینال دقیقاً روی پوشه‌ای هست که فایل پایتونِ برنامه‌ات (مثلاً `anonyma_gui.py`) توش قرار داره:

```bash
cd مسیر_پوشه_پروژه
```

---

#### مرحله ۳: اجرای دستور جادویی خروجی

حالا دستور زیر رو در ترمینال بنویس و اینتر بزن:

```bash
pyinstaller --noconsole --onefile anonyma_gui.py
```

---

### 🔍 پارامترهای این دستور یعنی چی؟

| پارامتر | توضیح |
|---------|-------|
| **`--onefile`** | به PyInstaller می‌گه تمام کتابخانه‌ها و فایل‌ها رو فشرده کن و فقط و فقط **یک فایل تک `.exe**` به من تحویل بده |
| **`--noconsole`** | وقتی کاربر روی برنامه کلیک می‌کنه، صفحه سیاه ترمینال (کنسول پایتون) پشت نرم‌افزار باز نشه |
| **`--icon="icon.ico"`** | (اختیاری) آیکون دلخواه برای فایل `.exe` تنظیم کنه |
| **`--name="نام"`** | (اختیاری) اسم فایل خروجی رو مشخص کنه |

---

### 📁 فایل خروجی کجاست؟

وقتی فرآیند پکیج کردن تموم شد (که ممکنه ۱ تا ۲ دقیقه طول بکشه)، چند پوشه جدید در کنار کدت ساخته میشه:

```
پروژه شما/
├── anonyma_gui.py         (کد اصلی)
├── build/                 (فایل‌های موقتی - قابل حذف)
├── dist/                  ✨ گنج اینجاست!
│   └── anonyma_gui.exe    (فایل اجرایی نهایی)
└── anonyma_gui.spec       (فایل تنظیمات PyInstaller)
```

> **⚠️ نکته مهم:** پوشه `build` رو می‌تونی بعداً پاک کنی. فقط پوشه `dist` و فایل `.exe` داخلش رو نگه دار.

---

### 🎨 اضافه کردن آیکون به فایل `.exe`

اگه می‌خوای فایل اجرایی‌ات آیکون دلخواه داشته باشه:

1. یک عکس با فرمت `.ico` (مثلاً `icon.ico`) در پوشه پروژه بذار.
2. دستور رو با `--icon` اجرا کن:

```bash
pyinstaller --noconsole --onefile --icon=icon.ico anonyma_gui.py
```

> **💡 تبدیل عکس به `.ico`:** می‌تونی از سایت‌های آنلاین مثل `icoconverter.com` برای تبدیل استفاده کنی.

---

### 📦 فایل‌های جانبی (عکس، صدا، فونت)

اگر در برنامه‌ات از فایل‌های خارجی استفاده می‌کنی (عکس، صدا، فونت)، باید آن‌ها رو به پوشه `dist` منتقل کنی:

```bash
# کپی کردن فایل‌های جانبی به پوشه dist
copy assets\* dist\assets\
```

> **⚠️ راهکار حرفه‌ای:** برای اینکه نیازی به کپی دستی نباشه، می‌تونی فایل‌های جانبی رو توی فایل `.spec` تنظیم کنی (مبحث پیشرفته).

---

### 🧪 تست فایل اجرایی

1. وارد پوشه `dist` بشو.
2. روی فایل `.exe` دابل کلیک کن.
3. برنامه باید مثل قبل باز بشه، بدون اینکه ترمینال پشتش باز بشه!

---

### ⚠️ مشکلات رایج و راه‌حل‌ها

| مشکل | راه‌حل |
|------|--------|
| **فایل اجرایی باز نمیشه** | مطمئن شو که `--noconsole` رو استفاده کردی و خطایی وجود نداره. توی ترمینال اجراش کن تا خطا رو ببینی. |
| **خطای `ModuleNotFoundError`** | کتابخانه مورد نیاز رو با `pip install` نصب کن و دوباره خروجی بگیر. |
| **فایل `.exe` خیلی بزرگه** | این طبیعیه! PyInstaller کل پایتون و کتابخانه‌ها رو بسته‌بندی می‌کنه. |
| **آنتی‌ویروس فایل رو حذف می‌کنه** | خیلی از آنتی‌ویروس‌ها فایل‌های `.exe` جدید رو مشکوک می‌دونن. بهش بگو استثنا قایل بشه. |

---

### 💻 دستورات کامل PyInstaller

#### خروجی ساده با کنسول

```bash
pyinstaller --onefile program.py
```

#### خروجی بدون کنسول (برای GUI)

```bash
pyinstaller --noconsole --onefile program.py
```

#### با آیکون دلخواه

```bash
pyinstaller --noconsole --onefile --icon=icon.ico program.py
```

#### با اسم دلخواه

```bash
pyinstaller --noconsole --onefile --name="MyApp" program.py
```

#### با فایل‌های جانبی

```bash
pyinstaller --noconsole --onefile --add-data "assets;assets" program.py
```

### 📌 اشتباهات رایج در این درس

> **🔴 فراموش کردن `--noconsole`:**
```bash
pyinstaller --onefile program.py  # ❌ کنسول پشت برنامه باز میشه
pyinstaller --noconsole --onefile program.py  # ✅ درسته
```

> **🟡 استفاده از `pyinstaller` بدون فعال‌سازی محیط مجازی:**
```bash
# ❌ کتابخانه‌ها توی محیط مجازی نصب شدن ولی pyinstaller از خارج صدا زده میشه

# ✅ اول محیط مجازی رو فعال کن
myenv\Scripts\activate  # ویندوز
pyinstaller --noconsole --onefile program.py
```

> **🟢 فراموش کردن کپی فایل‌های جانبی:**
```bash
# ❌ اگر برنامه از عکس استفاده می‌کنه و کپی نشده، خطا میده

# ✅ فایل‌های جانبی رو کپی کن
xcopy assets dist\assets /E
```

> **🟣 اجرای فایل `.exe` از پوشه‌ای با مسیر فارسی:**
```bash
# ❌ برخی از کتابخانه‌ها با مسیر فارسی مشکل دارن
C:\Users\احمد\Desktop\program.exe  # ممکنه کار نکنه

# ✅ از مسیر انگلیسی استفاده کن
C:\Users\Ahmad\Desktop\program.exe
```

### 🛠️ نوبت توئه: جشن تولید اولین نرم‌افزار رسمی شما!

بیا این مسیر رو برای پروژه Anonyma یا ماشین‌حسابت طی کنی:

**صورت مسئله:**

1. ابزار `pyinstaller` رو نصب کن.
2. از آخرین کدهای پیام‌رسانت (که با CustomTkinter نوشتی) یک خروجی تک‌فایله و بدون کنسول بساز.
3. فایل اجرایی ساخته شده در پوشه `dist` رو روی سیستمت تست کن.
4. (اختیاری) یه آیکون جذاب برای فایل `.exe` پیدا کن و بهش اضافه کن.
5. (اختیاری) فایل `.exe` رو برای یکی از دوستات بفرست تا بدون نصب پایتون اجراش کنن!

### 💪 چالش دوم (اختیاری - برای توزیع‌کنندگان نرم‌افزار!)

حالا که با ساخت `.exe` آشنا شدی، یه **پکیج کامل نرم‌افزاری** بساز:

1. برنامه‌ای که توی این فصل ساختی (ماشین‌حساب، Anonyma یا مدیریت تسک) رو انتخاب کن.

2. این کارها رو انجام بده:
   - یک آیکون `.ico` برای برنامه پیدا کن یا بساز.
   - خروجی `.exe` با آیکون و بدون کنسول بگیر.
   - یه پوشه `release` بساز و فایل `.exe` رو توش بذار.
   - یه فایل `README.txt` بنویس با توضیحات برنامه و راهنمای نصب.
   - یه فایل `requirements.txt` برای کتابخانه‌های مورد نیاز.

3. پوشه `release` رو زیپ کن و آماده‌ی توزیع کن.
