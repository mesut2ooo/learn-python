## 🎯 درس ۴.۴: توابع بازگشتی (Recursive Functions)

---

### 🔄 تابع بازگشتی یعنی چی؟

یک تعریف بسیار ساده برای تابع بازگشتی این است: **«تابعی که در داخل بدنه خود، خودش را صدا می‌زند!»**

این مفهوم در ابتدا ممکن است کمی عجیب یا شبیه به یک حلقه‌ی بی‌نهایت به نظر برسد. برای اینکه تابع بازگشتی تا ابد اجرا نشود و کامپیوتر را قفل نکند (که به آن خطای سرریز شدن حافظه یا `Stack Overflow` می‌گویند)، هر تابع بازگشتی **باید** دو بخش اساسی داشته باشد:

1. **شرط پایه (Base Case):** نقطه‌ی توقف تابع. شرطی که وقتی برقرار شد، تابع دیگر خودش را صدا نمی‌زند و زنجیره را متوقف می‌کند.
2. **گام بازگشت (Recursive Case):** بخشی که تابع دوباره خودش را صدا می‌زند، اما با یک ورودیِ کوچک‌تر یا تغییر یافته تا هر بار به شرط پایه نزدیک‌تر شود.

> **📌 تشبیه ساده:** تابع بازگشتی مثل یه آینه‌ست که توی یه آینه‌ی دیگه نگاه می‌کنه. ولی بالاخره یه جایی باید این زنجیره تموم بشه وگرنه تا بی‌نهایت ادامه پیدا می‌کنه!

---

### 💻 یک مثال کلاسیک: محاسبه فاکتوریل ($n!$)

در ریاضی، فاکتوریل یک عدد یعنی ضرب آن عدد در تمام اعداد طبیعی کوچک‌تر از خودش. مثلاً:


$$5! = 5 \times 4 \times 3 \times 2 \times 1 = 120$$

اگر دقت کنی، می‌توانیم $5!$ را به این صورت هم بنویسیم:


$$5! = 5 \times 4!$$

این یعنی فرمول کلی فاکتوریل به این صورت است: $n! = n \times (n-1)!$. این دقیقاً تعریف یک تابع بازگشتی است!

بیا کدهای پایتونی آن را ببینیم:

```python
def factorial(n):
    # ۱. شرط پایه (نقطه توقف): فاکتوریل عدد ۱ برابر با ۱ است
    if n == 1:
        return 1
    
    # ۲. گام بازگشت: صدا زدن خود تابع با یک واحد کمتر
    else:
        return n * factorial(n - 1)

# تست تابع
result = factorial(5)
print("فاکتوریل ۵ برابر است با:", result)  # خروجی: 120
print("فاکتوریل ۳ برابر است با:", factorial(3))  # خروجی: 6
print("فاکتوریل ۱ برابر است با:", factorial(1))  # خروجی: 1
```

---

### 🔍 در پشت صحنه چه اتفاقی می‌افتد؟

وقتی تو `factorial(3)` را صدا می‌زنی، پایتون محاسبات را مانند یک زنجیره در حافظه انباشته می‌کند تا به شرط پایه برسد و سپس مسیر را برمی‌گردد:

```
factorial(3) -> منتظر جواب factorial(2) می‌ماند
  factorial(2) -> منتظر جواب factorial(1) می‌ماند
    factorial(1) -> به شرط پایه می‌رسد و عدد 1 را برمی‌گرداند!
  factorial(2) -> حالا 2 را ضرب در 1 می‌کند و عدد 2 را پس می‌دهد.
factorial(3) -> حالا 3 را ضرب در 2 می‌کند و پاسخ نهایی 6 را برمی‌گرداند.
```

### 📊 مقایسه بازگشت با حلقه (Recursion vs Loop)

| معیار | حلقه (Loop) | بازگشت (Recursion) |
|-------|-------------|-------------------|
| تعریف | کار تکراری با `for`/`while` | تابع خودش رو صدا می‌زنه |
| سرعت | سریع‌تر | کندتر (به دلیل فراخوانی‌های مکرر) |
| خوانایی | برای مسائل ساده بهتر | برای مسائل پیچیده زیباتر |
| خطر | حلقه بی‌نهایت | سرریز حافظه (Stack Overflow) |
| پیچیدگی | ساده‌تر | پیچیده‌تر |
| کاربرد | اکثر موارد | مسائل درختی، جستجو، الگوریتم‌ها |

### 🎯 مثال‌های کاربردی از توابع بازگشتی

#### ۱. محاسبه توان (Power)

```python
def power(base, exponent):
    # شرط پایه: هر عدد به توان ۰ برابر ۱ است
    if exponent == 0:
        return 1
    # گام بازگشت: base^exponent = base * base^(exponent-1)
    else:
        return base * power(base, exponent - 1)

print(power(2, 3))   # خروجی: 8 (2*2*2)
print(power(5, 2))   # خروجی: 25 (5*5)
print(power(3, 0))   # خروجی: 1
```

#### ۲. جمع اعداد از ۱ تا n

```python
def sum_numbers(n):
    # شرط پایه: جمع از ۱ تا ۱ برابر ۱ است
    if n == 1:
        return 1
    # گام بازگشت: n + sum_numbers(n-1)
    else:
        return n + sum_numbers(n - 1)

print(sum_numbers(5))  # خروجی: 15 (1+2+3+4+5)
print(sum_numbers(10)) # خروجی: 55 (1+2+...+10)
```

#### ۳. دنباله فیبوناچی (Fibonacci)

```python
def fibonacci(n):
    # شرط پایه: دو عدد اول دنباله
    if n == 0:
        return 0
    elif n == 1:
        return 1
    # گام بازگشت: هر عدد = دو عدد قبلی
    else:
        return fibonacci(n - 1) + fibonacci(n - 2)

# 0, 1, 1, 2, 3, 5, 8, 13, 21, ...
print(fibonacci(0))  # خروجی: 0
print(fibonacci(1))  # خروجی: 1
print(fibonacci(5))  # خروجی: 5
print(fibonacci(8))  # خروجی: 21
```

### ⚠️ هشدار مهم: خطر سرریز حافظه (Stack Overflow)

هر بار که یک تابع صدا زده میشه، پایتون یک قاب (Frame) در حافظه‌ی پشته (Stack) ایجاد می‌کنه. اگر تعداد صدا زدن‌ها خیلی زیاد بشه، حافظه پر میشه و برنامه با خطای `RecursionError` متوقف میشه.

```python
# این کد رو اجرا نکن! باعث خطا میشه
def infinite_recursion():
    return infinite_recursion()  # تا بی‌نهایت ادامه میده!

# infinite_recursion()  # ❌ RecursionError!
```

برای جلوگیری از این مشکل:
1. حتماً **شرط پایه** رو درست تعریف کن
2. مطمئن شو که هر بار به شرط پایه نزدیک‌تر میشی
3. از بازگشت برای مسائل با عمق محدود استفاده کن

---

### 📌 اشتباهات رایج در این درس

> **🔴 فراموش کردن شرط پایه:**
```python
def countdown(n):
    print(n)
    return countdown(n - 1)  # ❌ هیچ شرط پایه‌ای نداره → تا بی‌نهایت!
```

> **🟡 شرط پایه به شرط بازگشت نزدیک نمیشه:**
```python
def countdown(n):
    if n == 0:
        return
    print(n)
    return countdown(n)  # ❌ همیشه n می‌مونه → تا بی‌نهایت!
```

> **🟢 فراموش کردن `return` در شرط پایه:**
```python
def factorial(n):
    if n == 1:
        1  # ❌ ارور! باید return 1 باشه
    return n * factorial(n - 1)
```

> **🟣 استفاده از بازگشت برای تعداد زیاد (باعث خطای RecursionError):**
```python
countdown(10000)  # ❌ ممکنه RecursionError بده! (حدود ۱۰۰۰ تا حد مجازه)
```

### 🛠️ نوبت توئه: چالش شمارش معکوس بازگشتی!

بیا برای درک کامل این مفهوم، یک تابع بازگشتی ساده اما جذاب بنویسی که بدون استفاده از حلقه‌های `for` یا `while` برای ما شمارش معکوس انجام دهد!

**صورت مسئله:**

1. یک فایل پایتون جدید بساز.
2. تابعی به نام `countdown(n)` بنویس.
3. داخل تابع منطق زیر را پیاده‌سازی کن:
   - ابتدا عدد `n` را چاپ کند.
   - **شرط پایه:** اگر `n` مساوی با `0` یا کمتر شد، متن `"پرتاب! 🚀"` را چاپ کند و کارش تمام شود (`return` خالی بدون برگرداندن مقدار).
   - **گام بازگشت:** در غیر این صورت، تابع خودش را با یک واحد کمتر صدا بزند: `countdown(n - 1)`.

اگر تابع را با ورودی ۵ صدا بزنی (یعنی `countdown(5)`)، خروجی باید به این صورت در ترمینال چاپ شود:

```text
5
4
3
2
1
پرتاب! 🚀
```

### 💪 چالش دوم (اختیاری - برای مبتکران واقعی!)

حالا که با توابع بازگشتی آشنا شدی، یه تابع بازگشتی برای **محاسبه‌ی مجموع ارقام یک عدد** بنویس!

**صورت مسئله:**

1. تابعی به نام `sum_digits(n)` بنویس که یک عدد صحیح مثبت بگیره و مجموع ارقامش رو برگردونه.

2. قواعد:
   - **شرط پایه:** اگر عدد فقط یک رقم داشت، همون رقم رو برگردون
   - **گام بازگشت:** آخرین رقم رو با مجموع ارقام بقیه‌ی عدد جمع کن

3. مثلاً:
   - `sum_digits(123)` باید برگردونه: `6` (چون ۱+۲+۳=۶)
   - `sum_digits(4567)` باید برگردونه: `22` (چون ۴+۵+۶+۷=۲۲)
   - `sum_digits(9)` باید برگردونه: `9`

**راهنمایی:**
- برای گرفتن آخرین رقم از `% 10` استفاده کن (`123 % 10 = 3`)
- برای حذف آخرین رقم از `// 10` استفاده کن (`123 // 10 = 12`)
