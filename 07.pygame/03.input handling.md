## 🎯 درس ۷.۳: کنترل بازی با کیبورد (Input Handling)

---

### 🎮 چطور ورودی کیبورد رو در بازی بگیریم؟

در بازی‌سازی، برای گرفتن کلیدهای فشرده شده دو راه اصلی داریم:

#### روش اول: `pygame.event.get()` (برای تک‌کلیک‌ها)

این روش برای رویدادهایی مثل یک‌بار فشار دادن دکمه (مثل پرش یا شلیک) عالیه:

```python
for event in pygame.event.get():
    if event.type == pygame.KEYDOWN:
        if event.key == pygame.K_SPACE:
            print("پرش! 🚀")
        elif event.key == pygame.K_r:
            print("بازی ریست شد! 🔄")
```

#### روش دوم: `pygame.key.get_pressed()` (برای نگه داشتن دکمه)

برای حرکت دادن بازیکن که نیاز داره دکمه رو **نگه داریم** و حرکت روان باشه، از دستور جادویی زیر استفاده می‌کنیم:

```python
keys = pygame.key.get_pressed()
```

این دستور در هر فریم، وضعیت تمام دکمه‌های کیبورد رو بررسی می‌کنه. اگر دکمه‌ای فشرده شده باشه، مقدارش `True` میشه.

---

### 🆚 مقایسه دو روش دریافت ورودی

| ویژگی | `pygame.event.get()` | `pygame.key.get_pressed()` |
|-------|----------------------|---------------------------|
| نوع | رویداد (Event) | وضعیت لحظه‌ای (State) |
| کاربرد | تک‌کلیک (پرش، شلیک) | نگه داشتن (حرکت روان) |
| تشخیص | فقط یک بار در هر فشار | هر فریم که نگه داشته بشه |
| مثال | `KEYDOWN`، `KEYUP` | `keys[pygame.K_LEFT]` |

### 💻 اضافه کردن کنترل کیبورد به بازی

بیا کدهای قبلی رو طوری ارتقا بدیم که با دکمه‌های جهت‌نما، مربع رو در ۴ جهت اصلی تکان بدیم:

```python
import pygame
import sys

pygame.init()

SCREEN_WIDTH = 800
SCREEN_HEIGHT = 600
screen = pygame.display.set_mode((SCREEN_WIDTH, SCREEN_HEIGHT))
pygame.display.set_caption("کنترل بازیکن با کیبورد")

BLACK = (0, 0, 0)
GREEN = (0, 255, 0)

# موقعیت و سرعت بازیکن
player_x = 375  # وسط صفحه از نظر افقی
player_y = 275  # وسط صفحه از نظر عمودی
player_width = 50
player_height = 50
player_speed = 7

clock = pygame.time.Clock()

is_running = True
while is_running:
    clock.tick(60)
    
    # --- بخش اول: مدیریت رویدادها ---
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            is_running = False
        # نمایش پیام با فشردن Space
        if event.type == pygame.KEYDOWN:
            if event.key == pygame.K_SPACE:
                print("🚀 پرش!")
            elif event.key == pygame.K_r:
                print("🔄 بازی ریست شد!")

    # --- بخش دوم: به روز رسانی منطق بازی (حرکت با کیبورد) ---
    keys = pygame.key.get_pressed()
    
    if keys[pygame.K_LEFT]:     # کلید جهت‌نمای چپ
        player_x -= player_speed
    if keys[pygame.K_RIGHT]:    # کلید جهت‌نمای راست
        player_x += player_speed
    if keys[pygame.K_UP]:       # کلید جهت‌نمای بالا
        player_y -= player_speed
    if keys[pygame.K_DOWN]:     # کلید جهت‌نمای پایین
        player_y += player_speed

    # --- بخش سوم: نقاشی روی صفحه ---
    screen.fill(BLACK)
    pygame.draw.rect(screen, GREEN, (player_x, player_y, player_width, player_height))
    pygame.display.flip()

pygame.quit()
sys.exit()
```

### 🧱 اضافه کردن دیوار مرزی (Collision with Borders)

برای اینکه بازیکن از صفحه خارج نشه، باید موقعیتش رو محدود کنیم:

```python
# محدودیت مرزی
# سمت چپ
if player_x < 0:
    player_x = 0

# سمت راست
if player_x > SCREEN_WIDTH - player_width:
    player_x = SCREEN_WIDTH - player_width

# سمت بالا
if player_y < 0:
    player_y = 0

# سمت پایین
if player_y > SCREEN_HEIGHT - player_height:
    player_y = SCREEN_HEIGHT - player_height
```

> **📌 نکته:** از `SCREEN_WIDTH - player_width` استفاده می‌کنیم چون موقعیت بازیکن گوشه‌ی بالا-چپش هست و باید عرض خودش رو هم حساب کنیم.

### 📌 کلیدهای پرکاربرد در Pygame

| کلید | نام در Pygame | کلید | نام در Pygame |
|------|---------------|------|---------------|
| ← | `pygame.K_LEFT` | ↑ | `pygame.K_UP` |
| → | `pygame.K_RIGHT` | ↓ | `pygame.K_DOWN` |
| Space | `pygame.K_SPACE` | Enter | `pygame.K_RETURN` |
| Shift | `pygame.K_LSHIFT` / `pygame.K_RSHIFT` | Esc | `pygame.K_ESCAPE` |
| W | `pygame.K_w` | A | `pygame.K_a` |
| S | `pygame.K_s` | D | `pygame.K_d` |
| R | `pygame.K_r` | F | `pygame.K_f` |

### 📌 اشتباهات رایج در این درس

> **🔴 استفاده از `elif` برای جهت‌ها:**
```python
# ❌ با elif فقط یک جهت در هر فریم کار می‌کنه
if keys[K_LEFT]:
    x -= speed
elif keys[K_RIGHT]:
    x += speed

# ✅ با if های جداگانه، همزمان چند جهت کار می‌کنه
if keys[K_LEFT]:
    x -= speed
if keys[K_RIGHT]:
    x += speed
```

> **🟡 فراموش کردن محدودیت مرزی برای سمت راست و پایین:**
```python
# ❌ فقط سمت چپ رو چک کرده
if player_x < 0:
    player_x = 0

# ✅ هر ۴ طرف رو چک کن
if player_x < 0:
    player_x = 0
if player_x > SCREEN_WIDTH - player_width:
    player_x = SCREEN_WIDTH - player_width
```

> **🟢 استفاده از `event.type == KEYDOWN` برای حرکت روان:**
```python
# ❌ این روش برای حرکت روان نیست
if event.type == KEYDOWN and event.key == K_RIGHT:
    x += 5

# ✅ از get_pressed برای حرکت روان استفاده کن
keys = pygame.key.get_pressed()
if keys[K_RIGHT]:
    x += 5
```

> **🟣 فراموش کردن آپدیت موقعیت در هر فریم:**
```python
while running:
    # ❌ موقعیت فقط یک بار تغییر می‌کنه
    if keys[K_RIGHT]:
        x += 5  # این فقط یه بار اجرا میشه!
```

### 🛠️ نوبت توئه: چالش دیوار مرزی بازی!

اگر کدهای بالا رو اجرا کنی، متوجه یک مشکل یا همان "باگ" بزرگ میشی: مربع به راحتی می‌تونه از کادر صفحه خارج بشه و کلاً ناپدید بشه!

**صورت مسئله:**

1. کدهای بالا رو کپی و در ادیتورت اجرا کن.
2. با اضافه کردن چند شرط ساده (`if`) در بخش دوم، دور صفحه دیوار بکش تا مربع نتواند از صفحه خارج شود.
   - *راهنمایی برای سمت چپ:* موقعیت $X$ مربع نباید هیچ‌وقت کمتر از صفر شود (`player_x < 0`). پس اگر کمتر از صفر شد، مقدارش را همان `0` نگه دار.
   - *راهنمایی برای سمت راست:* موقعیت $X$ نباید از مرز سمت راست بزرگتر شود. دقت کن که مرز سمت راست برابر است با: `SCREEN_WIDTH - player_width` (چون عرض خودِ مربع هم باید محاسبه شود).
3. این محدودیت مرزی را برای بالا و پایین صفحه هم اعمال کن.

### 💪 چالش دوم (اختیاری - برای طراحان کنترل!)

حالا که با کنترل کیبورد آشنا شدی، یه سیستم **کنترل پیشرفته** با قابلیت‌های زیر بساز:

1. **حرکت مورب:** وقتی دو کلید همزمان فشرده میشن (مثل بالا و راست)، بازیکن مورب حرکت کنه.

2. **سرعت متفاوت:** با فشردن کلید Shift، سرعت بازیکن دو برابر بشه:
   - اگر `keys[pygame.K_LSHIFT]` یا `keys[pygame.K_RSHIFT]` فشرده شده بود، `player_speed = 10`
   - در غیر این صورت `player_speed = 5`

3. **کلیدهای جدید:**
   - `W, A, S, D` هم مثل جهت‌نماها عمل کنن
   - `Space`: چاپ کنه `"💥 پرش!"`
   - `R`: ریست کردن موقعیت بازیکن به وسط صفحه

4. **نمایش موقعیت:** توی عنوان پنجره، موقعیت فعلی بازیکن رو نمایش بده:
   ```python
   pygame.display.set_caption(f"موقعیت: ({player_x}, {player_y})")
   ```

**نمونه رفتار:**
- با نگه داشتن Shift، بازیکن سریع‌تر حرکت می‌کنه
- با W/A/S/D هم میشه حرکت کرد
- Space پیام میده
- R بازیکن رو به وسط می‌بره
