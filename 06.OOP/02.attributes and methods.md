### 🏗️ ویژگی‌ها و متدها یعنی چی؟

توی دنیای واقعی، هر شیء دو تا ویژگی اصلی داره:

1. **مشخصات (چی داره؟):** مثل رنگ ماشین، تعداد چرخ‌ها، یا نام مدل. در برنامه‌نویسی به این‌ها می‌گیم **ویژگی (Attribute)**.
2. **رفتارها (چه کاری انجام میده؟):** مثل بوق زدن ماشین، ترمز گرفتن، یا روشن شدن. در برنامه‌نویسی به این‌ها می‌گیم **متد (Method)** که در واقع همان توابعی هستند که داخل کلاس تعریف میشن.

| مفهوم | تعریف | مثال در ماشین |
|-------|-------|---------------|
| **ویژگی (Attribute)** | داده‌ها و مشخصات شیء | رنگ، برند، سرعت |
| **متد (Method)** | کارهایی که شیء می‌تونه انجام بده | بوق زدن، ترمز گرفتن |

### 💻 ساختن کلاس با ویژگی‌ها و متدها

#### تابع سازنده (`__init__`)

برای اینکه بتونیم موقع ساختن هر شیء، مشخصاتش رو تعیین کنیم، از یک تابع جادویی و پیش‌فرض در پایتون به اسم `__init__` استفاده می‌کنیم. به این تابع می‌گیم **سازنده (Constructor)**.

```python
class Car:
    # تابع سازنده برای تعریف ویژگی‌های اولیه خودرو
    def __init__(self, brand, color):
        self.brand = brand  # ویژگی برند
        self.color = color  # ویژگی رنگ

    # تعریف یک متد (رفتار) برای خودرو
    def beep(self):
        # کلمه self به خودِ خودرویی اشاره می‌کنه که داره بوق می‌زنه
        print(f"خودروی {self.brand} {self.color} داره بوق می‌زنه: بییییپ! 🚗")
```

> **🔑 کلمه جادویی `self` چیه؟**
> توی کلاس‌ها، همیشه اولین ورودی هر متد (تابع داخل کلاس) باید کلمه‌ `self` باشه. این کلمه مثل ضمیر «من» یا «خودم» عمل می‌کنه. یعنی وقتی می‌گیم `self.color`، داریم به رنگِ «همین خودرویی که در حال حاضر ساخته شده» اشاره می‌کنیم.

### 🔑 چطور از کلاس استفاده کنیم؟

حالا بیا دو تا ماشین با مشخصات مختلف بسازیم و بوق بزنیم:

```python
# ساخت ماشین اول (برند تویوتا، رنگ قرمز)
my_car = Car("Toyota", "قرمز")

# ساخت ماشین دوم (برند بیام‌و، رنگ مشکی)
your_car = Car("BMW", "مشکی")

# دسترسی به ویژگی‌ها
print(my_car.brand)  # خروجی: Toyota
print(my_car.color)  # خروجی: قرمز

# صدا زدن متدها (رفتارها)
my_car.beep()    # خروجی: خودروی Toyota قرمز داره بوق می‌زنه: بییییپ! 🚗
your_car.beep()  # خروجی: خودروی BMW مشکی داره بوق می‌زنه: بییییپ! 🚗
```

### 🎯 مثال کامل: کلاس دانشجو

بیا یه کلاس واقعی‌تر برای مدیریت اطلاعات دانشجویان بنویسیم:

```python
class Student:
    def __init__(self, name, student_id, major):
        self.name = name
        self.student_id = student_id
        self.major = major
        self.grades = []  # لیست خالی برای ذخیره نمرات
    
    def add_grade(self, grade):
        """اضافه کردن نمره به لیست نمرات"""
        self.grades.append(grade)
        print(f"نمره {grade} به {self.name} اضافه شد.")
    
    def get_average(self):
        """محاسبه میانگین نمرات"""
        if len(self.grades) == 0:
            return 0
        return sum(self.grades) / len(self.grades)
    
    def introduce(self):
        """معرفی دانشجو"""
        avg = self.get_average()
        print(f"👨‍🎓 دانشجو: {self.name}")
        print(f"📚 رشته: {self.major}")
        print(f"🆔 شماره دانشجویی: {self.student_id}")
        print(f"📊 میانگین نمرات: {avg}")

# استفاده از کلاس
student1 = Student("احمد رضایی", "140312345", "مهندسی کامپیوتر")
student1.add_grade(18)
student1.add_grade(19)
student1.add_grade(17)
student1.introduce()

# خروجی:
# نمره 18 به احمد رضایی اضافه شد.
# نمره 19 به احمد رضایی اضافه شد.
# نمره 17 به احمد رضایی اضافه شد.
# 👨‍🎓 دانشجو: احمد رضایی
# 📚 رشته: مهندسی کامپیوتر
# 🆔 شماره دانشجویی: 140312345
# 📊 میانگین نمرات: 18.0
```

### 🆚 مقایسه متد با تابع عادی

| ویژگی | تابع عادی (Function) | متد (Method) |
|-------|---------------------|--------------|
| تعریف | بیرون از کلاس | داخل کلاس |
| پارامتر اول | اختیاری | حتماً `self` |
| دسترسی به داده‌های شیء | نه | بله (با `self`) |
| مثال | `def calculate(x, y):` | `def show(self):` |

### 📌 اشتباهات رایج در این درس

> **🔴 فراموش کردن `self` در متدها:**
```python
class Car:
    def __init__(self, brand):
        self.brand = brand
    
    def beep():  # ❌ اشتباه! self فراموش شده
        print("بوق!")
    
    def beep(self):  # ✅ درسته
        print("بوق!")
```

> **🟡 فراموش کردن `self` موقع دسترسی به ویژگی‌ها:**
```python
class Car:
    def __init__(self, brand):
        self.brand = brand
    
    def show(self):
        print(brand)  # ❌ خطا! brand تعریف نشده
        print(self.brand)  # ✅ درسته
```

> **🟢 فراموش کردن `__init__` و تعریف ویژگی‌ها بیرون از سازنده:**
```python
class Car:
    brand = "Toyota"  # ❌ این ویژگی کلاس هست، نه ویژگی شیء

car = Car()
print(car.brand)  # کار می‌کنه ولی روش درستی نیست
```

> **🟣 اشتباه در نام `__init__` (دو خط زیرین در دو طرف):**
```python
class Car:
    def _init_(self, brand):  # ❌ یک خط زیرین یا اشتباه
        self.brand = brand
    
    def __init__(self, brand):  # ✅ درسته (دو خط زیرین)
        self.brand = brand
```

### 🛠️ نوبت توئه: چالش شناسنامه حساب کاربری!

بیا یک سیستم مدیریت حساب کاربری (User Profile) به روش شی‌گرایی طراحی کنیم.

**صورت مسئله:**

1. یک کلاس به نام `User` بساز.
2. تابع سازنده (`__init__`) آن را طوری بنویس که دو ویژگی برای کاربر ذخیره کند:
   - `username` (نام کاربری)
   - `role` (نقش کاربر، مثلاً `"مدیر"` یا `"کاربر معمولی"`)
3. یک متد (تابع) داخل کلاس به نام `introduce` (معرفی) بنویس که مشخصات کاربر رو چاپ کنه. (مثلاً چاپ کنه: `"من کاربر amir با نقش مدیر هستم."`). *راهنمایی: یادت نره از f-string و کلمه `self` برای دسترسی به ویژگی‌ها استفاده کنی.*
4. بیرون از کلاس، یک شیء به نام `user1` با نام کاربری خودت و نقش دلخواه بساز.
5. متد `introduce` را برای این شیء صدا بزن تا خودش رو معرفی کنه.

### 💪 چالش دوم (اختیاری - برای توسعه‌دهندگان سیستم!)

حالا که با ویژگی‌ها و متدها آشنا شدی، یه کلاس **مدیریت حساب بانکی** کامل بساز:

1. کلاس `BankAccount` با این ویژگی‌ها بساز:
   - `account_holder` (نام دارنده حساب)
   - `balance` (موجودی حساب - پیش‌فرض: ۰)
   - `account_number` (شماره حساب - تصادفی و خودکار)

2. این متدها رو اضافه کن:
   - `deposit(amount)`: مبلغ رو به موجودی اضافه کنه و پیام چاپ کنه
   - `withdraw(amount)`: از موجودی کم کنه (اگه موجودی کافی نباشه، خطا بده)
   - `show_balance()`: موجودی فعلی رو چاپ کنه
   - `transfer(other_account, amount)`: مبلغ رو به حساب دیگه انتقال بده

3. بیرون از کلاس، دو حساب بساز و چندین عملیات انجام بده:
   - واریز به حساب اول
   - برداشت از حساب اول
   - انتقال از حساب اول به حساب دوم
   - نمایش موجودی هر دو حساب

**نمونه خروجی:**
```text
حساب علی با شماره 1234 ساخته شد.
حساب سارا با شماره 5678 ساخته شد.

✅ 1,000,000 تومان به حساب علی واریز شد.
موجودی حساب علی: 1,000,000 تومان

❌ برداشت 2,000,000 تومان ناموفق! موجودی کافی نیست.

✅ انتقال 500,000 تومان از علی به سارا انجام شد.
موجودی حساب علی: 500,000 تومان
موجودی حساب سارا: 500,000 تومان
```

> **💡 نکته:** برای تولید شماره حساب تصادفی می‌تونی از `random.randint(1000, 9999)` استفاده کنی.
