# 📓 فصل پنجم: ورود به دنیای واقعی (فایل‌ها و خطایابی)

## 🎯 درس ۵.۲: مدیریت خطاها (`try` و `except`)

---

### 🧨 خطاها و استثناها یعنی چی؟

در برنامه‌نویسی، خطاها همیشه به خاطر اشتباه ما در نوشتن کد رخ نمیدن. خیلی وقت‌ها کاربر کارهایی می‌کنه که کدمون رو با مغز می‌کوبونه زمین!

مثلاً:
- از کاربر می‌خوایم سنش رو وارد کنه (عدد)، ولی کاربر می‌نویسه `"سنتوری"`! (پایتون موقع تبدیل به عدد ارور میده)
- برنامه می‌خواد یک فایل رو بخونه، اما کاربر اون فایل رو دستی از روی هارد پاک کرده!
- می‌خوایم یک عدد رو بر صفر تقسیم کنیم (در ریاضی تعریف نشده)

توی پایتون، به این خطاهای زمان اجرا می‌گیم **استثنا (Exception)**. برای اینکه نذاریم این استثناها برنامه‌مون رو متوقف کنن، از ساختار `try ... except` استفاده می‌کنیم.

> **📌 تفاوت خطا (Error) و استثنا (Exception):**
> - **خطا (Syntax Error):** اشتباه توی نوشتن کد (مثل فراموش کردن `:`) → قبل از اجرا شناسایی میشه
> - **استثنا (Exception):** خطایی که موقع اجرا رخ میده (مثل تقسیم بر صفر) → با `try/except` قابل مدیریته

---

### 💻 ساختار سپر دفاعی پایتون

خیلی ساده‌ست؛ به پایتون می‌گیم: «این بخش از کد رو **امتحان کن (try)**؛ اگر ارور داد، کرش نکن! در عوض بیا کدهای بخش **مدیریت خطا (except)** رو اجرا کن.»

```python
try:
    # کدی که ممکنه خطا بده
    number = int(input("یک عدد وارد کنید: "))
    result = 10 / number
    print(f"نتیجه تقسیم ۱۰ بر عدد شما: {result}")
except ZeroDivisionError:
    # این بخش فقط زمانی اجرا میشه که کاربر عدد 0 رو وارد کنه
    print("خطا! تقسیم بر صفر در ریاضی تعریف نشده است.")
except ValueError:
    # این بخش فقط زمانی اجرا میشه که کاربر به جای عدد، متن تایپ کنه
    print("خطا! شما باید یک عدد صحیح وارد کنید، نه متن.")
```

**خروجی‌های مختلف:**

```text
# حالت ۱: ورودی درست
یک عدد وارد کنید: 5
نتیجه تقسیم ۱۰ بر عدد شما: 2.0

# حالت ۲: ورودی صفر
یک عدد وارد کنید: 0
خطا! تقسیم بر صفر در ریاضی تعریف نشده است.

# حالت ۳: ورودی غیرعدد
یک عدد وارد کنید: سلام
خطا! شما باید یک عدد صحیح وارد کنید، نه متن.
```

### 🛡️ انواع مختلف مدیریت خطا

#### ۱. گرفتن خطاهای مشخص

```python
try:
    with open("data.txt", "r") as file:
        content = file.read()
except FileNotFoundError:
    print("فایل پیدا نشد! لطفاً فایل رو بررسی کنید.")
except PermissionError:
    print("شما دسترسی خواندن این فایل رو ندارید.")
except Exception as error:
    print(f"خطای ناشناخته: {error}")
```

#### ۲. گرفتن همه‌ی خطاها (با `Exception`)

اگر دقیقاً نمی‌دونی چه اروری ممکنه رخ بده و می‌خوای جلوی هر نوع کرش کردنی رو بگیری، می‌تونی از `except Exception` استفاده کنی:

```python
try:
    with open("not_found.txt", "r") as file:
        content = file.read()
    result = 10 / 0
    number = int("سلام")
except Exception as error:
    print("یک مشکلی پیش اومد! جزییات خطا:")
    print(error)  # خود پایتون علت رو بهمون میگه
```

#### ۳. بخش `else` (اگه خطایی نیومد)

```python
try:
    number = int(input("یک عدد وارد کنید: "))
except ValueError:
    print("عدد معتبر وارد کنید!")
else:
    # این بخش فقط اگه خطایی نیاد اجرا میشه
    print(f"عدد شما {number} است و مربعش {number ** 2} است.")
```

#### ۴. بخش `finally` (همیشه اجرا میشه)

```python
try:
    file = open("test.txt", "w")
    file.write("متن آزمایشی")
except Exception as e:
    print(f"خطا: {e}")
finally:
    # این بخش همیشه اجرا میشه، چه خطا بیاد چه نیاد
    print("بخش finally: فایل بسته شد.")
    file.close()
```

### 🎯 مثال‌های واقعی مدیریت خطا

#### مثال ۱: تبدیل امن ورودی کاربر

```python
def get_safe_number(prompt):
    """گرفتن عدد از کاربر با مدیریت خطا"""
    while True:
        try:
            value = int(input(prompt))
            return value
        except ValueError:
            print("❌ لطفاً فقط عدد وارد کنید!")

# استفاده
age = get_safe_number("سن خود را وارد کنید: ")
print(f"سن شما: {age}")
```

#### مثال ۲: خواندن امن فایل

```python
def read_file_safely(filename):
    """خوندن فایل با مدیریت خطا"""
    try:
        with open(filename, "r", encoding="utf-8") as file:
            return file.read()
    except FileNotFoundError:
        print(f"⚠️ فایل '{filename}' پیدا نشد!")
        return None
    except PermissionError:
        print(f"⚠️ شما دسترسی به '{filename}' ندارید!")
        return None
    except Exception as e:
        print(f"⚠️ خطای ناشناخته: {e}")
        return None

# استفاده
content = read_file_safely("data.txt")
if content:
    print(content)
```

#### مثال ۳: محاسبه امن

```python
def safe_divide(a, b):
    """تقسیم دو عدد با مدیریت خطای تقسیم بر صفر"""
    try:
        return a / b
    except ZeroDivisionError:
        print("⚠️ تقسیم بر صفر امکان‌پذیر نیست!")
        return None
    except TypeError:
        print("⚠️ ورودی‌ها باید عدد باشند!")
        return None

print(safe_divide(10, 2))  # خروجی: 5.0
print(safe_divide(10, 0))  # خروجی: ⚠️ تقسیم بر صفر امکان‌پذیر نیست!
print(safe_divide(10, "سلام"))  # خروجی: ⚠️ ورودی‌ها باید عدد باشند!
```

### 📊 انواع خطاهای رایج در پایتون

| نوع خطا | توضیح | مثال |
|---------|-------|------|
| `ValueError` | مقدار نامعتبر | `int("سلام")` |
| `ZeroDivisionError` | تقسیم بر صفر | `10 / 0` |
| `FileNotFoundError` | فایل پیدا نشد | `open("notfound.txt")` |
| `PermissionError` | خطای دسترسی | `open("/root/file.txt")` |
| `KeyError` | کلید در دیکشنری نیست | `d = {}; d["key"]` |
| `IndexError` | اندیس خارج از محدوده | `[1,2][5]` |
| `TypeError` | عملیات با نوع اشتباه | `"5" + 3` |

### 📌 اشتباهات رایج در این درس

> **🔴 گرفتن خطا با `except` خالی (بدون مشخص کردن نوع):**
```python
try:
    number = int(input("عدد: "))
except:  # ❌ همه خطاها رو می‌گیره (روش بد)
    print("خطا!")

except ValueError:  # ✅ فقط خطای ValueError رو می‌گیره
    print("عدد معتبر وارد کن!")
```

> **🟡 نوشتن کدهای زیاد توی `try`:**
```python
try:
    # ❌ کدهای زیادی توی try، پیدا کردن خطا سخت میشه
    a = int(input())
    b = int(input())
    c = a / b
    d = some_function(c)
    e = d + 5

# ✅ بهتره هر بخشی که ممکنه خطا بده جداگانه مدیریت بشه
```

> **🟢 فراموش کردن خطاهای خاص و گرفتن همه با `Exception`:**
```python
try:
    with open("file.txt") as f:
        content = f.read()
except FileNotFoundError:  # ✅ خطای خاص رو گرفتی
    print("فایل پیدا نشد!")
except Exception as e:  # ✅ بقیه خطاها رو گرفتی
    print(f"خطای دیگه: {e}")
```

> **🟣 استفاده از `else` بدون `except`:**
```python
try:
    x = 5
except:  # ❌ 'except' لازمه
    pass
else:
    print(x)
```

### 🛠️ نوبت توئه: چالش ماشین‌حساب ضدضربه!

بیا برنامه‌ای بنویسیم که از کاربر دو عدد بگیره و اون‌ها رو جمع کنه، اما طوری طراحی بشه که تحت هیچ شرایطی با ورودی‌های عجیب کاربر کرش نکنه.

**صورت مسئله:**

1. یک ساختار `try` باز کن.
2. داخل بخش `try`، با استفاده از `input()` دو عدد از کاربر بگیر و آن‌ها را به عدد صحیح (`int`) تبدیل کن.
3. حاصل‌جمع آن‌ها را چاپ کن.
4. یک بخش `except ValueError` بنویس که اگر کاربر به جای عدد، حروف یا کاراکترهای نامعتبر وارد کرد، به جای کرش کردن برنامه، پیام زیر را چاپ کند:
   `"ورودی نامعتبر! لطفاً فقط عدد وارد کنید."`

کدت رو بنویس و عمداً با وارد کردن حروف انگلیسی یا فارسی تستش کن تا ببینی چقدر قشنگ خطا رو کنترل می‌کنه.

### 💪 چالش دوم (اختیاری - برای مهندسان کیفیت!)

حالا که با مدیریت خطا آشنا شدی، یه برنامه‌ی **مدیریت مخاطبین** با دفاع کامل در برابر خطاها بساز:

1. برنامه‌ای بنویس که اطلاعات مخاطبین رو توی فایل `contacts.txt` ذخیره کنه (هر خط: `نام,شماره`).

2. این قابلیت‌ها رو داشته باشه:
   - **افزودن مخاطب:** از کاربر نام و شماره بگیره و به فایل اضافه کنه
   - **نمایش همه مخاطبین:** فایل رو بخونه و نمایش بده
   - **جستجوی مخاطب:** یک نام از کاربر بگیره و شماره‌اش رو پیدا کنه

3. همه‌ی خطاهای ممکن رو مدیریت کن:
   - فایل وجود نداره (FileNotFoundError)
   - فرمت فایل خرابه (مثلاً خط بدون کاما)
   - ورودی کاربر نامعتبره
   - مخاطب پیدا نشد

4. از `try-except-else-finally` برای مدیریت خطاها استفاده کن.
