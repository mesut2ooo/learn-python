### 🌐 API یعنی چی؟

API مخفف **Application Programming Interface** هست. به زبان خیلی ساده، API یک **پل ارتباطی** بین برنامه‌ی شما و یک سرویس دیگه‌ست. به جای اینکه خودت بری توی دیتابیس یه شرکت بزرگ بگردی، به API اون شرکت درخواست می‌دی و اون داده‌های مورد نیازت رو برات می‌فرسته.

> **📌 تشبیه:** API مثل یک پیشخدمت توی رستورانه. شما به پیشخدمت (API) می‌گی «من فلان غذا رو می‌خوام» و اون می‌ره توی آشپزخانه (سرور) و غذای مورد نظرت رو می‌اره (داده). شما نیازی نداری بدونی توی آشپزخونه چی می‌گذره!

---

### 🔑 انواع درخواست‌های HTTP

| متد | کاربرد | توضیح |
|-----|--------|-------|
| **GET** | دریافت داده | خواندن اطلاعات از سرور |
| **POST** | ارسال داده | ایجاد اطلاعات جدید |
| **PUT** | به‌روزرسانی | جایگزینی کامل اطلاعات |
| **PATCH** | به‌روزرسانی جزئی | تغییر بخشی از اطلاعات |
| **DELETE** | حذف | حذف اطلاعات |

> **💡 نکته:** در این درس، بیشتر با **GET** کار می‌کنیم چون رایج‌ترین نوع درخواست برای دریافت داده است.

### 💻 کار با یک API عمومی: GitHub

بیا با یکی از محبوب‌ترین APIهای عمومی کار کنیم: **GitHub API**. بدون نیاز به توکن، می‌تونی اطلاعات عمومی مخزن‌ها رو بگیری:

```python
import requests
import json

# ۱. دریافت اطلاعات یک مخزن (Repository) از GitHub
url = "https://api.github.com/repos/python/cpython"
response = requests.get(url)

if response.status_code == 200:
    data = response.json()  # تبدیل JSON به دیکشنری
    
    print("📦 اطلاعات مخزن CPython:")
    print(f"📌 نام: {data['name']}")
    print(f"👤 سازنده: {data['owner']['login']}")
    print(f"⭐ ستاره‌ها: {data['stargazers_count']}")
    print(f"🔀 فورک‌ها: {data['forks_count']}")
    print(f"📝 توضیحات: {data['description']}")
    print(f"🔗 لینک: {data['html_url']}")
else:
    print(f"❌ خطا: {response.status_code}")
```

### 🎯 دریافت داده از APIهای مختلف

#### ۱. آب و هوا با OpenWeatherMap

```python
import requests

# این یک API کلید آزمایشی است. برای استفاده واقعی باید ثبت‌نام کنی و کلید بگیری!
API_KEY = "your_api_key_here"
city = "Tehran"
url = f"http://api.openweathermap.org/data/2.5/weather?q={city}&appid={API_KEY}&units=metric"

response = requests.get(url)

if response.status_code == 200:
    data = response.json()
    print(f"🌤️ آب و هوای {city}:")
    print(f"🌡️ دما: {data['main']['temp']}°C")
    print(f"💧 رطوبت: {data['main']['humidity']}%")
    print(f"🌬️ وضعیت: {data['weather'][0]['description']}")
else:
    print(f"❌ خطا: {response.status_code}")
```

#### ۳. اطلاعات کاربران با JSONPlaceholder (API تست)

```python
import requests

# JSONPlaceholder یک API تستی رایگان است
url = "https://jsonplaceholder.typicode.com/users"

response = requests.get(url)

if response.status_code == 200:
    users = response.json()  # لیستی از کاربران
    
    print("👥 لیست کاربران:")
    for user in users[:5]:  # ۵ کاربر اول
        print(f"  - {user['name']} ({user['email']})")
        print(f"    📍 {user['address']['city']}")
        print(f"    📞 {user['phone']}")
        print("  " + "-"*30)
else:
    print(f"❌ خطا: {response.status_code}")
```

### 🔍 کار با پارامترها در API

خیلی از APIها بهت اجازه می‌دن با پارامترهای مختلف، داده‌های خاصی رو درخواست کنی:

```python
import requests

# دریافت پست‌های یک کاربر خاص از JSONPlaceholder
user_id = 1
url = f"https://jsonplaceholder.typicode.com/posts?userId={user_id}"

response = requests.get(url)

if response.status_code == 200:
    posts = response.json()
    print(f"📝 پست‌های کاربر {user_id}:")
    for post in posts[:3]:
        print(f"  - {post['title']}")
else:
    print(f"❌ خطا: {response.status_code}")
```

### 🎯 مدیریت خطاها در API

```python
import requests

def fetch_data(url):
    try:
        response = requests.get(url, timeout=10)
        response.raise_for_status()  # اگه خطا باشه، استثنا پرتاب می‌کنه
        return response.json()
    except requests.exceptions.ConnectionError:
        print("❌ خطای اتصال به اینترنت!")
    except requests.exceptions.Timeout:
        print("❌ زمان درخواست به پایان رسید!")
    except requests.exceptions.HTTPError as e:
        print(f"❌ خطای HTTP: {e}")
    except requests.exceptions.JSONDecodeError:
        print("❌ پاسخ دریافتی JSON معتبر نیست!")
    except Exception as e:
        print(f"❌ خطای ناشناخته: {e}")
    return None

# استفاده
url = "https://api.github.com/repos/python/cpython"
data = fetch_data(url)

if data:
    print(f"✅ نام مخزن: {data.get('name', 'نامشخص')}")
```

### 📌 اشتباهات رایج در این درس

> **🔴 فراموش کردن `.json()` برای تبدیل پاسخ:**
```python
response = requests.get(url)
data = response  # ❌ این خود شیء response هست، نه داده‌ها
data = response.json()  # ✅ درسته
```

> **🟡 قاطی کردن API Key با Token:**
```python
# API Key: معمولاً توی URL یا پارامترها
url = f"http://api.com?api_key={KEY}"

# Token: معمولاً توی هدرها
headers = {"Authorization": f"Bearer {TOKEN}"}
```

> **🟢 فراموش کردن `raise_for_status()`:**
```python
response = requests.get(url)
data = response.json()  # ❌ اگه خطا باشه (مثلاً ۴۰۴)، باز هم اجرا میشه

response.raise_for_status()  # ✅ خطاها رو می‌گیره
data = response.json()
```

> **🟣 استفاده از API بدون مدیریت نرخ درخواست:**
```python
# ❌ ممکنه محدودیت API رو بزنی
for i in range(1000):
requests.get(url)

# ✅ بین درخواست‌ها مکث بذار
import time
for i in range(1000):
requests.get(url)
time.sleep(0.5)  # نیم ثانیه مکث
```

### 🛠️ نوبت توئه: نمایش اطلاعات مخزن GitHub!

بیا یک برنامه بنویسیم که اطلاعات یک مخزن GitHub رو از کاربر بگیره و نمایش بده.

**صورت مسئله:**

1. از کاربر نام یک مخزن GitHub بگیر (مثلاً `"python/cpython"` یا `"tensorflow/tensorflow"`).

2. با `requests` به آدرس زیر درخواست بفرست:
   `https://api.github.com/repos/{نام_مخزن}`

3. اطلاعات زیر رو از پاسخ استخراج و چاپ کن:
   - نام مخزن
   - سازنده
   - تعداد ستاره‌ها
   - تعداد فورک‌ها
   - توضیحات
   - لینک

4. اگه مخزن پیدا نشد (خطای ۴۰۴)، پیام `"❌ مخزن مورد نظر پیدا نشد!"` رو چاپ کن.

5. برای خطاهای اتصال، پیام مناسب چاپ کن.

### 💪 چالش دوم (اختیاری - برای توسعه‌دهندگان API!)

حالا که با APIها آشنا شدی، یه **داشبورد اطلاعاتی** کامل با چند API مختلف بساز:

1. سه API مختلف رو ترکیب کن:

   **API اول: GitHub**
   - اطلاعات یک مخزن محبوب (مثل `python/cpython`)

   **API دوم: Quote API**
   - یک نقل قول تصادفی

   **API سوم: JSONPlaceholder**
   - لیست ۵ پست اخیر

2. یک گزارش کامل به این شکل چاپ کن:
   ```
   📊 داشبورد اطلاعاتی
   ====================================
   
   🔗 گیت‌هاب:
   ────────────────────────────────
   📌 مخزن: python/cpython
   ⭐ ستاره‌ها: 45,000
   🔀 فورک‌ها: 22,000
   📝 توضیحات: The Python programming language
   
   💬 نقل قول روز:
   ────────────────────────────────
   "Code is like humor. When you have to explain it, it's bad."
   ✍️ نویسنده: Cory House
   
   📰 آخرین پست‌ها:
   ────────────────────────────────
   3. عنوان پست اول
   4. عنوان پست دوم
   5. عنوان پست سوم
   ====================================
   ```

6. از `try/except` برای مدیریت خطاهای هر API استفاده کن.

> **💡 نکته:** اگر یک API خطا داد، بقیه‌ی APIها رو همچنان اجرا کن.
